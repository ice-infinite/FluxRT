# Rust 迁移完成报告

记录日期：2026-09-21。

## 结论

相邻 C 算法库的 63/63 个生产模块已经迁移到本 `no_std` Rust crate。原 C 目录未修改。Rust 版保持无堆分配、无全局可变状态、无芯片 HAL 依赖，并在 crate 根禁止 `unsafe`。

这表示“算法迁移与主机/交叉构建验收完成”，不表示某个电机、逆变器或控制板已经通过闭环稳定性、保护响应、实时性、EMC、热与寿命验证。

## 四阶段范围

1. 基础数学、坐标变换、P/PI/PD/PID、滤波、斜坡、SPWM/SVPWM/DPWM、PLL、基础电流环。
2. CORDIC、六步换相、级联/前馈、数字滤波、MTPA/MTPV、V/f、弱磁。
3. BEMF、磁链、SMO、高频注入、Kalman、Luenberger、EKF、EKF+FOC、UKF。
4. ADRC 系列、自适应、反步、模糊、H∞、LQR、MPC、MRAC、滑模、神经网络、强化学习、遗传算法辅助函数。

逐模块映射见 [算法库移植状态.md](算法库移植状态.md)。

## 等价性与有意差异

- 66 个 Rust 测试覆盖相邻 C 测试的主要参考向量，并补充了固定容量、非法索引、缺失回调和状态残留等边界。
- MTPV 每次搜索前清除 `valid`，修复了 C 版可能保留上一次有效状态的问题；详情见 README。
- ADRC 带宽整定使用完整结构体初始化，不继承 C 编译器对缺失字段初始化的警告风险。
- 强化学习和神经网络保持 C 版固定容量/固定拓扑；没有擅自扩展成动态模型。
- 遗传算法仍由调用方提供变异信号，没有在算法库内绑定平台随机数源。

## 接入固件前必须继续完成

1. 在目标 MCU 上测量电流环、观测器和选定高级控制器的平均/最大执行周期。
2. 读取最终链接 map 和 RTOS 栈水位，确认 Flash、RAM、栈和中断裕量。
3. 用 SIL/HIL 验证参数误差、噪声、采样延迟、母线波动、限幅和模式切换。
4. 在低压限流条件下做相序、电流极性、编码器方向、电角度零位和极对数检查。
5. 验证硬件过流、驱动器故障、欠压、过压、过温和失速保护；算法软件不能替代独立关断链。
6. 完成实际电机的阶跃、扫频、堵转边界、温升、效率、再生制动和长时间运行测试。

实时对象尺寸、固定容量和 WCET 注意事项见 [算法库实时性说明.md](算法库实时性说明.md)。
