## 0. 一句话结论

1. **接法与星形模型一致，但不能仅靠端子阻抗唯一证明内部拓扑**：以下相参数仍按项目既有星形假设执行，即 `R_phase = R_LL/2`、`L_phase = L_LL/2`。
2. **1 kHz 小信号参数已通过复现性门**：同一转子状态下，Run B/Run C 的平均相感为 **1.1152/1.1133 mH**，仅差 **0.16%**；取工作候选 **`Ls_small_signal = 1.114 mH`**。
3. **当前温度下 DC `Rs` 已取得**：万用表线间 **10.0/10.0/10.1 Ω**，表笔短接 **0.1 Ω**；逐对扣除后为 9.9/9.9/10.0 Ω，星形假设下平均相阻 **`Rs_dc(T_meas) = 4.9667 Ω`**。由于环境/绕组温度尚未记录，暂不换算到 20℃参考值。该结果只比 Profiler 的 4.875 Ω 高约 1.9%，所以旧版“Profiler 低读 4.7%”结论撤销。
4. **Run C 证明 Run B 的三线对差异可复现**：

   | 量 | Run B | Run C | 变化 |
   |---|---|---|---|
   | 平均相感 | 1.1152 mH | **1.1133 mH** | **−0.16%** |
   | 线间 `L` 极差/均值 | 16.5% | **15.9%** | 基本不变 |
   | `Q/(ωL/R)` 三对 | 0.994 / 1.003 / 0.994 | **0.995 / 0.995 / 0.991** | 全部自洽 |
   | 隐含频率 | 994–1003 Hz | **991–995 Hz** | 均接近标称 1 kHz |

   这说明 15%～16% 的线对差异不是随机读数漂移；但仅靠三组线间电感仍不能把它唯一解释成 `Ld/Lq`、磁路不对称或某个特定转子角效应。
5. **10 kHz 数据仍只作定性交叉检查**：当前可用于工作候选的是 1 kHz 小信号结果；0.4/0.6/0.8 A 下的 `L(I)` 仍未测量。

| 线间 | LCR 镊子电阻挡 | 星形假设下相值 | 万用表 |

| **均值** | **10.1467 Ω** | **5.0733 Ω** | **10.0333 Ω** |

LT1 R 挡与 Run C 的 1 kHz 串联等效电阻只差 **0.16%**。根据 [LT1 用户手册](https://manuals.plus/m/e835ae579901ff59eb7570fff6a156c702222cb2a4340ba2306311cd4a7e246d)和[正点原子产品说明](https://www.cnblogs.com/zdyz/p/18959734)，R 挡仍使用可选的交流测试频率和 Vrms 电平，故它不是独立 DCR。万用表的 DC 线间均值为 **10.0333 Ω**，星形假设下未扣表笔的原始相阻为 **5.0167 Ω**。计算最终 DC 相阻时使用：

```text
Rs_dc_phase = (R_line_meter - R_leads_shorted) / 2
```

已测得 `R_leads_shorted = 0.1 Ω`，因此当前温度下：

```text
R_line_dc = 10.0333 - 0.1 = 9.9333 Ω
Rs_dc(T_meas) = 9.9333 / 2 = 4.9667 Ω
```

当前只缺环境/绕组温度；在温度补齐前，不把 4.9667 Ω 直接扩展成 20℃归一化后的生产参数。

### 1.5 `Q` 互检：Run B/Run C 全部自洽

用 `Q = ωLs/Rs`（`ω = 2π × 1000 = 6283.19 rad/s`）由同批 `L`、`R` 反算 `Q`，与实测 `Q` 比对。**`ω` 是物理常数，不含任何拟合系数**，因此这是有效检验：

**Run B（转子未动）**

| 线间 | `ωL/R` 反算 | 实测 `Q` | 比值 | 隐含频率 |
|---|---|---|---|---|
| U–V | 1.328 | 1.320 | **0.9939** | 994 Hz |
| V–W | 1.281 | 1.285 | **1.0033** | 1003 Hz |
| W–U | 1.508 | 1.500 | **0.9944** | 994 Hz |

**三对线间全部吻合到 0.7% 以内，隐含频率全部落在 994–1003 Hz**（标称 1000 Hz）。

**Run C（复测）**

| 线间 | `ωL/R` 反算 | 实测 `Q` | 比值 | 隐含频率 |
|---|---:|---:|---:|---:|
| U–V | 1.367 | 1.360 | 0.995 | 995 Hz |
| V–W | 1.296 | 1.290 | 0.995 | 995 Hz |
| W–U | 1.463 | 1.450 | 0.991 | 991 Hz |

Run C 三对均在 1% 内自洽，再次证明本轮 `L/R/Q` 抄录和 1 kHz 测试频率一致。

**Run A（转子自由）**

| 线间 | `ωL/R` 反算 | 实测 `Q` | 比值 | 判断 |
|---|---|---|---|---|
| U–V | 1.413 | 1.500 | 1.0616 | 尚可 |
| V–W | 1.688 | 1.390 | **0.8234** | **崩坏（−17.7%）** |
| W–U | 1.304 | 1.290 | 0.9890 | 一致 |

**两组对比的结论（本实验最强的一条证据链）：**

1. 两组测量唯一的差别是**转子位置**（Run A 转子自由、Run B 转子未动）。
2. Run A 中 VW 的 `Q` 偏离 `ωL/R` 达 17.7%，**Run B 中同一对线恢复到 1.0033**。
3. 因此该偏差**不是**仪器问题、不是公式用错、不是读数抄错，**只能是转子位置造成的**。
4. 这同时解释了为什么 §4.3 的两频段比值能自洽——每个转子位置本身是确定的、可复现的，只是不同位置给出不同 `L`。

**顺带确认等效模式**：Run B 的实测 `Q` 与**串联**模型 `ωLs/Rs` 三对全部吻合到 0.7% 以内，这只有在表按 `Rs`（串联电阻）读数时才成立。**故判定为串联模式**（严格说 `Qs ≡ Qp` 恒成立，故仍需目视确认，见 §7.7）。

| 组/频率 | `Q/(ωL/R)` 三对 | 说明 |
|---|---|---|

## 2. 接线模型：当前按星形换算

星形与三角形接法下，线间量到相参数的换算完全不同：

| 接法 | `R_LL` 与 `R_phase` 关系 | `L_LL` 与 `L_phase` 关系 | 由校正后 DC `R_LL ≈ 9.933 Ω` 反推 `R_phase` |
|---|---|---|---|
| **星形** | `R_LL = 2 R_phase` | `L_LL = 2 L_phase` | **4.9667 Ω** |
| 三角形 | `R_LL = 2/3 R_phase` | `L_LL = 2/3 L_phase` | 14.900 Ω |

星形换算结果与数据库和 Profiler 的既有相参数处于同一量级，因此项目继续采用星形模型；但仅凭三个外部端子的阻抗和已有参数邻域，不能从拓扑上唯一证明内部一定是星形。

**当前工程约定：`R_phase = R_LL / 2`，`L_phase = L_LL / 2`。** 若以后取得电机厂家绕组拓扑资料，应以厂家资料覆盖该约定。

### 3.2 温度归算：旧版“Profiler 明显低读”结论撤销

铜的电阻温度系数 `α = 0.00393 /°C`（以 20 °C 为基准）：

```
R(T) = R(20°C) × (1 + α × (T − 20°C))
```

本次直接 DC 测得 `Rs(T_meas)=4.9667 Ω`。若要与引用 20℃的参数比较，应使用：

```text
Rs_20 = 4.9667 / (1 + 0.00393 × (T_meas - 20))
```

| 测量温度 `T_meas` | 换算 `Rs_20` |
|---:|---:|
| 20℃ | 4.9667 Ω |
| 22℃ | 4.9280 Ω |
| 25℃ | 4.8710 Ω |
| 30℃ | 4.7788 Ω |

如果本次测量约为 **25℃**，换算出的 20℃值约 **4.871 Ω**，与 Profiler 的 4.875 Ω 几乎一致。因此在没有双方测量温度和 Profiler 输出参考温度定义前，不能再把 4.875 Ω 判成系统性低读。

### 3.4 电感量级的物理解释

当前三个来源的电感排序是 **LCR 1 kHz 小信号 1.114 > 数据库 1.058 > profiler 0.893**，这个顺序可能来自测量电流不同：

- LCR 表用约 1 Vrms 的小信号测量，铁芯磁通密度低、**不饱和**，测到的是最大电感。
- profiler 在 **0.8 A** 大电流下识别，铁芯进入饱和区，电感**下降**。`Ls` 是电流的函数，这是正常行为。
- **两次 LCR 测量都高于数据库**，指向数据库可能也是在较大电流下测得的，而非 LCR 偏高。

Profiler 的 `Rs=4.875 Ω` 现在不能判错：它与直接 DC 测量的差异只有约 1.9%，且温度口径尚未统一。`Ls=0.893 mH` 与 1 kHz 小信号 1.114 mH 仍不是同工况，需要 `Ls(I)` 才能判定差异来自饱和还是识别误差。

> 说明：`Rs` 与 `Ls` 在 profiler 内部的测量机理不同（`Rs` 走直流/低频斜坡，`Ls` 走交流注入识别时间常数），所以两者误差**不必然同比例**。

## 4. 三个异常及其诊断

### 4.1 异常一：线间电感离散（Run A 31.0% → Run B 16.5%）——**已定性**

**理论预期**：理想对称三相电机、星形接法，无论转子停在哪个位置，`L_uv = L_vw = L_wu = 2 L_phase`，只存在 6 次谐波量级的微小纹波。

**实测对照：**

| 组 | 线间 `L` 极差 | 线间 `R` 极差 | `Q` 自洽性 |
|---|---|---|---|
| Run A（转子自由） | 31.0% | 4.8% | VW 崩坏（0.823） |
| **Run B（转子未动）** | **16.5%** | **2.4%** | **三对全部自洽** |

**诊断（已由数据自证）：**

| 候选原因 | 判定 | 依据 |
|---|---|---|
| 接触电阻/表笔夹持不良 | **排除** | `R` 极差 2.4%，两次独立测量 `R` 均值差 0.26% |
| 绕组不对称 | **排除** | 三相电阻均衡；且不对称无法解释 Run A/Run B 的差异 |
| 仪器噪声/漂移 | **排除** | Run B 的 `Q` 与 `ωL/R` 三对吻合到 0.7% |
| 表的等效模式设错 | **排除** | 同上，串联模型自洽 |
| **转子位置** | **✅ 已确认（Run A vs Run B）** | 两组唯一差别是转子位置；`L` 极差减半、`R` 极差减半、VW 的 `Q` 异常消失。机理见 §7.1 |
| **残留 16.5%：转子该角度上的真实磁路不对称** | **待确认（§7.6）** | Run B 转子未动，`R` 极差仅 2.4% 而 `L` 极差 16.5%——差异来自磁路而非电接触 |

**残留 16.5% 的构成**：它混合了"凸极效应（`Ld` vs `Lq`）"与"转子恰好停在哪一个齿槽位置"两个成分。**不能直接当作凸极率读。**

### 4.2 异常二：10 kHz 的电阻涨了 2.1 倍（作废该栏）

| 频率 | 线间 `R` 均值 |
|---|---|
| 1 kHz | 10.24 Ω |
| 10 kHz | 21.51 Ω |

**电阻随频率上升，方向是对的**（趋肤效应 + 铁损都会让等效串联电阻上升）。异常的**是涨幅**——逐项看：

| 线间 | `R` @1 kHz | `R` @10 kHz | 比值 |
|---|---|---|---|
| U–V | 10.21 Ω | 20.80 Ω | 2.04× |
| V–W | 10.50 Ω | 25.00 Ω | 2.38× |
| W–U | 10.01 Ω | 18.73 Ω | 1.87× |

**v4 新增的直接判据（比相位敏感性论证更强）**：§1.6 显示 10 kHz 的 `Q/(ωL/R)` 只有 **0.19–0.22**，即有效串联电阻被铁损抬高到约 5 倍。**铁损主导是 10 kHz 整栏不可用的根本原因。**

**辅助论证（相位敏感性）**：

- 1 kHz 交流等效相阻约 5.1 Ω，10 kHz 时相感抗 `ωLs = 2π × 10000 × 1.1505e-3 ≈ 72.3 Ω`
- 线间感抗约 144.6 Ω，`R` 只占 `|Z|` 的 **7.1%**，阻抗相位 `85.95°`

| 相位读数误差 | 分离出的 `R` | 相对 1 kHz 的 10.24 Ω |
|---|---|---|
| −1.0° | 12.76 Ω | 1.25× |
| −2.0° | 15.28 Ω | 1.49× |
| −4.0° | ≈21.5 Ω | 2.10×（与实测吻合）|

要用电桥相位误差单独解释这 2.1 倍需约 4° 相位误差，对手持表偏大；**与铁损叠加后即可完整解释**。

**结论：10 kHz 的 `R` 与 `Q` 栏不可用，`L` 栏仅作定性交叉验证。1 kHz 是唯一可信频段。**

### 4.3 两频段自洽性检验（正面证据，支持"位置固定即可复现"）

| 线间 | `L` @1 kHz | `L` @10 kHz | 降幅 |
|---|---|---|---|
| U–V | 2.296 mH | 2.209 mH | 3.79% |
| V–W | 2.821 mH | 2.693 mH | 4.54% |
| W–U | 2.078 mH | 2.001 mH | 3.71% |
| 比值 | VW/WU = **1.3576** | VW/WU = **1.3458** | 差 0.9% |

**VW/WU 比值在两个频段几乎相同。** 三对的电感降幅集中在 **3.7%–4.5%** 的窄带内，说明三对线间测到的是**同一种物理效应**（趋肤效应与铁损），而非三种不同的样品状态。

## 7. 补测清单（按优先级）

### 7.1 已确认：`Ls` 读数随转子位置变化

**机理**

1. 星形接法下测某一对线（如 U–V），电流从 U 进、V 出，两个绕组的磁动势在空间合成**一个单一方向的磁场轴**。
2. 三个线间对（U–V / V–W / W–U）对应的磁场轴，在空间上互差 **60° 或 120° 电角度**。
3. 每次测量，这个磁场都会给转子一个**对齐转矩**，把转子吸向该磁场轴方向。
4. 于是三对线测的是**三个不同的转子位置**，而 `Ls` 是转子位置的函数 → 三个读数必然不同。

**转矩量级定量核算**

| 项 | 公式 | 数值 |
|---|---|---|
| LCR 测试信号（1 Vrms → 55 mA）的凸极转矩 | `T = 1.5 · p · (Ld − Lq) · id · iq`，最坏情况 `id = iq = I/√2` | **0.0050 mN·m**（0.051 g·cm）@ `Lq/Ld = 1.36` |
| 直流 0.6 A 的磁钢对齐转矩 | `T = 1.5 · p · λ · I`，`λ` 取**最小**口径 0.0055 Wb | **34.65 mN·m**（353 g·cm） |
| 比值 | — | **约 6900 倍** |

**两项结论：**

- **LCR 测试信号本身几乎推不动转子**（0.05 g·cm，连轴承静摩擦都未必过得了）。因此离散**不是**"测试信号把转子推着转"，而是"**转子在每次测量中稳定在不同的位置**"——三个线间对各把自己的磁场轴方向作为稳定点。
- **直流 0.6 A 的锁定转矩比 LCR 扰动大近 4 个数量级**，足以把转子钉死在指定位置。**这是 §7.2 磁锁定法可行的定量依据。**

### 7.2 方法 1（阻塞）：外加直流磁锁定时同时接 LT1

**禁止按旧版方案执行。** LT1 用户手册要求不要测量带电电路，也没有声明支持外部 DC bias。旧版曾建议把可调电源与 LT1 同时接到绕组，并假设 LT1 内部带隔直电容；该假设没有厂商证据，额外串联电容也不能自动保证仪表输入保护和测量模型正确。

因此，在取得厂商明确的 DC bias 能力、允许电压/电流和接线方法之前：

- 不得把外部直流电源与 LT1 同时接在电机绕组上；
- 不得用“串一个电容”作为仪表保护替代方案；
- `Ls(I)` 需要改用支持 DC bias 的 LCR 仪器，或由驱动器注入电压/电流并在 MCU 侧辨识。

### 7.3 方法 2（进阶）：锁定到 d 轴 / q 轴，分离 `Ld` 与 `Lq`

**目的**：拿到真正的凸极率，而不是"三个稳定位置之差"。

**原理**：磁锁定会把转子的 **d 轴**（磁钢 N 极方向）吸到与定子磁场轴对齐。所以从 U 相进、V 相出得到的锁定角，就是一个**确定的 d 轴位置**。

**步骤**

1. 使用具备可验证角度基准的机械锁定或编码器定位，不采用 §7.2 的外加 DC + LT1 并接方案。
2. 在同一电流和测试频率下，分别测量相差约 **90° 电角度**的两个转子位置，才有机会接近 `d/q` 两轴。
3. **同一对线反接只改变 180° 电角度，仍在同一轴线上，不能据此得到 `Lq`。**

**更系统的做法**：在转子轴上加刻度，每 **15° 机械角**测一组三个线间，共 24 个位置，得到 `L(θ)` 曲线，可直接读出 `Ld`、`Lq`、凸极率，以及**不受位置影响的平均相感**。

> 不通电时转子是自由的，只能停在自然稳定点。要扫掠角度必须用机械刻度法，或用 FluxRT 固件的开环强拖把转子拖到任意角度后**保持通电**再测（见 §7.5）。

### 7.4 方法 3（兜底）：机械锁定

**判据最弱（角度不可复现），但零成本**：

1. 用胶带 / 扎带 / 小夹具把转子轴**机械固定**。
2. 1 kHz，逐个测 U–V / V–W / W–U 各 **3 遍**（松开夹子重夹再测），每次都同时记录 `L`、`R`、`Q`。
3. 判据同 §7.2 第 5 步。

### 7.5 方法 4（需改固件，信息量最大）：用 FluxRT 开环强拖

FluxRT 的 `foc_start <rpm>` 是开环电压/频率强拖，可把转子拖到**任意指定角度并保持通电**。届时用 LCR 表在被锁定的转子上测量，可以得到完整的 `L(θ)` 与 `L(I)` 曲面。

**前置条件**：板子当前烧的是 ST Motor_Profiler 固件，需先重烧 FluxRT Diagnostic。**这一步涉及烧录，需项目所有者明确指示后再执行。**

### 7.6 补测清单（按优先级，v4 更新）

| 顺序 | 项目 | 耗时 | 判据 |
|---|---|---|---|
| **①（已完成）** | **Run C 三线对复测**：与 Run B 同姿态再次记录 `L`/`R`/`Q` | **完成** | 平均相感只差 **0.16%**，取 Run B/C 平均 **1.114 mH** 作为小信号候选 |

### 7.7 补测 2 与补测 3 的具体做法

**补测 2：`Rs` 直流复测**

用**万用表**（不是 LCR 表）直流电阻档测 U–V / V–W / W–U，先短路表笔 REL 归零。

- **目的**：LCR 的 1 kHz `R` 包含铁损分量，略高于纯直流值。纯直流值才是 FOC 模型里的 `Rs`。
- **预期**：DC 线间电阻应略低于 LT1 的约 10.15 Ω 交流等效电阻；实际结果符合该方向。
- **2026-09-27 结果**：LT1 R 挡为 10.08/10.10/10.26 Ω；手册确认它仍是交流 LCR 测量。0.1 Ω 分辨率万用表为 10.0/10.0/10.1 Ω，表笔短接 0.1 Ω；当前温度下 `Rs=(10.0333-0.1)/2=4.9667 Ω`。还需记录环境/绕组温度后才能归一化到 20℃。

**补测 3：等效模式目视确认**

复测的 `Q` 值已**间接判定为串联模式**（判据见 §1.5，Run B 三对全部吻合到 0.7%）。

- 仍建议下次**直接目视确认表显为 `Ls`**，理由是：`Qs ≡ Qp` 恒成立，故 `Q` 值本身无法从原理上排除并联模式；上述判定依赖"`Q` 与 `ωLs/Rs` 吻合"这一间接证据。目视是零成本的确定性检查。
- **提示**：Run A 的 `Q` 在 VW 对上偏离 17.7%，Run B 恢复到 0.7% 以内。**归因是转子位置，而非读数分散程度**——Run B 的 `Q`、`L`、`R` 同样是分次读出的。

## 8. 附录：关键计算

### A. 相参数换算

```
星形:  R_phase = R_LL / 2        L_phase = L_LL / 2
三角:  R_phase = 1.5 × R_LL      L_phase = 1.5 × L_LL
```
本实验判定为星形，用第一行。

### B. 铜电阻温度归算

```
R(T) = R(20°C) × (1 + 0.00393 × (T − 20°C))
```
参考点：`+20/+40/+60 °C` → `×1.000/×1.079/×1.157`

### C. 当前 DC `Rs` 的温度归一化

```
Rs_20 = 4.9667 / (1 + 0.00393 × (T_meas − 20°C))
```

在 `T_meas` 未记录前，4.9667 Ω 只表示当前测量温度，不冒充 20℃参考参数。若 `T_meas≈25℃`，则 `Rs_20≈4.871 Ω`。

### D. 10 kHz 下 `R` 的分离难度

```
相:  R_ac@1kHz ≈ 5.1 Ω,  XL = 2π × 10^4 × 1.1505e-3 = 72.3 Ω
线间: R_ac@1kHz ≈ 10.2 Ω, XL ≈ 144.6 Ω
阻抗相位约 86°，R 只占 |Z| 约 7%
```
| 相位读数误差 | 分离出的 `R` |
|---|---|
| −1.0° | 12.76 Ω |
| −2.0° | 15.28 Ω |
| −4.0° | ≈21.5 Ω（与实测 21.51 Ω 吻合）|

### E. LCR 测试电平产生的线间电流与转矩

```
|Z| @1 kHz = √(10.24² + (2π × 1000 × 2.398e-3)²) ≈ 18.2 Ω
测试电平取 1 Vrms → I ≈ 55 mA
T = 1.5 · p · (Ld − Lq) · id · iq,  最坏情况 id = iq = I/√2 = 38.9 mA
T = 1.5 × 7 × 0.317e-3 × (38.9e-3)² = 5.04e-6 N·m = 0.0050 mN·m = 0.051 g·cm
```
**结论**：LCR 测试信号产生的转矩只有 **0.05 g·cm**，**几乎不可能推动转子**。因此离散**不是**"测试信号把转子推着转"，而是"**转子在每次测量中稳定在不同的位置**"。

```
Q = ωLs / Rs,   ω = 2π × 1000 = 6283.19 rad/s

Run B (转子未动):                    Run A (转子自由):
UV: 1.328 -> 实测 1.320  (0.9939)    UV: 1.413 -> 实测 1.500  (1.0616)
VW: 1.281 -> 实测 1.285  (1.0033)    VW: 1.688 -> 实测 1.390  (0.8234)  <<< 崩坏
WU: 1.508 -> 实测 1.500  (0.9944)    WU: 1.304 -> 实测 1.290  (0.9890)
```

### G. 直流磁锁定的转矩核算

```
T = 1.5 · p · λ · I   (磁钢对齐项, 主导)
λ = 0.0055 Wb (最小口径), I = 0.6 A, p = 7
T = 1.5 × 7 × 0.0055 × 0.6 = 0.03465 N·m = 34.65 mN·m = 353 g·cm
```
