# 更换电机流程与参数匹配指南（含行业量产做法调研）

> 适用范围：同一块电调板（NUCLEO-G431RB + X-NUCLEO-IHM16M1 或未来国产 MCU 板）更换不同电机时，需要重新测量哪些数据、重算哪些参数、改哪些代码、按什么顺序验证。
> 参考基线电机：iPower GBM2804H-100T（SM-PMSM，7 对极）。
> 文档日期：2026-09-25。
> 关联文档：[EXP-B1_BEMF实测与Ke量纲判定](experiments/EXP-B1_BEMF实测与Ke量纲判定.md)、[更换MCU移植步骤](更换MCU移植步骤.md)、[参数候选与审批流程](parameters/参数候选与审批流程.md)。

---

## 0. 一页速览

```text
换电机 = 板级不动 + 电机本体重测（5 项）+ 派生参数重算（约 10 项）+ 档案换绑 + 三级验证

必须重测：极对数 p、定子电阻 Rs、定子电感 Ls、磁链 ψ（或 Ke）、额定电流/最高转速
必须重算：电流环 PI、SMO 增益/边界层/滤波、PLL、可靠性门、启动时序、速度环、过流跳闸
必须换绑：motor_id、profile_revision、CRC、approval_flags（清零重审）
验证顺序：PC 仿真 → 低压限流空载 → 相序/方向 → 电流环 → 观测器 → 速度环 → 带载/温升
```

**行业结论先行**：量产公司不在产线上"识别电机"，而是在产线上"标定传感器 + 验证功能"；电机参数在研发期用比产线更好的仪器一次性测准。本工程"研发侧仪器测量 + 档案审批"的路线与之一致（详见第 1 章）。

## 1. 行业调研：量产公司的电机-电调匹配做法

本章是公开工程实践的综述（非任何公司内部信息），用于校准本工程的路线取舍。

### 1.1 按行业分类

| 行业 | 代表 | 参数从哪来 | 产线逐台做什么 |
|---|---|---|---|
| 消费无人机 | 大疆 | 电机电调桨**一体化联合设计**，研发台架测一次写死 | 功能测试对照金样上下限（电流波形/转速/温升/异音），不做参数辨识 |
| 通用电调 | 好盈、T-Motor、VESC 生态 | **用户侧一次性自动辨识**（VESC motor detection：电压脉冲测 R/L，拖转测 BEMF；好盈"电机自学习"；ST Motor Profiler 同类） | 工厂只做功能测试 |
| 工业变频器 | 西门子、丹佛斯 | **交付调试时辨识一次**（输铭牌 → 电机数据识别：静止测 R/漏感、旋转测磁化曲线） | 功能测试 |
| 汽车 Tier 1 | 博世、大陆 | 电机供应商数据包 + 双方 dyno 联合标定 | **100% EOL 逐台标定**"会变的东西"：电流零偏/增益、旋变零位角；台架验证转矩精度 |
| 伺服 | 安川、汇川 | 电机+驱动器**配对出货** | 编码器零位逐台标，转矩常数逐台验证 |
| 白电 | GMCC 等压缩机厂 | 研发定型后**完全不动** | 100% 短转功能测试 + 抽检耐久 + 老化 |

### 1.2 收敛出的行业共识

1. **没有一家在量产线上逐台做全参数辨识**——太慢太贵，且参数散差（±5~10%）靠控制律鲁棒性吸收；
2. **产线逐台标定的只有**：电流采样零偏/增益、编码器/旋变零位（装配位置决定）、有时加死区补偿——即"逐台真的会变且精度敏感"的量；
3. **产线测试是功能验证不是辨识**：ICT → 烧录 → EOL 功能（对照金样上下限）→ 老化 → 终检；
4. **数据管理**：逐台标定参数进 NVM + 序列号绑定，测试记录进 MES 可追溯（汽车级十年），SPC 监控批次漂移，固件签名，按电机型号做变体编码（variant coding）；
5. **量产必做的两件可靠性工作**：老化筛选（burn-in，利用浴盆曲线在前几十高应力小时暴露早期失效；消费级抽检、汽车级 100%）和认证（EMC/安全规范，汽车加 ISO 26262）。

### 1.3 对照本工程现有体系

| 行业实践 | FluxRT 对应物 | 状态 |
|---|---|---|
| 变体编码 + 参数集签名 | A14 `ProductionMotorProfile`（CRC 绑定完整运行配置 + 审批位） | 已实现，`approvals=0` 默认拒绝闭环 ✅ |
| 逐台电流零偏标定 | 上电 32 次零偏自标定 | 已实现，且比"产线标一次存 Flash"更强 ✅ |
| EOL 逐台标定完整形态 | A17/A19 相电压采样 + 逐板标定 | A19 待仪器 |
| 辨识结果可信度验收 | EXP-09 三次重复性门（10%） | Rs 已过门（9.5%）✅ |
| 标定数据持久化 | —— | **缺口**：目前全部上电重算，无 Flash 存储（A28 范围） |
| 金样上下限 | —— | **缺口**：验收文档是开放式记录，无 pass/fail 限值（A28 范围） |
| 序列号/记录追溯 | Git + SHA-256 + 证据文件 | 开发侧已有，产品侧待做 |

**对本工程的两个直接推论**：
- 不必为"量产"执着于让 ST Profiler 跑完 `SC_COMPLETED`——Ls/Ke 用研发侧仪器测量（LCR/BEMF 实测）证据等级更高；
- 真正的量产缺口在 A28：Flash 持久化、EOL 限值、追溯链，而不是电机参数本身。

## 2. 换电机总原则：四类参数的分界

### 2.1 板级参数（换电机零改动）

| 类别 | 本工程对应 | 当前值 |
|---|---|---|
| 电流采样链 | Rshunt、增益、上电零偏自标定 | 0.33 Ω / 1.53 倍 / 32 次平均 |
| 母线采样 | `foc_bus_voltage_mv()` 换算 | 1/16 分压（52.8 V 满量程） |
| 功率级时序 | 死区、载波、Break2/PA11、占空比窗口 | 550 ns / 12 kHz / 3%~97% |
| 安全包络基线 | `foc_platform_config_t` 的母线窗口、ISR deadline | 7~18 V / 12,750 cycles |
| 数学后端 | CORDIC/FPU 配置与回退 | —— |

这些属于 `foc/platform/` 与 `board/`，换电机**完全不碰**。换 MCU 时才替换（见[更换MCU移植步骤](更换MCU移植步骤.md)）。

### 2.2 板 × 电机联合参数（换电机要重设，但不用"测"）

| 参数 | 字段 | 规则 |
|---|---|---|
| **软件过流跳闸** | 平台 `software_current_trip_a`（当前 1.15 A） | 新电机额定 × 1.4~1.5 余量，且 ≤ 功率板峰值能力（IHM16M1 约 2.12 Apk） |
| 母线电压窗口 | `minimum/maximum_bus_voltage_v` | 通常不动；新电机 Ke 大时重估高速反电势余量 |

### 2.3 电机本体参数（必须重测，5+2 项）

| # | 参数 | 固件字段 | 测量方法 | 精度期望 | 本工程工具 |
|---|---|---|---|---|---|
| 1 | **极对数 p** | `pole_pairs` | 数磁钢（最准）；或 BEMF 窗口测电频率 `p = 60·f_e/n`（n 由频率法外的独立手段给出时才用此式） | 必须精确 | BEMF 固定窗测频（EXP-B1 附录 C） |
| 2 | **定子电阻 Rs** | `stator_resistance_ohm` | 万用表线电阻 ÷2（星接）；DC 注入法；四线法最佳 | ±2~5% | EXP-B2（附录 A） |
| 3 | **定子电感 Ls** | `stator_inductance_h` | LCR 表 @1 kHz；电压脉冲测 di/dt（`L = V·Δt/Δi`） | ±5% | LT1 三相复测已得 1.114 mH；`Ls(I)` 可后补 |
| 4 | **磁链 ψ / Ke** | `flux_linkage_wb` | **频率法（V/f，推荐）**：停机后 BEMF 窗口同测幅值与电频率，`ψ = V_ph_pk/(2π·f_e)`，不依赖转速计；dyno 转矩法 `ψ = T/(1.5·p·Iq)` 备选 | ~3-6%（名义分压主导） | **EXP-B1 分析器 v5；三窗重复性已通过** |
| 5 | **额定电流** | `rated_current_a` | 规格书 + 温升实测（EXP-17） | 热约束 | EXP-17 框架 |
| 6 | 最高转速 | `max_speed_rpm` | 规格书 + `Ke·n_max + IR + 余量 ≤ V_bus·utilization` 验证 | 电压约束 | EXP-B1 后可算 |
| 7 | 相序/转向 | 接线 | 定向电流看转向（EXP-08） | 必须确认 | EXP-08 |
| 8 | 惯量 J / 摩擦 F | （当前控制律不用） | 仅影响速度环前馈品质；Rev-Up 为电流型开环，**可暂不测** | —— | 以后需要时加 |

### 2.4 派生参数（不用上仪器，但全是测量值的函数——换电机最易漏）

| 派生参数 | 字段 | 换算关系 / 规则 |
|---|---|---|
| **电流环 PI** | `id_pi`/`iq_pi` 的 kp/ki | 零极对消法：`kp = L·ωc`，`ki = R·ωc`（ωc 为电流环带宽 rad/s，见附录 C）。**Rs/Ls 变了必须跟着变** |
| SMO 滑模增益 | `observer_smo_k_slide_v` | 滑模可达性要求 k ≥ 最大反电势 `ψ·p·ω_max` 留余量；注意参考式 `bus×0.9` 对小电机过大（本项目实测失锁教训） |
| SMO 边界层 | `observer_smo_boundary_a` | 以新额定电流为基准缩放（等效增益 k/boundary） |
| BEMF 滤波系数 | `observer_emf_filter_alpha` | 截止频率 `fc ≥ (3~5)×f_e_max`（`f_e_max = p·n_max/60`）；过大相位滞后是失锁主因（本项目注释明确记录） |
| PLL 增益 | `observer_pll_kp/ki` | 按新电机工作电频率范围整定；捕获期用 `pll_acq` 比例缩放 |
| 可靠性门 | `observer_minimum_speed_rpm`、`observer_minimum_bemf_v` | 由新 Ke 决定：最低可信转速处的 BEMF 应为噪声底 3~5 倍以上 |
| 启动时序 | `startup_current_a`、`startup_final_speed_rpm`、`alignment_duration_s`、`open_loop_ramp_duration_s` | 对齐电流 ≥ 克服齿槽+摩擦所需 `T/(1.5·p·ψ)` 留余量且 ≤ 热额定；升速斜率受 `T_available/J` 约束；终速必须高于新电机观测器最低可信转速 |
| 速度环 PI | `speed_pi` | `kp_s = J·ωc_s/(p·ψ)`——J 未辨识时按 EXP-14 实验整定 |
| 电压利用率 | `voltage_utilization` | 一般不动；高 Ke 电机高速余量重估 |
| 交接/限速参数 | `handoff_torque_support_ratio`、`speed_pi_preload_ratio`、`closed_loop_current_slew_a_per_s` 等 | 按新转矩常数与额定电流重估 |

## 3. 磁链与 Ke 的口径陷阱（本项目已踩过，务必先读）

换电机填磁链时**两种口径不能混用**：

| 口径 | 定义 | 谁在用 | 换算 |
|---|---|---|---|
| **教科书 SI** | `ψ = V_ph_pk / ω_e`（每**电**弧度） | **本工程固件**（`params.rs` 基线 `0.005529 Wb`） | —— |
| MCSDK 折叠 | `V_ph_pk / ω_mech`（每**机械**弧度） | `motor_profiler_convert.py`、MCSDK Workbench | = **p × SI 口径**（GBM2804H 差 7 倍） |

**已验证事实（2026-09-25 算术核对）**：固件基线 `0.005529 Wb`（SI）与数据库 `Ke = 4.964 Vll_rms/kRPM` 经标准电机理论**精确自洽**；历史上"磁链差约 7 倍 / 3.83 倍"的警告是两种口径直接相除的假警报（`3.83 ≈ 7 × 0.547`）。

**Ke 本身还有一层口径**：线电压 RMS vs 相电压 RMS，差 √3 = 1.732。`SC_KE` 属于哪种由 **EXP-B1 实测裁定**。

**操作规则**：
- 候选 JSON / 固件里手填磁链 → 一律用 **SI 口径**（EXP-B1 分析器输出 `flux_si_wb`）；
- 用 `motor_profiler_convert.py` 从 Ke 换算 → 其输出是 MCSDK 口径，**除以 p** 后才是固件值，或直接用实测 `flux_si_wb`；
- 任何"差整数倍/√3 倍"的磁链告警，先查口径再怀疑数值。

## 4. 在 FluxRT 代码里的落位与流程

### 4.1 数据流（参数进入固件的唯一正路）

```text
仪器测量（EXP-B1/B2/LCR）
    ↓
候选 JSON：profiles/candidates/revN-<motor>-*.json
    │   必改：motor_id（新电机编码）、profile_revision 递增、
    │        全部测量值 + 派生参数、approvals = false
    ↓
tools/foc_profile_tool.py 校验（schema / CRC / 证据门）
    ↓
Diagnostic 固件低压空载整定（foc_cfg 在线调参，见 4.2）
    ↓ 定稿值回填候选
人工审批：approval_flags 置位（需 EXP-10~14 验证通过）
    ↓
生成片段编译入 foc_production_profile.c → CRC 绑定完整运行配置
    ↓
三档构建（build.ps1）+ 全回归（test.ps1）+ 烧录验证
```

**禁止事项**（本项目 AGENTS.md 与架构文档的既有规则）：
- 不手改 `rtconfig.h`（由 `.config` 经 menuconfig 生成）；
- 不在电机运行中改参数（`foc_cfg` 检测到 ARMED 直接拒绝）；
- 不跳过审批位直接把闭环打开（`approvals=0` 时 profile 启动门拒绝 closed_loop）；
- `params.rs` 的硬编码默认值是仿真/首次上电基线，**产品路径只走 profile 链**。

## 5. 验证顺序与门禁（不可跳级）

| 级 | 验证内容 | 工具/实验 | 通过判据 |
|---|---|---|---|
| 1 | **PC 仿真回归** | `foc-sim` 换同一组参数（架构保证与固件同一 Rust 控制链）+ `test.ps1` 全回归 | 仿真正反向、多转速启动/接管不发散 |
| 2 | **交叉构建** | 三档构建 + size/map 记录 | Flash/RAM 有记录，哈希入档 |
| 3 | **低压限流空载** | 12 V / 限流 2 A / 空载 / 手边急停 | 开环能拖到目标转速，无异响温升 |
| 4 | **相序/方向** | EXP-08 / EXP-11 | 三相波形相序与期望转向一致 |
| 5 | **电流环** | EXP-10（Id/Iq 阶跃） | 阶跃响应接近设计的 ωc，无振荡发散 |
| 6 | **观测器边界** | EXP-13 | 可靠性门按新 Ke 正确触发/恢复，获取时间记录 |
| 7 | **闭环/速度环** | EXP-12、EXP-14 | 启动成功率、接管、调速、带载 |
| 8 | **温升/热** | EXP-17 | 新电机额定电流下温升在限内 |
| 9 | **审批入档** | approval 置位 + CRC + 操作日志 | 全部证据文件齐备 |

## 6. 换电机总核对表（打印用）

```text
【测量】
□ 1. 极对数（数磁钢 / BEMF 测频交叉验证）
□ 2. Rs（万用表，扣表笔电阻，星接 ÷2；见附录 A）
□ 3. Ls（LCR @1kHz 或脉冲法）
□ 4. 磁链 ψ（EXP-B1 频率法：BEMF 窗口同测幅值+电频率 → flux_si_wb，SI 口径！）
□ 5. 额定电流 / 最高转速 / 接法（Y 还是 Δ）
□ 6. 相序与期望转向（EXP-08）
□ 7. 表贴 or 内嵌（Ld=Lq 假设是否成立；见附录 B）

【重算】
□ 8. 电流环 PI（kp=L·ωc，ki=R·ωc）
□ 9. SMO 增益/边界层/BEMF 滤波（按新 Ke 与电频率）
□ 10. PLL 与可靠性门（min speed / min BEMF）
□ 11. 启动时序（对齐电流/升速斜率/终速 ≥ 观测器最低可信转速）
□ 12. 软件过流跳闸（新额定 × 1.4~1.5，≤ 板能力）
□ 13. 速度环 PI（J 未辨识则实验整定）

【档案】
□ 14. 新候选 JSON：motor_id / revision 递增 / CRC 待算 / approvals=false
□ 15. foc_profile_tool.py 校验通过

【验证】
□ 16. PC 仿真回归 + test.ps1
□ 17. 三档交叉构建 + size/哈希入档
□ 18. 低压限流空载 → 相序 → 电流环 → 观测器 → 闭环 → 带载
```

## 附录 A：Rs 万用表测量要点

- **两线法误差**：表笔/接触电阻约 0.1~0.3 Ω，测前短接两表笔记下并扣除；有条件用四线法；
- **星接（Y）**：任意两线测得 `R_line = 2·Rs`；**角接（Δ）**：`R_line = (2/3)·Rs`；
- 云台/小型电机几乎都是星接；无法从端子区分 Y/Δ（两者三对读数都对称），查铭牌或拆机确认；
- 三对读数（U-V、V-W、U-W）差异 >5% 说明绕组不平衡，先查电机再谈参数；
- 温度系数：铜绕组约 +0.4%/°C，记录绕组温度（辨识值与万用表对拍时要同温）。

## 附录 B：表贴（SPM）vs 内嵌（IPM）

- 本工程当前按 `Ld = Lq` 处理（`foc_rust_bridge.h` 注明），对 GBM2804H 这类表贴电机成立；
- **换内嵌式电机（IPM）则 Ld ≠ Lq**：不是改参数而是改控制律——需要 MTPA（`Id = f(Iq)` 曲线）、凸极转矩利用、可能加弱磁；涉及 `foc-control` 控制律修改与 `foc-algorithm` 新构件（advanced_control.rs 已有部分预留）；
- 判别方法：铭牌/规格书；或 LCR 分别在 d/q 轴位置（转子对齐 vs 正交）测电感差异；差异 <10% 可按 SPM 处理。

## 附录 C：电流环带宽选择参考

- 零极对消整定：`kp = L·ωc` [V/A]，`ki = R·ωc` [V/(A·s)]——零点 `ki/kp = R/L` 恰好抵消电机极点；
- ωc 上限受采样/PWM 延迟约束：12 kHz 控制下，`ωc/(2π)` 建议 300~800 Hz 起步（约控制频率的 1/40~1/15），保证相位裕度；
- 本工程 `ki` 是**连续时间**增益（算法侧按 `ki·ts·error` 离散化），改控制频率只需改 ts，ki 不重算；
- 验证用 EXP-10 的 Id/Iq 阶跃：上升时间应接近 `2.2/ωc`，超调 <20%。

## 附录 D：磁链/Ke 的频率法（V/f 法）速查

完整操作规程见 [EXP-B1](experiments/EXP-B1_BEMF实测与Ke量纲判定.md)，此处为原理速查。

**为什么用频率而不用转速计**：同步电机 `f_e = p·n/60` 严格成立，电频率本身就是转速的精确表达；BEMF 幅值与频率来自**同一采集窗**，磁链直接从波形解出，**转速不参与计算**。这消除了开环强拖跟踪偏差（1~3%）和停机滑行衰减（1~2%）两类固有误差，也是 VESC 磁链辨识与测功机"发电机法"的标准做法。

```text
测量路径：开环强拖 → foc_stop → A17 固定窗（256 拍 @12 kHz，分压 ON）
                                    ↓ 同一窗口
  幅值：V_ph_pk = max|phase_raw - mean| × 4469 uV/count（三相取最大）
  频率：三相上升沿过零（线性插值）→ f_e 取中位数
  磁链：ψ_SI = V_ph_pk / (2π·f_e)              ← 固件 params.rs 口径
  转速：n = 60·f_e/p（仅用于 Ke 口径判定与诊断）
```

**约束**：转速 ≥500 rpm 才有足够过零点（@1000 rpm 窗口约 2.5 个电周期）；绝对精度 ~3-6%（主导项是名义分压模型，A19 逐板标定后可提升）；三次重复取均值，极差/均值 <10% 才可采用。

**口径红线**：`ψ_MCSDK = p × ψ_SI`（convert 工具输出为 MCSDK 口径，差 7 倍）；`Ke(线RMS) = √3 × Ke(相RMS)`。任何"差整数倍/√3 倍"的磁链告警，先查口径再怀疑数值。
