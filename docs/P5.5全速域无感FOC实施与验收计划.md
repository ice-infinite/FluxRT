# P5.5 全速域无感 FOC 实施与验收计划

## 1. 目标与边界

P5.5 把零/低速 HFI、过渡区融合和中高速 BEMF/SMO-PLL 组合成可配置、可回退、可验证的
全速域无感角度链。这里的“全速域”首先指无感角度覆盖：

```text
零速/低速       HFI + 独立磁极极性辨识
过渡区          HFI/BEMF 双通道可信度、滞环、驻留和无跳变融合
中高速          BEMF/SMO-PLL
电压受限高速    弱磁；凸极电机按收益启用 MTPV
```

HFI 不能绕过电机适用性和硬件安全门。`Ld≈Lq`、负序响应低于噪声底、没有独立角度真值，
或目标快环没有足够 Flash/WCET 时，HFI 必须保持不可配置，继续使用 Rev-Up + BEMF/SMO。

本阶段产品默认仍不使能功率级，目标HFI能力继续为0。为H3取证，当前板上暂时烧录了
Advanced-Lab H3动态query候选；它不是Basic/Production默认固件，只允许固定令牌和固定包络。

## 2. 当前事实基线

- 旧 `RotatingHfState` 是历史兼容的两轴同相解调，源码已明确它不是完整复数正/负序分离；
- P5.5-S1 新增 `RotatingHfSequenceState`，用复数负序解调提取 `2*theta`，仍只输出 mod `pi` 角度；
- P5.5-S2 新增凸极静止 PMSM 主动注入双仿真合同，覆盖四个角度以及低凸极/无凸极拒绝；
- P5.5-S3 新增 HFI/BEMF 融合监督器，具备极性门、滞环、驻留、角差门和超时回退；
- P5.5-S5 新增动态主动HFI双仿真合同，覆盖转动、基波、`Iq`阶跃、噪声、延迟和死区；
- P5.5-S6 新增有界磁极极性辨识状态机，异常同拍零输出并锁存失败；
- 独立 V1 sensorless ABI、逐拍请求账本、正式复合快环和 STM32G431 零能力提供者已完成；
  同一 ADC 电流样本、融合角、基本 PI 与 HFI 注入已进入单一事务，真实平台能力仍为 0；
- 当前 GBM2804H-100T 只有手持 LCR 的位置敏感性线索，没有受控电角度下的 `Ld/Lq` 和编码器真值；
- 最近 Advanced feature=0 实机快环软件 deadline 只余约 2.20%，必须先优化再接 HFI。

## 4. 配置责任

编译期决定是否包含 HFI 大模块；运行期只允许在 Disabled、功率输出关闭且无故障时提交：

- 注入幅值、频率、解调低通和确定性相位补偿；
- 响应/凸极/噪声阈值与稳定拍数；
- HFI、Blend、BEMF 的速度滞环；
- 最大角度分歧、融合权重变化率和无效超时；
- 极性辨识脉冲幅值、脉宽、间隔、电流上限和尝试次数；
- 失败策略：回退 Rev-Up、降为 BEMF 或安全停机。

硬件过流、母线、Break、最小脉宽和 PWM 有效窗口不能被运行配置放宽。

## 6. 本轮数值结果的解释

合成凸极电机采用 `Rs=5 ohm`、`Ld=0.8 mH`、`Lq=1.4 mH`、1 V/1 kHz 注入和12 kHz
采样。四个角度的 Rust 最终 mod `pi` 角误差为约 `0.0031～0.0099 rad`，峰值电流约
`0.175 A`；低凸极与无凸极场景均被拒绝。该参数是为了验证结构而设计的合成参数，
不是 GBM2804H-100T 的候选参数，也不是实机注入许可。
