### 公式与单位的统一约定

除某题特别注明外，PMSM 公式采用：**正弦基波模型、等幅值 Clarke 变换、转子永磁磁链沿 d 轴、Park 变换使用电角度**。默认无中性线、忽略零序，参数近似在讨论工作点保持不变。饱和、交叉饱和与高次谐波需要另外建模。[S17][S18][S19]

| 符号 | 本文含义 | 单位或约定 |
|---|---|---|
| $p$ | 极对数 | 不是磁极总数 |
| $\theta_m,\theta_e$ | 机械角度、电角度 | rad；方向与偏置另外定义 |
| $\omega_m,\omega_e$ | 机械角速度、电角速度 | rad/s |
| $n,f_e$ | 机械转速、电频率 | rpm、Hz |
| $i_a,i_b,i_c$ | 相电流瞬时值 | A；不等同于有效值或母线电流 |
| $i_d,i_q$ | 本文等幅值变换后的电流分量 | A；稳态矢量幅值与相电流峰值对应 |
| $v_d,v_q$ | 电压指令或模型电压分量 | V；具体要区分限幅前与实际施加值 |
| $R_s,L_d,L_q$ | 模型相电阻与 d/q 轴电感 | Ω、H；不是未换算的线间测量值 |
| $\psi_f$ | 永磁磁链 | Wb；须匹配所用变换与电机模型 |
| $T_e,J$ | 电磁转矩、所选轴侧等效惯量 | N·m、kg·m² |
| $V_{dc},T_s$ | 直流母线电压、离散更新周期 | V、s |

不同资料可能使用等功率变换、另一种 Park 方向、不同的峰值/有效值定义或标幺量。**发现系数不同，应先核对定义，而不是先判断谁写错。**标准 Markdown 阅读器不一定自动渲染数学公式，使用支持数学渲染的预览功能即可；原始文件仍可直接阅读。

### 实机安全边界

本文件用于备考和工程分析，不是对某一驱动器的安全操作授权。功率驱动涉及触电、母线储能、器件爆裂、意外转动和机械夹伤风险。实机验证应使用与风险相称的防护、限定能量和机械约束，保证独立保护有效；不要以不断提高限流、关闭保护或满载反复烧机来定位问题。

测量浮动相节点或高侧栅源电压，必须选用额定值和共模能力合适的差分/隔离方案。不要把普通接地示波器的地夹随意接到开关节点，也不要通过断开示波器保护地来“浮地”测量。器件波形的测量与回路布局应共同检查。[S16]

STO、停止 PWM、受控减速、机械抱闸与电气隔离不是同一功能；软件把电压指令设为零，也不自动等于功率级处于安全关断状态。[S20][S27]

## 第1章 电机基本原理｜P0｜Q001—Q008

<a id="q001"></a>
### Q001. 有刷直流、BLDC、PMSM、异步和步进电机有什么区别？

**参考回答：**有刷直流电机依靠电刷和换向器完成电枢换向；驱动相对直接，但机械换向会带来磨损和维护问题。BLDC 与 PMSM 都属于电子换相的永磁同步电机范畴，工程命名通常强调不同的反电动势设计与电流波形。异步电机依靠定、转子之间的相对运动感应出转子电流，转子速度通常不同于同步速度。步进电机通过离散励磁状态产生位置平衡点，常用于开环定位，也可配置闭环控制。

选择时比较的不只是额定功率，还包括转矩—转速范围、响应、定位需求、驱动复杂度、传感器、成本、散热和失效后果。

**常见追问：**直流供电的 BLDC 为什么绕组中仍是交变电流？答：直流描述供电母线，逆变器对绕组施加时变电压并完成电子换相。

<a id="q002"></a>
### Q002. BLDC 与 PMSM 应该从结构、波形还是控制方式区分？

**参考回答：**结构上它们有很大重叠，不能简单说“一个无刷，一个有刷”。常见约定是：BLDC 配合近似梯形反电动势和六步电流；PMSM 配合近似正弦反电动势和正弦电流/FOC。但实际厂家命名不统一，绕组、磁钢和气隙设计才决定真实电磁特性。

FOC 可以用于不少被称为 BLDC 的电机，但是否取得低转矩脉动和高效率，要看反电动势谐波、参数和控制策略；并非改用 FOC 就必然在所有工况都更优。

**易错点：**把“BLDC 不能做 FOC”或者“PMSM 只能正弦驱动”说成硬性物理限制。

<a id="q003"></a>
### Q003. 三相交流电为什么可以产生旋转磁场？

**参考回答：**在理想对称三相绕组中，三组绕组的空间磁轴相差 120° 电角度；再通入时间相位相差 120° 的对称正弦电流，三个脉动磁场叠加为幅值近似恒定、方向连续旋转的基波磁场。旋转方向取决于相序，电角速度取决于电源频率。

这里同时存在“空间相位”和“时间相位”。只有电流三相相差 120°，但绕组空间布置不满足条件，并不能直接得到同样结论。实际槽、极结构和磁饱和还会引入谐波。

**常见追问：**交换任意两相会怎样？对正常三相连接会改变旋转场方向，但闭环系统还必须同步处理编码器方向和软件映射。

<a id="q004"></a>
### Q004. 极数、极对数、机械角度、电角度怎样换算？

**参考回答：**一对 N/S 磁极对应一个极对。设极对数为 $p$，则在方向与零点定义一致时：

$$
\theta_e=\operatorname{wrap}(p\theta_m+\theta_{offset}),\qquad
\omega_e=p\omega_m,\qquad f_e=p\frac{n}{60}
$$

其中 $n$ 的单位为 rpm，角度用 rad，$f_e$ 单位为 Hz。一圈机械角对应 $p$ 圈电角度。

**工程落点：**编码器一般直接测机械位置，Park 变换需要电角度。极对数填错时，某个局部位置可能看似有转矩，但转起来会出现周期性失配，不能用增大 PI 掩盖。

<a id="q005"></a>
### Q005. 同步电机为什么叫同步？异步电机为什么需要转差？

**参考回答：**同步稳定运行时，转子的平均机械转速等于旋转磁场的同步转速，转子与定子场之间可保持一定负载角，但没有持续的平均转速差。转矩不是“完全没有角度差”产生的。

异步电机的转子需要相对旋转磁场运动，才会感应出转子电流并形成电磁转矩。定义转差率 $s=(n_s-n_r)/n_s$；电动状态通常为正，超过同步速度进入相应发电工况时可为负。

**易错点：**把同步理解成“两个磁场方向始终重合”，或者把异步电机的转差当作纯粹的控制误差。

<a id="q006"></a>
### Q006. 什么是反电动势？它与转速、磁链有什么关系？

**参考回答：**绕组磁链随时间变化会感应电压，电机转动产生的这一部分通常称为反电动势。对于理想正弦 PMSM，在本文约定下，永磁体导致的 q 轴速度电势项为 $\omega_e\psi_f$，幅值随电角速度与磁链增加。

反电动势会占用驱动器的电压裕量，因此高速电流控制更容易饱和；但在再生状态下，电机也能向母线送能。低速时反电动势信号小，基于它的位置估计更容易被采样误差和电阻压降误差淹没。

**易错点：**把“反电动势”当作始终消耗功率的电阻压降；能量方向需要结合电压、电流和转矩符号判断。

<a id="q007"></a>
### Q007. 转矩、转速和机械功率之间有什么关系？

**参考回答：**转轴机械功率满足：

$$
P_m=T\omega_m=T\frac{2\pi n}{60}
$$

例如 1 N·m、3000 rpm 对应约 314 W 机械功率。计算效率时，必须明确测量边界：电源输入、驱动器输入、电机轴输出或减速器输出。

堵转时 $\omega_m=0$，机械输出功率为零，但电流、铜耗和发热仍可很大。因此“电机没动、没输出功率”绝不意味着可以无限保持峰值电流。

**常见追问：**额定功率能不能推导启动转矩？仅凭功率不够，还需额定转速、峰值电流、磁链与热约束。

<a id="q008"></a>
### Q008. 电机四象限运行分别是什么？

**参考回答：**用转速和转矩的正负构造四象限。$T\omega_m>0$ 表示电磁作用在向机械侧供能；$T\omega_m<0$ 表示制动/发电方向的机械能转换。正转可以电动也可以制动，反转也同样如此。

是否真正把能量回收到电池，还取决于驱动拓扑、电源可回馈能力、母线和损耗。制动转矩不等于能量一定回到电池，能量也可能在绕组、制动电阻和其他器件中耗散。

**工程落点：**设计反转或停车流程时，要先处理当前动能，而不是把速度目标直接改成一个很大的负值。

**本章核对与延伸：**电机类型与模型见 [S08]、[S17]；控制总体分类见 [S01]。本章公式是给定定义下的基础推导。

## 第2章 电机参数、单位与选型｜P0｜Q009—Q016

<a id="q009"></a>
### Q009. 相电阻和线间电阻有什么关系？

**参考回答：**对三相对称且外部端子正常隔离的绕组，星形连接的两端测量相当于两相串联，因此 $R_{LL}=2R_{phase}$。三角形连接中，一相与另外两相串联支路并联，因此 $R_{LL}=2R_{phase}/3$。这里的 $R_{phase}$ 指真实单支绕组电阻，不是已经换算成星形的等效参数。

毫欧级测量必须关注表笔、接插件和焊接电阻，优先考虑四线测量或受控电流下测电压，并记录温度。

**易错点：**将万用表测到的线间电阻直接作为 FOC 模型中的定子每相电阻，造成 PI、损耗和观测器参数不一致。

<a id="q010"></a>
### Q010. 相电感、线间电感、Ld、Lq 是不是同一个参数？

**参考回答：**不是。线间测量得到的是特定端口、连接、转子位置、测试频率和测试电流下的等效电感，包含自感和互感关系。$L_d/L_q$ 是转子坐标系中的磁链—电流关系参数，凸极电机的两者通常不同。

对于对称、非凸极和定义匹配的近似模型，可以从线间测量换算模型电感；但不能把电阻的串并联关系机械套给所有电感情况。还需区别割线电感 $\lambda/i$ 与增量电感 $d\lambda/di$。

**追问：**为什么 LCR 表小信号电感与工作时辨识值不同？检查磁饱和、测试频率、转子位置和电流偏置。

<a id="q011"></a>
### Q011. 额定电流、峰值电流、相电流有效值和母线电流有什么区别？

**参考回答：**额定与峰值描述允许使用的工作条件，RMS 与峰值描述波形统计或幅值，母线与相电流描述测量位置。这是三组不同维度，不能混用。

对正弦相电流，$I_{peak}=\sqrt2 I_{rms}$。本文等幅值变换下，稳态电流矢量幅值 $\sqrt{i_d^2+i_q^2}$ 对应正弦相电流峰值。母线平均电流主要与输入功率有关，不等于相电流；低速大转矩时可出现相电流大、母线平均电流相对小的状态。

**工程落点：**接口中的 `current_limit=20` 必须说明是 A_peak、A_rms、Iq 还是母线平均电流，峰值还必须配套允许持续时间和温度条件。

<a id="q012"></a>
### Q012. Kv、Kt、反电动势常数和永磁磁链分别是什么？

**参考回答：**$K_v$ 常表示速度与某种电压的比值，单位常为 rpm/V；$K_t$ 表示转矩与某种电流的比值，单位 N·m/A；反电动势常数表达速度引起的感应电压；$\psi_f$ 是模型中的永磁体磁链参数，常用 Wb。

本文正弦、等幅值约定下，表贴式 PMSM 且 $i_d=0$ 时有 $T_e=(3/2)p\psi_f i_q$，因此这里以 q 轴电流为基准的 $K_t=(3/2)p\psi_f$。换成相电流 RMS，系数随之改变。

**易错点：**把不同厂商所写的 Kt 当成可直接互换参数，而不问电流基准。

<a id="q013"></a>
### Q013. 为什么不能不看定义直接用 Kv 换算 Kt？

**参考回答：**只有电压、电流、角速度和功率定义相互匹配时，电机常数的互易关系才能直接使用。$60/(2\pi K_v)$ 这一常见表达隐含了特定的等效定义；三相正弦电机若使用线电压 RMS、相电流峰值或驱动器内部 Iq，换算系数可能不同。

此外，拿“某母线电压下空载转速”估算 Kv，会受到调制利用率、损耗、控制角度和空载电流的影响，不一定等于严格测得的反电动势常数。

**工程落点：**优先查厂家测量定义，或实测反电动势/转矩—电流关系；文档中同时保存原始定义和模型转换结果。ODrive 的 Kt/Kv 说明只是其约定下的一个具体例子。[S11]

<a id="q014"></a>
### Q014. 为什么同额定功率电机，启动转矩和调速性能可能差很多？

**参考回答：**额定功率是某个持续工作点的指标，不决定整个转矩—转速包络。不同额定速度会对应不同额定转矩；磁链、电感、绕组电阻、转子惯量、允许峰值电流和热容量也会改变动态表现。

启动还受驱动器电流能力、位置反馈、负载静摩擦和启动算法限制。高速响应既受母线电压限制，也受机械惯量影响：在同样净转矩下，$\alpha=T_{net}/J$。

**追问：**能否只换大功率电机解决响应问题？不一定，更大的转子惯量可能抵消部分转矩收益，电源与驱动器也可能成为瓶颈。

<a id="q015"></a>
### Q015. 连续转矩和峰值转矩受什么限制？

**参考回答：**连续能力需要长期热平衡，受绕组温升、磁钢温度、冷却和机械条件限制。峰值能力还涉及磁饱和、退磁风险、功率器件、电源、电缆和结构强度，且必须给出持续时间和重复间隔。

同一电流在静止与高速下的总损耗可能不同，因为铁耗、风摩等也会变化。不能只用一个恒定电流上限代表完整工作包络。

**工程落点：**分别建立瞬时硬件保护、短时电流/转矩限制、热模型或温度降额和持续工况限制，并检查电机与驱动器哪个先达到边界。

<a id="q016"></a>
### Q016. 怎样根据负载选择电机和减速比？

**参考回答：**先列负载转矩、输出速度、加速度、工作周期和精度，再计算输出峰值转矩与周期 RMS 转矩。设减速比 $N=\omega_m/\omega_{out}$，理想刚性关系下，电机转速为 $N\omega_{out}$，负载惯量反射到电机侧为 $J_L/N^2$。

电动方向的输出转矩近似 $T_{out}=\eta N T_m$，但效率不是四象限通用常数，回驱、摩擦和静止接触应单独分析。随后核对电压、电流、热、背隙、刚度、噪声及机械限速。

**易错点：**只按减速比成倍放大转矩，却忽略速度损失、减速器额定转矩、冲击载荷和传动误差。

**本章核对与延伸：**模型参数与辨识见 [S08]、[S17]；驱动器单位与减速器配置示例见 [S11]、[S12]。

<a id="chapter-03"></a>
## 第3章 BLDC 六步换相｜P0/P1｜Q017—Q024

<a id="q017"></a>
### Q017. 六步换相的六个状态如何排列？

**参考回答：**一个示例顺序是 `A+ B- → A+ C- → B+ C- → B+ A- → C+ A- → C+ B-`，每步跨越 60° 电角度；具体顺序必须与相线定义、霍尔顺序和期望旋转方向一致，不能无条件复制。

“+/-”表示这一状态下的电流或桥臂作用方向，不是说相端对地电压永远保持正/负。PWM 导通和续流期间，实际电流路径会切换。

**自测要求：**任选一步，画出主导通路径、关断续流路径、悬空相和有效反电动势测量时刻。

<a id="q018"></a>
### Q018. 两相导通、一相悬空时电流怎么流？

**参考回答：**以 A 上管与 B 下管形成主导通为例，电流可由母线正端经 A 上管、A/B 绕组和 B 下管回到负端。进入 PWM 关断阶段后，绕组电感使电流不能瞬间归零，会通过被允许的同步整流开关或体二极管续流。

具体路径取决于 PWM 加在哪个开关、是否互补驱动、当前电流方向和续流方式。悬空相也可能受寄生电容与二极管钳位影响，并非理想无干扰节点。

**易错点：**只会画直流主导通路径，不知道关断期间为什么仍有相电流。

<a id="q019"></a>
### Q019. 120° 导通与 180° 导通有什么区别？

**参考回答：**传统 120° 六步方式中，每一桥臂开关的有效导通区间按 120° 电角度组织，通常两个相支路参与主电流路径、另一个相端用于浮相测量。180° 导通组织中每个开关跨越更长的电角区间，通常三相端子都连接到某一母线轨。

两者在电压波形、谐波、转矩波动、利用率和位置估计可用信号上不同。比较时必须说明是否叠加 PWM、采用何种续流和控制目标。

**易错点：**把“每个开关导通 120°”等同于“电机只工作三分之二时间”。

<a id="q020"></a>
### Q020. 霍尔信号如何映射换相表？哪些组合异常？

**参考回答：**先低能量标定霍尔状态序列、相序和旋转方向，再建立“霍尔码→对应桥臂状态”的映射；还要校验状态切换是否符合相邻扇区关系，以及超时是否与速度相容。

对常见 120° 电角度布置，`000/111` 常被视为无效码；但其他霍尔布置和极性组合可能不同，不能在不了解机械布置时直接使用该规则。正确的无效状态集合来自具体配置与标定。

**追问：**合法码突然跳到非相邻扇区怎么办？结合加速度上限、采样延迟和毛刺滤波判断，不能简单把所有跳变解释为真实高速转动。[S06]

<a id="q021"></a>
### Q021. 无感六步换相怎样检测反电动势过零？

**参考回答：**在合适的浮相与 PWM 状态下，把浮相电压与重建中性点或适当参考比较，寻找反电动势过零时刻。实现需要处理分压、母线变化、换相消隐、开关毛刺和数字确认。

并非任何时刻都能把“浮相端电压等于半母线”当作严格判据；PWM 模式、电流续流和中性点漂移决定具体采样方法。

**工程落点：**观察浮相模拟波形、比较参考、有效窗口和判定输出四者的对应关系，而不是只看最后的换相中断。

<a id="q022"></a>
### Q022. 反电动势过零后为什么通常还要延迟换相？

**参考回答：**在理想梯形反电动势、传统 120° 六步组织下，浮相过零相对下一理想换相点通常差 30° 电角度。因此常用最近的扇区时间估算延迟；高速、电感、负载以及滤波延迟可能需要调整提前角或补偿。

30° 是这一模型与状态定义下的结果，不是所有无感电机、所有电压采样策略的通用固定时间。转速变化时，时间延迟也必须随估计速度更新。

**追问：**滤波拖后 10°，还额外延迟完整 30° 会怎样？实际换相进一步滞后，可能增大电流和失步风险。

<a id="q023"></a>
### Q023. 静止时无反电动势，无感六步怎么启动？

**参考回答：**常见流程是检查停转/风车状态，必要时预定位，再按限制电流与斜坡频率开环拖动，待反电动势和连续过零可信后接管闭环。部分方案可通过脉冲响应辨识初始位置，减少反向预动。

启动需要协调初始转矩、负载惯量、加速度和限流。开环频率爬升过快会使转子跟不上，过慢或电压过高会发热；不能以一次空载成功证明带载启动可靠。

**验收建议：**记录供电上下限、温度、初始角度和负载变化下的成功率以及最大电流，而不只记录启动时间。

<a id="q024"></a>
### Q024. 如何处理反转、顺风/逆风启动和换相失败？

**参考回答：**启动前先判断是否已经旋转、方向和速度。顺向风车状态可尝试同步接入；逆向状态需要按母线吸能能力制动、等待或受控反转，不能把正常静止启动序列强行接入高速反转电机。

换相失败应限制能量，记录过零丢失、估计转速、母线与电流，进入预定故障状态。重新启动要有次数、间隔、温度和机械条件约束。

**易错点：**失步后不停加大占空比，或者无限循环自动重试。两者都可能把控制失配转变为硬件损坏。

**本章核对与延伸：**ST 六步控制入口见 [S10]；霍尔标定见 [S06]。状态机与测试建议为工程练习方案，不是某 SDK 的固定实现。

## 第4章 FOC 框架与坐标变换｜P0｜Q025—Q032

<a id="q025"></a>
### Q025. 画出一套有传感器 PMSM FOC 框图。

**参考回答：**核心是电流内环；速度和位置环可按模式选择启用。反馈包括相电流、转子角度、母线电压与必要的保护量。

```text
位置指令 → 位置控制器 → 速度指令 → 速度控制器 → 转矩/Iq 指令
                                             ↓
                                 Id/Iq 参考与限流
                                             ↓
相电流 → 校准 → Clarke → Park → dq 电流误差 → PI + 解耦
                            ↑                       ↓
编码器 → 方向/零点/极对数 → 电角度       电压矢量限幅 + 抗饱和
                            ↓                       ↓
                       角度时间补偿 → 反 Park → SVPWM
                                                      ↓
                               定时器 → 驱动器 → 逆变桥 → 电机
```

**工程补充：**硬件快速关断链独立于上述正常算法；温度、母线和状态机决定运行许可与限值。参考 [S01]、[S20]。

<a id="q026"></a>
### Q026. Clarke 变换为什么能把三相变成两相？

**参考回答：**三线制且忽略零序通路时，$i_a+i_b+i_c=0$，三个相电流只有两个独立自由度。本文采用等幅值形式：

$$
i_\alpha=\frac23(i_a-\frac12i_b-\frac12i_c),\quad
 i_\beta=\frac{1}{\sqrt3}(i_b-i_c)
$$

在电流和为零时可简化为 $i_\alpha=i_a$、$i_\beta=(i_a+2i_b)/\sqrt3$。它改变坐标表达，不是丢弃一相的物理作用。

**易错点：**有零序电流或测量不同时仍不加说明地套二相简式；三相测量残差也不应在诊断前被强行归零。[S19]

<a id="q027"></a>
### Q027. Park 变换为什么用电角度？

**参考回答：**Park 将静止 $\alpha\beta$ 坐标投影到跟随转子磁链旋转的 $dq$ 坐标。磁场重复周期由电角度决定，因此直接使用机械角会在多极电机中产生错误旋转速度。

本文规定：

$$
i_d=i_\alpha\cos\theta_e+i_\beta\sin\theta_e,\quad
 i_q=-i_\alpha\sin\theta_e+i_\beta\cos\theta_e
$$

**自测：**当 $\theta_e=0$ 时，d 对齐 α、q 对齐 β；用这一点检验程序与图示。若使用另一种轴方向，公式和控制符号必须整体一致。[S18]

<a id="q028"></a>
### Q028. d 轴和 q 轴相对哪个磁场定义？

**参考回答：**在本文 PMSM 转子磁链定向中，d 轴对齐转子永磁磁链，q 轴按本文正方向与之相差 90° 电角度。d/q 的命名本身并不保证控制已经解耦，它首先是一套坐标选择。

对于异步电机，可以选择转子磁链、定子磁链等不同定向，不能把所有控制场景都默认成“机械转子位置就是 d 轴”。

**易错点：**说“d 永远不产转矩、q 永远只产转矩”。凸极 PMSM 存在磁阻转矩，d 电流会影响转矩和电压约束。

<a id="q029"></a>
### Q029. 交流相电流为什么在 dq 中近似变成直流？

**参考回答：**稳态对称正弦电流形成一个以电角速度旋转的电流矢量；从同速旋转的坐标系观察，其投影不再周期变化，因此表现为近似恒定的 d/q 分量。这样 PI 可以用积分消除常值跟踪误差。

“近似直流”以稳态、角度正确、主要基波为前提。转矩变化、角度误差、电流谐波、采样不同步和死区都会使 dq 出现动态或纹波。

**工程落点：**观察 dq 波纹的频率与机械转频、电频率、采样频率的关系，有助于判断误差来源。

<a id="q030"></a>
### Q030. 等幅值与等功率 Clarke/Park 有什么区别？

**参考回答：**两种形式主要区别是缩放系数。等幅值便于使空间矢量幅值对应相电流峰值；功率不变形式使变换前后内积保持相应一致。本文等幅值、零序为零时：

$$
P_e=\frac32(v_di_d+v_qi_q)
$$

采用功率不变缩放后，电流/电压数值、转矩系数和限幅阈值都应相应转换。

**易错点：**从不同开源库各复制一段变换、转矩估算和 SVPWM，最后虽然可以转动，却存在固定比例误差。务必在接口文档写出基值和变换矩阵。

<a id="q031"></a>
### Q031. 相序、编码器方向或零点错误为什么破坏控制？

**参考回答：**控制器以估计的 d/q 轴分解电流并施加电压。如果角度错位，期望的 q 电流会混入 d 轴；方向或相映射错误还可能使负反馈变成正反馈，导致电流快速增加。

小的固定偏置可能表现为低效率、发热和转矩不足；大的偏置或错误方向可能表现为只抖、反转或失稳。不能以“能转”作为标定正确的唯一证据。

**验证建议：**先受控确认相序和编码器方向，再校准零点，最后在低能量条件下检查正负 Iq 与实际转矩方向、Id/Iq 跟踪关系。

<a id="q032"></a>
### Q032. FOC 和 SVPWM 是不是同一个算法？

**参考回答：**不是。FOC 规定在合适的坐标系中控制电流/磁链与转矩；SVPWM 是把电压矢量转换为逆变器开关占空比的方法。FOC 可搭配其他调制方法，SVPWM 也可为其他控制策略服务。

工程上应分为“控制器输出电压指令”和“调制器实现电压指令”两个接口，并说明母线测量、线性范围、采样窗口、死区和实际实现电压。

**常见追问：**只输出正弦 PWM，没有电流闭环，是不是 FOC？通常不能仅凭波形这样认定，还需看坐标定向和受控物理量。[S01][S04]

<a id="chapter-05"></a>
## 第5章 PMSM 模型与解耦｜P0/P1｜Q033—Q040

<a id="q033"></a>
### Q033. 写出 PMSM 的 dq 电压方程。

**参考回答：**本文符号约定下，线性参数模型为：

$$
v_d=R_si_d+L_d\frac{di_d}{dt}-\omega_eL_qi_q
$$
$$
v_q=R_si_q+L_q\frac{di_q}{dt}+\omega_e(L_di_d+\psi_f)
$$

模型忽略饱和、参数随位置变化、额外铁耗支路及逆变器非理想因素。$\omega_e$ 用电角速度 rad/s，不是机械 rpm；电感用 H 而不是原样代入 mH。

**自测要求：**能够从电压平衡解释每一项，知道静止、Id=0 和高速时哪些项占主导。[S17][S20]

<a id="q034"></a>
### Q034. 电阻项、电感项、交叉项和反电动势项分别是什么？

**参考回答：**$R_si$ 表示绕组电阻压降；$L\,di/dt$ 描述改变电流所需电压；$-\omega_eL_qi_q$ 与 $+\omega_eL_di_d$ 是旋转坐标系引入的轴间耦合项；$\omega_e\psi_f$ 是永磁磁链的速度电势。

低速大电流时电阻压降重要；电流快速变化时电感项重要；高速时速度相关项占用更多母线裕量。该分解也说明“电机没达到目标电流”可能是电压能力不足，而不一定是 PI 太小。

**追问：**温升后只有哪一项变化？不能只说电阻，磁链和电感也可能变化，取决于温度及磁工作点。

<a id="q035"></a>
### Q035. 为什么两个电流环不天然独立？

**参考回答：**从方程可见，d 轴电压需求包含 q 电流，q 轴电压需求包含 d 电流和磁链。速度越高，耦合越明显。两个独立 PI 通过反馈可以抑制部分影响，但动态性能与电压裕量会受限制。

另外，电压矢量限幅把两个轴联系起来；即使线性模型做了理想解耦，某一轴要求更多电压也会压缩另一轴的可用范围。

**易错点：**加入两个 PI 就宣称完全解耦，或者不检查限幅后的真实电压便判断参数效果。

<a id="q036"></a>
### Q036. 前馈解耦怎么写？符号错了会怎样？

**参考回答：**在本文定义下，可令：

$$
v_d^*=u_{PI,d}-\omega_eL_qi_q,
\qquad v_q^*=u_{PI,q}+\omega_e(L_di_d+\psi_f)
$$

使 PI 主要应对电阻—电感动态。使用测量电流、参考电流或预测电流会改变噪声和动态，需要一致设计。速度、参数、角度及延迟有误时只能做到近似补偿。

符号错误可能把耦合放大，因此上线时应先验证基本反馈，再分步启用前馈，并比较相同工况下的电流误差与电压饱和情况。

<a id="q037"></a>
### Q037. 转矩公式是什么？永磁转矩与磁阻转矩怎么解释？

**参考回答：**本文等幅值正弦模型下：

$$
T_e=\frac32p\left[\psi_fi_q+(L_d-L_q)i_di_q\right]
$$

第一项来自永磁磁链与 q 轴电流；第二项来自 d/q 方向磁阻差异。若 $L_d=L_q$，第二项在该模型下为零。

当常见 IPMSM 有 $L_q>L_d$ 时，合适的负 Id 与正 Iq 可产生正的磁阻转矩，但这不意味着 Id 越负越好，还要考虑总电流、电压、效率与退磁限制。

**易错点：**漏掉极对数或 3/2，却仍使用本书的等幅值电流定义。[S03]

<a id="q038"></a>
### Q038. 表贴式与内嵌式 PMSM 的 Ld/Lq 有什么差异？

**参考回答：**表贴式转子在简化模型中磁路较接近各向同性，常近似 $L_d\approx L_q$；内嵌式磁钢和磁通屏障形成明显凸极性，常见设计为 $L_q>L_d$。实际电机需要测量，不能仅凭名字规定一个固定比值。

这种差异会影响磁阻转矩、MTPA、弱磁范围和高频注入可观测性。饱和后两轴电感和交叉项还可能随 Id/Iq 改变。

**工程落点：**需要更高精度时，使用磁链图或电感地图，而不是长期依赖一个厂家典型电感值。

<a id="q039"></a>
### Q039. 为什么 Id=0 并非总是最佳？

**参考回答：**对理想非凸极 SPMSM、忽略其他损耗且低于电压边界时，Id=0 能把电流用于永磁转矩，是合理策略。对凸极电机，非零 Id 可贡献磁阻转矩，MTPA 一般不再是 Id=0。

超过基速时，需要负 Id 降低等效磁链满足电压约束；若优化的是总损耗而非电流，还可能采用其他参考策略。

**追问：**为什么低速空载也可能测出非零 Id？先检查标定、测量偏置和控制误差，再判断是否为算法主动给定，不能直接归因于弱磁。

<a id="q040"></a>
### Q040. 温度、饱和与交叉饱和如何影响控制？

**参考回答：**温度改变电阻和永磁体磁链；饱和改变磁链—电流斜率；交叉饱和意味着某一轴的磁链不仅与本轴电流有关。结果会影响 PI 初始设计、解耦、观测器、转矩估算及电压边界。

应根据要求选择固定参数加鲁棒裕量、温度补偿、分区查表或在线辨识。在线更新要有可信度、速率和参数范围限制，防止异常数据把控制参数带偏。

**工程落点：**在热机、峰值电流和高速边界分别验证，而不是仅在冷机空载下调出一套参数。

**本章核对与延伸：**PMSM 模型 [S17]、MTPA [S03]、参数辨识 [S08]。带有具体符号的解耦式均以本文坐标定义为准。

<a id="chapter-06"></a>
## 第6章 PWM、SVPWM 与调制｜P0｜Q041—Q048

<a id="q041"></a>
### Q041. 三相两电平逆变器为什么有八种开关状态？

**参考回答：**忽略死区、故障与非法直通状态，每个桥臂只能把相端连接到母线正端或负端，三桥臂组合为 $2^3=8$ 种。可用 `Sa Sb Sc` 表示上管有效状态，其中 `000` 和 `111` 在理想三线电机上不产生线间电压，称零矢量；另外六种是有效矢量。

“零矢量”不等于绕组电流为零，也不等于三相对地电压为零；此时原有电流仍可续流，两个零矢量的共模电压和采样条件也不同。

**追问：**为什么同桥臂上下管同时开不在这八种中？那是直通故障，不是合法调制状态。

<a id="q042"></a>
### Q042. 六个有效矢量和两个零矢量是什么？

**参考回答：**以 A 轴为 α 正向、本文等幅值变换为例，`100、110、010、011、001、101` 形成角度依次相差 60° 的六个有效电压矢量，长度为 $2V_{dc}/3$。`000、111` 对应原点。

六边形内部可通过时间平均合成参考电压。线性圆形旋转参考的最大幅值受六边形内切圆限制，为 $V_{dc}/\sqrt3$。这是基波相电压空间矢量幅值，不是相端开关电压峰值。

**自测要求：**由 `100` 推出相对浮动中性点的三相电压为 $2V_{dc}/3,-V_{dc}/3,-V_{dc}/3$，再做 Clarke 验证。

<a id="q043"></a>
### Q043. 怎么确定 SVPWM 扇区？

**参考回答：**可以由 $\operatorname{atan2}(v_\beta,v_\alpha)$ 求参考角，再按每 60° 划分；也可利用投影和符号比较实现无反正切判断。不同实现的编号和相序不一定相同，不能混用扇区表。

边界需要定义归属，接近零电压时角度并无实际意义，可以直接输出约定的零矢量/中点占空比。使用浮点计算时还要防 NaN、极小值和边界舍入。

**工程落点：**用六个主轴方向、六个边界附近点和随机矢量做单元测试，比较最终平均电压，而不只比较扇区数字。

<a id="q044"></a>
### Q044. T1、T2、T0 怎样计算？

**参考回答：**在一个扇区内，设参考角相对前一个有效矢量为 $\phi\in[0,\pi/3]$，参考幅值为 $V_r$，完整调制周期为 $T_s$：

$$
T_1=\sqrt3\frac{V_r}{V_{dc}}T_s\sin(\pi/3-\phi),\qquad
T_2=\sqrt3\frac{V_r}{V_{dc}}T_s\sin\phi
$$
$$
T_0=T_s-T_1-T_2
$$

这些是两个相邻矢量的合成时间；如何分配到上、下半周期取决于开关序列。若 $T_0<0$，意味着超出这一线性合成条件，应由限幅或明确的过调制策略处理。

**易错点：**把半周期定时器计数长度与完整 PWM 周期混用，得到两倍或一半的占空比。

<a id="q045"></a>
### Q045. 七段式、五段式和不连续 PWM 有何取舍？

**参考回答：**七段式常用对称的零矢量和有效矢量序列，便于形成对称波形。五段式或不连续 PWM 可在部分角度区间钳位某桥臂，减少开关动作，可能降低开关损耗。

代价可能包括谐波分布、共模电压、电流纹波、损耗均衡和有效采样窗口改变。不能把“少两段”直接等同于总效率更高，还要看电流相位、功率器件和实际工作区间。

**追问：**在单电阻采样方案中换调制策略，需要一起改什么？至少重新核对电流重构映射、最小有效矢量时间和 ADC 触发点。

<a id="q046"></a>
### Q046. SVPWM 比 SPWM 的母线利用率优势如何推导？

**参考回答：**理想线性正弦 PWM 的相电压基波峰值上限为 $V_{dc}/2$；通过合适零序注入实现的线性 SVPWM 上限为 $V_{dc}/\sqrt3$。因此两者比值为：

$$
\frac{V_{dc}/\sqrt3}{V_{dc}/2}=\frac2{\sqrt3}\approx1.1547
$$

即在这些定义和理想条件下，可用基波电压幅值约增加 15.47%。实际还需留采样、死区、自举刷新和器件压降余量。

**易错点：**说“电机效率提高 15%”，或者脱离归一化基准直接比较不同软件中的调制度数值。[S04]

<a id="q047"></a>
### Q047. 什么是线性区和过调制区？超限怎么处理？

**参考回答：**在线性区，平均输出电压与参考矢量保持线性关系；超出可实现边界后，简单占空比裁剪会改变幅值和方向，产生谐波并破坏原有控制假设。过调制是有规则地利用六边形边界提高电压输出，不是放任定时器溢出。

普通 FOC 实现可先采用电压矢量整体缩放，保持方向；需要弱磁时再由上层协调电流参考。限幅后的实现电压应回送抗饱和和必要的观测器。

**追问：**为什么分别裁剪 Vd/Vq 不等于圆限幅？独立矩形约束会让合成幅值超过圆形边界，也可能产生不同方向误差。

<a id="q048"></a>
### Q048. 中心对齐和边沿对齐 PWM 对控制有什么影响？

**参考回答：**边沿对齐把一个开关边沿固定在周期边界；中心对齐通过上下计数形成更对称的脉冲。后者经常方便把电流采样安排在稳定导通区，但“中心对齐”本身不保证采到有效电流。

还应说明比较事件、计数方向、更新事件是否一周期发生一次或两次，以及 ADC 触发和占空比生效的关系。某些配置会让算法无意中运行两次，或错过一次更新。

**工程落点：**画时序并用示波器验证 PWM、ADC 触发标记和控制 ISR 标记；不要只根据定时器寄存器名称推断行为。

**本章核对与延伸：**调制定义与实现方法 [S04]；控制调度 [S05]；采样窗口 [S15]。公式为指定空间矢量定义下的推导。

## 第7章 PI/PID 与环路整定｜P0｜Q049—Q056

<a id="q049"></a>
### Q049. 电流环为什么常用 PI？什么时候考虑其他控制器？

**参考回答：**同步旋转坐标系中的稳态参考近似常值，PI 结构简单、计算可控，积分能在未饱和且闭环稳定时消除常值误差。加入合理解耦后，电流对象可近似为电阻—电感一阶环节。

D 项会放大高频噪声，通常不宜直接对带 PWM 纹波的电流做裸微分。若存在特定谐波、强约束或动态需求，可以考虑谐振控制、预测控制等，但需说明计算成本、参数敏感性和验证收益。

**易错点：**“PI 能消除静差”不代表输出饱和、反馈错误或系统不稳定时也能消除误差。

<a id="q050"></a>
### Q050. 电流环、速度环和位置环各输入输出什么？

**参考回答：**常见级联结构是：位置环根据位置误差给速度参考；速度环根据速度误差给转矩或 Iq 参考；电流环根据 Id/Iq 误差给 Vd/Vq。外环输出必须受内层可实现能力约束。

可以加入速度、加速度和转矩前馈，因此真实结构不一定是三个纯串联 PID。转矩模式一般不需要位置和速度反馈来形成正常调节，但仍可能有超速保护和运动边界。

**工程落点：**每个接口写明单位，例如 rad、rad/s、N·m、A、V，避免 rpm 与 rad/s、输出轴与电机轴混用。[S11]

<a id="q051"></a>
### Q051. 为什么先调电流环，再速度环，最后位置环？

**参考回答：**外环把内环当作执行器。如果内环不稳定、严重饱和或延迟未知，外环调参的结论不可靠。因此先确认电流采样和内环动态，再辨识机械行为、整定速度环，最后根据位置要求和机械共振整定位置环。

调试时还应暂时冻结或限制外环，防止内环测试被速度积分器等其他状态干扰。不是把所有环同时开着，然后逐个旋钮随机调。

**追问：**外环一定比内环慢十倍吗？这是可作起点的经验量级，不是定律；最终看模型、耦合、延迟和稳定裕量。

<a id="q052"></a>
### Q052. 怎样根据 R、L 和目标带宽初估电流 PI？

**参考回答：**对已解耦且暂不考虑延迟的 $G(s)=1/(Ls+R)$，使用 $C(s)=K_p+K_i/s$，令 $K_i/K_p=R/L$ 抵消对象极点；目标近似闭环带宽为 $\omega_c$ 时：

$$
K_p=L\omega_c,\qquad K_i=R\omega_c
$$

这是连续时间、理想对象下的初始设计，不是直接可用的最终参数。实际还要加入零阶保持、采样、计算、PWM 和传感器滤波延迟，再检查离散闭环与限幅行为。

**易错点：**把 Hz 直接当 rad/s，或把已经乘 Ts 的积分系数再乘一次。详算见 Q188。[S02]

<a id="q053"></a>
### Q053. 控制执行频率与控制带宽有什么区别？

**参考回答：**执行频率表示算法每秒运行多少次；带宽描述闭环对不同频率输入的跟随能力，是系统动态属性。20 kHz 电流环执行频率不等于 20 kHz 电流带宽。

采样、计算和 PWM 延迟会引入相位滞后，电感和可用电压也限制电流变化速度。因此带宽必须显著低于受到这些因素限制的频率，并通过频域或时域验证。

**工程落点：**不要只报告“FOC 20 kHz”，还应报告闭环测试条件、带宽测量方法、相位裕量或阶跃性能。[S02][S05]

<a id="q054"></a>
### Q054. 什么是积分饱和？条件积分和反算有什么区别？

**参考回答：**执行器达到极限时，控制误差仍可能持续，积分器继续积累，解除饱和后需要很久才能恢复，导致超调或长时间错误输出。

条件积分在误差会进一步推向饱和方向时停止积分，而允许帮助脱离饱和的积分。反算则把“实际可施加输出−未限幅输出”按一定增益反馈到积分状态。反算对复杂限幅可更灵活，但要选好恢复时间尺度。

**追问：**只给积分状态加一个固定上下限够吗？能限制数值，却不一定与当前母线电压、前馈和矢量限幅相匹配。

<a id="q055"></a>
### Q055. 电压矢量限幅后怎样处理积分器和解耦前馈？

**参考回答：**应先明确未限幅总指令由 PI 与前馈组成，再算实际可实现电压。若采用反算，补偿量应反映总指令与实际实现之间的差，避免只限制 PI 而让前馈把总输出再次推过边界。

电压圆限幅、轴优先级、过调制和最小脉宽会导致不同实现电压，因此抗饱和最好与调制结果一致。母线快速下降时也要同步降低限值。

**工程落点：**同时记录 `u_pi`、`u_ff`、`u_unsat`、`u_applied` 和积分状态，才能判断是增益问题还是长时间饱和。附录 C 给出矢量反算示例。

<a id="q056"></a>
### Q056. 怎样通过阶跃和频率响应判断控制器？

**参考回答：**小信号阶跃可观察上升时间、超调、整定、稳态误差与噪声放大；频率响应可观察带宽、相位与增益裕量。大信号阶跃还会触及限流/限压，因此应区分线性动态与饱和恢复。

测试要固定负载、温度、母线与工作点；电流环和机械环测试方法不同。带机械负载时必须限制激励，避免扫频触发危险共振。

**易错点：**只看一张平滑滤波后的波形就宣称高带宽。应保留原始信号、滤波设置和采样率，以便复现。[S02]

<a id="chapter-08"></a>
## 第8章 电流采样与模拟前端｜P0｜Q057—Q064

<a id="q057"></a>
### Q057. 单、双、三电阻电流采样各是什么结构？

**参考回答：**单电阻通常放在直流母线回路，通过不同有效开关状态的母线电流重构相电流。双/三电阻通常放在两/三条低侧支路，也可以采用两/三路相内测量，不能只按电阻数量推断位置。

单电阻节约通道，但采样窗口与重构更复杂；三路测量增加硬件，却可提供更多有效相选择或诊断信息。是否实际连续可测，取决于拓扑和前端动态。

**易错点：**认为有三颗低侧采样电阻，就能在任意时刻直接获得三个相电流。[S15]

<a id="q058"></a>
### Q058. 母线、低侧、相内采样有什么区别？

**参考回答：**母线采样得到某个开关状态下的组合电流；低侧采样只有在目标电流路径经过该低侧支路时才可对应相电流；相内采样直接置于电机相线上，观察范围更完整，但承受很大的共模电压和快速跳变。

除成本外，还应比较带宽、共模范围、隔离、电流双向能力、零偏、故障可见性和保护延迟。测控链路和快速保护链路可以采用不同传感与滤波路径。

**追问：**母线平均电流传感器能否替代相电流测量？不能直接替代，必须满足 PWM 同步重构条件，而不只是测到平均功率。[S15]

<a id="q059"></a>
### Q059. 什么条件下能用两相推第三相？

**参考回答：**对无中性线、忽略漏电和高频寄生电流的三线制电机，端口瞬时电流满足 $i_a+i_b+i_c=0$，可算 $i_c=-i_a-i_b$。两路数据必须对应足够接近的时间、正确极性和有效采样状态。

若两路顺序采样间隔较长，电流斜率会引入误差；若存在对地漏电或故障，则关系偏差本身可能是诊断信息。重构得到的第三相不能再作为独立传感器来证明“三相和为零”。

**易错点：**用数学重构后天然为零的残差去做传感器一致性诊断。

<a id="q060"></a>
### Q060. 为什么不能在 PWM 任意时刻采电流？

**参考回答：**开关瞬间有振铃、共模冲击、二极管恢复和运放恢复，采样值可能偏离真实相电流。某些拓扑在某些开关状态根本没有目标相的有效测量路径。

应把 ADC 采样保持窗口放在已知导通状态内，并为消隐、前端建立和采样保持预留时间。数字滤波不能把根本无效或已削顶的样本恢复成真实电流。

**工程落点：**把桥臂状态、模拟输出和 ADC 触发一起观察，验证最差占空比下仍有有效窗口。[S15]

<a id="q061"></a>
### Q061. 什么是采样盲区？为什么高占空比/窄脉冲更困难？

**参考回答：**当某个可用于测量的导通区间太短，或两个有效矢量之一接近零时，前端尚未稳定就必须切换，无法获取可靠样本。单电阻在某些扇区边界和小电压区域尤其需要处理有效矢量时间不足。

方案包括改变采样相、移动触发、限制占空比、相移/脉冲扩展、利用预测或改变调制。每种方法都可能改变输出电压、噪声或模型误差。

**易错点：**只按“占空比小于 95%”设置一个固定上限，却不验证不同扇区、电流方向和温度下的实际建立时间。

<a id="q062"></a>
### Q062. 如何核算采样窗口的时间预算？

**参考回答：**可先写必要约束：

$$
T_{valid}>T_{blank}+T_{settle}+T_{acq}+T_{margin}
$$

消隐覆盖不可信开关瞬态，建立时间保证前端达到目标误差，采样时间保证 ADC 保持电容充电。ADC 转换本身未必都要在同一有效模拟窗口内完成，但必须在控制读取与下一任务冲突前完成。

参数来自真实带宽、压摆率、源阻抗、输出摆幅和芯片时序；不能只用运放增益带宽积替代完整建立时间评估。

**追问：**为什么 RC 加大后噪声低了，控制反而差？有效动态信号被延迟或衰减，前端也可能不能及时建立。

<a id="q063"></a>
### Q063. 采样电阻、增益、偏置和量程怎么选？

**参考回答：**先定义连续、峰值和保护电流，再根据可用 ADC 电压范围选择 $R_sG$：

$$
V_{out}=V_{bias}+I R_sG
$$

预留正负电流、输出摆幅和过冲裕量，再核算电阻 $I_{rms}^2R_s$ 发热、脉冲能力、温漂、Kelvin 接法以及运放输入共模和恢复特性。量程过大牺牲小电流分辨率，过小会在正常瞬态削顶。

**工程落点：**把量化、零偏、增益、参考电压、温漂和噪声列为误差预算。Q187 给出量程计算示例。

<a id="q064"></a>
### Q064. 怎么做零偏、增益和极性校准？

**参考回答：**零偏校准必须在确认没有真实相电流、前端供电已稳定的条件下采集；对异常值做筛选并记录温度。增益校准使用已知电流或可信标准仪器，在多个正负点拟合比例和偏置。

极性与相映射要通过受控激励或外部电流测量核对，不能仅凭“闭环没报错”判断。在线更新偏置必须保证观测条件，不应把实际低频电流误当成漂移消掉。

**追问：**校准失败怎么办？禁止进入正常运行，给出具体失败原因和原始读数；不要静默使用全零默认参数。[S06]

**本章核对与延伸：**三种采样拓扑、窗口与模拟前端的核心比较见 TI [S15]；ADC 校准见 [S06]。公式和排查建议按本文设定整理。

<a id="chapter-09"></a>
## 第9章 MCU、同步与实时执行｜P0｜Q065—Q072

<a id="q065"></a>
### Q065. 怎样用定时器硬件触发 ADC？

**参考回答：**由 PWM 定时器的比较/更新事件经芯片触发链路启动 ADC，必要时使用多 ADC 同步采样；数据完成后通过中断或确定时序的数据搬运进入控制计算。这样采样时间由硬件定义，而不依赖普通任务何时获得 CPU。

具体要核对触发沿、计数方向、序列长度、采样完成时刻与 ADC 忙状态；DMA 完成时间是数据可用时间，不一定等于模拟采样时间。

**自测要求：**能画出某颗 MCU 的“定时器事件→ADC 采样→计算→比较寄存器→实际输出”链路。[S05]

<a id="q066"></a>
### Q066. 一次 FOC 周期内怎样安排采样、角度和更新？

**参考回答：**通常先在有效窗口取相电流，同时获得带时间戳的位置；将位置换算到电流采样时刻用于 Park；随后计算电流误差、PI/解耦、限幅，再把角度预测到电压实际作用时刻进行反 Park，最后在指定边界生效新占空比。

```text
有效导通窗口 → 电流采样 → 数据完成 → 控制计算 → 写影子寄存器
                  ↑                                ↓
         对齐到采样时刻的角度               规定更新边界 → 电压生效
```

**易错点：**所有地方使用同一个“刚读到的角度”，却忽略编码器传输和 PWM 更新的不同延迟。Q190 给出误差量级。

<a id="q067"></a>
### Q067. 预装载/影子寄存器和更新事件为什么重要？

**参考回答：**直接改变正在比较的寄存器，可能在当前周期造成非预期窄脉冲或提前/推迟边沿。影子寄存器让软件先写下一组值，再由硬件在预定边界一致装载。

但还要确认芯片的影子机制覆盖哪些通道、更新事件是否可能被其他操作提前触发，以及计算是否赶得上装载截止时刻。影子寄存器不是自动解决所有同步问题的魔法。

**追问：**错过一次更新会怎样？通常等效为多保持一个周期旧指令，增加延迟；系统应检测、统计并按严重程度处理。

<a id="q068"></a>
### Q068. 三相占空比怎样一致更新？

**参考回答：**优先使用同一同步定时器组与预装载机制，把三相下一周期值全部写完后在同一硬件事件提交。多定时器时需要明确主从同步、共同装载或厂商支持的全局装载机制。

保护配置、互补极性、死区和最小脉宽也要同步考虑。紧急停机应由独立硬件路径覆盖正常更新机制，不能等待三次软件写寄存器依次完成。

**工程落点：**对最大/最小指令、方向切换和故障瞬间做边沿检查，确认不存在单相新值、两相旧值的混合周期。

<a id="q069"></a>
### Q069. 电流环、通信、日志和参数保存怎么分优先级？

**参考回答：**快速硬件保护优先独立实现；电流采样与控制执行走确定时序高优先级；速度/位置按所需周期运行；通信处理、日志传输、温度管理和非易失保存放在较低优先级。

RTOS 可以负责管理任务，但不能仅靠普通线程延时保证精确采样。控制 ISR 内避免阻塞、动态分配、格式化打印和不可控临界区；Flash 写入是否停顿取指也要针对芯片验证。

**易错点：**认为 DMA 不占 CPU 就没有任何时序影响，忽略总线争用、缓存维护和 DMA 中断。[S05]

<a id="q070"></a>
### Q070. 怎样测最坏执行时间和抖动？

**参考回答：**使用周期计数器、硬件计时或 GPIO 标记测量执行窗口，并覆盖不同分支、保护路径、缓存状态、通信负载和多轴并发。记录最大值、分布与截止期错失，不只看平均 CPU 百分比。

软件测到的最大值只是在已覆盖测试中的最大值，不是数学证明的绝对 WCET；高可靠项目还需分析任务调度、抢占、存储访问和最长临界区。

**工程落点：**明确区分 ISR 执行时间、采样到输出延迟、周期抖动和数据年龄，四者不能混为一个“延迟”。

<a id="q071"></a>
### Q071. FPU、CORDIC、查表和定点怎样选择？

**参考回答：**FPU 便于浮点实现，但精度、指令时延和上下文保存由架构决定；CORDIC 可加速特定三角/向量运算，但有接口开销和格式约束；查表速度可控但占存储并有插值误差；定点需要显式处理范围、缩放和饱和。

应先用目标 MCU 编译并测量热点，再选择方案。硬件模块快不等于完整调用链更快，浮点源码里无意使用 double 也可能显著改变性能。

**追问：**怎样验证替换实现没改变控制？比对边界误差、数值范围、运行时间，再做闭环同工况测试。

<a id="q072"></a>
### Q072. 一颗 MCU 控四台电机，要核算什么？

**参考回答：**逐轴列出六路互补开关资源、死区/故障输入、ADC 通道与同时性、位置接口、运放/比较器、控制周期和数据缓冲。共享资源需做时间表，检查最差负载下是否能按时采样和提交输出。

还要考虑编码器总线争用、母线纹波、相移 PWM、多轴同步，以及一轴故障对其他轴的影响。计算能力、模拟资源、保护隔离和软件可维护性缺一不可。

**工程落点：**提交“资源表＋最坏周期预算＋故障矩阵”，比只说主频与 PWM 数量更能证明方案可行。

**本章核对与延伸：**硬件部署与多速率调度见 [S05]、[S09]、[S10]。具体触发与寄存器语义必须查所用 MCU 参考手册。

<a id="chapter-10"></a>
## 第10章 编码器、霍尔与旋变｜P0｜Q073—Q080

<a id="q073"></a>
### Q073. 增量与绝对编码器上电后知道什么？

**参考回答：**增量编码器输出位移变化，普通 ABZ 方案上电后通常不知道绝对机械位置，需寻索引、回零或其他初始化。单圈绝对编码器提供圈内位置，但不能无条件知道上次掉电后已经转了多少圈；多圈能力需由具体器件和供电/记忆机制实现。

对电机换相，需要电角度；对机构定位，可能还需要多圈输出位置，两者需求不同。

**易错点：**把上电有一个角度读数等同于整个机械机构已经完成回零并可安全运动。[S06]

<a id="q074"></a>
### Q074. ABZ、SPI、SSI/BiSS 和旋变有什么特点？

**参考回答：**ABZ 适合硬件计数，需考虑电平、差分传输和边沿质量；SPI 易于 MCU 接入，但需看帧延迟、流水线与诊断；SSI/BiSS 是常见串行位置接口体系，具体时序和 CRC 能力看协议版本与器件；旋变通过激励与正余弦响应解算角度，需模拟调理或 RDC。

选型还看线长、共模干扰、更新时间、绝对精度、机械安装和故障检测，不是只比较输出位数。

**追问：**SPI 时钟提高一倍，角度延迟就减半吗？未必，传感器内部采样和数字滤波延迟可能占主导。

<a id="q075"></a>
### Q075. 分辨率、精度、重复性和更新率有什么区别？

**参考回答：**分辨率是最小输出刻度；精度是结果接近真实位置的程度；重复性描述重复到同一位置时的离散性；更新率是新结果产生速度。通信频率还可能高于真正内部更新率。

例如高位数输出可以很细，但磁钢偏心、谐波非线性或安装误差仍造成较大角度误差。高分辨率也不保证低延迟或良好高速相位表现。

**工程落点：**评估编码器时至少分开记录静态角误差、速度噪声、动态延迟和异常诊断能力。

<a id="q076"></a>
### Q076. 编码器零点、电角度零点和机械回零是同一个吗？

**参考回答：**编码器零点是传感器定义的参考；电角度零点是转子磁链相对绕组坐标的参考；机械回零是机构工作坐标的参考。它们之间可以通过偏置和传动关系转换，但不是天然相同。

更换编码器、调整磁钢或改相线后，电角度偏置可能变化；更换减速器和机构安装后，机械零位也可能变化。

**追问：**保存一次电角偏置就能终身免校准吗？必须保证装配关系、方向与电机身份不变，并有参数版本与有效性校验。

<a id="q077"></a>
### Q077. 怎样标定相序、方向、极对数和电角偏置？

**参考回答：**先核对接线与有效电流极性，在限流和机械防护下施加已知旋转场/测试激励，观察机械转角方向与电角变化次数，从而确认方向和极对数。再用受控对齐或完整标定序列估计磁链零位偏置。

受摩擦、负载和齿槽影响，单次强行对齐可能存在误差，可通过双向多点采样和一致性检查改善。标定过程需防堵转发热和机构撞限位。

**工程落点：**保存校准结果、条件、校验码与电机/编码器身份；失败时不给正常运行许可。[S06]

<a id="q078"></a>
### Q078. 角度跨越 0/2π 怎么算速度和连续位置？

**参考回答：**若相邻采样之间真实转角小于半圈，可用最短环绕差：$\Delta\theta=\operatorname{wrap}_{[-\pi,\pi)}(\theta_k-\theta_{k-1})$，再以 $\Delta\theta/\Delta t$ 算速度，累加得到连续位置。

半圈条件是关键：掉帧或速度过高导致跨越超过半圈时，最短差会歧义，需额外计数、速度预测或更快采样。对计数器也应使用明确模数的回绕算法。

**易错点：**不检查时间戳，就在丢包后继续使用固定 Ts；或者在 ±π 点没有一致的边界约定。

<a id="q079"></a>
### Q079. 编码器延迟在高速下造成多大误差？

**参考回答：**恒速近似下，$\Delta\theta_e\approx\omega_e T_d=p\omega_mT_d$。极对数越多、转速越高，同样微秒延迟造成的电角偏差越大。

应分别考虑传感器采样、内部滤波、串行传输、软件读取、控制计算和 PWM 生效时间，并用时间戳或预测把角度对齐到所需时刻。加速度高时恒速补偿本身也有误差。

**工程落点：**Q190 的 7 对极、6000 rpm、20 μs 示例约为 5.04° 电角度；这说明不能仅以接口“几微秒很快”判断影响。

<a id="q080"></a>
### Q080. 怎样检测编码器异常？

**参考回答：**结合协议 CRC/错误位、更新计数或时间戳、机械速度与加速度边界、连续性、双传感器一致性及电机电流/观测器残差。CRC 正确只能证明帧校验通过，不证明机械安装正确或数据足够新。

对于短暂失效，可根据系统风险选择短时预测、降额或立即停机；任何预测继续运行都需要严格时间上限和可信边界。磁钢偏心通常表现为周期性非线性，不能简单当作随机噪声滤掉。

**追问：**如何发现“数值一直合法，但传感器冻结”？检查真实更新时间、动态响应和冗余物理一致性。

**本章核对与延伸：**位置传感与标定见 [S06]；实际驱动器编码器配置与双反馈示例见 [S12]。接口电气与延迟最终以器件文档为准。

<a id="chapter-11"></a>
## 第11章 无位置传感器控制｜P1；无感岗位 P0｜Q081—Q088

<a id="q081"></a>
### Q081. 无感 FOC 到底省掉什么？

**参考回答：**通常省掉机械位置/速度传感器，通过电流、电压及电机模型估计转子角度和速度。多数方案仍需要相电流和母线电压，某些方案用占空比重构相电压；“无感”不是“无测量”。

估计器与电流环构成耦合系统：角度估错影响控制，错误控制又改变观测输入。应设置启动、可信接管、失锁检测和回退策略。

**易错点：**认为上一个无感示例就能覆盖所有电机、零速、弱磁与满负载。必须说明所用观测器的适用速度、电机凸极性和参数条件。[S07]

<a id="q082"></a>
### Q082. 反电动势估计为什么低速、零速困难？

**参考回答：**速度相关反电动势随转速减小，在零速理想情况下没有可利用的旋转反电动势。此时电阻误差、死区压降、偏置和噪声相对更大，基于它的角度估计条件恶化。

这不是所有无感方法的共同绝对结论。可利用磁凸极性或饱和特征的注入方法提供额外信息；也可以在启动阶段使用开环电流—频率控制，再在可观测区接管。

**追问：**能否仅靠滤波解决？滤波不能创造原本缺失的角度信息，过度滤波还会增加延迟。[S07][S26]

<a id="q083"></a>
### Q083. SMO、磁链观测器和扩展反电动势观测器有什么区别？

**参考回答：**滑模观测器根据电流模型与电流估计误差构造校正项，再从等效反电动势估计角度；磁链观测器从电压和电流关系估计磁链，再分离需要的转子磁链；扩展反电动势法把凸极电机中的相关动态项组织成可估计的扩展电势。

比较应看模型假设、参数敏感性、低速能力、噪声、带宽、离散实现及计算量。不能只说“SMO 鲁棒、其他不鲁棒”，而不指出针对哪种不确定性。

**工程落点：**同工况下记录角度误差、速度误差、负载突变、参数偏差与失锁边界，再作选择。[S23][S24][S25]

<a id="q084"></a>
### Q084. 滑模抖振怎么来？滤波为什么带来相位误差？

**参考回答：**理想滑模切换项常含符号函数，有限采样、量化与开关实现会使估计值围绕滑模面反复切换。可用边界层、连续近似、合适增益或更高阶结构缓解，但会改变误差与收敛特性。

从切换项提取反电动势时常需滤波；滤波器对旋转电势引入频率相关相位滞后，最终形成角度误差。补偿需要依据实际离散滤波器及速度范围，而不是任意加一个固定角度。

**追问：**增益越大越好吗？过大可能放大噪声、离散抖动并恶化数值稳定性。[S23]

<a id="q085"></a>
### Q085. PLL 在角度/速度估计中做什么？

**参考回答：**PLL 根据估计的正交电势/磁链与内部角度之间的相位误差，调节内部角速度，再积分得到连续角度。它可以平滑角度并同时输出速度，但不是独立于上游信号质量的“真值生成器”。

带宽高时跟踪动态快，但噪声和异常更易传入；带宽低时速度平滑，但加速和负载突变可能出现较大相位滞后。要检查启动捕获范围、积分限值、方向和低幅值输入处理。

**工程落点：**不要只看速度曲线是否平滑，还要看相位误差与失锁指标，以及电流环是否因此额外耗电。

<a id="q086"></a>
### Q086. I/F 启动和闭环接管如何避免转矩突变？

**参考回答：**I/F 启动在给定旋转频率下控制电流幅值，提供受限转矩并逐渐提高电角频率，随后等待观测器满足幅值、速度和连续一致性条件。接管时需要把估计角度、速度和控制器内部状态与开环轨迹协调起来。

可采用角度差渐变补偿、参考斜坡与积分状态预置，避免突然换坐标导致 Id/Iq 跳变。直接在某固定转速切换而不验证可信度，会对负载和温度敏感。

**验收建议：**在不同初始位置、惯量和负载下测最大电流、接管角度差、反转量和成功率。[S07]

<a id="q087"></a>
### Q087. 高频注入为什么能帮助低速定位？

**参考回答：**向电机施加受控高频激励，观察不同方向的电流响应，利用凸极性或饱和产生的方向相关差异估计转子磁轴。即使机械静止，激励仍能形成可测响应。

但它依赖足够可辨识的各向异性和合适的采样/解调，可能增加噪声、损耗与转矩纹波。某些方法首先只确定磁轴而有 180° 电角极性歧义，还需额外辨极。

**易错点：**看到一个“初始位置估计”演示，就把它当作已验证的全转速、全负载零速力矩闭环。要区分初始辨识与连续跟踪能力。[S26]

<a id="q088"></a>
### Q088. 电阻变化、死区、重构误差和负载突变如何影响观测器？

**参考回答：**观测器将输入电压与模型预测进行比较；若所用电压不是电机端真实平均电压，误差会被错当成反电动势或磁链变化。低速时 Rs 和器件压降误差尤其显著，高速时角度延迟与电压饱和影响增大。

负载突变会改变电流和速度动态，检验模型、观测器带宽及接管逻辑。应使用受限、可信的参数更新和失锁检测，而不是无限提高增益。

**工程落点：**分别注入 Rs、Ld/Lq、磁链、母线测量和延迟误差，形成观测器的鲁棒性测试矩阵。[S23][S24][S25]

<a id="chapter-12"></a>
## 第12章 MTPA、弱磁与高速控制｜P1/P2｜Q089—Q096

<a id="q089"></a>
### Q089. MTPA 优化的是什么？

**参考回答：**Maximum Torque Per Ampere 以电流幅值为约束提高转矩，或在给定转矩下最小化所需电流幅值。对本文线性模型，可以把转矩方程与 $i_d^2+i_q^2$ 的约束结合，求最优 Id/Iq 分配。

这通常有利于降低铜耗，但不是自动使整个驱动系统总损耗最小；铁耗、逆变器开关损耗、温度和机械损耗不一定由该目标覆盖。

**追问：**MTPA 是提高峰值转矩还是提高效率？它的数学目标是转矩/电流关系，其他收益要结合约束和损耗模型验证。[S03]

<a id="q090"></a>
### Q090. 为什么 IPMSM 的最优 Id 可能为负？

**参考回答：**常见 IPMSM 有 $L_q>L_d$，因此转矩中的 $(L_d-L_q)i_di_q$ 在正 Iq、适当负 Id 时为正。把一部分电流分配到负 d 轴，可获得额外磁阻转矩，在某些工作点比全用 q 轴更有效。

最优值由磁链、两轴电感和目标转矩决定。强饱和或交叉饱和时，固定参数解析关系可能偏离真实最优轨迹。

**易错点：**把所有 PMSM 都设一个固定负 Id；对近似非凸极电机，在低速可能只增加铜耗而不增加相应转矩。[S03]

<a id="q091"></a>
### Q091. 基速是什么？为什么高速受电压限制？

**参考回答：**在指定母线、限流和参考策略下，当保持目标转矩所需电压达到逆变器可用电压边界时，对应的速度可称这一条件下的基速。它不是完全独立于负载和供电的固定物理常数。

随速度升高，$\omega_e\psi_f$ 和耦合电压增加，PI 可用来改变电流的剩余电压变小。即使电流没有超过额定值，也可能无法跟踪目标电流。

**追问：**母线从 48 V 降到 40 V 后基速会怎样？通常可用电压降低，必须重新评估工作包络，而不能保持原有峰值速度承诺。[S21]

<a id="q092"></a>
### Q092. 弱磁控制的目标与代价是什么？

**参考回答：**对适用 PMSM，通过负 d 轴电流降低等效 d 轴磁链，减小高速电压需求，从而在母线不变时扩展转速范围。它不是让永磁体永久变弱，而是运行时用定子电流抵消部分磁链。

负 Id 占用总电流容量，通常减少可分配 Iq，并增加损耗和温升；还必须遵守退磁电流、磁钢温度和机械最高转速边界。

**易错点：**把弱磁理解成免费增加功率，或把不可逆退磁误当成正常控制效果。[S21]

<a id="q093"></a>
### Q093. 电流限制圆与电压限制椭圆怎样写？

**参考回答：**电流幅值约束是：

$$
i_d^2+i_q^2\le I_{max}^2
$$

稳态且暂时忽略 Rs、动态项时，电压约束为：

$$
(\omega_e L_q i_q)^2+
\left[\omega_e(L_d i_d+\psi_f)\right]^2\le V_{max}^2
$$

在 Id/Iq 平面形成随速度变化的椭圆。真实 Rs、参数非线性和动态项会改变边界。

**自测要求：**能解释速度升高时电压允许区域为什么收缩，以及最优工作点为什么可能从 MTPA 轨迹移动到电压边界。[S03][S21]

<a id="q094"></a>
### Q094. MTPA、弱磁和 MTPV 各适用什么区间？

**参考回答：**电压裕量充足时可按 MTPA 分配电流；达到电压边界后，需要沿满足电压/电流约束的轨迹进行弱磁；在适用电机和高速约束区，可使用最大转矩每电压 MTPV 轨迹进一步选择工作点。

不是每台电机或驱动器都会进入完整的三个区域。区域划分依赖凸极性、磁链、限流、机械限速和母线能力。

**易错点：**把 MTPV 当成所有电机达到某固定 rpm 就开启的模式。应先画出该电机的约束图。[S03]

<a id="q095"></a>
### Q095. 怎样协调弱磁、转矩要求和限幅？

**参考回答：**参考生成器根据转矩要求和当前母线/速度给 Id/Iq，再施加电流圆、退磁边界、温度和功率限制。电流控制器保留抗饱和；如果使用电压裕量反馈调节 Id，需控制该调节环的带宽和恢复过程。

加减速、母线下跌和转矩阶跃可能同时触发多个限制，应明确优先级和状态转移，并处理退出弱磁时 Id/Iq 的连续性。

**追问：**进入弱磁后角度反馈丢失怎么办？高速能量和电压条件更严苛，必须使用事先验证的故障策略，而不是沿用静止时简单关断的假设。

<a id="q096"></a>
### Q096. 解析公式与查表方案如何选？

**参考回答：**固定参数解析式代码紧凑、可解释，适合作为基线；查表可以覆盖饱和、温度和实测效率，但需要高质量标定、插值连续性、边界和存储管理。也可以采用解析初值加实测修正。

表格应带适用电机版本、温度、单位和电流定义；查表越界时要有安全退化策略。在线辨识不能绕过同样的有效性检查。

**工程落点：**拿独立测试点而非标定数据本身验证转矩误差、损耗和控制稳定性，防止“在已测点看起来很好”。[S08]

## 第13章 功率级、栅极驱动与 PCB｜P0｜Q097—Q104

<a id="q097"></a>
### Q097. 画出三相逆变桥并说明电流路径。

**参考回答：**三个半桥共用母线，每个半桥含高侧、低侧开关及其反向导电路径。电机相端接在桥臂中点。开关状态决定端口电压，而电流方向由电机状态决定，二者不是一一同号。

```text
              DC+
               │
         ┌─────┼─────┐
         QAH   QBH   QCH
         │A    │B    │C ──→ 三相电机
         QAL   QBL   QCL
         └─────┼─────┘
               │
              DC-
```

**追问：**PWM 全关时是否一定没有电流？不一定，电感电流与被拖动电机的反电动势仍可能通过二极管等路径续流或回灌。

<a id="q098"></a>
### Q098. MOSFET 选型为什么不能只看 RDS(on)？

**参考回答：**还要看 VDS 裕量、实际栅压与温度下的导通电阻、Qg/Qgd、输出电容、反向恢复、SOA、封装寄生、热阻、脉冲能力和可靠性。数据表首页的最大电流通常依赖理想壳温或封装条件，不能直接作为 PCB 连续能力。

低 RDS(on) 常伴随不同电荷和电容，可能降低导通损耗却增加开关损耗。总选择应对应母线、相电流、PWM 频率、冷却和故障能量。

**工程落点：**分别建立导通、开关、反向导电和驱动损耗估算，再用实测热与波形修正。

<a id="q099"></a>
### Q099. 栅极电荷、驱动电流、栅电阻和损耗怎样关联？

**参考回答：**近似平均栅极供电电流与 $Q_gf_{sw}$ 有关，而开关速度取决于平台电荷、驱动峰值电流、内外电阻及寄生参数。减小栅电阻可能加快切换并降低部分交叠损耗，却增加振铃、EMI 与误导通风险。

开通/关断可采用不同电阻，并结合实际 VGS、VDS 与电流波形评估。驱动器标注的峰值电流不是任何条件下都能持续提供的恒定电流。

**易错点：**只按 Qg/总时间得到一个驱动电流，就忽略米勒区、供电跌落和布局电感。

<a id="q100"></a>
### Q100. 什么是米勒平台和寄生误导通？

**参考回答：**开关期间，栅极驱动有一段主要改变漏源电压、VGS 相对停滞的区间，称米勒平台。另一开关的快速 dv/dt 可通过栅漏电容向关断开关栅极注入电流，若关断回路阻抗大，可能抬高 VGS 导致误导通。

处理手段包括低电感回路、足够下拉能力、合适栅阻、Kelvin 源极、必要的米勒钳位或负栅压，并受器件 VGS 额定范围约束。

**工程落点：**测量必须是对应开关的栅源差分电压，不是随意测栅极对系统地。[S16]

<a id="q101"></a>
### Q101. 自举高侧供电有什么限制？

**参考回答：**自举电容通常在开关节点较低时充电，高侧导通时给驱动器供电。持续长时间高侧导通会消耗电荷，电压可能跌入欠压锁定，因此高占空比和静态 100% 高侧状态需要刷新条件或其他供电方式。

可按每周期所需栅极电荷、驱动静态消耗、漏电和允许压降估算电容，再考虑二极管、启动、温度、直流偏压降容及最短充电时间。

**追问：**换更大电容就一定支持永久 100% 吗？不行，有持续消耗就需要充电来源；可能要电荷泵或独立高侧电源。

<a id="q102"></a>
### Q102. 死区怎么确定？过长、过短各有什么问题？

**参考回答：**死区防止同桥臂上下开关因关断延迟、传播不匹配、温度和寄生效应重叠导通。应依据最差关断/开通链路及实测裕量确定，而不是套一个所有 MOS 都适用的固定数。

死区过短可能直通；过长会增加反向导电损耗并引入与电流方向有关的电压误差，影响低速和小电流控制。补偿需要知道电流方向，在过零附近应防抖动。

**工程落点：**核对 MCU 死区、驱动器内部死区和实际传播延迟的叠加关系，不能只看一个寄存器。

<a id="q103"></a>
### Q103. 母线、功率、栅极和采样回路怎么布置？

**参考回答：**先识别大 di/dt 换流回路并减小面积，把合适的高频母线去耦靠近桥臂；栅极驱动回路短、回流清晰，必要时用 Kelvin 源。采样电阻采用 Kelvin 引出，远离开关节点与大电流公共阻抗。

地平面和单点连接策略要结合器件推荐、回流频率和隔离边界，不能机械认为“把模拟地割开就一定干净”。跨分割走线可能使回流绕远，反而增加耦合。

**自测要求：**在 PCB 上标出功率换流、驱动和测量三个闭合回路，而不仅指出“粗线是大电流”。[S16]

<a id="q104"></a>
### Q104. 怎样分析振铃、VDS 尖峰、地弹和采样干扰？

**参考回答：**先确认测量方法和探头寄生，避免把长地线引起的振铃当成电路真实行为。再把现象对应到寄生 L/C、di/dt、dv/dt 与共阻抗耦合。

可从缩短回路、改善去耦、调整开关速度、阻尼/吸收网络和屏蔽等方向逐一验证。TVS、RC/RCD 等器件必须核对触发/钳位、电压公差、寄生与能量，不能只按标称耐压随便加。

**工程落点：**保存整改前后同带宽、同探头、同负载波形，同时检查温升和效率，防止“尖峰小了却过热”。[S16]

<a id="chapter-14"></a>
## 第14章 保护、状态机与再生制动｜P0｜Q105—Q112

<a id="q105"></a>
### Q105. 上电到运行应该有哪些状态与准入条件？

**参考回答：**一个复习用结构是 `POWER_OFF → INIT → SELF_TEST → CALIBRATION → READY → RUN → CONTROLLED_STOP`，任意状态可按规则进入 `FAULT`。具体名称可变，但每个状态要有进入条件、允许动作、退出条件和失败处理。

进入 RUN 前至少确认电源稳定、驱动器无故障、采样可信、校准有效、位置/估计有效、命令未超时、参数范围合法以及机械许可满足。

**易错点：**只有一个 `motor_enable` 布尔值，导致校准、清故障和运行命令互相穿透。附录 B 给出状态迁移评审模板。

<a id="q106"></a>
### Q106. 硬件过流与软件限流分别负责什么？

**参考回答：**软件电流环和限流负责正常控制及较慢过载管理；比较器、驱动器保护、去饱和检测或定时器刹车输入等硬件路径处理比软件响应更快的危险事件。还需核对故障点能否被当前传感器看见。

硬件阈值不应等同于正常目标电流；它需要包含传播延迟、消隐、器件短路承受能力和噪声裕量。保护后由软件记录原因并执行锁存/恢复管理。

**易错点：**认为 20 kHz 采样意味着所有亚微秒到微秒级过流都一定能被软件捕获。

<a id="q107"></a>
### Q107. 过压、欠压、过温、堵转、超速、缺相和反馈异常怎么处理？

**参考回答：**为每种故障定义测量源、阈值、持续时间、迟滞、严重等级、即时动作和恢复条件。过压涉及母线能量，欠压涉及驱动欠压与控制能力，温度可先降额，堵转需要区分正常零速力矩与异常不能运动。

缺相可由驱动状态、相电流与模型残差判断；反馈异常需要考虑是否允许短时预测。不同故障不应统一处理为“清零速度并继续运行”。

**工程落点：**建立故障矩阵并进行受控注入，验证从检测到实际关断/制动的完整链路。

<a id="q108"></a>
### Q108. 哪些故障锁存，哪些可以自动恢复？

**参考回答：**应由风险和失效机理决定。短时可恢复通信或电源异常可能允许有条件恢复；功率器件疑似短路、严重过流、校准失效等不宜未经检查自动反复上电。

恢复必须确认根因消失、母线/温度满足条件、传感器恢复可信、输出被禁用且上层重新给出有效许可。清除故障位不等于允许执行之前缓存的运动命令。

**易错点：**统一定时一秒清故障重试，或者重启 MCU 后丢失故障锁存和危险状态。

<a id="q109"></a>
### Q109. 失联、看门狗复位和 MCU 掉电时如何进入预定状态？

**参考回答：**失联由命令年龄和超时监督处理，选择受控减速、保持、降额或关断，取决于机构风险。复位和掉电时 GPIO 会经历默认态，功率级必须靠硬件上拉/下拉、驱动使能与保护设计保持预定状态。

看门狗只能发现某些软件失活，不能替代电流保护和安全功能；系统还应防止异常程序仍周期喂狗。复位恢复应重新检查校准、命令和机械条件。

**追问：**输出默认全关就是所有系统最安全吗？对重力负载不一定，还要考虑抱闸、惯性与再生路径。

<a id="q110"></a>
### Q110. 减速时母线为什么升压？电源/电池能吸收吗？

**参考回答：**电机在制动中把机械能转回电能，若母线吸收能力不足，电容储能增加而升压。电容能量变化为 $\Delta E=\tfrac12C(V_2^2-V_1^2)$。普通台式电源往往不能按负电流工作，电池也受充电允许电流、SOC、温度和 BMS 状态限制。

BMS 突然断开可能让原有吸能路径消失，所以“接电池就一定不会过压”是错误假设。可采用允许回馈的电源、受控制动回路或降低减速度等策略。

**工程落点：**把最坏惯量、速度、制动时间和电源状态一起核算。[S12]

<a id="q111"></a>
### Q111. 制动电阻怎样算瞬时功率、能量和重复能力？

**参考回答：**先算要处理的动能/势能变化，例如纯转动 $\Delta E=\tfrac12J(\omega_1^2-\omega_2^2)$，再扣除能够可靠计入的其他能量路径。电阻接通时约有 $P=V^2/R$，脉冲能量为 $\int Pdt$，重复周期决定平均热负荷。

阻值过大可能瞬时吸能不足；过小可能超过斩波器电流。还需核对电阻脉冲曲线、外壳温度、风道、开路检测以及开关器件 SOA。

**易错点：**只按平均瓦数选电阻，忽略短时间峰值能量和连续重复刹车。[S12]

<a id="q112"></a>
### Q112. STO、受控停车和机械抱闸有什么区别？

**参考回答：**STO 的目标是阻止驱动器向电机提供产生转矩的能量，不等于主动减速，不提供电气隔离，也不意味着母线和电机端已经无危险电压。受控停车利用可控转矩先减速；机械抱闸用于保持或制动，具体能力看设计用途。

垂直轴失去转矩可能因重力下落，需要根据风险设计减速、抱闸建立、确认和撤销转矩的顺序。普通 MCU 把 PWM 设零不能自动宣称实现经过认证的 STO。

**工程边界：**安全等级、诊断覆盖和认证是整机工程任务，面试回答应讲清功能区别，不应凭一个接口名称声称已满足标准。[S27]

<a id="chapter-15"></a>
## 第15章 工业伺服、三环与机械共振｜P1；伺服岗位 P0｜Q113—Q120

<a id="q113"></a>
### Q113. 位置、速度和转矩模式分别启用哪些环？

**参考回答：**常见级联方案中，位置模式使用位置外环、速度中环和电流内环；速度模式绕过位置环；转矩模式把转矩参考变换为电流参考，主要依靠电流闭环实现。实际也存在不同结构，需以系统框图为准。

模式切换要处理参考连续性、积分状态和限值，防止旧位置误差在重新启用时突然输出很大转矩。即便转矩模式绕过速度调节，仍应保留适当的超速和行程保护。

**追问：**电流闭环就等于实际输出转矩闭环吗？不一定，摩擦、磁链、传动效率和弹性仍可能造成偏差。[S11]

<a id="q114"></a>
### Q114. 差分、测周期和混合测速低速时怎么取舍？

**参考回答：**固定时间计数法适合脉冲较多的速度区间，低速时计数可能只有 0 或 1，量化明显；测相邻边沿时间在低速更细，但无新边沿时速度会变旧，高速还受时间分辨率限制。

混合估计或观测器可利用两者信息，必须处理无边沿超时、方向反转和计数器回绕。滤波降低噪声的同时会增加相位延迟。

**工程落点：**报告最低可用速度、速度延迟、静止漂移和反转响应，不要只在中速展示平滑曲线。

<a id="q115"></a>
### Q115. 跟随误差、稳态误差、超调和整定时间怎样定义？

**参考回答：**跟随误差是参考轨迹与实际位置/速度的时变差；稳态误差是满足稳定工况后的残余差；超调需要说明相对最终目标还是阶跃幅度；整定时间需给出允许误差带及持续判定条件。

位置精度和重复定位精度也不同。测量单位要说明电机轴或输出轴，编码器读数未必覆盖传动背隙与末端变形。

**易错点：**只报告“误差 0.01°”，没有负载、速度、温度、测量位置和统计方法。

<a id="q116"></a>
### Q116. 速度/加速度前馈与增加反馈增益有什么区别？

**参考回答：**前馈根据期望轨迹或模型提前提供执行量，减少需要由误差推动的反馈动作；提高反馈增益则是在误差已经出现后更强地校正。理想情况下，速度前馈改善轨迹跟随，加速度对应的惯性转矩前馈减小加减速误差。

前馈依赖模型与轨迹，不能消除未知扰动，也不能绕过限流/限压。过大的反馈增益可能放大噪声或激发机械共振。

**工程落点：**先建立稳定反馈，再逐项加前馈，比较同轨迹误差和峰值电流，而不是把前馈当成重新调高增益。[S11]

<a id="q117"></a>
### Q117. 梯形速度与 S 曲线轨迹有什么区别？

**参考回答：**梯形速度限制速度和加速度，但加速度在分段交界处可能突变；S 曲线进一步限制加加速度 jerk，使加速度变化更平滑，有助于降低激励高频机械模态的程度。

代价可能是相同距离和约束下的运动时间变化，且短距离轨迹不一定出现完整匀速段。实时改目标还要保证位置、速度和必要的加速度连续。

**追问：**轨迹足够平滑就不需要闭环吗？仍需要反馈处理负载、模型误差、摩擦和扰动。

<a id="q118"></a>
### Q118. 两惯量、共振和反共振如何影响带宽？

**参考回答：**电机与负载通过有限刚度联轴器、皮带或减速机构连接，可以近似为两个惯量加弹性/阻尼。系统频率响应会出现共振与反共振，电机端运动不再总等于负载端运动。

若速度/位置环跨越这些模态时没有足够相位裕量，增益提高可能导致振荡。可通过机械改进、传感器位置选择、滤波和控制结构处理。

**工程落点：**先测频率响应与模态随负载变化的范围，再决定带宽；不能仅靠“噪声一响就把 P 调小”完成整定。

<a id="q119"></a>
### Q119. 陷波、低通和扰动观测器分别解决什么问题？

**参考回答：**陷波在特定频段衰减，可抑制已识别的机械共振；低通广泛衰减高频噪声，也会带来延迟；扰动观测器用模型和测量估计等效扰动，再实施补偿。

任何一种都可能因模型/频率变化、延迟和非最小相位特性而受到限制。陷波中心与实际模态偏离可能效果变差；扰动估计过快可能放大测量噪声。

**易错点：**叠很多滤波器让波形好看，却不检查总相位和真实跟随性能。

<a id="q120"></a>
### Q120. 背隙、摩擦和弹性怎样影响定位？

**参考回答：**背隙在换向时形成输入位移不能立即传到输出的区间；静摩擦会造成起动门槛和小幅黏滑；库仑摩擦与速度符号有关；弹性使负载随转矩产生形变并引入模态。

提高积分可以积累足够力克服摩擦，却可能形成低速爬行或极限环。补偿需要实验和物理边界，双编码器、机械预紧及更好传动设计有时比增加算法更直接。

**工程落点：**分别做双向定位、低速匀速、负载阶跃和不同温度实验，避免只在单向空载行程上宣称精度达标。

**本章核对与延伸：**级联控制、前馈、轨迹和输入滤波的具体实现示例见 [S11]；机械模型与辨识入口见 [S08]。机械调试部分为通用分析框架，不是所有系统共用的参数建议。

<a id="chapter-16"></a>
## 第16章 机器人关节与力矩控制｜P1；机器人岗位 P0｜Q121—Q128

<a id="q121"></a>
### Q121. 电流估算转矩为什么不等于输出端实际转矩？

**参考回答：**电流经电机模型得到的是电磁转矩估计，实际电机轴转矩还受惯量加速、摩擦和损耗影响；再经过减速器，又受到传动效率、静摩擦、弹性、背隙和输出端惯量影响。

静止接触时，单一效率常数甚至不足以表达摩擦方向与负载传递。需要高质量输出力矩时，可加入输出端力矩传感器、弹性元件测量或经过验证的动力学估计。

**易错点：**简单使用 `输出力矩 = Iq × Kt × 减速比`，就宣称达到高精度输出力矩闭环。该式只能作为明确假设下的近似。

<a id="q122"></a>
### Q122. 单编码器与双编码器分别能观测什么？

**参考回答：**电机端编码器适合换相和高速局部反馈，但无法直接看见减速器之后的背隙与弹性误差；输出端编码器观察机构实际位置，但单独用于换相可能受分辨率、传动误差、弹性和延迟影响。

双编码器可让电机端负责换相/内环、输出端负责位置或形变观测，但两者的时间对齐、单位转换和稳定性要单独设计。不能把两个位置值直接平均当作更准确的反馈。

**工程落点：**定义两路角度到同一物理坐标的映射和差值意义，再判断差值是背隙、弹性、滑动还是传感器异常。[S12]

<a id="q123"></a>
### Q123. 减速比如何影响速度、转矩、惯量和单位？

**参考回答：**定义 $N=\omega_m/\omega_o$，刚性理想关系下 $\theta_m=N\theta_o$、$\omega_m=N\omega_o$，负载惯量反射为 $J_L/N^2$。电动方向输出转矩可近似 $T_o=\eta NT_m$。

控制器必须说明反馈和参考使用电机轴还是输出轴单位；速度 PI 若把输出端速度当成电机端速度，增益和限值都会错。减速比也不能直接把编码器绝对精度提高 N 倍，因为还存在传动误差。

**追问：**输出端高刚度控制是否会与电机端速度环冲突？需要考虑两惯量动态和环路带宽分配。

<a id="q124"></a>
### Q124. 阻抗控制与导纳控制有什么区别？

**参考回答：**阻抗控制规定运动误差对应怎样的力/转矩响应，常以位置和速度测量生成转矩指令；导纳控制根据测得的力/转矩求运动响应，再给位置/速度执行器。二者分别类似实现“机械阻抗”和它的逆关系。

选择依赖执行器可控变量、是否易回驱、力传感、接触刚度和延迟。名称相近不表示代码只是正负号或输入输出对调，离散实现与稳定性约束不同。

**工程落点：**用已知弹性/阻尼环境验证接触稳定性，不能只在自由空间看动作平滑就认定可以安全接触。

<a id="q125"></a>
### Q125. 刚度、阻尼和前馈转矩如何构成关节指令？

**参考回答：**一种常见的简化关节律是：

$$
\tau_{cmd}=K_p(q_{ref}-q)+K_d(\dot q_{ref}-\dot q)+\tau_{ff}
$$

其中 Kp 对应角刚度意义、Kd 对应阻尼意义，但这是控制律而不是证明系统已经等效为理想弹簧阻尼。电流环动态、传动、采样和饱和都会改变实际行为。

指令还应经过转矩、速度、功率、温度与变化率等限制；前馈不能绕过安全限制。位置与速度单位必须一致，尤其注意 rad 与圈、deg 的换算。

**易错点：**照抄另一个电机的 Kp/Kd 数值，却没有核对转矩单位、减速比和执行频率。

<a id="q126"></a>
### Q126. 怎样做重力、摩擦和负载补偿？

**参考回答：**重力补偿来自机构几何、质量分布和姿态；摩擦可从双向低速与不同载荷实验拟合；负载变化可通过力传感、动力学残差或参数估计处理。先确保基本反馈稳定，再逐项加入补偿。

补偿应有范围、平滑性和失效退化，尤其在速度过零时，直接使用不连续符号摩擦项可能引入抖动。质量模型不准确时也可能在某些姿态过补偿。

**工程落点：**用未参与拟合的姿态、温度和负载测试，检查跟随、静止保持、电流与接触行为是否真正改善。

<a id="q127"></a>
### Q127. 延迟、速度噪声和机械弹性为什么影响接触稳定性？

**参考回答：**接触环境可能非常刚，短时间位置误差就产生较大作用力；反馈延迟导致施加的阻尼/刚度转矩相对真实运动滞后，可能不再耗能而反向注入能量。速度噪声经阻尼增益放大，机械弹性又带来额外模态。

因此不能只提高位置刚度追求“更稳”。应结合内环带宽、滤波、采样、环境刚度、转矩限制和必要的被动性/能量约束分析。

**追问：**PC 上 1 kHz 发命令，是否等于关节有 1 kHz 接触控制带宽？不等于，还要看通信、执行器和整个闭环延迟。

<a id="q128"></a>
### Q128. 单关节故障时整机怎样协调？

**参考回答：**先判断故障关节失去的是传感、通信、可控转矩还是供电，再评估整机姿态、重力负载和相邻关节约束。可能需要受控停车、支撑转移、抱闸或停止其他轴，不能让上层继续使用过期关节状态规划。

故障消息应包含时间戳、原因和实际输出状态；整机与关节要有一致的失联与恢复协议。恢复时重新建立位置可信度与运动许可。

**工程落点：**对每种单点故障写出“谁检测、谁决策、谁执行、多久完成、怎么确认”，再做受控验证。

**本章核对与延伸：**控制模式与转矩单位示例见 [S11]，减速器与双编码器配置见 [S12]。阻抗/导纳与动力学部分为给定模型下的分析和备考展开。

<a id="chapter-17"></a>
## 第17章 CAN、CANopen、EtherCAT 与多轴同步｜P1｜Q129—Q136

<a id="q129"></a>
### Q129. CAN 与 CAN FD 有哪些关键区别？

**参考回答：**经典 CAN 单帧数据载荷最多 8 字节；CAN FD 最多 64 字节，并允许数据阶段相对仲裁阶段使用更高速率，需控制器、收发器和物理网络满足要求。CAN FD 不是把经典 CAN 波特率简单调高。

工程还要考虑协议兼容、终端、线长、支线、EMI、错误处理、数据长度编码和上层负载。经典节点与 FD 帧共网的可行性不能只依据“都是 CAN 接口”。

**易错点：**以为 64 字节载荷总比多个短帧延迟小，忽略仲裁优先级、阻塞时间和数据阶段速率。[S22]

<a id="q130"></a>
### Q130. 怎样估算多电机总线负载？

**参考回答：**对每类命令/反馈列出周期、载荷、标识符格式，再计算包含协议开销、位填充、帧间隔以及必要重发裕量的占线时间。CAN FD 仲裁和数据阶段速率不同，应分段计算。

总利用率仅反映平均资源，还需分析最高优先级和低优先级报文的最坏响应时间。调试日志和参数读写不能无预算地与实时控制竞争。

**练习：**四个关节，每轴 1 kHz 下行加 1 kHz 上行，先列 8000 帧/秒，再核算每帧实际时间；不要只用 `8000 × 8 字节` 推结论。

<a id="q131"></a>
### Q131. 仲裁、重发和错误怎样影响指令延迟？

**参考回答：**CAN 采用基于标识符的非破坏仲裁，低优先级报文可能等待。已经发送中的一帧一般不能被普通更高优先级帧中途抢占，因此长帧也影响阻塞时间。错误重发增加抖动，持续错误还可能导致节点进入错误被动或 bus-off。

控制程序必须把“消息最终可靠送到”和“在截止期前送到”分开设计。对于过期运动指令，迟到交付未必仍有价值。

**工程落点：**记录排队时间、发送时间、接收时间和执行时间，并对网络异常制定受限恢复，不让重连自动执行积压指令。[S22]

<a id="q132"></a>
### Q132. 多轴为什么需要时间戳或统一执行时刻？

**参考回答：**如果各轴收到即执行，先后到达的命令会造成相位偏差。可以让命令包含执行时刻，在各驱动器上同步时钟并提前缓存；也可在共同同步事件时采纳最新有效指令。

必须处理时钟偏差、指令迟到、序号重复、跨回绕和队列溢出。统一时间戳只有在双方时基可比较、调度可兑现时才有意义。

**易错点：**给每帧加上 MCU 自己的计数值，就宣称多个设备已同步；还要建立时钟偏移、漂移与误差边界。

<a id="q133"></a>
### Q133. PDO、SDO、对象字典和心跳分别做什么？

**参考回答：**CANopen 对象字典描述设备参数及其访问方式；PDO 用于时间敏感过程数据交换；SDO 用于参数读写等服务数据访问；心跳用于节点可用性与状态监督。具体映射、传输类型和周期由设备配置决定。

PDO 简洁但不是自动给每个变量提供确认；SDO 的请求响应也不适合无限挤占快速控制周期。心跳存在不代表运动命令未超时，更不证明相电流闭环正常。

**工程落点：**把网络状态、驱动运行状态、运动命令年龄和硬件保护状态分开管理。[S13]

<a id="q134"></a>
### Q134. CiA 402 控制字、状态字与驱动状态机是什么关系？

**参考回答：**控制字由主站请求状态动作，状态字反映驱动器当前状态及相关标志，二者通过规定的驱动状态机和转移条件关联。典型流程涉及禁止启动、准备上电、已上电、操作使能与故障等状态。

主站不能仅写一个常量就假定驱动已经使能，必须读取状态并核对条件。设备还可能有厂商扩展和可选行为，应遵循其对象字典与实现说明。

**易错点：**把 CANopen 的 NMT 节点状态与 CiA 402 功率驱动状态当成同一个状态机。[S13]

<a id="q135"></a>
### Q135. CSP、CSV、CST 中主站与驱动器分别做什么？

**参考回答：**循环同步位置、速度、转矩模式分别以位置、速度、转矩目标作为同步过程数据输入。通常主站负责轨迹/协同，驱动器按模式保留相应局部闭环；CSP 常由驱动器执行位置及更内层环，CSV 主要执行速度及电流环，CST 主要执行转矩/电流控制。

具体还看插值、前馈对象、单位与厂商实现。必须确认同步周期、命令保持、迟到处理以及模式切换行为。

**追问：**在主站实现位置环时选哪种模式？取决于分层方案和延迟预算，不能只因为名称里有“位置”就选择 CSP。[S13]

<a id="q136"></a>
### Q136. 通信同步、控制周期同步和 PWM 同步是一回事吗？

**参考回答：**通信同步解决消息与时钟组织，控制同步解决各轴何时采样/计算/采纳目标，PWM 同步解决功率开关载波相位。三者可以协同，但没有自动等价关系。

例如 EtherCAT 的分布式时钟可作为精确事件时基，应用仍需把事件接到真实采样与控制链路。多轴 PWM 有时选择错相以降低母线纹波，而不是所有载波严格同相。

**工程落点：**分别给出时间基准、目标同步精度、可测量标记和最坏误差，不只说“用了 EtherCAT，所以同步”。[S28]

<a id="chapter-18"></a>
## 第18章 建模、MATLAB/Simulink 与代码生成｜P1｜Q137—Q144

<a id="q137"></a>
### Q137. 怎样搭建完整电机闭环模型？

**参考回答：**至少包含供电与母线、逆变器、电机电磁模型、机械负载、传感/量化/延迟、控制器和保护。先写出模型边界与假设，再使用电机参数建立可重复的测试工况。

建议先用简单模型验证控制符号和单位，再逐步增加非理想因素。模型输出应包括相电流、dq、电压、角度、转矩、速度及能量量，避免只看一条转速曲线。

**追问：**怎样判断仿真不是“自己证明自己”？用独立测量参数和未参与调参的工况进行交叉验证。[S08]

<a id="q138"></a>
### Q138. 平均值逆变器与开关模型各验证什么？

**参考回答：**平均值模型用周期平均电压表达调制，适合控制结构、较低频动态、轨迹和参数扫描；开关模型显式表示开关动作，更适合电流纹波、采样窗口、死区等研究，但计算步长和运行成本更高。

再精细的开关模型也未必包含布局寄生、器件实际温度和所有 EMI 路径。根据要验证的问题选择模型保真度，不是模型越复杂就一定越正确。

**工程落点：**先说明“本次模型能验证什么、不能验证什么”，再引用仿真结果。[S08]

<a id="q139"></a>
### Q139. 连续模型和离散控制器怎样匹配时间设置？

**参考回答：**控制器以明确采样周期执行，连续电机模型由求解器积分，之间通过采样和保持连接。固定步长要能正确表达控制/PWM 事件关系；多速率模型需处理速率转换和数据一致性。

仿真求解器步长不是 MCU 的真实控制周期，也不是自动包含运算延迟。代码生成通常要求离散、确定的任务设置和可实现的数据类型。

**易错点：**把仿真自动变步长取得的稳定结果，直接当成固定周期 MCU 实时稳定性的证明。[S05][S09]

<a id="q140"></a>
### Q140. 为什么仿真稳定，上板却振荡？

**参考回答：**检查模型是否遗漏采样/执行延迟、角度延迟、PWM 更新、限压、量化、噪声、死区、传感器极性、饱和、实际负载和参数温漂。还要核对单位与标幺转换是否与代码一致。

排查顺序应从硬件测量与时间链路开始，不要一上来改高级算法。先让模型复现已观察到的异常，再讨论参数修改，才能建立可解释的闭环。

**工程落点：**用上板日志离线重放控制器，比较同输入下模型与代码输出，区分算法误差和外设/时序误差。

<a id="q141"></a>
### Q141. 怎样加入死区、延迟、噪声、量化和限幅？

**参考回答：**死区需与电流方向和开关策略相关；延迟可分别放在采样、角度、计算和执行路径；量化按真实 ADC/编码器分辨率实现；噪声既考虑随机成分，也考虑开关相关误差；限压随母线变化，并加入抗饱和。

不要只在理想电流上添加白噪声就认为模拟了全部硬件。开关毛刺、削顶和采样盲区是结构性误差，模型形式不同。

**追问：**怎样做鲁棒性实验？给参数、延迟和测量误差设合理范围，组合扫描并报告失败边界，不只展示成功样本。

<a id="q142"></a>
### Q142. MIL、SIL、PIL、HIL 分别验证什么？

**参考回答：**MIL 在模型层验证算法；SIL 在主机运行生成或实现代码，与模型比较；PIL 在目标处理器运行代码，检查数值与执行性能；HIL 用实时仿真对象与真实控制硬件交互，测试控制器 I/O、实时性与故障反应。

名称的具体组织可因工具变化，但验证边界要清楚。HIL 的被控对象仍是模型，不能替代真实功率级、热、电磁兼容和机械可靠性试验。

**易错点：**把“程序能在仿真器运行”称为已经完成 HIL；必须说明哪部分真实、哪部分模拟、接口如何闭环。[S09]

<a id="q143"></a>
### Q143. 自动生成代码怎样与手写驱动/通信结合？

**参考回答：**把算法核心与硬件抽象分开，明确输入、输出、状态、初始化/复位和调用周期；手写或厂商驱动负责采样、PWM、通信、保护与板级管理。避免模型和手写代码同时写同一状态或寄存器。

代码生成时需要审查数据类型、资源、静态/动态分配、重入性、错误处理和调用图，并保存生成配置以便复现。

**工程落点：**可以生成算法而保留独立安全监督，但算法函数的 `Enable=false` 是否真的关闭硬件必须单独验证，不可想当然。[S09][S20]

<a id="q144"></a>
### Q144. 怎样证明代码与模型一致并满足实时性？

**参考回答：**构造代表性输入和边界序列，比较关键内部状态及输出误差；对固定点/单精度定义容差，而不是要求所有浮点逐位相同。再测目标平台执行时间、栈、RAM、Flash 与任务截止期。

对保护、模式切换、参数更新和复位也做一致性测试。代码与模型一致只能证明转换/实现层面符合预期，不能证明原模型满足现实需求。

**交付物：**模型版本、代码版本、编译配置、测试向量、误差统计、执行时间和未覆盖项。[S09]

## 第19章 参数辨识、测量与验证｜P0/P1｜Q145—Q152

<a id="q145"></a>
### Q145. 怎样辨识电阻、电感、磁链和极对数？

**参考回答：**电阻可在已知稳态电流和电压下估计，注意逆变器压降与线量换算；电感可由受控激励下的电流动态辨识，需考虑转子位置；磁链可通过已知速度下的反电动势或模型辨识；极对数可由机械一圈对应电周期计数得到。

测试必须限定电压、电流、时间和机械运动范围。不同方法在低速、高速、锁轴和带载时的适用性不同，不应把工具输出当作无需核对的真值。

**工程落点：**至少用另一方法或独立工况复核关键参数。[S08]

<a id="q146"></a>
### Q146. 为什么电感随转子位置与电流变化？怎样测 Ld/Lq？

**参考回答：**转子凸极性使不同磁轴的磁路磁阻不同；电流增大导致磁饱和，磁链—电流斜率变化。若存在交叉饱和，d 轴响应还会受 q 轴偏置影响。

可先对齐或识别转子磁轴，再沿 d/q 方向施加受控小信号/脉冲，在指定偏置电流和频率下辨识。结果应注明增量还是割线电感、温度和工作点。

**易错点：**用转子任意位置的单次 LCR 读数，直接宣称测出了两个独立轴的完整电感。[S08]

<a id="q147"></a>
### Q147. 怎么辨识惯量和摩擦？负载未知怎么办？

**参考回答：**可用机械方程 $J\dot\omega=T_e-T_L-B\omega-\tau_f$ 建立辨识模型。在已知或可估计电磁转矩下，通过加减速、稳态和双向实验区分惯量与摩擦；需要关注速度微分噪声。

负载未知且变化时，惯量与负载转矩可能难以唯一分离，要增加工况、额外传感或先验约束，并报告不确定性。不要把所有残差都塞进一个“摩擦系数”。

**追问：**为什么空载惯量参数上机后不好用？安装后的负载、耦合弹性和传动摩擦改变了被控对象。[S08]

<a id="q148"></a>
### Q148. 怎样测电流环、速度环的阶跃和频率响应？

**参考回答：**电流环应尽量避免机械外环干预，选择安全电流与转速工作点；速度环测试时内环应已验证。小幅阶跃/扫频用于线性分析，大幅变化用于测试限流、限压和恢复。

测量应保留指令、反馈、实际执行量与限幅标志，确认测试没有长期饱和，否则不能按线性模型解释带宽。扫频范围和激励应避开可能损伤机构的条件。

**工程落点：**报告幅值、频率、采样、滤波、供电、负载和温度，保证别人能重做实验。[S02]

<a id="q149"></a>
### Q149. 转矩脉动、速度波动、谐波和效率怎么测？

**参考回答：**转矩脉动需合适带宽的转矩测量或明确的估计方法，速度波动要考虑编码器量化；电流谐波需要足够采样率、同步长度和合理频谱处理；效率则需一致功率边界和校准仪器。

简单时均 $V$ 乘时均 $I$ 不总等于真实输入功率，尤其存在纹波时应考虑 $\langle v(t)i(t)\rangle$。输出机械功率需转矩与速度对应同一时间/边界。

**易错点：**以软件 Iq 乘 Kt 作为独立转矩测量，再用它证明同一个 Kt 模型非常准确。

<a id="q150"></a>
### Q150. 为什么不能只凭母线或空载电流评估控制？

**参考回答：**母线平均电流反映电功率的一部分，不能直接描述相电流纹波和磁化电流。空载通常转矩需求小，不能检验满载电流能力、转矩线性、热和电压边界。

更小的空载电流可能来自更好控制，也可能因为实际速度、母线、负载或角度策略不同。比较需同工况，并结合温升、相电流、转矩、跟随误差和稳定裕量。

**追问：**哪几个图最值得同时看？相电流、Id/Iq、Vd/Vq/限幅、角度/速度、母线以及故障时序。

<a id="q151"></a>
### Q151. 示波器、电流探头、功率分析仪和测功机各测什么？

**参考回答：**示波器用于瞬态、时序和开关波形；电流探头提供相电流波形但需校零并注意带宽/饱和；功率分析仪用于准确功率与效率；测功机提供可控机械负载和转矩/速度测量。

测高侧 VGS、开关节点或浮动电压，应使用满足差模、共模和安全额定值的差分/隔离方案。不能把普通接地探头地夹随意接到相端，也不能以断开示波器保护地作为替代办法。

**工程落点：**记录探头型号、量程、带宽、校准和连接方法；测量链本身也是误差和风险来源。

<a id="q152"></a>
### Q152. 怎样制定完整验证计划？

**参考回答：**按需求建立矩阵：电源上下限、速度/转矩包络、环境温度、冷/热机、不同电机批次、连续与重复负载、通信负荷、传感异常和复位恢复。每项给出激励、合格阈值、保护条件和证据文件。

故障注入优先从仿真、HIL 和低能量台架开始，不能直接短接大功率母线来“验证保护”。长期测试还应监控温漂、错误计数和资源泄漏。

**交付物：**需求—测试追踪表、原始数据、统计结果、失败记录和未覆盖边界；附录 D 提供可复制模板。[S09]

## 第20章 其他电机与控制方法｜P2｜Q153—Q160

<a id="q153"></a>
### Q153. 异步电机转差率、同步转速和转子速度怎样关联？

**参考回答：**同步机械转速为 $n_s=60f/p$，转差率 $s=(n_s-n_r)/n_s$，因此 $n_r=(1-s)n_s$。电动状态下通常 $0<s<1$，启动静止时在该定义下 s=1。

转差不是一个所有负载都固定不变的常数；磁链、负载、电源和控制策略都会影响它。发电或其他工况也会出现不同符号与范围。

**追问：**为什么负载增加时转速可能略降？在相应供电与控制条件下，需要更大转差以建立相应转子电流与转矩。

<a id="q154"></a>
### Q154. V/F 为什么低频要补偿？与矢量控制有什么不同？

**参考回答：**基波近似下保持电压/频率有助于保持磁链，但低频时电阻压降相对显著，单纯同比降低电压可能使有效磁链不足，因此可能需要低频补偿。

V/F 更偏标量调节，通常不直接实现定向的磁链/转矩解耦；矢量控制利用电流、位置/磁链信息调节更明确的分量，动态能力和实现要求不同。

**易错点：**给所有频率固定电压补偿而不防过磁或过流，也不能把 PMSM 和异步电机的所有标量启动行为混同。[S01]

<a id="q155"></a>
### Q155. 异步电机转子磁链定向与 PMSM 有什么不同？

**参考回答：**PMSM 永磁磁链与转子结构相关，机械角经极对数和偏置可得到转子磁链角；异步电机的转子磁链需要由电磁过程建立，其同步磁链角与机械角之间还包含转差角速度。

因此异步 FOC 需要估计或计算磁链、转差，并对转子时间常数等参数敏感。不能把 PMSM 的编码器电角度直接代入就完成相同的磁链定向。

**工程落点：**先定义定向对象、磁链模型与参数，再讨论解耦和整定。[S01]

<a id="q156"></a>
### Q156. 经典 DTC 与 FOC 有何区别？

**参考回答：**经典 DTC 常从估计的转矩和磁链误差出发，通过滞环比较和开关表选电压矢量；FOC 常在 dq 坐标下控制电流并通过调制生成电压。两者都可实现转矩控制，但控制结构和波纹/开关行为不同。

现代 DTC 还有结合 PI、预测或 SVPWM 的变体，不能把经典 DTC 的可变开关频率等特征说成所有 DTC 的必然属性。

**追问：**哪种一定更快更好？需指定实现、采样、模型、约束和测试指标，不适合脱离条件作绝对判断。[S01]

<a id="q157"></a>
### Q157. 步进电机为什么失步？

**参考回答：**开环步进依靠转子跟随励磁平衡点移动。所需加速转矩加负载转矩超过当前转速下可用转矩，或受到共振、供电和电流建立速度影响时，转子可能跟不上，实际位置与指令步数分离。

高速时电感与反电动势限制绕组电流建立，保持转矩不能代表高速能力。加减速规划、合适驱动电压与电流控制、机械阻尼和反馈可改善。

**易错点：**认为只要脉冲计数正确就能保证机械位置正确；开环系统没有独立证明未失步的能力。

<a id="q158"></a>
### Q158. 细分提高什么？为什么不自动提高定位精度？

**参考回答：**细分用更平滑的两相电流比例产生更多中间平衡位置，改善指令分辨率、平顺性和部分噪声表现。但实际角度还受电机磁路误差、负载、摩擦和电流比例误差影响。

细分越细，每个微步对应的增量恢复转矩越小，负载可能让多个微步才体现明显机械移动。因此“256 细分”不等于真实绝对位置精度就是整步角除以 256。

**工程落点：**用独立位置测量验证负载下的微步线性和重复性。[S14]

<a id="q159"></a>
### Q159. 快衰减、慢衰减、混合衰减怎样影响步进电流？

**参考回答：**在斩波电流控制中，开关关断后的续流路径决定绕组电流下降速度。慢衰减通常使电流较慢衰减，可能在目标快速下降时跟不上；快衰减可更快降低电流，但纹波和噪声取舍不同；混合衰减结合两个阶段。

具体电流方向与路径由桥式拓扑和器件实现决定。应结合驱动电压、电感、速度和目标正弦波检查实际电流波形。

**追问：**为什么同一电机低速正弦电流畸变？除了细分表，还要检查衰减模式、最小导通时间与采样消隐。

<a id="q160"></a>
### Q160. 开关磁阻电机怎样产生转矩？为什么关注导通角？

**参考回答：**转子倾向于向磁阻较小、相电感较大的方向运动。在简化未饱和单相表达下，$T\approx\tfrac12i^2\,dL/d\theta_m$。因此电流应与电感上升/下降区间配合，转矩符号与导通位置密切相关。

高速时电流建立和衰减需要时间，开通/关断角影响正转矩区利用、负转矩、效率和转矩脉动。实际饱和模型应通过磁共能或磁链图分析，不宜一直套线性公式。

**易错点：**把 SRM 的励磁角和 PMSM 的 Park 角度当作同一件事，或者直接照搬 PMSM 三相逆变器控制逻辑。

**本章核对与延伸：**电机模型 [S08]、FOC/DTC 及 SRM 控制入口 [S01]、微步分辨率与精度 [S14]。

<a id="chapter-21"></a>
## 第21章 调试与故障分析｜P0｜Q161—Q175

> 本章是排查框架，不是“一个现象对应一个确定故障”。先建立安全测试条件，记录原始证据，再以可证伪的假设逐层定位。避免直接提高电流、关闭保护或在未知状态下重复上电。

<a id="q161"></a>
### Q161. 电机上电只抖不转，怎么排查？

**参考回答：**先确定系统有没有进入 RUN，是否因驱动故障、欠压或校准失败停在启动阶段。再核对三相桥实际输出、供电、接线和机械卡滞。不要把“听到声音”当作三相都正常工作。

若电气输出正常，检查相电流极性/比例、编码器方向、极对数和零点。最后再看启动参考、转矩是否足以克服负载，以及无感开环加速度是否过快。

**应采证据：**状态迁移、首个故障时间、母线、三相电流、Id/Iq 指令与反馈、角度和占空比。**下一步验证：**限制能量，逐项确认一条测量/执行链，不同时更改相序、PI 和编码器方向。

<a id="q162"></a>
### Q162. 开环能转，切入电流闭环就失控，怎么查？

**参考回答：**开环转动只能说明某种电压组织能够带动转子，不能证明反馈链正确。优先检查电流换算系数、相通道映射与正负号，再检查 Clarke/Park 约定和电角度。

随后核对闭环入口时积分初值、电流参考是否突变、实际调用周期与 KiTs 是否一致，以及限幅是否作用于总电压。若零速小电流也不稳定，通常应先查基本反馈，不急于加入复杂解耦。

**验证思路：**利用受控的小幅测试，把预期电流方向与独立测量比较；在低能量条件下分别验证 d/q 轴，而非直接让速度外环给满电流。

<a id="q163"></a>
### Q163. 正转正常，反转异常，怎么查？

**参考回答：**检查速度、电角速度、反电动势和摩擦补偿中的符号是否一致；查角度回绕、无符号整数参与负速度计算、换相表反向路径与传感器方向映射。

同时考虑负载本身是否方向不对称，例如单向机构、抱闸、线缆拖链与风车状态。无感算法在反向捕获时是否使用了仅对正向成立的 PLL/角度公式，也要验证。

**应采证据：**同幅度正反转下的 Id、Iq、电压、角度残差和状态。**易错点：**把反向 PI 单独调一套来掩盖坐标符号错误。

<a id="q164"></a>
### Q164. 空载正常，一带负载就停，怎么查？

**参考回答：**先记录负载施加前后母线与实际相电流，判断是电源掉压、限流、驱动保护还是失锁。如果电流到达上限，进一步确认 Kt、机械负载和峰值持续时间；如果指令很大但实际电流上不去，检查电压饱和和采样问题。

若电流很大而转矩不足，检查角度偏差、相序、机械传动和电机参数。无感系统还要看观测器在负载阶跃时是否失去同步。

**验证思路：**用可重复的阶梯负载而不是手抓电机轴，逐步建立转矩—电流—速度—电压关系。

<a id="q165"></a>
### Q165. 低速抖、高速正常，怎么查？

**参考回答：**先分清是速度反馈量化、真实力矩波动还是机械黏滑。检查测速窗、无边沿保持、编码器非线性、静摩擦、齿槽转矩、电流零偏与死区误差。

无感反电动势算法在低速信噪比差，也可能导致角度摆动。速度环过强或积分不断跨越静摩擦门槛，会形成周期性爬行。

**应采证据：**未经重滤波的角度、速度估计、Iq 和独立运动观察。**验证思路：**先验证电流/转矩模式下的小电流稳定性，再区分外环和机械因素。

<a id="q166"></a>
### Q166. 低速正常，高速失稳，怎么查？

**参考回答：**按顺序核对电压裕量、每电周期控制次数、角度总延迟、PWM 更新是否错期、电流有效采样窗以及母线瞬态。高速下几个微秒也可能产生不可忽视的电角误差。

然后看电流 PI 饱和恢复、解耦参数和弱磁参考。机械最高转速、负载共振和编码器信号完整性也必须检查，不是所有高速失稳都由控制增益引起。

**应采证据：**调制度/限幅标志、Vd/Vq、Id/Iq、角度预测差、ISR 最长时间。**易错点：**看到 Iq 误差就继续提高 PI，却不看是否已经没有可用电压。

<a id="q167"></a>
### Q167. 三相电流不对称，怎么查？

**参考回答：**先用独立仪器确认是真实不对称还是测量失真。逐通道检查偏置、增益、方向、ADC 排序、相映射、有效采样窗口及前端是否削顶。

若确实不对称，再查接线接触、绕组、单桥臂损坏、驱动延迟和不一致的死区。电流方向翻转后误差是否改变，有助于判断死区与偏置成分。

**易错点：**第三相由另外两相重构时，再用三相和为零来证明传感器正确；这个结论是算法强制成立的，不能当作独立证据。

<a id="q168"></a>
### Q168. Iq 给定为零，电机仍发热，怎么查？

**参考回答：**检查实际 Id/Iq，而非只看参考；可能仍在主动励磁、静止保持、振荡或观测注入。测量零偏和角度错误还可能使软件显示接近零，而真实电流并不小。

区分静止与旋转：旋转时还有铁耗、风摩及其他损耗。并检查 PWM 全开闭策略、自举、短接制动状态和功率器件自身发热，不能将整个板子的热都归给电机铜耗。

**验证思路：**同时记录相电流 RMS、温升位置、转速与控制状态；在安全条件下比较禁用功率级和零电流闭环两个不同状态。

<a id="q169"></a>
### Q169. 速度周期性起伏，怎样定位周期来源？

**参考回答：**把纹波频率分别除以机械转频、电频率、控制频率和通信频率，观察是否锁定某个阶次。随转速同比变化的成分可能与机械/磁周期相关；固定频率成分可能与控制调度或结构共振有关，但都需继续验证。

结合编码器原始角、Iq、母线和负载，区分测速假象、转矩波纹、供电波纹和机构周期负载。频谱使用正确采样率并防混叠。

**验证思路：**改变转速、负载或通信周期中的一个变量，观察该成分是否按假设移动，而不是只凭频谱峰值命名故障。

<a id="q170"></a>
### Q170. 一刹车母线就过压，怎么处理？

**参考回答：**先判断回灌路径与能量是否超过电源、电池或制动回路能力，检查 BMS 是否在充电/过压保护中断开、斩波器是否工作、制动电阻是否开路。

再核对减速度、系统惯量、母线电容和阈值协调。可在安全边界内降低减速度或使用合适吸能方案，但不能仅抬高过压阈值把风险转交给 MOS 和电容。

**应采证据：**母线电压/电流、制动电阻电流或占空比、速度曲线和故障先后顺序。能量计算见 Q110—Q111。[S12]

<a id="q171"></a>
### Q171. 偶发烧 MOS，但软件没记录过流，说明什么？

**参考回答：**只能说明现有软件日志没记录到相应事件，不能证明不存在快速过流。可能包括直通、米勒误导通、过压雪崩、局部过热、驱动欠压或保护盲区；日志也可能在复位/断电前未写出。

优先检查失效位置、栅极与漏极波形、硬件故障锁存、保护传播时间和热状态。低侧/母线传感对某些故障路径可能不可见。

**验证原则：**先在降低能量且具备防护的台架定位机理，不直接更换更大 MOS 继续满载复现。[S16]

<a id="q172"></a>
### Q172. 加串口打印后电流变差，怎么查？

**参考回答：**检查打印是否位于控制 ISR、是否阻塞等待发送、是否使用全局锁或动态内存、格式化是否引入耗时浮点运算；DMA 也要看中断优先级、总线冲突和缓存处理。

用 GPIO/计数器比较开启与关闭日志时的执行时间和 PWM 截止期，确认问题是否确由实时性引起。日志应先采样到有界缓冲，再由后台限速输出，并允许明确丢弃非关键数据。

**易错点：**把日志频率降低一点后看似正常，就认为已证明没有其他长尾抖动；仍要测试最坏路径。

<a id="q173"></a>
### Q173. 单轴正常，四轴一起异常，怎么查？

**参考回答：**先区分电源/地/热的共用问题与计算资源问题。测母线和驱动供电；列出 ADC、定时器、DMA、编码器总线与内存的共享关系；检查多个 ISR 同时触发时的截止期。

软件还要查控制器状态是否误用静态全局变量、函数是否可重入、轴索引是否越界、校准参数是否串轴。错相 PWM 对母线有帮助，但会改变任务调度与采样关系。

**验证思路：**先让四轴逻辑全运行但限制功率，再逐轴增加负载，分离 CPU 负载和功率负载影响。

<a id="q174"></a>
### Q174. 冷机正常，热机误差或失稳，怎么查？

**参考回答：**检查 Rs、磁链、前端偏置/增益、传感器精度、驱动传播与器件导通特性随温度的变化，同时核对是否进入热降额或供电能力下降。热导致机构预紧与摩擦改变也会影响控制。

应在可测的绕组、功率器件、采样电阻和环境温度条件下记录参数漂移，不要只记录一个板载温度。

**验证思路：**用稳定温度平台逐级测试，比较固定参数、补偿参数和降低带宽的结果；补偿逻辑也需处理传感器断线和异常温度。

<a id="q175"></a>
### Q175. 同型号换一台电机就不稳，怎么查？

**参考回答：**同型号不保证相线顺序、编码器装配零位、真实参数和负载完全一致。先做身份、方向、零点和采样校验，再比较电阻、电感、磁链、摩擦与机械连接。

把参数分成产品级、型号级、单机校准和运行自适应四类；单机偏置不能直接复制。算法也要对合理批次分散保留稳定裕量。

**工程落点：**建立多样机验证和出厂校准流程，保存参数版本、校验与失配拒绝规则，而不是维护一份来源不明的“万能参数”。[S08]

## 第22章 C/C++ 与现场编程｜P0｜Q176—Q185

> 数学核心应能脱离 MCU 编译测试；硬件保护与实时性必须回到目标平台验证。附录 C 提供可编译的 C17 数学练习代码与测试，以下同时说明并发、状态机和协议题的设计边界。

<a id="q176"></a>
### Q176. 写一个有抗积分饱和的 PI 控制器。

**参考回答：**最少包含 Kp、Ki、Ts、积分状态、输出限值和复位接口。先说明采用连续 Ki 还是离散 KiTs，并明确当输入非法时返回失败、由上层撤销运行许可。

单轴可用条件积分；FOC 电压通常是 d/q 矢量受限，宜根据真实总电压实现结果反算：

$$
z_{k+1}=z_k+T_s\left[K_i e_k+K_{aw}(u_{applied}-u_{unsat})\right]
$$

其中 z 为输出单位的积分状态，$K_{aw}$ 单位为 1/s。附录 C 的示例使用当前状态生成本周期输出，再更新下一周期积分。

**测试：**零误差、正/负阶跃、长时间饱和、反向脱饱和、限值突变、禁用后重启、NaN/Inf 和不合法 Ts。Kaw、离散步长与模型仍需整定。

<a id="q177"></a>
### Q177. 写 Clarke、Park 和反 Park，并说明如何测试。

**参考回答：**使用同一套幅值和方向约定。本文两相简式为 `alpha=ia; beta=(ia+2*ib)/sqrt(3)`，只适用于零序可忽略且两相有效的条件。Park 与反 Park 互为旋转矩阵的逆。

**测试：**在 0、π/2、π、3π/2 等角度验证已知矢量；遍历多角度，做 `Park → inverse Park` 往返；验证 $\alpha^2+\beta^2\approx d^2+q^2$；再用三相对称正弦验证 dq 为常值。

**易错点：**只测试 θ=0，会漏掉 sin 项符号错误；只测试 Ia=0，会漏掉通道映射和幅值问题。代码见附录 C。[S18][S19]

<a id="q178"></a>
### Q178. 写角度归一化和最短角差。

**参考回答：**首先规定区间，例如 $[-\pi,\pi)$，再实现取模并处理负数。恰好半圈有方向歧义，必须固定返回一侧，不可在不同模块使用不同约定。

角度应在正常范围内持续归一化，避免累计巨大浮点角导致低位精度丢失；连续多圈位置宜独立维护，不要把归一化角直接当成机械绝对位置。

**测试：**零、±π、接近边界、若干整数圈、负输入、NaN/Inf。最短角差还必须有“真实变化小于半圈”的外部约束。附录 C 提供实现。

<a id="q179"></a>
### Q179. 写编码器速度估计。

**参考回答：**输入不只是计数值，还需要计数模数、时间戳、每机械圈有效计数和方向。先按明确模数求最短计数差，再除以实际时间，必要时滤波；超过半模数或时间异常应标记不可信，而非继续输出一个看似合理的速度。

**伪代码：**

```text
读取带时间戳的计数快照
检查计数范围、时间间隔和最大允许机械速度
delta = 有符号的模数回绕差
若恰好半模数或与速度上界冲突：返回 INVALID
velocity = delta * 2π / counts_per_rev / dt
滤波并记录数据年龄；无新数据时执行超时规则
```

**易错点：**把 PPR 与四倍频后的 CPR 混用；普通 C 的窄有符号类型强转回绕也不应当作无需说明的可移植算法。

<a id="q180"></a>
### Q180. 写 ADC 到相电流换算与校准。

**参考回答：**接口保存 ADC 位数/码值范围、参考电压、偏置码、正负增益和采样电阻。示例换算：

$$
I=(code-code_{offset})\frac{V_{ref}}{2^N G R_s}
$$

这里采用理想 ADC 的 $V_{ref}/2^N$ LSB 约定；某些工程通过标定斜率直接换算更合适。应检查轨到轨削顶、参数非法和校准状态，不能只返回一个数值。

**测试：**零点、已知正负电流、满量程附近、不同增益极性、错误 ADC 码和非有限参数。运行时自动更新偏置必须保证真实零电流条件。代码见附录 C。

<a id="q181"></a>
### Q181. 写故障前后波形的环形缓冲区。

**参考回答：**推荐把“高速采样记录”和“后台读取/导出”分开设计。单生产者单消费者队列可用独立读写索引与 acquire/release 发布，但 ISR 是否允许所用原子操作，要核实目标平台是否无锁；`volatile` 不提供并发同步。

故障录波若采用循环覆盖，可让控制上下文独占数据区，触发后再记录固定数量样本，随后发布冻结快照；读者只读取冻结区，避免边覆盖边导出。若消费者也实时读取，则覆盖策略和读索引所有权必须另行设计，不能混用两种方案。

**数据建议：**每条包含采样序号、时间、Ia/Ib、Id/Iq、参考、电压、角度、母线与状态。禁止在 ISR 分配内存或把 SD 写完成作为控制继续的条件。

**测试：**绕回、满/空、触发时刚好绕回、故障后样本计数、重复触发、导出期间重新使能以及消费者滞后。

<a id="q182"></a>
### Q182. 写电机状态机。

**参考回答：**状态迁移应集中处理，事件与准入条件分离。进入/退出动作明确定义，故障优先于普通运动事件。对不允许迁移返回错误并保持安全状态，不能静默跳过校准。

```text
process_event(event, measurements):
    if hardware_fault_latched:
        request_hardware_safe_action()
        commit_state(FAULT)
        return

    target = transition_table[state, event]
    if target 不存在 or guard 不满足:
        记录拒绝原因
        return

    执行本迁移要求的有界动作
    验证硬件/软件后置条件
    提交新状态与原因
```

**测试：**所有合法边、非法边、同时故障与启动、校准超时、故障清除但许可未重新建立、复位后旧命令。安全动作要由硬件保障，伪代码不是安全认证实现。

<a id="q183"></a>
### Q183. 写通信命令解析与超时处理。

**参考回答：**先验证长度、类型、版本、CRC、序号和参数范围，再原子提交完整的新命令快照；在校验前不得更新目标值。对网络数据不要直接 `reinterpret_cast` 为结构体，避免对齐、填充、大小端和非有限浮点输入问题。

```text
receive(frame):
    校验长度/版本/目的轴/CRC
    解码到临时结构；检查有限值、范围、模式和执行时刻
    拒绝过期、重复或超出允许时间窗的命令
    发布完整命令快照及接收时间

control_tick(now):
    读取一致快照
    若命令年龄超限：执行预定失联策略
    否则按状态机许可和变化率限制生成参考
```

**测试：**截断、错误长度、大小端、CRC、序号回绕、旧包重放、长时间失联和恢复。CRC 是差错检测，不是对抗恶意伪造的身份认证。

<a id="q184"></a>
### Q184. 把浮点算法改成定点，需要处理什么？

**参考回答：**为每个物理量选择量程与 Q 格式，分析加乘和积分的中间位宽。乘法后明确右移/除法、舍入和饱和规则，避免有符号溢出等未定义行为。积分器通常需要比输入更大的动态范围。

Q15 的 -1 可精确表示而正 1 不能，`(-1)×(-1)` 必须饱和到最大正值。附录 C 用宽整数乘法、对称舍入与饱和实现 Q15 乘法，避免依赖负数右移行为。

**测试：**最大/最小值、正负乘积、半 LSB、长期积分和正常工作分布；除了最大误差，还比较闭环稳定与极限环。

<a id="q185"></a>
### Q185. 怎样设计 PC 上的单元测试？

**参考回答：**把变换、PI、限幅、角度、标定、协议和状态机做成独立模块；硬件输入用可控快照替代，输出以结构体表示，不在数学函数中访问寄存器。使用固定向量、随机性质测试和日志重放组合验证。

除了典型值，还测试非法参数、NaN/Inf、计数回绕、长时间饱和、复位和多实例隔离。内存检查器可发现越界等错误，但不能证明算法稳定，也不能覆盖 MCU 的所有并发/缓存行为。

**交付物：**测试源码、固定随机种子、编译参数、PASS/FAIL、误差阈值与未覆盖项。附录 C 的主机测试是入门样例，不代替 PIL、HIL 或上板测试。[S09]

## 第23章 白板计算题｜P0｜Q186—Q190

> 以下均为给定参数下的示例计算，不是某款驱动器的能力保证。代入前先声明单位、变换约定和理想化假设。

<a id="q186"></a>
### Q186. 7 对极、3000 rpm、20 kHz 控制，电频率与每电周期控制次数是多少？

**推导：**

$$
f_m=\frac{3000}{60}=50\ \mathrm{Hz},\qquad
f_e=pf_m=7\times50=350\ \mathrm{Hz}
$$
$$
N=\frac{f_{control}}{f_e}=\frac{20000}{350}\approx57.14
$$

**参考结果：**电频率 350 Hz，每个电周期平均约 57.1 次控制，每周期电角度前进约 $360°/57.14=6.3°$。这不是说每个电周期恰好都有 57 次，实际相位关系会变化。

**追问：**机械速度提高一倍时会怎样？电频率加倍，每电周期控制次数减半。同一时间延迟造成的电角误差也加倍。

**易错点：**把 7 对极当作 7 极，或把 PWM 频率直接当成真实电流算法频率，忽略一周期可能更新一次/两次的配置。

<a id="q187"></a>
### Q187. 5 mΩ、20 倍增益、3.3 V、1.65 V 偏置、12 位 ADC 怎么算？

**假设：**模拟前端理想、双向量程对称，ADC 的理想 LSB 采用 $3.3/4096$。

$$
R_sG=0.005\times20=0.1\ \mathrm{V/A}
$$
$$
I_{max,ideal}=\frac{1.65}{0.1}=16.5\ \mathrm A
$$
$$
\Delta I=\frac{3.3/4096}{0.1}
=0.00805664\ \mathrm A\approx8.06\ \mathrm{mA/LSB}
$$

**参考结果：**理想模拟范围约 ±16.5 A，量化步长约 8.06 mA。12 位最大码为 4095，因此数字正端可表示值比理想模拟边界少约一个 LSB，这不改变量程初估结论。

若采样电阻承受 10 A RMS，耗散约 $10^2\times0.005=0.5W$，仍要按温升与脉冲要求留裕量。

**易错点：**8.06 mA 是量化步长，不是系统精度；真实还受零偏、增益、温漂、噪声和输出摆幅限制。[S15]

<a id="q188"></a>
### Q188. R=0.2 Ω、L=0.4 mH、目标带宽 1 kHz，PI 初值是多少？

**假设：**电流对象已解耦，忽略延迟，用连续 PI 零点抵消 $R/L$ 极点。

$$
L=0.0004\ \mathrm H,\qquad
\omega_c=2\pi\times1000\approx6283.185\ \mathrm{rad/s}
$$
$$
K_p=L\omega_c\approx2.51327\ \mathrm{V/A}
$$
$$
K_i=R\omega_c\approx1256.637\ \mathrm{V/(A\cdot s)}
$$

当 $T_s=50\mu s$ 且离散积分为 $z_k=z_{k-1}+K_iT_se_k$：

$$
K_iT_s\approx0.0628319\ \mathrm{V/A}
$$

**参考结果：**Kp≈2.5133，连续 Ki≈1256.64，离散积分增量系数约 0.06283。

**必须补充：**该值是起点。把延迟、采样、实际 PWM、解耦误差和电压限幅加入模型后，目标 1 kHz 未必仍满足所需稳定裕量。不同 PI 代码可能采用不同状态更新顺序。[S02]

<a id="q189"></a>
### Q189. 48 V 母线在线性 SVPWM 下能输出多大基波电压？

**假设：**理想两电平三相逆变器、三线对称负载、线性 SVPWM，不计死区、压降与采样留白。

$$
V_{phase,peak,max}=\frac{48}{\sqrt3}\approx27.7128\ \mathrm V
$$
$$
V_{phase,rms,max}=\frac{48}{\sqrt6}\approx19.5959\ \mathrm V
$$
$$
V_{line,rms,max}=\sqrt3V_{phase,rms,max}
=\frac{48}{\sqrt2}\approx33.9411\ \mathrm V
$$

**参考结果：**相电压基波峰值约 27.71 V，线电压基波 RMS 约 33.94 V。这里相电压指相对电机中性点的基波，不是相端对 DC- 的 PWM 瞬时电压。

**追问：**为什么实际低于此值？驱动需满足最小脉宽、采样、自举和器件压降；母线也有纹波与跌落。[S04]

<a id="q190"></a>
### Q190. 7 对极、6000 rpm、20 μs 角度延迟，误差多少？

**假设：**短时间内转速近似恒定。

$$
\omega_m=2\pi\frac{6000}{60}=200\pi\approx628.319\ \mathrm{rad/s}
$$
$$
\omega_e=7\omega_m\approx4398.230\ \mathrm{rad/s}
$$
$$
\Delta\theta_e=\omega_eT_d
=4398.230\times20\times10^{-6}
\approx0.0879646\ \mathrm{rad}\approx5.04°
$$

**参考结果：**约 5.04° 电角度；对应机械角误差约 0.72°。

**追问：**如何补偿？使用带时间戳位置和速度估计，将角度预测到目标采样或电压作用时刻。加速度和速度估计误差会残留，所以不能仅加一个固定 5° 解决全部转速。

### Q191. 为什么选择这类电机和控制方案？替代方案是什么？

**回答结构：**先交代负载、速度/转矩、响应、精度、成本和供电约束；再比较候选电机与驱动；最后说明选择理由及放弃的能力。例如“为了低速力矩与受控接触，选择带位置反馈的电流闭环”，比“FOC 更先进”更有说服力。

### Q192. 电机关键参数是多少？来自哪里？

**必须区分：**厂家值、实测值、辨识值、暂定假设。若只知道线间电阻或相电流 RMS，应说明怎样转换成算法参数。

**追问：**哪个参数最不可信？回答误差来源和对控制的影响，并拿出复核方式，而不是把所有值都称为精确值。

### Q193. 控制框图、硬件框图、软件任务图怎样对应？

### Q194. 各环频率是多少？为什么这样选？

**必须区分：**设计频率、实测频率和闭环带宽；日志频率低于控制频率时，不能用低速日志证明高频没有纹波。

**追问：**将 PWM 翻倍会怎样？同时分析损耗、采样时间、分辨率和计算余量，不能只说响应更快。

<a id="q195"></a>
### Q195. 最坏执行时间是多少？怎么测？

**回答结构：**说明使用周期计数器、GPIO 或分析工具，测试过哪些分支、缓存状态、通信负荷和多轴组合，并给出测得最大值、截止期和剩余裕量。

**诚实边界：**未做严格 WCET 分析时，称“已覆盖场景下测得的最大执行时间”，不要称已证明的绝对上界。解释你怎样检测运行时超期。

**追问：**优化前后提升从哪里来？给调用热点、编译配置和数值误差验证，而不是只报总体百分比。

### Q196. 你亲自做了什么？哪些来自 SDK 或开源项目？

**回答结构：**按算法、硬件、外设、上位机、调试和测试列真实负责范围。使用 SDK 可以直接说明，再解释修改点、接口、参数依据和验证成果。

### Q197. 最难故障是什么？怎样证明根因？

**回答结构：**按“现象—环境—候选原因—测量—排除—根因—修复—回归”叙述。讲明为什么其他候选被排除，而不是“换了某器件就好了”。

**必须准备：**至少一张关键波形、一段时序或一次可重复实验。若根因仍只是高概率判断，就明确证据和不确定性。

### Q198. 改进前后有什么可量化差异？

**回答结构：**固定供电、负载、温度、速度、测量带宽与算法版本，比较目标指标，例如电流阶跃、跟随误差、CPU 时间、峰值电流、效率或启动成功率。

**必须避免：**一边改控制算法，一边换更大电机/更高母线，却把全部收益归给算法。要有单变量实验或明确承认因素耦合。

**追问：**改进有没有代价？同时报告噪声、算力、参数敏感性、热和维护复杂度，不能只展示有利指标。

<a id="q199"></a>
### Q199. 做过哪些长期、异常和故障恢复测试？

**回答结构：**列测试时长、样机数、环境范围、负载循环、异常注入和恢复条件，并区分仿真、HIL 与实机验证。失败项和未覆盖项也要明确。

**必须准备：**温升曲线、错误计数、故障先后时间、参数版本和重启后的安全状态。只说“跑了一晚上没事”缺少可判断的测试条件。

**追问：**未发生故障是否证明可靠？只能支持已覆盖条件下的观察，需要结合风险、样本量和针对性试验判断。

<a id="q200"></a>
### Q200. 重新设计一版，你会保留和修改什么？

**回答结构：**从已验证问题出发，分别给结构、硬件、算法和测试改进。每项写收益、代价和如何验收，例如“增加独立故障锁存解决复位前日志丢失”，而不是只说换更快芯片。

**建议表达：**先保留已经有证据可靠的部分，再解决最影响产品目标的瓶颈；新算法或新器件应以可测指标验证价值。

**最后自问：**是否能完整解释“一次 FOC 周期发生了什么”和“一次故障如何被证实并防止再次出现”？这两条贯通之后，题库里的知识才能成为可展示的工程能力。

## 附录 A：公式与术语速查

### A.1 常用公式

这一页用于回忆，不替代正文中的前提条件。特别是电机电压、转矩、调制边界必须匹配同一套坐标与幅值定义。[S03][S04][S17][S18][S19]

| 项目 | 公式 | 适用条件/注意点 |
|---|---|---|
| 电角度 | $\theta_e=\operatorname{wrap}(p\theta_m+\theta_0)$ | 方向与相序一致；多圈机械位置应另外保存 |
| 电频率 | $f_e=pn/60$ | $n$ 为 rpm |
| 角速度 | $\omega_m=2\pi n/60$，$\omega_e=p\omega_m$ | 不要把 Hz 直接用于 rad/s 的公式 |
| 每电周期控制次数 | $N=f_{ctrl}/f_e$ | 只是时域密度，不是闭环带宽 |
| 机械功率 | $P_m=T\omega_m$ | 转矩与速度必须对应同一根轴 |
| 机械能 | $E_k=J\omega_m^2/2$ | 另计负载、重力势能和其他储能 |
| 三相铜耗 | $P_{cu}=3I_{phase,rms}^2R_s$ | 对称电流、相电阻与温度对应 |
| 二相采样 Clarke | $i_\alpha=i_a$，$i_\beta=(i_a+2i_b)/\sqrt3$ | 同步、有效采样且无零序 |
| Park | $i_d=i_\alpha\cos\theta_e+i_\beta\sin\theta_e$ | d 轴沿转子磁链 |
| Park | $i_q=-i_\alpha\sin\theta_e+i_\beta\cos\theta_e$ | 正 q 轴及正转矩定义须统一 |
| 反 Park | $v_\alpha=v_d\cos\theta_e-v_q\sin\theta_e$ | 电压角度需对应实际施加时刻 |
| 反 Park | $v_\beta=v_d\sin\theta_e+v_q\cos\theta_e$ | 与正变换成对验证 |
| dq 功率 | $P_e=\tfrac32(v_di_d+v_qi_q)$ | 本文等幅值变换且忽略零序 |
| PMSM 转矩 | $T_e=\tfrac32p[\psi_fi_q+(L_d-L_q)i_di_q]$ | 线性近似模型，不包含传动损耗 |
| 电压矢量限制 | $\sqrt{v_d^2+v_q^2}\le V_{lim}$ | 圆形限制；实际调制/采样可能再收紧 |
| 线性 SVPWM 理想限制 | $V_{lim}=V_{dc}/\sqrt3$ | 相基波峰值；不包含非理想因素 |
| PI 初估 | $K_p=L\omega_c$，$K_i=R\omega_c$ | 理想解耦 RL 对象，需另验延迟与稳定性 |
| 离散积分 | $z[k+1]=z[k]+K_iT_se[k]$ | 先更新还是后更新，代码与模型必须一致 |
| 角度延迟误差 | $\Delta\theta_e\approx\omega_eT_d$ | 延迟时间内速度变化可忽略 |
| 采样电阻损耗 | $P_{shunt}=I_{rms}^2R_{shunt}$ | 核算实际通路占空与散热，不只看额定电流 |
| 异步电机转差 | $s=(n_s-n_r)/n_s$ | $n_s\ne0$，符号与运行象限有关 |

对于本文的 PMSM 模型：

$$
v_d=R_si_d+L_d\frac{di_d}{dt}-\omega_eL_qi_q
$$

$$
v_q=R_si_q+L_q\frac{di_q}{dt}+\omega_e(L_di_d+\psi_f)
$$

由此构造解耦前馈时，应把模型中的速度相关项按同样的符号加到对应电压指令上。不能只记“d 轴减、q 轴加”，却没有说明角度、q 轴或转速符号的定义。

|---|---|---|

| MTPV | Maximum Torque Per Voltage | 在相应高速电压约束下的转矩优化 |

| PDO / SDO | 过程数据/服务数据对象 | CANopen 中不同的数据访问服务 |
| CSP / CSV / CST | 循环同步位置/速度/转矩模式 | 模式定义与控制环分工要分开核对 |
| STO | Safe Torque Off | 不能代替隔离、抱闸或所有情况下的受控停车 |
| RMS | Root Mean Square | 有效值不等于峰值、平均值或瞬时值 |

### B.4 状态迁移评审模板

建议把“状态、事件、守卫、动作、输出许可、故障后果”写成表，而不是只有一张框图。

| 当前状态 → 下一状态 | 事件 | 必要守卫 | 迁移动作 | 输出许可 |
|---|---|---|---|---|
| INIT → SELFTEST | 基础初始化完成 | 关键配置及硬件身份有效 | 清除易失命令，检查默认关断状态 | 禁止 |
| SELFTEST → CALIBRATION | 自检通过 | 传感链可用，校准条件允许 | 建立有效性与时间戳，执行受控校准 | 仅校准所需权限；不能等同正常运行 |
| CALIBRATION → READY | 标定完成 | 结果通过范围与一致性检查 | 保存版本/校验，清除过期命令 | 禁止正常转矩 |
| READY → RUN | 新的启动请求 | 指令新鲜、传感有效、保护无阻断、机构许可 | 同步控制状态，以受限轨迹进入运行 | 允许，但受实时门控约束 |
| RUN → STOPPING | 正常停止请求 | 停车方式满足负载风险 | 受限减速/制动与能量管理 | 取决于停车策略 |
| STOPPING → READY | 停车完成 | 停止判据、抱闸/能量状态满足要求 | 撤销运行许可，清理暂态指令 | 禁止正常转矩 |
| 任意状态 → FAULT | 危险或关键故障 | 不应依赖正常调度完成 | 按故障级别直接关断或执行已验证动作，锁存首故障 | 由独立保护与故障策略强制约束 |
| FAULT → SELFTEST | 显式复位请求 | 故障根因解除且复位允许 | 清除旧命令，重新验证必要条件 | 仍禁止；不得直接恢复上次运动 |

### C.3 完整代码

```c
/* C17 host exercise: mathematical helpers, NOT a production motor driver.
 * Build without -ffast-math: finite-input checks are intentional.
 * SI units, amplitude-invariant Clarke, d-axis aligned with alpha at theta=0.
 */
#include <assert.h>
#include <math.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

#define MC_PI 3.14159265358979323846f
#define MC_TAU (2.0f * MC_PI)
#define MC_INV_SQRT3 0.57735026918962576451f

typedef struct { float alpha, beta; } AB;
typedef struct { float d, q; } DQ;

static float clampf(float x, float low, float high) {
    return fminf(high, fmaxf(low, x));
}

static bool dq_finite(DQ x) {
    return isfinite(x.d) && isfinite(x.q);
}

static bool clarke2(float ia, float ib, AB *out) {
    if (out == NULL) return false;
    *out = (AB){0.0f, 0.0f};
    if (!isfinite(ia) || !isfinite(ib)) return false;
    AB value = {ia, (ia + 2.0f * ib) * MC_INV_SQRT3};
    if (!isfinite(value.alpha) || !isfinite(value.beta)) return false;
    *out = value;
    return true;
}

static bool park(AB x, float theta, DQ *out) {
    if (out == NULL) return false;
    *out = (DQ){0.0f, 0.0f};
    if (!isfinite(x.alpha) || !isfinite(x.beta) || !isfinite(theta))
        return false;
    float c = cosf(theta), s = sinf(theta);
    DQ value = {x.alpha * c + x.beta * s,
                -x.alpha * s + x.beta * c};
    if (!dq_finite(value)) return false;
    *out = value;
    return true;
}

static bool inverse_park(DQ x, float theta, AB *out) {
    if (out == NULL) return false;
    *out = (AB){0.0f, 0.0f};
    if (!dq_finite(x) || !isfinite(theta)) return false;
    float c = cosf(theta), s = sinf(theta);
    AB value = {x.d * c - x.q * s, x.d * s + x.q * c};
    if (!isfinite(value.alpha) || !isfinite(value.beta)) return false;
    *out = value;
    return true;
}

/* Output interval: [-pi, pi). Very large floats have already lost resolution. */
static bool angle_wrap(float theta, float *out) {
    if (out == NULL) return false;
    *out = 0.0f;
    if (!isfinite(theta)) return false;
    float value = fmodf(theta, MC_TAU);
    if (value >= MC_PI) value -= MC_TAU;
    if (value < -MC_PI) value += MC_TAU;
    *out = value;
    return true;
}

static bool angle_delta(float now, float previous, float *out) {
    if (out == NULL) return false;
    *out = 0.0f;
    if (!isfinite(now) || !isfinite(previous)) return false;
    return angle_wrap(now - previous, out);
}

/* Assumption: true motion between samples is less than half the modulus.
 * Exact half-modulus difference is ambiguous and rejected.
 * This function does not establish whether the physical assumption is true.
 */
static bool encoder_delta(uint32_t now, uint32_t previous,
                          uint32_t modulus, int32_t *out) {
    if (out == NULL) return false;
    *out = 0;
    if (modulus < 2u || modulus > (uint32_t)INT32_MAX ||
        now >= modulus || previous >= modulus) return false;
    int64_t d = (int64_t)now - (int64_t)previous;
    int64_t m = (int64_t)modulus;
    if (2 * d == m || 2 * d == -m) return false;
    if (2 * d > m) d -= m;
    if (2 * d < -m) d += m;
    *out = (int32_t)d;
    return true;
}

/* adc_counts = 2^N, not maximum code. Reject rail codes conservatively.
 * Negative gain may encode a deliberately calibrated sensor polarity.
 */
static bool adc_to_current(uint32_t raw, uint32_t adc_counts,
                           float offset_code, float vref,
                           float gain, float r_shunt, float *out) {
    if (out == NULL) return false;
    *out = 0.0f;
    if (adc_counts < 4u || adc_counts > 16777216u ||
        raw == 0u || raw >= adc_counts - 1u ||
        !isfinite(offset_code) || offset_code < 0.0f ||
        offset_code > (float)(adc_counts - 1u) ||
        !isfinite(vref) || vref <= 0.0f ||
        !isfinite(gain) || gain == 0.0f ||
        !isfinite(r_shunt) || r_shunt <= 0.0f) return false;
    float denominator = gain * r_shunt;
    if (!isfinite(denominator) || denominator == 0.0f) return false;
    float value = (((float)raw - offset_code) * (vref / (float)adc_counts))
                  / denominator;
    if (!isfinite(value)) return false;
    *out = value;
    return true;
}

typedef struct {
    float kp_d, ki_d, kp_q, ki_q;
    float kaw, ts;
    float z_d, z_q;       /* Integrator states in volts. */
    float z_limit;        /* Numeric/state guard; not the voltage circle. */
} DqPi;

static void dq_pi_reset(DqPi *p) {
    if (p != NULL) { p->z_d = 0.0f; p->z_q = 0.0f; }
}

/* Common circular saturation of total PI + feed-forward voltage.
 * z[k] produces u[k]; z[k+1] is then updated by forward Euler.
 * Real hardware may impose additional duty/voltage limits: feed those back
 * to anti-windup as well. Returning false must revoke the run permit upstream.
 * A zero voltage vector is NOT an equivalent to disabling the power stage.
 */
static bool dq_pi_step(DqPi *p, DQ reference, DQ measured, DQ feedforward,
                       float voltage_limit, DQ *out) {
    if (out == NULL) return false;
    *out = (DQ){0.0f, 0.0f};
    if (p == NULL || !dq_finite(reference) || !dq_finite(measured) ||
        !dq_finite(feedforward) ||
        !isfinite(p->kp_d) || p->kp_d < 0.0f ||
        !isfinite(p->ki_d) || p->ki_d < 0.0f ||
        !isfinite(p->kp_q) || p->kp_q < 0.0f ||
        !isfinite(p->ki_q) || p->ki_q < 0.0f ||
        !isfinite(p->kaw) || p->kaw < 0.0f ||
        !isfinite(p->ts) || p->ts <= 0.0f ||
        !isfinite(p->z_d) || !isfinite(p->z_q) ||
        !isfinite(p->z_limit) || p->z_limit <= 0.0f ||
        !isfinite(voltage_limit) || voltage_limit < 0.0f) return false;

    DQ error = {reference.d - measured.d, reference.q - measured.q};
    if (!dq_finite(error)) return false;
    DQ unsat = {p->kp_d * error.d + p->z_d + feedforward.d,
                p->kp_q * error.q + p->z_q + feedforward.q};
    if (!dq_finite(unsat)) return false;
    float magnitude = hypotf(unsat.d, unsat.q);
    if (!isfinite(magnitude)) return false;
    DQ applied = unsat;
    if (magnitude > voltage_limit) {
        float scale = voltage_limit / magnitude;
        applied.d *= scale;
        applied.q *= scale;
    }
    float zd = p->z_d + p->ts *
        (p->ki_d * error.d + p->kaw * (applied.d - unsat.d));
    float zq = p->z_q + p->ts *
        (p->ki_q * error.q + p->kaw * (applied.q - unsat.q));
    if (!isfinite(zd) || !isfinite(zq)) return false;
    p->z_d = clampf(zd, -p->z_limit, p->z_limit);
    p->z_q = clampf(zq, -p->z_limit, p->z_limit);
    *out = applied;
    return true;
}

/* Q15 multiplication: nearest rounding, ties away from zero, saturating. */
static int16_t q15_mul(int16_t a, int16_t b) {
    int32_t product = (int32_t)a * (int32_t)b;
    int32_t value;
    if (product >= 0)
        value = (product + 16384) / 32768;
    else
        value = -((-product + 16384) / 32768);
    if (value > INT16_MAX) value = INT16_MAX;
    if (value < INT16_MIN) value = INT16_MIN;
    return (int16_t)value;
}

static bool nearf(float a, float b, float tolerance) {
    return fabsf(a - b) <= tolerance;
}

int main(void) {
    AB ab, restored;
    DQ dq;
    float value;
    int32_t delta;

    for (int k = 0; k < 1000; ++k) {
        float theta = -MC_PI + MC_TAU * (float)k / 1000.0f;
        float ia = 2.5f * cosf(theta);
        float ib = 2.5f * cosf(theta - 2.0f * MC_PI / 3.0f);
        assert(clarke2(ia, ib, &ab));
        assert(park(ab, theta, &dq));
        assert(nearf(dq.d, 2.5f, 3e-5f));
        assert(nearf(dq.q, 0.0f, 3e-5f));
        assert(inverse_park(dq, theta, &restored));
        assert(nearf(restored.alpha, ab.alpha, 3e-5f));
        assert(nearf(restored.beta, ab.beta, 3e-5f));
    }
    assert(!clarke2(NAN, 1.0f, &ab));
    assert(!park((AB){1.0f, 0.0f}, INFINITY, &dq));
    assert(!inverse_park((DQ){NAN, 0.0f}, 0.0f, &ab));
    assert(angle_wrap(MC_PI, &value));
    assert(nearf(value, -MC_PI, 1e-6f));
    assert(angle_delta(0.02f, MC_TAU - 0.03f, &value));
    assert(nearf(value, 0.05f, 1e-6f));
    assert(!angle_wrap(NAN, &value));

    assert(encoder_delta(6u, 4090u, 4096u, &delta) && delta == 12);
    assert(encoder_delta(4090u, 6u, 4096u, &delta) && delta == -12);
    assert(!encoder_delta(2048u, 0u, 4096u, &delta));
    assert(!encoder_delta(4096u, 0u, 4096u, &delta));
    assert(encoder_delta(0u, 4u, 5u, &delta) && delta == 1);

    assert(adc_to_current(2048u, 4096u, 2048.0f, 3.3f,
                          20.0f, 0.005f, &value));
    assert(nearf(value, 0.0f, 1e-6f));
    assert(adc_to_current(2148u, 4096u, 2048.0f, 3.3f,
                          20.0f, 0.005f, &value));
    assert(nearf(value, 0.8056641f, 1e-5f));
    assert(!adc_to_current(4095u, 4096u, 2048.0f, 3.3f,
                           20.0f, 0.005f, &value));
    assert(!adc_to_current(2048u, 4096u, 2048.0f, 3.3f,
                           0.0f, 0.005f, &value));

    DqPi controller = {2.0f, 20.0f, 2.0f, 20.0f,
                       20.0f, 0.001f, 0.0f, 0.0f, 100.0f};
    DQ current = {0.0f, 0.0f}, voltage;
    /* Synthetic RL plant: R=1 ohm, L=0.1 H. Not a full motor simulation. */
    for (int k = 0; k < 2000; ++k) {
        assert(dq_pi_step(&controller, (DQ){20.0f, 0.0f}, current,
                          (DQ){0.0f, 0.0f}, 3.0f, &voltage));
        assert(hypotf(voltage.d, voltage.q) <= 3.00001f);
        current.d += 0.001f * (voltage.d - current.d) / 0.1f;
        current.q += 0.001f * (voltage.q - current.q) / 0.1f;
    }
    assert(current.d > 2.9f && current.d < 3.01f);
    for (int k = 0; k < 4000; ++k) {
        assert(dq_pi_step(&controller, (DQ){0.0f, 0.0f}, current,
                          (DQ){0.0f, 0.0f}, 3.0f, &voltage));
        current.d += 0.001f * (voltage.d - current.d) / 0.1f;
        current.q += 0.001f * (voltage.q - current.q) / 0.1f;
    }
    assert(fabsf(current.d) < 1e-3f);
    assert(fabsf(current.q) < 1e-3f);
    assert(!dq_pi_step(&controller, (DQ){NAN, 0.0f}, current,
                       (DQ){0.0f, 0.0f}, 3.0f, &voltage));
    dq_pi_reset(&controller);
    assert(controller.z_d == 0.0f && controller.z_q == 0.0f);
    assert(dq_pi_step(&controller, (DQ){10.0f, 10.0f}, (DQ){0.0f, 0.0f},
                      (DQ){0.0f, 0.0f}, 3.0f, &voltage));
    assert(hypotf(voltage.d, voltage.q) <= 3.00001f);

    assert(q15_mul(16384, 16384) == 8192);
    assert(q15_mul(-16384, 16384) == -8192);
    assert(q15_mul(INT16_MIN, INT16_MIN) == INT16_MAX);
    assert(q15_mul(INT16_MIN, INT16_MAX) == -32767);
    puts("All motor math demo tests passed.");
    return 0;
}
```
