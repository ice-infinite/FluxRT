## 第一次运行

解压后在MATLAB中将当前目录切到包内`matlab`：

```matlab
startup_course
selftest_math
r = run_lab(4);      % 坐标变换与角度误差
r = run_lab(11);     % 完整平均值FOC
```

输出写入你本地新生成的`results_matlab/Lxx`。PNG默认保存后关闭窗口，未弹窗不代表没运行。基础实验不依赖专用控制/优化工具箱；可选Simulink生成器需Simulink，运行后才产生.slx。

原包没有`results_matlab`中的伪造输出。`figures`、`reference_results`明确是Python参考数据。完整ZIP应保持目录结构，单独拷贝Markdown会丢失相对路径图片。

## 学习顺序

L01→L02→L04→L05→L06→L07→L08→L11构成第一轮主线。随后补采样、编码器、保护与多轴，再选无感、弱磁或机器人专项。每个实验按“预测→运行→解释→只改一个参数→再验证”完成。

## 文件说明

`docs/`：分册与实验说明；`matlab/`：源码；`figures/`：47张Python参考图；`reference_results/`：参考CSV/JSON；`reference_python/`：独立参考程序；`templates/`：4个记录模板；`source/`：原题备份。

这些是教学模型与工程分析，不是可直接烧录的驱动固件或安全认证方案。真实功率与机械实验必须有额定值核算、限制能量、机械防护与独立保护；尤其不能在48V板上复现L18计算出的危险超压。
