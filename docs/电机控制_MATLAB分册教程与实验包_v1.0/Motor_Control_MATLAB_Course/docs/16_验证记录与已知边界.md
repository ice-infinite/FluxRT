# 验证记录与已知边界

## 1. 实际执行情况

本包生成于2026-09-27。实际数值环境：Python 3.13.5、NumPy 2.3.5、Matplotlib 3.10.8。

**已执行：**独立Python参考程序24项主实验，24项通过；507个数学断言案例；生成47张结果图与24份数据CSV。原始报告见[validation_report.json](../reference_results/validation_report.json)，完整指标见[metrics_all.json](../reference_results/metrics_all.json)。

**未执行：**MATLAB原生运行、Simulink原生运行、MATLAB与Python双运行逐样本等价验证、C/Rust目标固件、任何MCU或功率板实机。

MATLAB脚本提供完整源码与依赖，进行了结构和公式检查，但本环境没有MATLAB/Octave运行时，不能宣称编译或原生运行通过。可选Simulink脚本同样未运行，不交付虚构的.slx结果。

507是数学断言案例数，不是507种硬件工况；24个PASS只覆盖代码中实际检查的输入和阈值，也不代表每个200题知识点都有独立动态仿真。

## 4. 本地MATLAB验收建议

先不修改默认参数，执行`selftest_math`和`run_all`，保留`results_matlab`。确认所有24项输出列、曲线方向与默认参考指标同数量级，再比较细节。浮点舍入级指标无需要求逐位相同；真实模型参数、输入事件、边界规则和离散状态更新顺序则必须一致。

运行单项后可用`verify_reference(id)`读取本地CSV与随包参考做容差比较；当前没有原生MATLAB比对结果，该工具本身也待本地验证。

随后做三类独立测试：对象积分步长收敛、对象与控制器参数失配、饱和/故障路径。不要把改控制周期当作只提高积分精度，也不要仅测量平均CPU时间当作最坏截止期。

对于新增PLL、HFI、动态弱磁、异步完整模型、通信栈或真实器件寄生，需要新增测试与边界说明，不能继承本包24项PASS当作已验证。
