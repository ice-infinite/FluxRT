## 1. 资料来源与使用方式

本套教材以用户已有的《电机控制面试200题：详细答案与工程实战》为题号和答案基础，原件备份在[source目录](../source/original_question_bank.md)。该原题库属于综合学习整理，不是某公司固定官方题库，也不是200道均已核实的真实面试原题。

新增加的连贯教程、案例、MATLAB代码和数值实验是本次编写内容。具体原理参考官方资料；结果是所列教学方程在给定参数下的计算，不是从厂家资料搬来的性能值。S编号保留原件引用，N编号是本次补充的软件接口资料。

下表“本次复核”只表示本次打开相应官方页面核对关键相关信息，并不表示验证其所有链接、当前产品授权价格或针对全部版本的兼容性。标记“原文保留”的条目不冒充本次全部重新查证。标准、器件细节和工具版本以目标项目使用的正式文档为准。

## 2. 符号与定义

| 符号 | 含义 | 单位/注意 |
|---|---|---|
| p | 极对数 | 不是磁极总数 |
| θm / θe | 机械/电角度 | rad；θe=pθm+offset，另约定方向 |
| ωm / ωe | 机械/电角速度 | rad/s；ωe=pωm |
| n / fe | 机械转速/电频率 | rpm、Hz；fe=pn/60 |
| ia/ib/ic | 瞬时相电流 | A；非母线平均电流 |
| id/iq | 等幅值变换电流 | A；稳态矢量幅值对应相峰值 |
| vd/vq | 旋转坐标电压 | V；区分命令与实际实现 |
| R/Ld/Lq | 模型相电阻/两轴电感 | Ω/H；不等于未经换算的端口测量 |
| ψf | 永磁磁链 | Wb；与变换缩放对应 |
| Te/TL | 电磁/负载转矩 | N·m；轴侧一致 |
| J/B | 惯量/粘性阻尼 | kg·m²、N·m/(rad/s) |
| Ts/fc | 控制周期/目标带宽 | s/Hz；不是互为倒数 |
| Vdc | 直流母线电压 | V；固定源与有限电容是不同模型 |
| z | PI积分状态 | 本包电流环为V |

采用转子永磁磁链对齐d轴，Park在θe=0时d=α、q=β：

$$i_d=i_\alpha\cos\theta_e+i_\beta\sin\theta_e,\quad i_q=-i_\alpha\sin\theta_e+i_\beta\cos\theta_e.$$

等幅值、零序为零时：

$$P_e=\frac32(v_di_d+v_qi_q),\quad P_{cu}=\frac32R(i_d^2+i_q^2),$$
$$T_e=\frac32p[\psi_fi_q+(L_d-L_q)i_di_q].$$

这些公式不能与另一种Park轴向或等功率缩放的部分公式随意拼接。所有角度函数使用rad；只在标注为degree的输出中乘180/π。

## 4. 软件能力与模型能力不要混淆

能够用Simulink导入函数，不表示函数状态与采样时序已正确；能够生成代码，不表示目标MCU已满足最坏截止期；能够运行PMSM模型，不表示参数已经覆盖真实饱和与热变化。Rust支持包只是可选集成途径，主实验不依赖它。运行环境、许可与版本以其官方页面为准。

## 5. 外部资料不能替代你自己的验证

厂家文档的示例电机、硬件、限制与命名不一定等于本包。迁移时先做单位表、坐标表和时间表，再复用算法。原题S27为2016年特定手册，用于说明功能区别，不用于声明现行安全标准版本或任何产品合规。
