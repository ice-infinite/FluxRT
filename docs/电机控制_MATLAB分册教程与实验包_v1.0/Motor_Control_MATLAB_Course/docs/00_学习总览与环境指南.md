> 学习对象：有嵌入式/编程基础，希望从原理、波形和实验掌握电机控制，而不只背面试答案。

## 1. 这套资料是什么

由原来的200题重组为13个知识分册，保留全部题号和答案主体，逐题新增案例与验证任务。另有24项MATLAB主实验、47张实际参考结果图、对应CSV数据、一个可选Simulink模型生成脚本，以及实验/故障/参数模板。

**它不是200个互相独立的完整仿真模型。**同一实验会同时解释若干相关问题；PCB寄生、协议标准、器件测量、项目表达等内容用工程案例和推演补充，而不为了“每题有图”伪造可运行效果。未实现的扩展均标成作业或后续集成任务。

## 3. 先从哪条路线开始

第一轮：第01册电气/机械基础→第03册坐标与模型→第04册调制→第05册PI与完整FOC。先依次运行L01、L02、L04、L05、L06、L07、L08、L11。你应该能解释一个电流参考怎样最终改变真实转速。

第二轮：第06册采样与编码器→第10册保护与能源→第11册多轴与代码。运行L09、L10、L18、L19、L21、L22，理解“公式正确但工程仍可能失败”的原因。

第三轮按方向选：无感读第07册；高速效率读第08册；机器人/伺服读第09册。再读第12册辨识与Simulink，将已有方程组织成自己可重复使用的实验工程。

不要要求自己先学完全部控制理论才做第一次实验，也不要只看一个闭环动画就认为已经掌握。每次做“预测→运行→解释→改一个参数→再次验证”五步。

## 5. 第一次在MATLAB运行

解压后把MATLAB当前目录切到包内的`matlab`文件夹。也可以用下面的目录选择方式，不需要改写固定盘符：

```matlab
courseFolder = uigetdir(pwd, '选择 Motor_Control_MATLAB_Course 文件夹');

cd(fullfile(courseFolder, 'matlab'));
startup_course;

```

运行之后看命令窗口打印的输出目录：`results_matlab/L04`。每个实验保存`Lxx_data.csv`、`Lxx_data.mat`、`Lxx_metrics.txt`和若干PNG。为了批量不弹出几十个窗口，绘图函数使用隐藏窗口保存后关闭；**没有自动弹图不代表没运行**。可直接打开PNG，或者：

```matlab
img = imread(fullfile(courseFolder,'results_matlab','L04','L04_dq.png'));
```

### 5.1 本地运行后与参考数据比较

```matlab
r = run_lab(4);

```

比对器读取本机`results_matlab`与随包`reference_results`，检查数据尺寸、NaN位置和逐列绝对/相对误差。默认容差是发现差异的工具，不是对所有模型的精度保证；修改参数后不应继续要求匹配原基线。该比对器也需你本地运行，当前未取得MATLAB比对结果。L03的等值相选择、L14的网格并列最优等边界可能因舍入导致单点不同；先核对物理目标和边界规则，不把任何非零差异直接认定为算法错误。

## 6. 怎么改参数才不污染基线

先保留原包不动，复制到一个实验副本。公共SPMSM参数在`common/mc_params.m`，IPMSM参数在`mc_ipm_params.m`；各实验还可能有局部频率、网格、负载、限值等参数。改公共参数会影响多个实验，且固定算例断言可能仍针对默认值，应该明确标记这是新工况而非“默认回归失败”。

实验函数允许指定输出文件夹。例如：

```matlab
startup_course;
out = fullfile(mc_root(), 'results_matlab', 'L04_variant_negative_angle');
r = lab04_transforms(out);  % 先在副本内修改delta，再运行
```

先预测方向和数量级，再运行。将每个变体的源码差异、参数和输出路径写到报告里。不建议为了让断言通过直接删断言；应区分“破坏了原前提的试验”和“公式确实写错”。

## 7. 两台教学电机，不能混参数

| 参数 | SPMSM主模型 | IPMSM扫描模型 |
|---|---:|---:|
| Rs | 0.2Ω | 0.2Ω |
| Ld | 0.4mH | 0.6mH |
| Lq | 0.4mH | 1.0mH |
| ψf | 0.02Wb | 0.012Wb |
| 极对数p | 4 | 4 |
| 母线 | 48V | 48V |
| 电流矢量上限 | 8A峰值 | 12A峰值 |
| 机械参数 | J=2e−4，B=1e−4（SI） | 本册主要作稳态扫描 |

角度用rad，机械角速度rad/s，电角速度pωm，图中部分转为rpm并标明。默认等幅值Clarke、转子磁链沿d轴，因此功率公式有3/2系数。源题中的7对极、6000rpm等白板算例是独立题设，不要覆盖全局p=4。详见[符号约定](15_参考资料与符号约定.md)。

## 8. 报错排查

| 现象 | 优先检查 |
|---|---|
| 找不到mc_params/run_lab | 是否切到matlab目录并运行startup_course；别只复制某一个.m |
| 未弹出图窗 | 图片默认保存后关闭；按输出路径打开PNG |
| 输出目录无权限 | 将完整包放到当前账户可写目录，避免受保护的安装目录 |
| assert失败 | 先恢复默认参数；检查改的是对象还是控制器，是否破坏测试前提 |
| L14曲线断开 | id=0在该速度下可能无可行点，NaN断线是模型语义，不应补成0冒充结果 |
| 同名Simulink模型已存在 | 保存/关闭已有模型，或手动选择新模型名；生成器不会静默覆盖 |
| MATLAB与参考曲线略不同 | 先比较方程、参数、步长、初值和分段事件，再看数值容差；不要假定已证等价 |

## 9. 安全边界

这些实验先在电脑中进行。任何真实功率级实验都需要额定值核算、机械固定、限流限压、独立保护和合适仪器。不得用关闭保护、反复满能量烧机或超过器件耐压来复现实验。L18的约102V是危险能量算例，不是给48V板的操作步骤。

浮动相节点和高侧Vgs测量必须使用额定与共模能力合适的差分/隔离方案；不能随意把普通接地示波器地夹接到开关节点，也不能断开保护地让仪器“浮地”。STO、停PWM、受控减速、抱闸和电气隔离不是同一种功能。

## 10. 怎样判断真的学会

以坐标变换为例：不仅能运行L04，还要能手算15°混轴、解释闭环后真实id为何可能变负，并把角度对齐到正确采样时刻。以PI为例：不仅会改Kp，还要能解释不可达参考、积分记忆、延迟相位和真实电压限制。以完整项目为例：不仅能截图，还要能保存参数、原始数据、指标定义、失败条件与验证范围。
