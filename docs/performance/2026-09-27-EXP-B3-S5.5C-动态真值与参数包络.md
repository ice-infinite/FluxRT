# EXP-B3 S5.5C：动态真值设计与参数不确定性包络

## 1. 结论

本次 **PC 比例区分审计 PASS、Rust 功能包络 PASS、参数更新仍 REJECT、再次 powered run
仍未授权**。

S5.5A/B 给出的诊断电感包络为 0.98～1.4103 mH。S5.4 的 120 点实测以精确离散 RL
回归得到 1.9503 mH；把真实电流/电压分别解释为名义换算的 ±5% 后，拟合范围反而为
1.9503～2.0402 mH，没有进入 LCR 包络。进一步把“电压比例/电流比例”从 0.1 扫到3.0，
最低仍为 1.9503 mH。因此**简单乘法比例误差不能单独解释当前差异**，也不能再用“可能
只是比例不准”作为自动重复硬件注入的理由。

同一时间，Rust `foc-bringup-sim` 对5个 L 点分别运行“控制器仍用1.058 mH”和“模型与
plant 匹配”两组，共10个10 s空载闭环工况，全部到达 final state 7、观察器有可靠样本，
峰值相电流不超过0.806 A。它证明当前控制骨架在该 L 范围内具有PC功能余量，但不证明
参数准确，也不证明真实硬件会同样稳定。

## 2. 输入与方法

输入：

- S5.4 锁转子 6×6 原始日志；
- S5.5A 固定角度三轮 Q/R/L；
- S5.5B 多方向手动粗扫范围；
- PC release `foc-bringup-sim.exe`。

比例定义：

```text
真实电流 = 名义换算电流 × current_multiplier
真实施加电压 = 名义重构电压 × voltage_multiplier
Rs 固定为 DC 实测 4.9666667 Ω
```

对连续 pulse transition 使用精确离散 RL 形式：

```text
i[k+1] = a*i[k] + (1-a)*v[k]/Rs
L = -Rs*dt/ln(a)
```

公共的电流/电压乘法因子会从回归中抵消，因此实测轨迹只能观察两者的**相对比例**，不能
凭同一条 MCU ADC 轨迹分别证明电流传递函数和实际端电压。

## 3. 比例区分结果

| 项 | 结果 |
|---|---:|
| LCR 诊断包络 | 0.9800～1.4103 mH |
| 名义精确离散拟合 | 1.9503 mH，71个连续 transition |
| 电流/电压各±5%组合 | 1.9503～2.0402 mH |
| ±5%组合进入包络 | 否 |
| 电压/电流相对比例0.1～3.0 | 最低1.9503 mH，仍未进入包络 |
| 单条轨迹能否分别识别两个比例 | 否 |

该结论只排除了“整体乘法比例”作为单一解释；它没有排除：

- PWM 周期内的非线性端电压、器件压降或钳位；
- 电流放大器带宽、相位延迟或开关同步扰动；
- ADC 采样时刻与实际 CCR 生效时刻不一致；
- 1 kHz小信号电感与0.2 A脉冲增量电感的物理差异；
- 单一转子角度下 d/q 投影与交叉耦合。

## 4. Rust 参数包络结果

共同工况：12.3 V、582 rpm、空载、10 s、Rs plant/model 均为4.9667 Ω、550 ns死区及双补偿。
L 点为0.9800、1.0580、1.1814、1.3000、1.4103 mH；每点分别保持模型1.058 mH和令模型
匹配 plant。

| 指标 | 10个工况结果 |
|---|---:|
| final state | 全部7 |
| 每组 reliable samples | 最少334 |
| 峰值相电流 | 最大0.806 A；0.81 A PC门内 |
| 稳态观察器RMSE | 最大0.781 rpm |
| 稳态 Iq RMSE | 最大0.010684 A |
| 稳态 Id RMSE | 最大0.012565 A |

这说明暂时保持1.058 mH模型不会让该**特定PC空载场景**立即失效，支持先继续软件架构、
质量门和ABI工作；它不是带载、冷热机、实机接管或量产验收。

## 5. 下一次动态真值最小方案

若以后恢复 A26 powered 辨识，必须在同一时基取得：

1. 独立相电流：隔离电流探头，或校准分流器加差分示波器通道；不能用待校准 MCU ADC
   或电源面板读数自证；
2. 差分相间 PWM 电压：使用满足共模和带宽要求的隔离差分探头，逐控制周期积分；不能把
   接地逻辑分析仪或手持万用表接到 U/V/W 开关节点；
3. ADC trigger、ISR marker、PWM update marker：LA1010 只能接隔离的3.3 V时序探针；
4. 固定转子机械索引和绕组温度；同条件至少三次，跨次极差/均值小于10%。

现有 LT1、万用表、可调电源和 LA1010 足以继续静态标定、LCR和3.3 V时序验证，但不能
提供动态相电流与开关相电压的独立幅值真值。因此 A26 的下一次 powered 参数门暂缓；不
妨碍继续 A22/A23 的质量状态、回退和版本化物理量ABI等纯软件工作。
