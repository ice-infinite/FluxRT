# P2.5A3 外部输入原始采集端口与 PC2 候选

## 1. 结论

P2.5A3 已完成目标中立的原始输入端口，以及 STM32G431 + X-NUCLEO-IHM16M1 上
`PC2/ADC1_IN8` 模拟量的默认关闭采集候选。它达到 S1 Host/Fake-register 和 S2 目标链接
证据，但还没有形成可由产品配置启用的外部控制能力：

- `board_input_mask` 仍为 `0`；
- 应用只绑定端口，不调用 `start()`；
- 原始样本尚未接入 `InputService` 的归一化和失效状态机；
- 没有烧录、板端采样、输入信号或电机运行证据。

因此本批完成的是“可移植契约 + 单板候选驱动”，不是“Analog 输入可用”。下一批
P2.5A4 必须完成生命周期、资源仲裁、失败动作和无功率板端验收，才可以考虑开放板能力。

## 2. 资源事实

### 2.1 Analog

本地 ST MCSDK 参考工程
`C:/Users/y2389_4rq4ld9/.st_workbench/Projects2/P-IHM03-Potentiometer` 表明：

- `PC2` 是 `ADC1_IN8`，用于 IHM16M1 的 `SPEED` 模拟输入；
- 参考实现的 ADC regular conversion manager 每个高频拍读取上一拍结果，再启动下一次
  regular conversion，不在高频路径轮询等待；
- FluxRT 已有 ADC1/ADC2 injected 电流采样，因此 regular group 必须与现有停机监控读取者
  统一仲裁，不能由两个模块同时发起。

据此，本批只实现“读取上一拍 EOC/DR，再启动 PC2 下一次转换”的固定上界流水线。

### 2.2 PWM pulse 与 Step/Dir

IHM16M1 原理图显示 `PB4` 经 `R40=0 Ω` 连接到驱动器 `CURRENT_REF`。虽然该引脚具备
TIM3 复用能力，但在当前扩展板上不是可自由分配的外部脉冲输入。因此：

- `FOC_G431_RESOURCE_IHM16_CURRENT_REF_PB4` 被列为保留资源；
- PWM pulse 的候选资源与该保留资源冲突；
- PWM pulse 和 Step/Dir 没有经过连接器、复用和定时器核验的专用引脚，继续保持关闭；
- DShot 仍遵守“不自写第三方协议实现”的既有边界。

## 4. 公共原始采集契约

`foc_external_input_port.h` 冻结 V1 固定布局：

- `foc_external_input_raw_sample_t`：40 B，包含输入类型、实例、序号、采样时间、有效位、
  质量位、原始值和辅助值；
- `foc_external_input_raw_health_t`：40 B，包含支持/启用/健康/故障 mask、样本数、漏采数、
  最近时间和最近错误；
- `start/stop/read_latest/get_health` 为 management-only ops；
- ISR 不通过函数表分派，只调用构建期确定的平台 tick hook；
- 端口校验拒绝未知输入位、坏版本、坏尺寸、空 context 和不完整 ops。

该层不做 ADC 码到 SI 的换算，不做 deadband，不生成 `ProductCommand`，也不接触 PWM。

## 5. STM32G431 候选实现

### 5.1 数据路径

当且仅当 `FOC_EXTERNAL_IO_FRAMEWORK` 与 `FLUXRT_INPUT_ANALOG` 均编入，平台 provider 才
声明支持 Analog。驱动在控制拍执行：

1. 若上一拍有 pending conversion，检查 EOC；
2. EOC 有效时读取 DR，发布带原启动时间戳的原始样本；
3. EOC 未到时只计一次 missed capture，并返回 busy，不轮询等待；
4. 配置 regular rank1 为 channel 8、47.5 cycles；
5. 记录本拍时间并置 `ADSTART`，由下一拍读取结果。

12 kHz 软件时间戳使用 83/84 µs 余数累加，避免固定 83 µs 的长期漂移。ISR/线程快照使用
单写者 publish guard；`start/stop` 在目标上临时屏蔽 ADC1_2 IRQ，避免生命周期切换与 ISR
写入交错。

### 5.2 启动保护

- ADC regular group 正在转换时，`start()` 返回 busy；
- 启动前清空遗留 EOC/DR，避免把原停机 Vbus/温度结果误当作 PC2；
- 未启用时平台 tick 是短路径 no-op；
- 当前应用没有调用 `start()`，所以即使 feature-on 构建也不会发起 PC2 转换；
- `board_input_mask=0`，配置校验仍拒绝把 Analog 作为板级产品能力启用。

## 8. P2.5A4 必须关闭的门

1. 只在 Axis stopped/Disabled 且配置事务批准后调用端口 `start/stop`；
2. 把现有停机 `foc_platform_sample_monitor_inputs()` 与 PC2 scheduler 收敛为一个 ADC1 regular
   owner，禁止并发写 SQR/ADSTART；
3. 实现 timeout、越界、开路/短路候选、漏采阈值、恢复滞回和明确的 Release/受控停机动作；
4. 把 raw sample 送入 `InputService` 和既有 Analog 归一化，不允许绕过 CommandArbiter；
5. 断电条件烧录，核对 `FRAW`、寄存器、序号、83/84 µs 时间戳、漏采和失败注入；
6. 测量 feature-on ADC ISR 同拍 WCET/jitter，确认与 injected 电流采样、BEMF/temp 监控无冲突；
7. 只有上述门全部通过后，才评估将 `board_input_mask` 的 Analog 位从 0 打开。

PWM pulse 与 Step/Dir 必须先选定独立连接器引脚并完成原理图/复用/Timer 资源审查，不能复用
PB4。P2.5A4 也不得因为 Analog 通过而顺带宣称它们可用。
