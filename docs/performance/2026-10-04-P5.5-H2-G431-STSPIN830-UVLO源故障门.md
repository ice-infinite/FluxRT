# P5.5 H2 STM32G431 STSPIN830 UVLO 源故障门

## 1. 目的

H2-3a/H2-3b已经证明TIM1内部Break2、IHM16M1的R35/R37无源网络和正常Break ISR。
本门只补最后一个缺口：故障必须由STSPIN830内部保护电路产生，而不是由MCU的PB12环回产生。

不采用相间短路、堵转过流或加热触发。STSPIN830官方数据手册说明：VS上升未达到
`VSth(ON)=6.0～6.5 V`前，功率级保持disabled且内部开漏把FAULT拉低；VS下降时阈值带
约0.4 V滞回。这允许用5.0 V低压、低限流安全验证驱动器自身的UVLO故障输出。

- [STSPIN830官方数据手册](https://www.st.com/resource/en/datasheet/stspin830.pdf)
- [X-NUCLEO-IHM16M1官方用户手册](https://www.st.com/resource/en/user_manual/dm00505841-getting-started-with-the-xnucleoihm16m1-threephase-brushless-motor-driver-board-based-on-stspin830-for-stm32-nucleo-stmicroelectronics.pdf)

## 2. 当前0 V基线

用户已确认主电源断开，只保留USB/ST-LINK。最终Identification镜像为：

- BIN 123,136 B，SHA-256 `73DC145D2783443F493EA23FCD7C8A8A0BDEEFDDF294AD64C05AB95D3F0447D8`；
- `foc_status`：disabled、fault0、duty0/0/0、Vbus约52 mV；
- TIM1：CR1 `0x131`、DIER `0`、SR `0x11`、CCER `0x1000`、BDTR `0x03302C00`；
- 仅CH4内部采样通道开启，CH1/2/3关闭，MOE=0，Break标志为0；
- GPIOA IDR `0x0000C80C`，PA11为高。

## 3. 受控测试步骤

1. 不改变电机接线，不触碰板上焊盘；保持USB/ST-LINK连接；
2. 可调电源先不接板，设置`5.0 V`、限流`0.20 A`，确认输出端电压；
3. 再次执行`foc_stop`并读取0 V基线；
4. 用户把5.0 V接到IHM16M1主电源输入；不执行任何arm/start/PWM命令；
5. Codex立即只读PA11、TIM1 SR/BDTR/CCER和COM6状态；
6. 取得证据后用户断开5.0 V，Codex确认PA11恢复高、输出仍关闭；
7. 若B2IF或fault latch保留，执行硬复位，再确认disabled/fault0/duty0。

## 4. 通过条件

- 电源为5.0 V且没有触及限流；
- STSPIN830内部UVLO把EN_FAULT/PA11拉低，板上D1可能点亮；
- TIM1 B2IF可以锁存，但MOE必须始终为0，CH1/2/3和Gate必须始终关闭；
- 没有电机动作、尖叫、发热或异常电源电流；
- 断开5.0 V后PA11恢复高，最终硬复位状态为disabled/fault0/duty0。

只有这组“驱动器自产生fault + 既有外部网络/ISR证据”组合成立，才评估批准
`HARDWARE_FAST_SHUTDOWN`。它仍不证明过流阈值、热保护或全工况故障延迟。

## 5. 立即停止条件

- 电源进入恒流、读数明显异常或超过0.20 A限流；
- 电机有任何动作或声音；
- 板卡、芯片、电源线出现发热、异味或闪烁异常；
- PA11保持低且断电后不能恢复；
- 任何输出通道、Gate或MOE意外开启。

任一条件出现时立即断开5.0 V；不提高电流限额、不改为12.3 V、不自动重试。

## 6. 当前阻塞与恢复条件

2026-10-04 19:11，用户确认当前没有可调电源，因此本门延期，尚未取得任何UVLO实机
证据。现有H2-3a/H2-3b结果继续有效，但不能据此批准`HARDWARE_FAST_SHUTDOWN`，也不
进入H2-4带功率验收。

以下方式不能替代本门所需电源：

- 固定12.3 V充电器：电压高于UVLO释放阈值，不能形成目标故障条件；
- USB 5 V或板上5 V：存在供电路径、地线和回灌边界不明确的问题；
- 电阻分压、临时串联电阻或其他无稳压/限流的降压方法：负载变化时电压和故障电流不可控。

恢复测试必须同时满足：电源能在板外设置并确认5.0 V，具备可调恒流限流且设为0.20 A，
接线前输出关闭。设备未具备前，只允许继续不依赖H2-3c结论的软件准备、仿真和Host测试，
板卡保持无主电安全状态。
