# CM2：Target 可编译逆变器电压模型

## 1. 结论

CM2 纯软件阶段已完成。原来只存在于 Host bridge 的死区补偿公式已拆成：

- `foc-algorithm/inverter.rs`：唯一正式纯数学公式，处理死区、器件压降和软零带；
- `foc-control/voltage.rs`：处理配置、电流极性滤波状态、观测器等效电压和 PWM 前馈组合；
- `foc-rt-bridge`：Host 只保留参数安装和一拍调度，不再拥有补偿公式；
- `foc-sim`：plant 的物理损失复用同一纯公式，但仍使用硬符号极性，与控制器软零带保持模型边界。

新模型已能被 `thumbv7em-none-eabihf` CPU/CORDIC 两种目标库和三个固件档编译，
但**没有接入目标 `Controller` 快环，没有 C ABI 开关，默认关闭**。本批没有烧录、
不访问串口、不使能功率级、不运行电机。

## 2. 公式与量纲

每相平均损失为：

```text
loss_phase_v = (2 * dead_time_s / pwm_period_s * vbus_v + device_drop_v)
               * polarity(filtered_current_a)
```

- `dead_time_s` / `pwm_period_s` 为秒，归一化始终用 PWM 载波周期；
- `device_drop_v` 是等效单相导通压降，为一阶平均值近似；
- `polarity` 在 `current_zero_band_a` 内从 -1 线性过渡到 +1，带外饱和；
- 相电流滤波为 `y += alpha * (x-y)`，`alpha=1` 与旧 Host 路径一致；
- 观测器修正是“指令电压减损失”，PWM 前馈是“指令电压加 `gain*loss`”；
- 前馈占空比最后钳位到 `[0,1]`，观测器等效占空比不限幅且不回写真实 PWM。

该公式不声称模拟了开关纹波、MOSFET/二极管非线性、母线纹波、ADC 量化或温度漂移。

## 3. 默认和安全边界

`InverterVoltageModelConfig::default()` 保持：

```text
enabled = false
observer_voltage_correction_enabled = false
feedforward_enabled = false
source = CommandModel
dead_time_s = 0
device_drop_v = 0
current_sign_filter_alpha = 1
```

配置整组校验：非有限值、非法周期、越界增益/零带/滤波系数/器件压降、
未批准的 `PhaseVoltage/Hybrid` 以及“总开关关闭但子开关开启”都会被拒绝。

目标 bridge 用 `#[cfg(not(target_os = "none"))]` 排除模型状态和调用；链接 map 中可看到
新函数仅作为地址 `0x00000000` 的已丢弃输入 section，没有进入目标运行路径。

## 4. 验证结果

### S1：Host 回归

`test.ps1` 通过：

- Profile/Python 27 项；
- Rust：`foc-algorithm` 72、`foc-control` 22、`foc-rt-bridge` 11、`foc-sim` 15，共 120 项；
- `FOC_SIM_PASS`；
- `cargo fmt --check`与 `clippy -D warnings`；
- CPU-only 与 STM32G4 CORDIC 两个 Cortex-M4F 静态库；
- CTest 4/4。

重点新回归包含：默认关闭透明、旧死区路径等价、过零软带、滤波状态、
器件压降、配置整组拒绝、plant 损失符号和补偿后闭环误差门。

```text
rows = 7
max_absolute_error = 4.3027324e-08
tolerance = 2e-06
PASS
```

## 5. 未完成与 CM3 入口

CM2 只证明架构、数值和目标可编译性。它不证明 550 ns、5 mA 零带、滤波系数、
器件压降或前馈增益适合实机。CM3 在动力实验前必须先补齐：

1. 把配置做成默认关闭、只能停机修改的版本化目标接口；
2. 先只开观测器电压修正，再独立评估 PWM 前馈，禁止一次同开后只看“能不能转”；
3. 重测完整 ADC ISR WCET、deadline miss 和输出复核路径；
4. 重新确认低压、限流、空载、电机可自由旋转、急停命令和主电源条件；
5. 用多次启动/停止比较观测器失锁、电流过零抖动、声音和电流峰值；
6. 没有编码器/外部速度真值时，不宣称角度或速度精度得到验证。
