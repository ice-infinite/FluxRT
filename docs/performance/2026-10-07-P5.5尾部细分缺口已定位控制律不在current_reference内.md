## 1. 结论：**我上一份文档的裁剪建议方向错了，现已更正**

上一份文档（`2026-10-07-P5.5核心分段归属.md`）把 `core_current_loop_cycles`（约 4,300）读作"显式电流环段"，并据此建议**下一刀砍尾部事务、不要动控制律**。

**这个归属是错的。** 本轮细分暴露出内部矛盾，只读核实后原因明确：

```rust
// lib.rs:3659-3672
fn force_reference(&self) -> bool {
    match self {
        ...
        Self::SensorlessComposite(_) => false,   // ← 复合路径为 false
        Self::Legacy(_) => false,
    }
}
```

配合 `startup.phase != RevUpPhase::ClosedLoop`（探针从未进入闭环），

```rust
controller.current_reference = if startup.phase == RevUpPhase::ClosedLoop || force_reference {
    ... 真正的电流环/参考整形 ...
} else {
    startup.current_reference        // ← 复合路径实际走这里
};
```

→ **复合路径只执行 else 分支（简单赋值），因此 `mark_reference → mark_after_reference` 只有 81 cycles 是合理的，不是测量错误。**

## 2. 缺口的位置（已核实）

三个标记与电流环预计算的实际相对位置：

| 行 | 内容 | 相对标记 |
|---|---|---|
| L4110 | `mark_startup` | 起点 |
| L4254 | `mark_reference` | |
| **L4291** | `CurrentLoop::precompute_current_frame_with_math(...)` | 在 `current_reference` 的 else 分支**之内** |
| L4351 | `mark_after_reference` | → 因此只覆盖了该块的**廉价路径** |
| **L4472** | `precompute_current_frame_with_math(...)` | **在 `mark_after_reference` 之后** |
| **L4606** | `precompute_current_frame_with_math(...)` | **在 `mark_after_reference` 之后** |

**因此 `mark_after_reference → 返回` 的 3,999 cycles 与其余 4,284 的缺口，正是电流环预计算、Park/逆 Park、限幅与 SVPWM 的实际所在。**

我给它起的名字 `tail_finish`（"遥测组装与输出快照"）**名不副实**。
