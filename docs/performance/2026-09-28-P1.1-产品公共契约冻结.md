# P1.1 产品公共契约冻结

## 1. 结论

P1.1 已完成，可以作为 P1.2 命令仲裁和 P1.3 双仿真共同 schema 的串行前置基线。
本轮冻结了 Axis 生命周期/请求、控制/输入/反馈模式、SI 命令、反馈/遥测/故障快照及
C/Rust 布局；未知值、非法组合、旧尺寸、非有限值和非规范残留字段均 fail-closed。

最高证据为 S2：全量 Host/仿真回归和四档 STM32G431 交叉构建通过。本轮没有烧录、串口、
PWM arm 或电机运行，不产生新的 S4～S6 证据。

## 2. 实现范围

- 新增 `rust/crates/foc-control/src/contract.rs`：产品类型、flag、`ProductCommand::validate()`
  和布局/组合/旧启动等价测试；
- 新增 `foc/include/foc_product_contract.h`：C 侧冻结值、SI 字段、尺寸与关键 offset 断言；
- bridge 新增产品契约版本查询和纯命令校验 FFI；全局 ABI V19→V20 / `0x00140000`；
- `main.c` 启动同时校验 bridge ABI 与产品契约版本，并打印 `FBOOT,pc=00010000`；
- 新增 C Host 布局和 524 rpm→rad/s→rpm 等价测试；C Host 总数 19→20；
- 既有 `foc_realtime_input_t` 仍是 V19 / 88 B，配置 V11、快环参数、PWM/控制频率、
  默认闭环和功率安全门均未修改；
- 完整冻结说明见[产品公共契约 V1](../产品公共契约V1.md)。

## 5. 证据边界和下一步

- P1.1 没有实现来源优先级、lease、timeout 或 mailbox；这些属于 P1.2；
- 旧 MATLAB `firmwareAbi=0x00080000` 尚未迁移，不能误当作产品契约 identity；P1.3 必须
  同时建立 scenario/profile/trace/comparison schema 后再迁移；
- 遥测/故障结构已冻结，但当前还没有产品层聚合器输出这些快照；
- `Current`、`Torque`、`Position` 等模式已定义，不等于目标状态机和硬件已经支持；
- 本轮没有 WCET 或实机结果；48 B ROM 增量来自启动版本门与打印，不授权默认闭环。

下一批可按既定文件边界并行推进 P1.2 和 P1.3；共享契约如需修改仍须回到集成主线。
