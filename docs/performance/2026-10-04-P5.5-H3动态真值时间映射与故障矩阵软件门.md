# P5.5 H3 动态真值时间映射与故障矩阵软件门

## 1. 结论

H3 动态真值的首个纯软件前置门已完成 S1。新工具不使用 UART 接收时刻推断转子相位，而是
要求 G431 与真值 MCU 对同一个物理同步边沿分别记录本地 tick，再以至少三个硬件锚点拟合
仿射时钟映射：

```text
G431 control_tick = slope * truth_tick + intercept
```

映射通过漂移与锚点残差门后，才允许把 AS5600 机械角圆周插值到 12 kHz 控制拍，并按极对数、
机械方向和电角度零偏换算真值电角度。查询不得落在硬件锚点区间或AS5600样本区间之外，不做
动态外推。

本结果只输出 `aligned-offline`，参数和目标能力始终为 `not-granted`。

## 2. 文件与合同

- 执行器：`tools/foc_h3_time_map.py`；
- manifest schema：`profiles/schema/fluxrt-h3-time-map-v1.schema.json`；
- 输入文件全部使用项目相对路径和SHA-256绑定。

三个CSV职责如下：

| 文件 | 必需字段 | 含义 |
|---|---|---|
| anchors | `edge_sequence, reference_control_tick, truth_tick` | 同一物理同步边沿在两块MCU上的本地时刻 |
| truth | `sequence, truth_tick, mechanical_angle_rad, valid, read_failures` | AS5600动态真值 |
| queries | `sequence, reference_control_tick, estimated_electrical_angle_rad, reliable` | G431每个待比较控制拍及估计角 |

manifest显式给出控制tick频率、真值tick频率、最小锚点数、最大漂移ppm、最大锚点残差和最大
真值样本间隔。这些验收值以后必须根据真实同步链路审批，不在工具内冒充电机默认参数。

## 3. 离线故障矩阵

自动测试覆盖：

1. 正常仿射映射及机械角跨`0/2pi`圆周插值；
2. 时钟漂移超限；
3. 同步锚点残差超限；
4. 锚点序号丢失；
5. AS5600序号丢失、无效样本和样本间隔超限；
6. 动态查询超出硬件锚点区间；
7. G431 `u32` control tick 回绕；
8. 文件篡改和输入错误声称批准。

所有异常路径均拒绝生成对齐结果。专项8/8、全部Profile 195/195通过。

## 4. 物理实现与首轮板端结果

物理链已经选择并完成首轮无主电验证：G431使用`PB6/TIM4_CH1`发送，DengFOC使用
`IO23/RMT RX`接收，另接公共GND；两端只由USB供电。G431在首个compare处形成连续
170 MHz DWT和12 kHz控制拍锚点，DengFOC用GPIO上升沿锁存与AS5600相同的1 MHz时基。

受控复位DengFOC后发送sequence 70～74，5/5身份与CRC匹配，
`frame_fail=0/truth_fail=0/rejected=0/overflow=0`。5个DWT锚点的首轮仿射拟合为：漂移约21.116 ppm、最大残差
3.312 us、RMS 2.248 us。这个结果证明时间合同已落到两块目标板，但采样点少、窗口短，
后续已用PB7独立回采PB6实际引脚边沿；最终run3取得20/20锚点、8,294条真值，绝对漂移
23.328 ppm、最大残差1.326 us、RMS 0.558 us。仍没有G431观察器动态query，不能作为
H3动态角度验收。

后续物理适配继续满足：

- 一个同步源、一个明确边沿；
- G431在与控制tick同一计时域记录边沿；
- DengFOC/真值板在与AS5600 `truth_tick`同一计时域记录同一边沿；
- ISR只记录固定大小事件，不在中断内打印或分配内存；
- UART只搬运已经带设备tick的数据，不参与相位对齐；
- 丢边沿、重复边沿、计数回绕歧义或漂移超限全部使动态真值无效。

## 5. 证据边界与下一步

当前证据分两层：8类合成故障矩阵仍只证明离线工具fail-closed；上述5点S4证明两端固件、
身份帧和短窗时钟拟合可运行。它们都没有arm、PWM、功率级或电机动作，也没有把能力位置1。

PB6→PB7/TIM4_CH2独立物理回采、anchors/truth和错序fail-closed已经完成；自动产物位于
`profiles/identification/sessions/h3-loopback-20261004-run3/`。下一门需要确认AS5600与
G431执行器作用于同一根转子，再采集观察器`queries.csv`并执行动态AS5600插值、角误差、
越界查询和带功率噪声验收。完成前结果仍只能是`captured-not-approved/aligned-offline`。
