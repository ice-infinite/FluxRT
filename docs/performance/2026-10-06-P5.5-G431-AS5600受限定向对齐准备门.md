# P5.5 G431 直连 AS5600 受限定向对齐准备门

## 结论

准备门之后已按固定条件执行且只执行一次带12.3 V的S5事务。G431在12,000个合法
Alignment提交拍后由同一ADC ISR关断，最终`disabled`、duty 0、fault/miss 0。G431直连
AS5600得到加法零偏候选`0.8387807509 rad`，但尚未批准写入电角度零偏，也没有提升
Sensorless/HFI能力。

候选入口只能用固定命令：

```text
foc_encoder_align P55-ALIGN1
```

它不是通用启动接口，不能改变电流、时长、角度或转速。普通 `foc_start` 在应用层继续
编译期拒绝，在平台层也无法取得候选 authority。

## 固定安全包络

| 项目 | 固定值 | 实现位置 |
|---|---:|---|
| 控制频率 | 12 kHz | `foc_as5600_alignment_trial.h` |
| 请求对齐电流 | 0.20 A | 同上；Rust 配置严格等值校验 |
| Rust 对齐时长 | 1.25 s | 同上 |
| 硬停止点 | 12,000 个已提交 Alignment 拍，即 1.0 s | ADC ISR + 纯 C trial owner |
| 最大总拍数 | 12,600 拍 | 超时即 fault-stop |
| 软件过流阈值 | 0.45 A | 命令临时收紧平台配置，结束后恢复 |
| AS5600 采样 | 20 ms，最多 64 点 | Shell 线程，I2C 不进入 ISR |
| 重复策略 | 每次启动最多一次 arm 尝试 | 失败或完成后须复位才能再试 |

ISR 在每次占空比真正提交后核对 Rust 状态必须仍为 `ALIGNMENT`；状态提前进入 Ramp、
总拍数超限、控制错误、输出拒绝、Break、驱动故障、过流、母线越界或 deadline miss 都
沿平台现有硬关断路径关闭 Gate/MOE/CCER。第 12,000 个合法对齐输出提交后，同一 ADC ISR
立即关断，因此 Shell 调度或串口阻塞不能延长功率窗口。

## 架构落位

- `foc/runtime/foc_as5600_alignment_trial.c`：硬件无关的固定包络/状态机；
- `foc/platform/stm32g431/foc_platform_stm32g431.c`：唯一 arm authority、ISR 计数和物理关断；
- `applications/main.c`：令牌、停机改参、任务态 I2C 采样、结果输出和配置恢复；
- `tools/foc_g431_as5600_alignment_capture.py`：解析结果、计算零偏候选、与历史候选交叉比较；
- `tests/host/test_foc_as5600_alignment_trial.c`：精确包络、错误状态、超时、abort 和一次性状态。

## 一次性S5结果与尚未批准项

固定条件为12.3 V、限流2 A、M0空载自由旋转、DengFOC功率输出断开。实测结果：

| 项目 | 结果 |
|---|---:|
| trial | `state=4/result=1`，12,000/12,000拍 |
| 实时/故障 | 0 deadline、0 realtime error、fault 0 |
| 峰值电流 | 93 ADC count，约148 mA |
| ISR最坏时间 | 7,731/12,750 cycles，余量39.36% |
| 加法零偏候选 | 0.8387807509 rad |
| 尾段最大偏差 | 0.0150330678 rad |
| 与历史候选圆周差 | 0.1270885814 rad |

末段满足既定两项数值门：

- 零偏候选最大偏差不超过 0.05 rad；
- 与历史 `0.9658693323 rad` 候选的圆周差不超过 0.15 rad。

目标报告51/51点有效，Host串口收到49点，缺少早期索引1、2；连续尾段35～49和完成点50
完整。因此验收器现在分别报告`transaction_ok=true`、`tail_capture_complete=true`与
`transport_capture_complete=false`，不会把早期非尾段传输缺口误判成控制事务失败，也不会
容忍稳定尾段缺口。

即使本次通过，本工具仍输出 `parameter_approval=not-granted` 和
`target_capability_approval=not-granted`；是否批准参数必须由后续记录明确决定，不能由脚本
自动提升 Sensorless/HFI 能力位。
