# EXP-B3 S5.5B：LCR 手动角度粗扫

## 1. 结论

本次 **转子位置敏感性定性筛查 PASS，精确 `Ld/Lq` 量化延期，参数更新仍 REJECT**。

用户在 S5.5A 同一测量会话后手动向多个方向转动电机，报告线间 L 最小约 1.96 mH、
最大约 2.60 mH。没有记录精确机械角度、每个极值对应的线对和逐点原始 Q/R，因此不能
拟合角度曲线；但 0.64 mH 的可见跨度已经足够说明转子位置影响具有工程量级，当前没有
必要继续人工逐 5°测量。

## 2. 与固定角度数据合并解释

| 数据 | 线间 L/mH | 证据边界 |
|---|---:|---|
| S5.5B 手动多方向粗扫 | 约 1.96～2.60 | 无精确角度/线对映射，定性使用 |
| S5.5A 固定角度 A | WV=2.1353、VU=2.8207、WU=2.1327 | 每线对三次，同线对误差 <0.4% |
| 合并观察包络 | 1.96～2.8207 | 不是统计分布，也不是 `Ld/Lq` |

本轮手动粗扫没有再次找到 S5.5A 的 2.8207 mH，不构成对固定角度数据的否定：粗扫可能
没有经过相同转子位置，且没有记录极值线对。后续若确实需要量产级 `Ld/Lq`，应改用带
角度索引的自动/半自动辨识或 Motor Profiler，不应继续依赖手持逐角度抄表。

将线间值简单除二只能得到用于仿真包络的诊断范围：本轮约 0.98～1.30 mH，合并 S5.5A
上限约 1.4103 mH。S5.4 动态值 1.950 mH 仍比该合并诊断上限高 38.27%，所以转子角度
变化是已确认的重要因素，但不能单独解释全部动态差异。

## 3. 当前决定

- 停止当前手持逐角度 LCR 测量，不要求用户完成 0/5/10/15/20/25°密集表格；
- 仿真暂用 0.98～1.41 mH 作为**不确定性扫描范围**，不写入正式 `Ld/Lq`；
- 后续 S5.5C 转向离线设计逐板动态电流/施加电压真值，检查 S5.4 的系统比例与采样模型；
- 不生成 revision，不修改 PI/SMO/PLL，不授权再次 `LSI1`；
- 精确 `Ld/Lq` 留到具备角度索引或自动辨识条件时再完成。

## 4. 证据边界

- 本报告记录的是用户口述的极值范围，不伪造不存在的逐角度原始数据；
- 主电源状态沿用 S5.5A 无主电源测量会话，本轮未执行任何板端命令；
- 未知绕组温度、精确机械角度、极值线对和接触重复次数；
- “角度敏感性 PASS”是定性筛查结论，不等于 `Ld/Lq` 数值审批。
