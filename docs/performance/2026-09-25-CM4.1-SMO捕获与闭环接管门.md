# CM4.1 SMO 捕获与闭环接管门

## 1. 结论

CM4.1 已从 CM4 的 `observer startup timeout` 推进到可重复的受限闭环：

- 修正强拖获取方向、相位门、起动期/运行期可靠性分层和终速重捕获；
- 进入 `OpenLoopHold` 时立即从已知强制角/终速重捕获，后续重试改为 200 ms；
- 200 ms 约为 582 rpm、7 极对下的 13.58 个电周期，避免旧 250 ms
  约 16.98 周期造成的“每次都在近似相位重试”；
- 观察器通过完整获取门后，50 ms 角度渐变改为单向完成；持续失锁
  仍由 200 ms 运行超时故障停机，不是取消保护；
- stage 2 只修正观察器等效电压，PWM 前馈仍关闭；该候选完成连续
  3/3 次 10 s 冷启动及 1 次 30 s 运行，均为 0 error / 0 deadline miss /
  0 fault。

这是 S5 低压、限流、空载证据，不是量产或全工况证据。实机没有编码器/
独立测速真值，因此观察器的 582 rpm 不能单独证明实际转速精度。

## 3. 失败链与根因收敛

1. 早期反向估速由低速不可观和 PLL 反向吸引域叠加；捕获期限制已知
   强拖方向，闭环后解除，保留双向运行能力。
2. 保留升速段 SMO 状态 250 ms 会继续使用约 100～180 rpm 偏置估速；改为
   终速保持首拍立即从已知速度重捕获。
3. 250 ms 重试与当前电周期近似同步，错误吸引域会被重复；改为 200 ms
   后本轮冷启动 3/3 通过。
4. 5 ms 交接与原始相位门单拍回滚会在强制/观察坐标系间摇摆；
   50 ms 单向交接让电流 PI 可以跟随，而持续失锁仍有超时保护。
5. stage 0 闭环时观察器重建 BEMF 可塌陷；stage 2 只引入已分层的观察器
   电压修正，不改变实际 PWM，实机 30 s 保持可靠。

过程中的失败也被保留：5 ms/50 ms、stage 0/2、`alpha=0.015/0.03`、
0.08/0.28 A 支撑以及 50/200 ms 失锁超时都有原始 CSV/LOG，不用最终 PASS 覆盖。

## 5. 当前边界和下一步

- 30 s 证据只覆盖一块板、一台电机、空载、约 12.3 V 和 582 rpm；
- 没有编码器/测功机，不得把观察器当成独立真值；
- 实机启动观察峰值约 894 rpm，PC 真值峰值约 842.5 rpm；两边同形，但
  启动超调仍是 A27 需要处理的问题；
- stage 2、0.24 A 边界、0.015 滤波、200 ms 失锁、50 ms 交接和 0.35 支撑
  都仍是 Diagnostic 候选，未审批进入 Production profile；
- 完成后已再次 `foc_stop`，恢复 `closedloop=0` 和 `invstage 0`；`FTIMING`
  回读三门 `0/0/0`，duty `500/500/500`，0 fault。`FSTAT state=closed` 是停机前
  遥测快照，不是 PWM 仍在输出。

下一步为 CM4.2/A27 启动超调整定：先在 PC 扫描强拖电流、升速时间和
接管转矩，然后只把通过保护与重复门的单变量候选送入受限实机。
