# P2.5A4-HW2 Analog 无功率 S4 板端门

日期：2026-10-01
证据等级：S1 全量软件回归 + S2 STM32G431 交叉构建 + S4 无功率烧录/启动/通信
硬件：NUCLEO-G431RB + X-NUCLEO-IHM16M1，ST-LINK `00400027544B500120343637`
安全状态：12.3 V 电机主电源断开，仅 USB/ST-LINK 供电；未使能功率级、未运行电机

## 1. 结论

P2.5A4-HW2 关闭了 PC2 Analog 候选的**无功率板端通路门**：

- feature-on 固件能够下载、校验、启动并通过 COM6 通信；
- 启动时 Analog 只显示“已编译支持”，enabled/healthy/fault 均为 0；
- 诊断探针临时让 PC2 持有 ADC1 regular，停机反馈监控同时从 ADC2 读取同一 PA0
  母线分压通路；三次最终探针和五次前置重复均未出现 raw 漏采；
- PC2 释放后 enabled mask 和 ADC1 owner 都恢复为 0；
- 输出、realtime arm、trial arm 和 fault 保持关闭，未提交 ProductCommand；
- PC2 窗口没有扩大已观察到的同步间隔全局 min/max，monitor ISR 最坏值为 1064 cycles，
  约为 12 kHz 名义 14167-cycle 预算的 7.5%。

这不是 Analog 产品功能开放证明。PC2 电气最小值/最大值、断线与恢复阈值、正式 Flash/RT
配置事务和 MotorService 仍未验证，所以 `board_input_mask` 继续为 0，默认 Kconfig 继续关闭。

## 2. 首次启动失败与资源保护

首次烧录的 126748 B feature-on 镜像通过 SWD 下载与校验，但启动在
`rt_application_init:218` 的 `tid != RT_NULL` 断言停止。map 显示静态 RAM 28512 B，链接器
可见 heap 仅剩 4256 B，不能可靠分配 4 KiB main 线程及 RT-Thread 元数据。

修正包括：

1. 专用 motion/external-input 探针构建把 trace 容量从 64 项降为 16 项；普通 Diagnostic
   构建仍保留 64 项；
2. 链接脚本增加 `_minimum_runtime_heap_size = 0x2400` 和 ASSERT，今后剩余运行时 heap
   少于 9 KiB 时直接链接失败，不再生成“可烧录但不能启动”的镜像；
3. feature-on 最终镜像静态 RAM 为 21800 B，`__bss_end=0x20005528`，链接器可见 heap
   为 10968 B；板端 `free` 显示 allocator 总量约 10872 B、启动后剩余约 1640 B。

这关闭了启动分配失败，但运行时余量仍紧。后续通信协议不得继续把大缓冲区无预算地加入
该组合，必须逐功能给出静态 RAM、启动后 heap 和队列上限。

## 3. 诊断探针边界

`foc_input_probe` 只在 `FOC_EXTERNAL_IO_FRAMEWORK + FLUXRT_INPUT_ANALOG + Diagnostic`
组合存在，并执行以下固定流程：

1. 幂等调用 stop，检查 Gate safe、ADC 已配置/校准、同步采样运行；
2. 拒绝 output/realtime/trial arm、fault、deadline、control error 和其他危险状态；
3. 要求 raw port 已绑定但未启用，且 ADC1 regular 无 owner；
4. 只启动 PC2 raw capture，十次读取停机反馈以触发 ADC2 Vbus fallback；
5. 读取 sample/health，等待已经开始的转换结束后释放 PC2；
6. 打印时序与结果，并要求最终 enabled/owner 都回到 0。

它不修改活动产品配置、不提交 ProductCommand、不请求 Axis 状态、不 arm，也不写 TIM1 PWM。
因此它只能用来验证物理 raw 路径和资源仲裁，不能成为日常 Shell 控制面。

## 5. 板端观测

启动能力行：

```text
FEXT,0,00000000,00000000,00000000,0
FRAW,0,00000004,00000000
FINPUT,0,00000004,00000000,00000000
FMON,0,0004231f,12000,12000,1,1189,0,off
```

其中 raw supported mask `0x4` 表示 Analog 编译存在，但 enabled mask 为 0；management
capability 仍为 0，故产品层没有公开可启用输入。

三次最终探针：

| 项 | 第1次 | 第2次 | 第3次 |
|---|---:|---:|---:|
| 新增 sample count | 1191 | 1196 | 1192 |
| missed capture | 0 | 0 | 0 |
| PC2 raw | 2047 | 2046 | 2043 |
| ADC2 Vbus raw min..max | 0..2 | 0..0 | 0..2 |
| ADC2 fallback used | 1 | 1 | 1 |
| final enabled/ADC owner | 0/0 | 0/0 | 0/0 |
| sync interval全局min..max是否扩大 | 否 | 否 | 否 |
| monitor ISR全局max | 1064 cycles | 1064 cycles | 1064 cycles |

PC2 约为中点只证明当前接线/悬空状态的 raw 值，不证明完整电压传递函数。主电源断开时 ADC1
基线和 ADC2 fallback 的 Vbus raw 都接近 0，说明没有明显路由错误；由于没有施加已知多点电压，
本轮不能建立 ADC1/ADC2 增益、偏置和温漂误差界限。

## 7. 决策与下一步

- P2.5A4-HW2 标记为完成，含义仅为 raw/default-off/ADC owner/ADC2 fallback/无功率时序通过；
- `board_input_mask` 保持 0，直到 HW3 完成 PC2 已知多点输入、端点、断线/恢复迟滞，以及
  正式配置服务对 `foc_external_input_owner_apply_config()` 的事务调用；
- 不让上述剩余电气门阻塞纯软件通信架构，主线可进入 P2.6 FluxRT Native；
- PWM/Step-Dir仍等待专用板级引脚，DShot继续受官方上游来源门约束；
- 电机主电源保持断开；本轮没有取得任何转动、闭环或控制品质证据。
