# EXP-B3 S4.4：Rust PWM 注入计划静态门

## 1. 结论

S4.4 完成了 Identification 状态请求到三相 duty **计划**的纯 Rust 路径，并通过 Host、
C ABI、四档目标构建和链接隔离检查。该计划尚未接入 ISR 的 CCR 写入路径，也没有
`foc_lsi_start`、栅极使能或 Shell 启动命令；本轮未烧录、未上主电源、未运行电机，
因此只达到 S1/S2，不构成 S5 许可。

当前板上仍是 S4.3 Identification 固件：BIN
`4BA420C62DEB09B6DD90EE88849AAD4744F548DD5475D4142AA0BEEC5979B4D9`，主电源关闭。

## 2. 分层与数据流

```text
应用状态机 foc_lsi_output_t
  OFF / BIAS / +PULSE / -PULSE
            │ 数值映射由 Host _Static_assert 锁定
            ▼
ABI V18: foc_rust_lsi_plan()
            ▼
foc-control::plan_lsi_actuation()
  纯计算、无分配、无 HAL/RTOS、无寄存器
            ▼
foc_lsi_actuation_output_t
  safe_required + source_tick + expected_active_tick + duty U/V/W
            │
            └── 尚未连接到 ISR/CCR/CCER/MOE/栅极
```

平台仍是唯一 PWM 所有者。Identification 目标初始化只调用一次 OFF 和 BIAS 计划做
“算而不写”的 ABI/包络自检；通过后置位
`FOC_PLATFORM_DIAG_LSI_ACTUATION_PLAN_CONFIGURED`。该位明确不代表硬件执行适配器存在。

## 3. 冻结数学与包络

当前计划使用筛查前馈，不闭合电流环：

```text
Vu_cmd = Rs_screening * I_bias + V_perturb
Vv_cmd = Vw_cmd = -Vu_cmd / 2
duty_u = 0.5 + Vu_cmd / Vbus
duty_v = duty_w = 0.5 - Vu_cmd / (2 * Vbus)
```

这样三相相电压和为 0，公共模固定为 0.5。任何越界都拒绝，不做钳位后继续。

| 项目 | 冻结值 | 说明 |
|---|---:|---|
| 控制/采样频率 | 12 kHz | 必须等于 Identification 同步 ISR |
| preload 名义延迟 | 1 control tick | `expected_active_tick=source_tick+1` |
| `Rs_screening` | 4.9666667 Ω/相 | 万用表三组 DC 端子值扣 0.1 Ω 表笔后折算；非 Production 审批参数 |
| 最大 bias | 0.2 A | 不允许扩大 |
| 最大扰动 | ±0.4 V | 请求方向与枚举必须一致 |
| 母线窗口 | 7～18 V | 窗外返回 fault |
| 电流 trip | 1.15 A | 绝对 U 相电流超限返回 fault |
| duty 窗口 | 3%～97% | 三相逐项检查 |

在 12.3 V 名义母线下的计划值：

| 状态 | `Vu_cmd` | `duty U/V/W` |
|---|---:|---:|
| `PULSE_NEGATIVE` | 0.593333 V | 0.548238 / 0.475881 / 0.475881 |
| `BIAS` | 0.993333 V | 0.580759 / 0.459621 / 0.459621 |
| `PULSE_POSITIVE` | 1.393333 V | 0.613279 / 0.443360 / 0.443360 |

本层不叠加死区补偿。后续辨识必须继续使用同步 Vbus、实际 CCR 和统一逆变器损失模型
重构**实际施加电压**，不能拿 `Vu_cmd` 直接拟合 Ls。

## 4. Fail-closed 语义

| 条件 | 返回 | 输出 |
|---|---|---|
| 合法 `OFF` + `force_safe=1` | `OK` | `safe_required=1`，三个 duty=0 |
| active 但 capture 未就绪 | `NOT_CONFIGURED` | 安全输出 |
| capture 已满、硬件 fault、软件 trip、电流/母线越界 | `HARDWARE_FAULT` | 安全输出 |
| 枚举、方向、布尔、版本、尺寸、NaN、包络非法 | `INVALID_ARGUMENT` | 安全输出 |
| 合法 BIAS/±PULSE | `OK` | 只返回计划；不触碰硬件 |

ABI 从 V17 提升到 V18（`0x00120000`），新增结构尺寸为 48/52/40 B；C `_Static_assert`
与 Rust `size_of` 双侧锁定。

## 5. 验证证据

### S1 / S3 回归

- `test.ps1`：profile 140、simulation 7、Rust `75 + 38 + 21 + 17`、闭环 PC 仿真、
  fmt、Clippy、CPU/CORDIC Cortex-M4F 静态库、C Host 12/12 均通过。
- 新增 Rust 测试覆盖 OFF、三种 active 计划、1 拍 ledger、方向错配、NaN、未就绪、
  满窗、fault、母线/电流越界和试图扩大冻结包络。
- C Host `_Static_assert` 锁定应用枚举与 ABI 枚举逐项相等。
- 首次全回归在 Clippy 因测试代码 `field_reassign_with_default` 停止；改为结构体更新语法后
  完整重跑通过，没有放宽 lint。

### S2 四档目标构建

| 档位 | ROM | RAM | BIN SHA-256 | Ls(I) plan 符号 |
|---|---:|---:|---|---|
| Diagnostic | 130,888 B | 23,136 B | `7E30F71A...97FFF8E` | 0 |
| Calibration | 100,304 B | 13,080 B | `84F9899B...46369687` | 0 |
| Identification | 104,500 B | 15,320 B | `6F484E65...7E386F3` | 2 |
| Production | 98,404 B | 8,960 B | `991DC57E...DD5B9FC` | 0 |

Identification 相比 S4.3 增加 2,096 B ROM、RAM 不变。最终 ELF 只有 Identification
包含 `foc_rust_lsi_default_actuation_config` 和 `foc_rust_lsi_plan`；四档均不含
`foc_lsi_start`，状态机 `foc_lsi_request_start` 也没有进入最终镜像。

ADC ISR 指令数保持 S4.3 的 539 / 436 / 548 / 404（Diagnostic / Calibration /
Identification / Production），说明本轮计划器没有进入实时 ISR。
