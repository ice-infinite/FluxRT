# EXP-B3 S5.5A：锁转子 LCR 同角度重复性

## 1. 结论

本次 **同角度重复性 PASS，线对差异可重复，参数更新仍 REJECT**。

用户保持 GBM2804H-100T 转子固定且 12.3 V 主电源未连接，用正点原子 LT1 在显示
`1 kHz / 0.6 V` 条件下按 `WV→VU→WU`、`WU→VU→WV`、`WV→VU→WU` 完成三轮
Q/R/L 测量。三条线对各自的 L 极差/均值均小于 0.4%，说明此前 VU 偏高不是随机接触
波动；但单一机械角度只能证明“线对差异稳定”，还不能单独证明它一定来自转子角度或
直接给出 `Ld/Lq`。

## 2. 原始结果

| 线对 | 三次 L/mH | 均值/mH | 样本标准差/mH | 极差/均值 |
|---|---|---:|---:|---:|
| WV | 2.138 / 2.130 / 2.138 | 2.1353 | 0.00462 | 0.375% |
| VU | 2.822 / 2.820 / 2.820 | 2.8207 | 0.00115 | 0.071% |
| WU | 2.130 / 2.138 / 2.130 | 2.1327 | 0.00462 | 0.375% |

Q、R 与 L 满足 1 kHz 串联关系 `Q≈2πfL/R`，例如首个 WV 点由 Q=1.322、R=10.16 Ω
反算 L=2.1377 mH，与用户复核后的 2.138 mH 一致。测量顺序反转后高值仍固定在 VU，
排除了简单的测量顺序漂移。

## 3. 参数解释边界

三个线对均值的整体平均为 2.3629 mH，线对间极差/均值为 **29.12%**；VU 比 WV/WU
均值高约 **32.17%**。该结果与电机凸极性、固定转子电角度或可重复的相别差异相容，
但还需要改变机械角度后观察“高电感线对是否随角度迁移”才能区分。

若仅为诊断而使用各线对平均再除以二，可得 1.1814 mH；这个换算只适合对称非凸极星形
近似，**不能作为 `Ld/Lq` 辨识结果**。S5.4 动态 1.950 mH 仍比该诊断值高 65.05%，甚至
比最高线对 VU 的一半高 38.27%，所以本次证据不能关闭动态电压/电流比例与采样模型问题。

LT1 的 0.6 V / 1 kHz 测量属于小信号、固定频率条件；板上 S5.4 是约 0.2 A 偏置附近的
短脉冲动态拟合。频率、测试电流、磁饱和和等效模型都可能使二者不同，但现有证据不足以
把 65% 差异全部归因于测试电压。

## 4. 判定与下一门

| 判定 | 结果 |
|---|---|
| 同一角度、同一线对重复性 | PASS，最大 0.375% |
| VU 与 WV/WU 的差异可重复 | PASS |
| 已证明转子角度依赖 | 否；尚未改变角度 |
| 可直接求得 Ld/Lq | 否 |
| revision/profile 参数更新 | REJECT |
| 再次 powered LSI | 未授权且本次不需要 |

下一门记为 **S5.5B 无功率机械角度扫描**：标记当前角度 A，在电机与驱动板隔离、主电源
保持断开的条件下，覆盖约 0°、5°、10°、15°、20°、25°机械角。GBM2804H-100T 为
7 极对，凸极电感的 180°电角度周期约等于 25.7°机械角。每个角度至少记录 WV/VU/WU
一轮；若高值随角度按周期迁移，则支持角度/凸极解释，否则优先检查相别、接线和仪器模型。
