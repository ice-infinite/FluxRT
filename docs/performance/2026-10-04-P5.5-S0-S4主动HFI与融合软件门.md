# P5.5-S0～S4 主动 HFI 与融合软件门

## 结论

P5.5 第一批纯软件门通过：新负序解调、凸极静止 plant、MATLAB 独立模型和 HFI/BEMF
融合监督器已建立。目标固件没有开放 HFI，未烧录、未上电、未运行电机。

## 变更摘要

- 保留旧 `RotatingHfState`，新增完整复数负序解调 `RotatingHfSequenceState`；
- 新增6场景主动HFI合同：4个凸极角度通过，低凸极和无凸极拒绝；
- 新增 MATLAB 独立模型和 Python 逐字段比较门；
- 新增 `SensorlessFusionSupervisor`，覆盖极性未决拒绝、HFI/Blend/BEMF滞环、角差门、
  权重限速、无效超时回退和角度跨零连续性；
- 为高级探针 Cargo example 补上 `required-features = ["advanced-foc"]`，普通 workspace
  测试不再错误编译专有示例。

## 限制

- 当前只验证静止、无基波的凸极RL模型，尚未加入速度、负载、死区、噪声或ADC延迟；
- mod `pi` 角度仍需脉冲/饱和极性辨识；
- 当前 GBM2804H 的凸极性和相位补偿没有独立真值；
- 目标 bridge 仍拒绝 HFI；Advanced 热路径仍需先解决 Flash/WCET 余量。
