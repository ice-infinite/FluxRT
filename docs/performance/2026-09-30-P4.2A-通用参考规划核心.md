# P4.2A 通用参考规划核心

## 范围

本阶段新增 `foc-control::motion`，实现默认关闭、无堆、板级无关的Torque/Velocity/Position
参考规划器。不修改现有V19/V20快环、电机参数、配置schema、C ABI、Shell、ISR或硬件。

## 交付

- `MotionPlannerConfig`：硬限制、ramp/filter/trajectory和软限位；
- `MotionReferencePlanner`：显式enable、模式/InputMode切换预置、事务式step；
- `MotionReference`：规划参考、独立前馈、生效限制和限幅/transition标志；
- Cargo feature `motion-control`：默认关闭，Host `--all-features`覆盖；
- 11项专项测试：默认关闭、配置/命令负例、三模式规划、限制、双向梯形轨迹、切换和反馈失败。

## 失败与修正

第一次四档构建只依赖“没有调用入口”的链接回收，ROM分别增加约200～208 B。该结果说明
公开Rust模块仍可能给最终staticlib带来容量成本，不满足严格feature-off。随后增加默认关闭的
`motion-control` Cargo feature，Host全量测试显式使用all-features，四档重新构建后尺寸和
SHA-256恢复到P4.1C基线。第一次结果不作为最终S2证据。

## 未完成

- transition标志只提供预置时机，尚未证明最终转矩/Iq逐拍连续；
- 没有配置持久化映射、C ABI、RT-Thread服务、双仿真或实机入口；
- 没有烧录、串口、电源或电机操作。

下一步是P4.2B级联控制核心；只有它完成最终输出限制和积分预置后，才能进入ABI和双仿真。
