# A19.1：官方名义相电压模型与 CommandModel 基线

## 1. 结论

本批按用户决定采用 ST 官方参考路径继续主线开发：

- X-NUCLEO-IHM16M1 的端电压诊断换算先采用官方原理图名义值；
- 无感观察器继续使用上一拍 PWM 命令与实测母线电压重构 αβ 电压；
- TP6/TP7/TP8 对应 ADC 的原始码仍不进入闭环；
- `PhaseVoltage` 与 `Hybrid` 保留稳定接口，但在逐板标定、质量门、物理量 ABI 和失效回退
  完成前明确不可用。

这使“先按官方参考工程跑通 CommandModel 主线”和“以后提高端电压测量精度”成为两条
可独立推进的路径。采用名义参数不等于 A19 逐板实测标定完成，也不构成相电压观察器证据。

- `Src/mc_tasks_foc.c:627`：STO 同时取得平均母线电压；
- `Src/mc_tasks_foc.c:700,704,716`：逆 Park 得到 `Valphabeta`，写入 PWM，并保存供下一拍
  STO 使用；
- IHM16M1 官方相端采样网络名义值为上臂 10 kΩ、下臂 2.2 kΩ，PC9 低有效接通。

名义换算：

```text
ADC/phase = 2.2 / (10 + 2.2) = 0.1803278689
phase full scale = 3.3 * (10 + 2.2) / 2.2 = 18.3 V
scale = 18.3 / 4095 = 0.004468864 V/count
display scale = 4469 uV/count
```

该公式没有逐板电阻误差、Vref 误差、ADC 偏置、保护器件、源阻抗或采样时间误差，所以
固件把它标为 `nominal-not-calibrated`，而不是 `board-calibrated`。

## 3. 代码落点和边界

| 层 | 路径 | 本批职责 |
|---|---|---|
| 通用 C 契约 | `foc/include/foc_phase_voltage_model.h` | 固定版本、来源、能力位和 40 B 整数模型 |
| 通用 C 换算 | `foc/runtime/foc_phase_voltage_model.c` | 校验元件关系；只在 divider-on 时执行 raw→mV |
| STM32G431/IHM16M1 平台 | `foc/platform/stm32g431/foc_platform_stm32g431.c` | 编入 3.3 V、4095、10 kΩ/2.2 kΩ、18.3 V 名义模型 |
| Shell/证据 | `applications/main.c`、`simulation/capture_phase_voltage_window.py` | 输出并解析 `FPV_MODEL`，拒绝 observer-eligible 名义模型 |
| Rust 控制组合 | `rust/crates/foc-control/src/voltage.rs` | `ObserverVoltageSource` 与默认 `CommandModel` 的唯一入口 |
| Rust 观察器 | `rust/crates/foc-control/src/observer.rs` | 两个后端改走统一 CommandModel 函数，数值公式不变 |

四个标志含义固定：

- `NOMINAL_COMPONENTS`：只证明参数来源于官方名义元件值；
- `BOARD_CALIBRATED`：只能由未来已审批的逐板记录产生，本批不设置；
- `DIAGNOSTIC_ONLY`：只用于采集、显示和对拍；
- `OBSERVER_ELIGIBLE`：通过全部质量门后才能设置；名义模型若同时设置此位会被校验拒绝。

模型 v1 只有共用的理论分压关系，没有每相 slope/intercept，因此校验器也会明确拒绝
`BOARD_CALIBRATED`。未来逐板模型必须升版并携带 U/V/W 独立拟合值，不能把一个共用斜率
冒充三相标定结果。

当前观察器数据流为：

```text
上一拍 PwmCommand + 本拍实测 Vbus
  → 去掉 SVPWM 共模
  → CommandModel αβ 电压
  → BEMF-SMO/PLL
```

这是现有数值路径的集中化，不是控制律变化，不提升 C/Rust ABI 版本。目标端死区/管压降
补偿仍是下一批工作；本批没有把 Host-only 补偿偷偷带入实机。

## 5. 后续顺序

官方兼容主线不再等待 TP6/7/8 逐板标定：

1. 把 Host-only 死区/管压降模型迁入 target 可编译的 Rust 电压层，但保持默认关闭；
2. PC/MATLAB 先验证 CommandModel 补偿的符号、量纲、过零零带和回退；
3. 再做低压、限流、空载、短时 target A/B，并重新测完整 ISR WCET；
4. 在不同时修改 PI/SMO/PLL 的条件下，比较启动成功率和失锁；
5. 之后再单独整定观察器与 Rev-Up。

实测相电压支线仍保留：A19 多点标定 → A20 动态相序/采样窗 → A22 质量门 → A23 ABI
→ A24 仿真 → A25 Hybrid A/B。该支线未完成前，`PhaseVoltage/Hybrid` 不得启用。
