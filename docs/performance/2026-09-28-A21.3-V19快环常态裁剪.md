# A21.3 V19 快环常态裁剪

## 1. 结论

A21.3 已通过原定实时性阶段门：Diagnostic + Rust `s` + V19 在 12 kHz、
trace 关闭时，实测完整 ADC ISR 最坏为 **9,627 cycles**，占 170 MHz
物理周期 14,166.67 cycles 的 **67.96%**，低于 70% 门槛 9,917 cycles。

相对 A21.2 同口径 trace-off 基线 10,612 cycles，本轮减少 985 cycles（**9.28%**）；
Rust control 段从 9,217 降至 8,524 cycles，减少 693 cycles（**7.52%**）。三个
5 s 开环场景均为 0 invalid / 0 control error / 0 fault / 0 deadline miss。

本结论只关闭 **A21 trace-off 软件实时性门**，不等于闭环稳定、转速准确、
长时运行或量产验收。trace 开启时最坏 10,047 cycles，占物理周期
70.92%，但仍低于 12,750-cycle 软件 deadline，且无 miss。

## 2. 目标与不变量

### 2.1 目标

- 不改变控制公式、参数和安全门，降低 V19 快环常态路径开销；
- trace 关闭时完整 ISR 不高于 12 kHz 物理周期的 70%；
- 保留 V19 完整输入拒绝、硬件故障 fail-closed、输出范围复核、deadline 关断、
  逆变器补偿启用路径和管理线程一致遥测读取。

### 2.2 本轮没有改变

| 项目 | 值 |
|---|---|
| PWM / 控制频率 | 12 kHz / 12 kHz |
| 目标速度 | 582 rpm 开环短测 |
| 默认闭环 | 关闭 |
| 观察器电压源 | `CommandModel` |
| 逆变器观察器修正 / PWM 前馈 | 关闭 / 关闭 |
| PI、SMO/PLL、Rev-Up、限流和保护阈值 | 不变 |
| Rust 优化等级 | `s` |

## 3. 修改内容

### 3.1 V19 只做一次 FFI 校验

`foc_rust_realtime_step()` 仍是唯一目标板 FFI 入口，由它完成指针、上下文、
粘滞故障和 V19 包络校验，然后把已验证引用交给私有 control core。旧的 legacy
包装器只在 Rust 测试中保留，用于 128 拍数值等价回归，不进入目标镜像。

### 3.2 CommandModel 精确快路径

V19 先校验结构尺寸、版本、flags、硬件故障位和 `actual_dt_s`。当输入正好是
当前板端已批准的 CommandModel 包络时，直接校验必需物理量；任何不同元数据、
Measured/Hybrid 候选或非标准 flags 都回落到原完整 V19 验证器。因此不是以删除输入
防御换取速度。

### 3.3 默认关闭功能不再进入重计算

- 观察器电压修正关闭时，不再计算损耗模型；
- PWM 前馈关闭时，不再调用前馈与第二次补偿输出复核；
- 一旦启用前馈，原补偿计算与第二道输出范围检查仍完整执行。

### 3.4 遥测按需复制

Rust 每拍仍更新 controller 内部遥测快照。C ISR 仅在下一拍确实要写 trace
时请求 100 B 输出副本，不再每拍复制到全局结构。管理线程的
`foc_platform_get_telemetry()` 在短临界区内通过 `foc_rust_get_telemetry()` 取一致快照，
所以未将并发一致性降级为无保护读取。

## 6. 实机条件与结束状态

- NUCLEO-G431RB + X-NUCLEO-IHM16M1 + GBM2804H-100T；
- ST-LINK `00400027544B500120343637`，COM6 @115200；
- 用户确认 12.3 V、2 A 限流、电机空载且可自由旋转、异常时可立即断电；
- 末次回读 Vbus 12.275 V，峰值电流计数 547（固件换算 872 mA）；
- 完成板上只读回后再次显式执行 `foc_trace stop`、`foc_stop`、`foc_status`；
  `st=0`、duty 0/0/0、step/error/miss=0，输出关闭、电机停止。

## 7. 边界与后续

- 没有编码器、光电测速或扭矩真值，不据固件估算速度判定精度；
- 本轮是三组 5 s 开环短测，未执行闭环、带载、长测、温升或故障注入；
- trace-on 不满足 70% 物理周期的较严格目标，但仍有 21.20% 软件 deadline
  余量且 0 miss；trace 是诊断路径，不把它的开销隐藏成常态指标；
- A21 可按已完成处理，但不因此自动提频或开放默认闭环；
- 下一个实机阶段应回到 A19/A20/A25/A26 各自的仪器、标定和独立真值
  前置，不得用本报告跨过这些门。
