# P5.5 H2 STM32G431 Break2 无主电自检门

## 1. 结论

H2-3a 已完成：Identification 增加显式`B2G1`确认字的无主电Break2自检。在Gate全低、
CH1/2/3关闭、母线约52 mV、控制器未arm的前提下，测试仅临时置TIM1 MOE，然后用内部
`B2G`生成Break2事件。板端证明硬件自动清除MOE、锁存B2IF，并经受保护路径恢复；测试前后
没有相输出、没有电机动作，最终仍disabled。

该结果证明 **TIM1内部Break2逻辑与软件恢复合同**，不证明IHM16M1外部故障网络到MCU
BKIN2引脚的动态传播。`HARDWARE_FAST_SHUTDOWN`能力继续保持0。

## 2. 实现边界

- 新增`foc_platform_lsi_break2_self_test()`，只在G431 Identification编译；
- 显式token为`B2G1`，错误token不进入平台；
- 前置要求：低母线、safety Disabled、非LSI session、Gate低、driver无故障；
- 测试期间CH1/2/3的CCER位始终为0，PB13/14/15始终为低；
- MOE置位后立即产生内部B2G，必须观测到`B2IF=1`且`MOE=0`；
- 恢复必须只得到`B2IF | B2IF_REARMED`事实，最终BIF/B2IF/MOE和三相输出均为0；
- 任一不一致立即走平台fault latch，不返回PASS。

## 3. 验证

| 等级 | 场景 | 结果 |
|---|---|---|
| S1 | `foc_platform_tests.exe`与Host C全回归 | PASS；安全空平台桩通过，60/60通过 |
| S2 | `.\build.ps1 -Profile Identification` | PASS；ROM 119,552 B（91.21%），RAM 15,496 B（47.29%） |
| S2 | Diagnostic/Calibration/Production `-BuildOnly` | PASS；证明新增平台符号不破坏其他构建档，Shell命令仍只在Identification暴露 |
| S4 | under-reset下载/verify/reset | PASS；BIN SHA-256 `7770854AC28459973E94F4C859F5BCAEB784715D0948198349BBC3733D900382` |
| S4 | `foc_lsi_break_test WRONG` | 拒绝；前后disabled、duty0、fault0 |
| S4 | `foc_lsi_break_test B2G1` | PASS；返回status 0，详见下表 |

板端机器行：

```text
FLSI_BREAK,1,0,00000011,03302c00,0330ac00,00000111,03302c00,00000802,00000011,03302c00,1,1,0,0
```

| 字段 | 解释 |
|---|---|
| before SR/BDTR | `0x11 / 0x03302C00`，无BIF/B2IF、MOE=0 |
| armed BDTR | `0x0330AC00`，仅MOE临时为1 |
| event SR/BDTR | `0x111 / 0x03302C00`，B2IF=1且MOE已由硬件清0 |
| recovery facts | `0x0802`，B2IF + B2IF_REARMED |
| after SR/BDTR | `0x11 / 0x03302C00`，Break标志与MOE恢复安全态 |
| Gate before/after | `1/1`表示两端都确认Gate低 |
| phase outputs before/after | `0/0`，CH1/2/3始终关闭 |

最终`foc_status`仍为disabled、duty0/0/0、fault0、miss0、Vbus约52 mV；ARM诊断保留
stage 2/facts `0x0802`作为自检证据，不是活动故障。

## 4. 外部路径未关闭

ST官方IHM16M1原理图显示PA11经R35连接到BKIN2选择网络，同时另有PB12经R37连接
`EN_FAULT`；不同MCU/电阻装配选项不能仅凭“PA11”字样推断为可直接短接的测试点：

- [ST官方IHM16M1原理图](https://www.st.com/resource/en/schematic_pack/x-nucleo-ihm16m1_schematic.pdf)
- [ST官方IHM16M1产品页](https://www.st.com/en/evaluation-tools/x-nucleo-ihm16m1.html)

后续H2-3b已通过PB12开漏环回完成，无需人工短接：R35/R37外部网络让硬件清MOE，
真实Break IRQ锁存fault并停止TIM1。由于STSPIN830自身的故障输出源尚未受控注入，
sensorless `HARDWARE_FAST_SHUTDOWN`仍保持0，也不进入H2-4低压锁转子注入。
