# 2026-10-01 批量代码冻结与并行验证入口

## 1. 目的与完成口径

本批采用“先完成不依赖硬件的软件代码，再并行测试”的方式，但不把未知硬件、第三方
官方协议栈或上位机用占位实现冒充完成。代码冻结只表示职责、接口、状态机、默认关闭接线
和可重复测试入口已经存在；S1/S2/S3、板端实时性和实机仍分别给证据。

上位机继续放在最后。本批不创建Host SDK、QML页面或真实设备连接。

## 2. 本批落地内容

| 工作包 | 核心落点 | 责任边界 |
|---|---|---|
| P5.1功率监督 | `power_supervisor.rs`、`power_abi.rs`、`foc_power_management.*` | Rust做温度/母线/source-sink/再生策略；C提供真实采样、硬件能力与立即关断。128 B固定上下文，默认关闭 |
| P5.2动态双仿真 | `dynamic_plant.rs`、`full_speed.rs`、`run_full_speed_closed_loop_contract.m` | Rust复用产品控制器；MATLAB独立实现；两端各自推进动态PMSM/DC link，不共享输出 |
| P5.3目标故障回退 | `advanced_abi.rs`、`foc_advanced_bridge.h` | 观察器不可靠退回基础FOC；非法输入、supervisor或PWM失败归零/故障；不自行arm |
| P2.6C参数协议 | `payload.rs`、`foc_native_bridge.h`、`payload-schema-v1.json` | 冻结定宽get/set/transaction线格式和严格校验；Fake写请求只返回`READ_ONLY` |
| P2.6C有界Fake driver | `foc_native_fake_driver.*` | 64 B packet与Rust字节流之间的分片、半帧、背压、断流和恢复；不含物理I/O |

全速域动态场景固定为正转基础、高速弱磁、反转、负载阶跃、母线跌落和再生换向六类。
当前场景使用理想转子反馈，目的是验证控制/plant/功率状态机，不是无感观察器或实机证明。

## 6. 批量验证结果

2026-10-01最终结果：

| 通道 | 结果 |
|---|---|
| Rust默认workspace | 332/332 PASS；fmt PASS |
| Rust全target/全feature Clippy | PASS，`-D warnings`下0 warning |
| Rust feature/ARM | bridge全关键feature 63/63 PASS；`thumbv7em-none-eabihf` check/release archive PASS |
| Host C | 50/50 PASS，含Power owner和Native Fake driver |
| Python仿真合同 | 47/47 PASS |
| 高级FOC双仿真 | 9/9场景PASS |
| Motion双仿真 | 11场景/31392行PASS |
| Feedback双仿真 | 5场景/80行PASS |
| 全速域动态双仿真 | 6场景/1256行PASS；所有场景最终误差进入`max(50 rpm, 10%)`设计门 |

全速域再生换向延长到3.5 s后，Rust/MATLAB最终速度分别为`-192.660767`和
`-192.661053 rpm`，双引擎差`0.000286 rpm`，相对`-200 rpm`目标的误差约`7.34 rpm`。
这仍是理想反馈下的设计模型，不是无感或硬件真值。

目标构建结论：默认Diagnostic、Advanced-only、Power-only、Native+Analog、Power+Native+
Analog以及Calibration/Identification/Production普通档均链接通过。Power上下文从256 B收缩为
128 B后，Advanced+Power也链接通过，但只比9 KiB运行堆底线多24 B；Power+Native+Analog
在收缩前的构建也只剩约1.6 KiB Flash。Advanced+Power+Native+Analog按当前源码仍超出
128 KiB Flash 6592 B，故G431RB必须按产品profile选择功能，不能宣称“所有候选同时装入一个镜像”。

验证中修复了：Power ABI五个`# Safety`文档、一个严格Clippy表达式、MATLAB loader的V20→V21
ABI身份漂移，以及再生换向场景未留足稳定时间/缺少最终误差门。所有修复均已重跑对应门。
