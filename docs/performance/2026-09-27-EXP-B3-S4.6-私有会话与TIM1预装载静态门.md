# EXP-B3 S4.6：私有会话与 TIM1 预装载静态门

## 1. 结论

S4.6 已增加 STM32G431 平台私有的 one-shot validation session，并把 S4.5 的
`WRITE_PRELOAD` 决策绑定到真实 `TIM1->CCR1/2/3`。启动期自检会在栅极、CCER 和 MOE
全部关闭时，完成一次 BIAS 计划、内部许可签发、CCR 写入、读回、下一拍 ledger 对账和
CCR 清零。Host 全回归、四档交叉构建和链接隔离通过，ADC ISR 仍为 550 条指令。

本门只达到 **S1/S2**。新 session 只允许一次**输出关闭状态下的验证写入**，不包含带功率
运行模式；preload sink 没有 ADC ISR 调用者，Shell 没有 start，Identification 普通
`foc_start` 仍在应用层和平台层双重拒绝。此固件没有烧录，板上仍是 S4.3，主电源仍关闭，
所以这里没有板端 CCR 读回、PWM 生效、采样相位或电机证据，S5 继续禁止。

## 2. 独立安全复核

实现前按“是否可能意外形成新的功率路径”复核，结论如下：

1. **不能复用普通 arm**：Identification 定义 `FLUXRT_MOTOR_ARM_DISABLED_BUILD`，
   `foc_platform_control_start()` 必须继续先硬关断再返回 `FOC_STATUS_DISABLED`。
2. **许可必须私有**：session/permit 头文件留在 `foc/platform/stm32g431/`，不进入
   `foc/include`，Shell 和应用公共接口均看不到它。
3. **许可必须一次性并绑定内容**：permit 绑定 generation、source/expected tick、三相
   compare 和 ARR；成功后立即消费，重复使用、旧 generation 或修改输出都会拒绝。
4. **最终硬件事实由平台复核**：写入前重新读取 TIM1 时钟、OC1/2/3 preload 位、ARR、
   CCER、MOE、栅极 ODR、Break/driver fault 和软件 trip，不能只相信上游布尔量。
5. **验证模式禁止有输出**：gate、MOE、任一 CH1～3 使能只要有一个为真，sink 就拒绝；
   本模块没有任何置位 gate/MOE/CCER 的代码。
6. **失败先回安全态**：validation sink 拒绝时清三相 compare；真实 STM32 wrapper 随后调用
   `foc_platform_disable_power_fast()`，保持“先 gate、再 MOE/CCER/CCR”的既有平台关断顺序。
7. **confirmation/tag 不是安全密钥**：它们用于阻止误接线、陈旧许可和内存破坏，不用于
   对抗恶意代码；真正的安全边界仍是构建隔离、私有调用图、硬件复核与快速关断。

因此 S4.6 可以实现“真实寄存器 sink 已存在且默认不可达”，但不能被解释为 powered
session 已完成。

## 3. 调用与数据流

```text
启动期、输出关闭
  Rust BIAS plan
    -> C executor 校验并量化 compare
    -> private validation session 签发 one-shot permit
    -> STM32 wrapper 复核 RCC/TIM1/gate/fault
    -> 写 CCR1/2/3
    -> 立即读回 compare
    -> 合成下一拍 raw 做 ledger 对账
    -> abort validation session
    -> disable_power_fast() 清 CCR/CCER/MOE/gate
```

不在本门中的路径：

```text
Shell/start -> powered session -> gate/MOE/CCER -> ADC ISR 连续 preload
```

上面第二条路径仍不存在。

## 4. 代码落点

| 路径 | 职责 |
|---|---|
| `foc/platform/stm32g431/foc_lsi_preload_sink_internal.h` | STM32G431 私有 session、permit、fake/real register binding 和结果码；不导出为公共平台 ABI |
| `foc/platform/stm32g431/foc_lsi_preload_sink.c` | one-shot generation/tag、输出二次校验、硬件安全事实校验、三相写入与读回、重放拒绝 |
| `foc/platform/stm32g431/foc_platform_stm32g431.c` | 唯一真实 TIM1 绑定；启动期 BIAS preload→ledger→OFF→清零自检 |
| `foc/include/foc_platform.h` | 追加 bit 23：`LSI_PRELOAD_SINK_CONFIGURED`；只表示安全状态启动自检通过 |
| `tests/host/test_foc_lsi_preload_sink.c` | fake-register 下覆盖成功、重放、陈旧/篡改 permit、输出越界、硬件不安全、ARR 错配和写回错配 |

## 5. Fail-closed 矩阵

| 条件 | 结果 |
|---|---|
| confirmation 错误、session 未初始化或重复 open | 拒绝，不签发 permit |
| 输出不是 `PRELOAD_READY/FOC_STATUS_OK` | 关闭 validation session |
| tick、compare、period、plan duty 或 tag 被修改 | permit 拒绝并清 validation compare |
| permit 已消费或 generation 陈旧 | 拒绝重放并清 validation compare |
| TIM1 时钟/配置/preload 位缺失或 ARR 错配 | 硬件不安全，平台快速关断 |
| gate、MOE、CCER 任一开启 | 硬件不安全，平台快速关断 |
| driver/Break/software trip | 硬件不安全，平台快速关断 |
| CCR 写后读回不一致 | 清 compare，平台快速关断 |
| 成功 | permit 消费、validation session 关闭，随后启动自检显式清零 |
