# 2026-10-07 P5.5 传感链内部归属：HFI 占链 51%，融合 20%，ABI 边界与包装 29%

日期：2026-10-07
基线：`main@627b169` + 本提交（链内与 ABI 分段计时）
证据等级：S4（烧录 + 板端运行；**主电源已接通但控制器未武装、无输出**）
板：NUCLEO-G431RB + X-NUCLEO-IHM16M1，ST-LINK `00400027544B500120343637`，COM6@115200
安全：控制器保持未武装；Gate/MOE/CCER 关闭；`duty=0/0/0`；`rf=00000000`；输出无法到达引脚

## 1. 结论

`chain` 约 7,500 cycles 的完整归属（128 拍，取 4 拍代表值）：

| 分段 | cycles | 占 chain | 占 12,750 预算 |
|---|---:|---:|---:|
| **HFI 旋转注入更新**（含阶段簿记） | **约 3,800** | **50.7%** | 29.8% |
| **融合监督器**（角度/速度估计） | **约 1,475** | 19.7% | 11.6% |
| **调用边界 + 入口序列**（未归属残余） | **约 936** | 12.5% | 7.3% |
| `abi_checks`（序号/账本校验 + 两次 `prepare_output` + `input_valid`） | 853 | 11.4% | 6.7% |
| `publish_chain_output` + 状态位 | 232 | 3.1% | 1.8% |
| 高频电流分离器（LPF） | 140 | 1.9% | 1.1% |
| `abi_tail` | 18 | 0.2% | 0.1% |
| **合计** | **7,464** | 100% | — |

**单拍总账**（tick 1）：`total 17,535 = control 17,018 + 前后 517`，其中 `chain 7,504`、`core 9,514`。

`abi_prepare`（入口指针/上下文解析）**稳定为 0**，即该段低于计数粒度——说明 936 的残余**不是解析开销**，而主要是 `extern "C"` 调用边界与 120 B 输出的构造/搬运。

---

## 2. 这对裁剪意味着什么（关键判断）

**可安全抽取的部分只有 fusion（1,475）与部分 HFI 解调，合计远不足以补上约 4,800 cycles 的缺口。**

1. **注入载波必须保持节拍。** HFI 的 3,800 中，旋转注入矢量的合成是载体本身；降速会改变注入频谱，而不是省下重复劳动。真正可抽取的只是解调与响应评估。
2. **即使把 fusion 全抽到 1/3，也只省约 1,000**（1,475 → 500），覆盖缺口的 21%。
3. **核心（9,514）必须同幅度削减。** 假设链侧最多省约 2,000，核心仍需再减约 2,800（29%）。核心是真正的电流环，空间更小、风险更高。

**因此"抽样链即可回到预算内"在数据上被彻底关闭**——不仅契约不允许（见 `2026-10-07-P5.5传感链抽样可行性评估.md`），而且即使允许，收益也不够。**裁剪必须同时覆盖链侧（上限约 2,000）与核心（约 2,800）。**

---

## 3. 关于 ABI 包装（约 2,040 cycles，占链 27%）

构成：未归属残余 936 + `abi_checks` 853 + publish 232 + tail 18。

**对其中两项的核查结论（本轮已更正一处错误判断）：**

- **`prepare_output` 被调用两次（`:754` 与 `:766`），但这不是浪费。** 第一次保证每条提前返回路径上输出都是完全定义的，第二次写入真实序号。两者语义不同，**不应合并**。
- **`input_valid`（`:551-562`）每拍校验结构尺寸、版本与掩码。** 这些在配置期已成立且此后不变，属于每拍重复验证常量。**这一项是真实可削减的**，但它只占 `abi_checks` 的一部分（853 中的一部分）。

**该区间的残余 936 主要是调用边界成本（120 B 结构 + 参数搬运 + 栈帧），削减需要改 ABI 形态，属于结构性改动，风险高于收益。**

---

## 4. 测量方法

链内与 ABI 包装的标记通过**函数指针注入**（`no_std` 友好、零成本抽象）：

- `foc-control` 新增 `SensorlessChainTiming` 与 `step_measured(..., mark: fn() -> u32, &mut timing)`；`step()` 保留为不计时的薄包装，**既有调用方不受影响**；
- `foc-rt-bridge` 的 `composite_mark_cycles()` 为唯一计数器入口，**宿主构建返回 0**；
- 输出结构 V3 追加 `chain_hfi/fusion/separator_cycles` 与 `abi_prepare/checks/publish/tail_cycles`（84 → 116 B，追加在末尾故旧偏移不变）；
- 平台 RAM 缓冲扩为 10 列 × 128 拍（`foc_probe_decomp_tick_t`，20 B），由 `foc_sensorless_wcet_decomp` 在 ISR 外输出。

**ISR 内无任何打印**（`AGENTS.md` 第 8 条）。

## 5. 边界与不确定

- 单一镜像、单次运行、单板、**空载**；主电源虽已接通，但控制器未武装、无输出，电流读数为静止噪声——**不代表带功率工况**；
- `run-to-run` 变异：tick 0 的链为 7,112 而 tick 1 起为 7,464～7,504（约 5%），首拍与前一份文档的 16,648→17,535 漂移同源。本节的**量级判断**（HFI 占半、融合占五分之一）稳固，100-cycle 级结论不稳固；
- `core` 仍为**差值**（`control − chain`），并吸收 Clarke、组合事务、限幅与计数器开销；
- 9 个分段标记本身的开销计入被测量区间，量级为数 cycles/标记，远低于分段差异；
- 未测：不同 feature 组合、带功率、其它转速、其它 profile。

## 6. 建议的下一步（按风险升序）

1. **把每拍不变的校验移出热路径**（`input_valid` 的尺寸/版本/掩码部分），改为一次配置期检查。**无契约风险，是唯一已确认的纯收益项。**
2. **评估 fusion 与 HFI 解调的抽取**（路线 A：保留每拍调用，仅链内降速）。上限约 1,500～2,000，需重新整定 HFI 响应与 PLL 带宽。
3. **对核心 9,514 做同样的分段归属**，找出可削减的约 2,800。**这是缺口的大头，必须做。**

**在 1 与 3 的数据到手之前，不建议启动 2。**
