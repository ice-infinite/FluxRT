# P4.2E2 逐模式低功率双仿真门

## 1. 结论

P4.2E2 已完成第一段 **S3 软件门**：Torque、Velocity、Position 分别拥有独立的低功率
候选场景、动态机械 plant、模式专属阈值和 Rust/MATLAB 双实现验收。之后Torque又完成
专用候选代码和真实板端S4无功率门；三种模式不能互相替代，S5仍未执行。

本文件第2～5节记录S3时没有修改目标控制律、产品配置、目标 ABI、Kconfig或硬件平台；
后续S4实现与板端结果见第6节。源码最终仍默认关闭candidate，电机主电源保持断开。

## 2. 实现分配

| 对象 | 职责 |
|---|---|
| `simulation/scenarios/motion_control_matrix_v1.json` | 场景revision 2；新增三种模式的动态plant、限制和候选阈值 |
| `rust/crates/foc-sim/src/motion_contract.rs` | 复用产品`MotionReferencePlanner`和`MotionCascadeController`，独立推进一阶电流响应与机械状态并执行模式门 |
| `simulink/run_motion_control_contract.m` | 不调用Rust，独立实现相同SI模型、状态推进和验收 |
| `simulation/compare_motion_control_results.py` | 校验identity、31,392行trace、D0～D4、三种模式门并输出摘要 |
| `simulation/run_motion_control_gate.ps1` | Rust→MATLAB→Python的统一入口 |

机械模型为：

```text
iq[k+1] = iq[k] + clamp(w_i * dt, 0, 1) * (iq_ref[k] - iq[k])
Te[k+1] = Kt * iq[k+1]
J * dw/dt = Te - Tload - B * w
position[k+1] = position[k] + w[k+1] * dt
```

固定参数来自当前simulation profile：`J=2.91e-5 kg*m^2`、`B=9.37e-6 N*m*s`、
`Kt=0.05805447795 N*m/A`、`dt=1/12000 s`。三个候选场景均采用
`current_response_bandwidth=2500 rad/s`和空载机械模型。

## 3. 分模式场景和结果

### 3.1 Torque

- 命令：TorqueRamp，`0.002 N*m`；
- 命令限制：`0.08 A`、`0.003 N*m`；
- 时长：1,200拍，即100 ms；
- 门：峰值电流不超过0.06 A、速度不超过8 rad/s、末端转矩误差不超过0.0001 N·m，
  且正向速度至少5 rad/s。

结果：末端转矩`0.002000 N*m`，误差`0.000000 N*m`，峰值Iq `0.0345 A`，末端速度
`6.4009 rad/s`，PASS。

Torque模式在空载下会持续加速，因此后续实机门必须使用100 ms硬时限、低电流限制和立即停机，
不能把该场景改成长时间恒转矩运行。

### 3.2 Velocity

- 命令：VelocityRamp，`5 rad/s`（约47.75 rpm）；
- 命令限制：`0.25 A`、`0.012 N*m`、`6 rad/s`；
- 时长：6,000拍，即500 ms；
- 门：峰值电流不超过0.25 A、速度不超过5.5 rad/s、末端速度误差不超过0.05 rad/s，
  超调不超过0.25 rad/s。

结果：末端速度`5.00211 rad/s`，误差`0.00211 rad/s`，超调`0.02513 rad/s`，峰值Iq
`0.0108 A`，PASS。

### 3.3 Position

- 命令：PositionFilter，目标`0.2 rad`；
- 命令限制：`0.25 A`、`0.012 N*m`、`0.5 rad/s`；
- 时长：24,000拍，即2 s；
- 门：峰值电流不超过0.25 A、速度不超过0.55 rad/s、末端位置误差不超过0.04 rad，
  位置超调不超过0.02 rad、末端绝对速度不超过0.05 rad/s。

结果：末端位置`0.20000 rad`，误差`0.00000 rad`，超调`0.00015 rad`，末端速度
`0.00009 rad/s`，峰值Iq `0.1724 A`，PASS。

Position实机门仍被真实ABZ/Hall反馈、方向、零位和硬限位前置条件阻塞；本次理想位置反馈
不能替代P4.1D。

## 5. 证据边界与powered前置条件

本门只证明：共享场景、产品planner/cascade、独立MATLAB公式和候选机械响应在给定参数下
满足S3阈值。它没有包含：

- 逆变器开关、死区、母线波动、ADC偏置/噪声和真实电流环；
- BEMF-SMO/PLL观察器、开环到闭环接管和低速可观测性；
- 真实转矩、速度或位置真值；
- 电机磁链约6.91倍口径歧义的解决；
- ABZ/Hall方向、零位、Index和硬限位；
- powered条件下observer + motion + current-loop的ISR峰值。

因此下一段不是“一次性打开三种模式”，而是：

1. 先形成Torque S5独立检查表：12.3 V、2 A电源上限、命令电流不超过0.08 A、100 ms硬时限、
   fault/deadline/duty/停止检查和立即断电条件；
2. Torque通过后才能评审Velocity，起点为5 rad/s、500 ms，重新测powered完整ISR和观察器状态；
3. Position必须等待P4.1D真实位置反馈、方向、零位及限位门，不因Torque/Velocity通过而自动开放；
4. 每一模式的实机阈值都必须根据首轮安全数据重新审批，不能把理想机械模型数值写成量产指标。

## 6. Torque S4无功率门进展

Torque现已有固定的目标状态机和Shell入口：传感器less启动沿用2 s对齐、5 s升到582 rpm、
0.8 A启动上限；只有进入ClosedLoop后才执行0.002 N·m、0.08 A上限、100 ms硬窗。普通
`foc_start`在专用镜像中固定拒绝，第1,200个Torque tick提交后在同一ADC ISR关闭输出。

候选镜像ROM 124,100 B、RAM 14,184 B；无功率板端mode 1最坏12,233/12,750 cycles、
0 miss，六点注入均fail-closed。低母线下正确确认词也在arm前拒绝且保持duty 0/0/0。
源码已恢复candidate默认关闭，但板上暂留已验证候选、输出关闭，等待用户在下一轮重新确认
12.3 V、2 A限流、空载自由旋转和可立即断电后，才执行一次powered Torque S5。
