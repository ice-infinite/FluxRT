## 1. 先核对参考工程

实际参考工程 `P-IHM03-Potentiometer` 中：

```c
#define PARK_ANGLE_COMPENSATION_FACTOR      0
#define REV_PARK_ANGLE_COMPENSATION_FACTOR  0
```

`mc_tasks_foc.c` 先把 `speedDpp * PARK_FACTOR` 加到 Park 角，随后再把
`speedDpp * REV_PARK_FACTOR` 累加后用于逆 Park。也就是说，MCSDK 提供了入口，但这份
可运行参考工程并没有启用非零角度补偿。FluxRT 因此不能把某个非零值冒充“ST 默认值”。

## 2. 本次实现

- C/Rust ABI 增加 `FocAngleCompensationConfig` /
  `foc_angle_compensation_config_t`；ABI `0x000A0000 → 0x000B0000`，配置 V5 → V6，
  运行配置 232 → 240 B。
- 配置使用两个相对基础控制角的**绝对预测拍数**：
  `park_prediction_ticks`、`reverse_park_prediction_ticks`，范围均为 `[-2, 2]`。
- 默认值为 `0/0`。Shell 只允许停机修改：

```text
foc_cfg parkdelay <milli-ticks>
foc_cfg revparkdelay <milli-ticks>
```

- PC 同源仿真增加：

```text
--park-delay-ticks <ticks>
--rev-park-delay-ticks <ticks>
```

- 每拍偏移按下式生成：

```text
delta_theta_e = mechanical_speed_rad_s * pole_pairs * control_dt_s
park_offset    = delta_theta_e * park_prediction_ticks
revpark_offset = delta_theta_e * reverse_park_prediction_ticks
```

开环使用强拖轨迹速度，接管/闭环使用观测器估速。配置为 `0/0` 时跳过速度换算。

## 3. 实时实现为什么不增加第二次 CORDIC

电流环仍只对基础角调用一次 `sin_cos`。非零偏移用五阶 `sin(delta)`、四阶
`cos(delta)` 小角度旋转已有 sin/cos；±0.25 rad 单元测试最大误差限制为 `2e-6`。
配置范围对应本项目最高转速附近不超过约 ±0.2 rad，满足该近似前提。

新增测试证明：

- 非零 Park/逆 Park 偏移仍只有 1 次 `sin_cos`、1 次 `magnitude`；
- `0/0` 路径不改变数值结果；
- 非有限值和超出 ±2 拍的配置被拒绝。

## 4. PC 多工况扫描

共同条件：同一 `foc-rt-bridge` 控制链、12/12 kHz、5 s、12.3 V、闭环、550 ns
死区模型与现有 Host 死区补偿开启。先做 `[-1, -0.5, 0, 0.5, 1]²`，再在负 Park
区域用 0.25 拍细化；最后选择四个候选与 `0/0` 在 582/800/1200 rpm、空载和
0.002 N·m 下交叉验证。

## 6. 后续使用条件

非零值只有同时满足以下条件才可再次升格：

1. GPIO/定时器测得 ADC 采样、Park 使用和 CCR 生效的实际相位延迟；
2. 接入编码器或等价角度真值，不用观测器自己证明自己；
3. 正反转、多个转速、空载/负载和母线变化下都优于 `0/0`；
4. 非零开启后的完整 ISR WCET 仍满足截止，且故障/停机路径不退化；
5. 低压限流实机 A/B 后仍保持默认关闭，直到长期与故障测试完成。
