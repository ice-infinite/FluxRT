# P5.5 H2 STM32G431 无主电平台门

## 1. 结论

2026-10-04 在用户确认12.3 V主电源断开、只连接USB/ST-LINK后，STM32G431
Identification镜像完成下载、verify、复位和无主电S4。默认禁能、同步ADC固定窗、低母线
拒绝、普通arm编译拒绝及HotPlug寄存器读回全部通过。H2-2关闭，但这不授权低压注入，
也不置位sensorless能力。

## 3. 串口安全门

烧录前旧Basic先执行`foc_stop/foc_status`：disabled、duty 0/0/0、fault/miss 0，母线
raw 8≈103 mV。烧录后结果：

| 检查 | 结果 |
|---|---|
| 启动身份 | RT-Thread 5.3.1；`p=identification,o=s` |
| 默认状态 | disabled，duty 0/0/0，fault 0，deadline miss 0 |
| 母线 | raw 7→4，约90→52 mV |
| LSI管理 | build/start命令/PWM/ADC adapter=`1/1/1/1`；state=IDLE；start consumed=0 |
| 无功率固定窗 | `256/256`完成，contract/storage error=`0/0` |
| 错误确认字 | `foc_lsi_start WRONG`明确拒绝 |
| 正确确认字但低母线 | `foc_lsi_start LSI1`返回status 2，state仍IDLE，token未消费 |
| 普通启动 | `foc_start 582`由Identification编译档明确拒绝 |
| 最终状态 | 再次`foc_stop`，disabled、duty 0/0/0、fault/miss 0 |

## 4. HotPlug寄存器证据

| 寄存器/对象 | 读回 | 判定 |
|---|---:|---|
| TIM1 CR1 | `0x00000131` | 中心对齐、计数运行、preload生效 |
| TIM1 CR2 | `0x00000070` | MMS=`111`，TRGO=OC4REF |
| TIM1 ARR/RCR | `7083 / 1` | 12 kHz基线 |
| TIM1 CCR1/2/3 | `0/0/0` | 三相命令为零 |
| TIM1 CCR4 | `7082` | 顶点前一计数产生同步采样触发 |
| TIM1 CCER | `0x00001000` | 只启用内部CH4；CH1/2/3输出关闭 |
| TIM1 BDTR | `0x03302C00` | Break/Break2配置存在，MOE=0 |
| TIM1 SR | `0x00000011` | 无BIF/B2IF锁存 |
| ADC1 JSQR | `0x00008481` | 2 ranks、TIM1_TRGO、上升沿 |
| ADC2 JSQR | `0x00001C80` | 1 rank、TIM1_TRGO、上升沿 |
| GPIOB ODR | `0x00000000` | PB13/14/15三路Gate全低 |
| GPIOA IDR | `0x0000C80C` | PA11保护输入为高，当前无active-low故障 |

`FLSI_HW`同时显示configured/valid=`1/1`，采样计数持续增加，周期`7083`，flags
`0x01E8231F`包含Gate安全、TIM1/ADC配置、自校准、offset有效、同步运行/有效样本和LSI
配置位，不包含output active、Break/current trip、deadline、control/output error或session running。

## 5. 证据边界与下一门

本门证明G431具备可继续验证的同步采样与默认禁能基础，但尚未证明：

- Break事件发生时硬件先于软件关闭输出；
- 电流比例、极性和目标电机offset已经批准；
- HFI下一拍电压、最终矢量限幅和BEMF通道已经取得目标证据；
- 任何带12.3 V的注入或电机动作。

下一步H2-3仍保持12.3 V断开，增加/执行Identification专用的Break故障注入门；只有
Gate、CCER和母线均安全时才允许测试，并在测试后恢复disabled。该门完成前
`HARDWARE_FAST_SHUTDOWN`继续为0。
