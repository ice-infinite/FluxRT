# A11：观测器接管保持门与诊断快照

## 结论

默认 12/12 kHz 闭环的偶发 `FOC_RUST_FAULT_OBSERVER_LOST` 已定位并修正。根因不是
BEMF 太低、dq 电压饱和或 ISR 超期，而是把 ST 的启动收敛门 `524 rpm` 同时当成了
接管后的运行保持门。空载接管后 Iq 接近零，估速短时下探到约 488 rpm，旧实现连续
50 ms 判为不可靠并保护停机。

修正后保留两道不同的门：

```text
首次接管：估速 >= 524 rpm + BEMF + 方差 + 连续窗口
接管保持：估速 >= 0 rpm   + BEMF + 方差 + 50 ms 失锁计时
```

`run_min=0` 不等于允许无条件零速运行；最低 BEMF 250 mV、速度方差、有限值、最大转速
和 50 ms 连续失锁保护仍然生效。

## 证据链

### 1. 失败前诊断

新增 BEMF α/β、PLL 鉴相误差、估速均值/方差、分解门位、连续窗口数、等待/失锁计时
和电压限幅快照后，默认 12 kHz 首次复现得到：

- 约 2.16 s 已进入闭环，Iq 给定从启动 0.8 A 降到空载约 0 A；
- BEMF 仍约 0.69 V，高于 0.25 V 门限；
- 方差比约 0.00262，低于 0.01 门限；
- `voltage_limited=0`，不是电压饱和；
- 只有最低速度位丢失：`gate=0x3b/0x3f`，平均估速约 488 rpm；
- 失锁计时达到约 50 ms 后锁存 `rust_fault=0x00000008`；
- ISR 最坏 11,806/12,500 cycles，无 deadline miss。

原始证据：

- `simulation/results/observer_diag_default_12k_closed_trial1_20260924.csv`
- `simulation/results/observer_diag_default_12k_closed_trial1_20260924.log`

### 2. ST 参考工程核对

参考工程 `P-IHM03-Potentiometer` 明确分开两项：

- `OBS_MINIMUM_SPEED_RPM=524` 写入 `STO_PLL_M1.MinStartUpValidSpeed`，只用于启动收敛；
- `MIN_APPLICATION_SPEED_RPM=0` 写入 `_Super.hMinReliableMecSpeedUnit`，用于 RUN 期速度
  传感器可靠性。

参考工程也会在 `SWITCH_OVER` 中把 Iq 从启动给定渐变到观测器坐标系实测 Iq，并在
`PID_SPEED_INTEGRAL_INIT_DIV=0` 时把速度 PI 积分置零。因此 Iq 在空载切换后接近零是
参考流程的一部分，不能把它单独认定为本工程 bug。

## 实现

- C/Rust ABI：`0x000A0000`；运行配置版本：V5。
- 新增分组配置 `FocObserverRunReliabilityConfig` /
  `foc_observer_run_reliability_config_t`，默认 `minimum_speed_rpm=0`。
- `RotorEstimator::is_reliable()` 继续负责首次接管；新增
  `is_reliable_for_run()` 负责接管后的保持判定。
- SMO 的运行门只替换最低转速条件，窗口就绪、有限值、最大转速、BEMF 和方差门不变。
- `foc_cfg runminspeed <rpm>` 允许停机后修改，校验要求 `0 <= runminspeed <= minspeed`。
- trace 文本扩展后将允许速率限制为 10～50 Hz。
- `RT_CONSOLEBUF_SIZE` 从 128 B 提升到 512 B；256 B 已能容纳数据行，但仍会截断
  约 374 B 的 `FTR_HEADER`，因此最终值取 512 B。

## 边界与下一步

- 这是两次 5 s 空载 S5 证据，不是负载、温升、堵转、长期或量产验证。
- 估速仍是内部观察器结果，没有编码器/测速仪真值；不能据此声称轴端误差约 1 rpm。
- ISR 软件余量只有约 632 cycles（5.1%）；诊断档可以继续用于短测，但下一步仍应
  降低最坏执行时间或建立 production 配置，不能继续无预算地增加 ISR 工作。
- 下一步优先加入/评估 Park 与逆 Park 延迟角补偿，并先在 PC/仿真中扫描系数，再做
  同口径短时实机 A/B；保持默认 `closed_loop_enable=0`。
