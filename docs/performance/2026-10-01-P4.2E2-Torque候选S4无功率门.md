# P4.2E2 Torque 候选：S4门、首次S5中止与2秒边界修复

## 1. 结论

P4.2E2 的 Torque 路线完成了原S1/S2/S4无功率准备门，并执行了第一次powered S5；
该次S5**没有通过**，但两次异常都按设计fail-closed：

- 固定候选只接受 `foc_motion_torque_trial TORQUE1`，不能由 Shell 修改转矩、电流或时长；
- 普通 `foc_start` 在专用 candidate 镜像的平台层固定返回 `DISABLED`；
- 传感器less启动沿用 CM4.4：2 s 对齐、5 s 开环升到 582 rpm，启动电流上限 0.8 A；
- 只有观察器已进入闭环后才允许 Torque 段，固定 `0.002 N·m`、`0.08 A`、1,200拍
  （12 kHz 下100 ms）；第1,200个有效输出在同一个 ADC ISR 内提交后立即关闭 Gate/MOE/CCER；
- 启动至Torque完成的总等待由ISR状态机限制为最多168,000拍（14 s），命令租约15 s；
- Vbus=0时正确确认词也在arm前拒绝，普通启动、错误确认词和候选入口均不能产生占空比；
- NUCLEO-G431RB 上原1,200 tick无功率mode 0/1、六点故障注入和最终关断均通过；
- powered第一次启动被历史B2IF在arm前拒绝，清故障后没有持续重现；
- powered第二次运行到24,003 tick（约2 s）发生ISR deadline miss并同拍关断；
- 26,000 tick无功率mode 0在相同tick确定性复现，证明问题不依赖电机、电源或机械负载；
- 源码根因是Alignment前已经完整reset，进入OpenLoopRamp首拍又完整prepare并清零两个
  64点可靠性FIFO；现已改成只预置电流模型的轻量边界seed，并生成修复candidate。

板上当前仍是旧candidate，处于deadline fault锁存、Gate/MOE/CCER关闭、duty 0/0/0；
用户已再次接入12.3 V，但禁止在旧固件上重试。修复candidate已完成S1/S2并归档，尚未烧录；
必须先断开12.3 V，完成跨2秒边界的S4复验，才能重新进入powered S5。

## 2. 固定执行契约

| 阶段 | 控制所有者 | 固定边界 | 终止条件 |
|---|---|---|---|
| Disabled/Ready | C平台安全事务 | Gate/MOE/CCER保持关闭；错误确认词拒绝 | 参数、配置、Vbus或安全门不满足即拒绝 |
| Sensorless startup | 既有Rust启动器/观察器 | 2 s alignment + 5 s ramp；582 rpm；`Iq <= 0.8 A` | 观察器可靠并进入ClosedLoop，或fault/14 s总超时 |
| Torque active | Rust motion planner/cascade | TorqueRamp `0.002 N·m`；`|Iq| <= 0.08 A`；`|T| <= 0.003 N·m` | 恰好1,200个已验证tick后同ISR硬停止 |
| Complete/Failed | C平台 | route撤销，Gate/MOE/CCER关闭 | Shell只读取结果并执行保险stop/恢复配置 |

`0.08 A`只约束进入闭环后的Torque段，**不替代**传感器less启动所需的0.8 A上限。
因此S5仍是一次约7～14 s的启动过程加100 ms Torque窗，不能描述成“全程0.08 A”。

## 5. S4无功率板端结果

### 5.1 条件

- NUCLEO-G431RB / STM32G431RBT6，ST-LINK `00400027544B500120343637`，COM6 @115200；
- 仅USB/SWD供电，电机主电源断开；预检Vbus raw=0、disabled、fault 0、duty 0/0/0；
- CubeProgrammer v2.19.0 under-reset下载、verify、reset全部PASS。

### 5.2 启动权限和低母线门

| 操作 | 板端结果 | 输出状态 |
|---|---|---|
| `foc_start 582` | `FSTART,refused,1` | disabled、duty 0/0/0 |
| `foc_motion_torque_trial BAD` | `FMT,confirm` | 未配置、未arm |
| `foc_motion_torque_trial TORQUE1`，Vbus=0 | `FMT,start,2`，在arm前拒绝 | fault 0、duty 0/0/0 |

### 5.3 无功率实时预算

| 模式 | 结果 | 完整ISR WCET | control WCET | 余量 | miss |
|---:|---|---:|---:|---:|---:|
| 0 | 1,200/1,200，1,200次安全preload | 11,405 | 10,871 | 1,345 cycles / 10.55% | 0 |
| 1 | 1,200/1,200，motion路径 | 12,233 | 11,729 | 517 cycles / 4.05% | 0 |

mode 1通过12,750-cycle硬门，但4.05%不是宽裕余量；powered时观察器、真实启动状态和Torque
切换仍须重新记录峰值。不得在这个ISR继续无预算增加工作。

### 5.4 六点故障注入

六项每次都先硬复位，分别覆盖configure前/后、combined前/中、commit前/后：1/2返回
`FMWCET,start,4`；3/5为`s=4,r=5`；4/6为`s=4,r=4`。全部保持`duty=0/0/0`、
`miss=0`并锁存预期fault。最终再次硬复位和`foc_stop`后为disabled、fault 0、Vbus raw=0。

## 6. 第一次powered S5、故障复现与下一门

### 6.1 Powered结果

条件为12.3 V、2 A限流、电机空载自由旋转、可立即断电。第一次`TORQUE1`在arm前返回
`FMT,start,4`；HotPlug只读确认PA11当前为高、Gate为低、MOE关闭，但TIM1 SR仍有历史B2IF。
执行安全`foc_fault_clear`后B2IF没有在输出关闭状态重新出现，未改Break极性或屏蔽保护。

第二次`TORQUE1`进入启动并在24,003 tick安全中止：

```text
FMT,s=5,r=5,n=0/24003,first=0,peak=439,wcet=14579,miss=1,f=00000010
FMT,end,1,3
```

`0x10`为deadline fault；峰值439 count约700 mA，仍低于0.8 A启动上限。该次没有进入Torque
闭环段，不能作为0.002 N·m、0.08 A闭环段或仿真实机一致性的证据。

### 6.2 无功率同tick复现

清故障、保持Gate/MOE/CH1-3关闭后执行`foc_motion_wcet 26000 0`：

```text
FMWCET,m=0,s=4,r=6,n=24003/26000,c=24003,inj=0,wcet=15271,ctrl=14767,miss=1
```

失败tick与powered完全一致，排除了功率输入、电机和机械负载。调用链显示启动入口已在Alignment
前完整reset；进入OpenLoopRamp首拍再次完整prepare，重复清空两个`[f32;64]`可靠性FIFO，且同拍
还要执行观察器更新和电流环，形成只在状态边界出现的WCET尖峰。

修复保留启动前完整reset，只把边界动作改成轻量`seed_after_alignment()`：SMO只设置
`current_est`，BEMF只设置`last_current/initialized`。这既避免首拍虚假的`L*di/dt`/滑模误差，
也不再重复清空统计窗。

### 6.3 下一门：先断电烧录，再做S4

当前不允许直接再跑powered。下一步必须依次执行：

1. 用户断开12.3 V并确认；
2. 烧录修复BIN `138D0E3F...30444DD`，download/verify/reset；
3. 在Vbus为0、Gate/MOE/CCER关闭条件下运行`foc_motion_wcet 26000 0`；
4. 再运行`foc_motion_wcet 1200 1`；
5. 两项都要求完整执行、`miss=0`、无fault、最终duty 0/0/0；
6. 只有上述S4通过，才重新请求12.3 V/2 A/空载确认并执行唯一一次`TORQUE1`。

重新进入powered前仍必须由用户明确确认：

1. 12.3 V电机电源已接，电源限流仍为2 A；
2. 电机空载、可自由旋转，周围无缠绕物；
3. 可在异常声音、剧烈抖动、过流或失控时立即断电；
4. 不触碰转子，逻辑分析仪探头不短接功率节点。

确认后只执行一次`foc_motion_torque_trial TORQUE1`。采集`FMT`结果、观察器状态、完整ISR
WCET/miss、fault、三相duty和最终关断；不会连续重试，也不会自动进入Velocity/Position。

## 7. 证据边界

本报告证明专用镜像、权限收口、低母线拒绝、旧候选边界故障的确定性复现、源码修复候选
及故障关断，尚不能证明：

- 观察器能在本次上电稳定获取并进入闭环；
- 真实Torque等于0.002 N·m，或仿真速度曲线与实机一致；
- 修复candidate已在目标板跨过24,000 tick而`miss=0`；
- powered完整启动路径满足实时预算，原4.05%余量也不能外推到新候选；
- 磁链口径、Rs/Ld/Lq已获得最终审批；
- Velocity、Position、长时间、负载或产品安全已经通过。
