# CM4 重复启动与闭环基线门

## 1. 结论

CM4 在约 12.3 V、2 A 限流、空载条件下完成 12 次开环重复启动，并只执行了一次
stage 0 闭环请求：

- stage 0 开环 5/6 次在 5 秒结束时 reliable；
- stage 2 开环 3/3 次 reliable；
- stage 4 开环 3/3 次 reliable；
- 12 次开环均为 0 error/miss/fault，峰值电流不超过约 936 mA；
- 末尾追加的 stage 0 为 3/3，说明温升/运行顺序是明显混杂因素，不能用本批小样本证明
  stage 2/4 优于基线；
- stage 0 的首次闭环请求没有进入闭环状态：观察器估速最终稳定在反向约 -817 rpm，
  触发 `FOC_RUST_FAULT_OBSERVER_STARTUP (0x00000004)` 并自动关断；
- 因为基线接管失败，本轮没有继续尝试 stage 2/4 闭环。

当前板卡已复位回默认 stage `0/0/0`、closed 0、输出关闭，Vbus 12.288 V，
0 step/error/miss/fault。

## 2. 条件与不变量

| 项目 | 值 |
|---|---|
| 板卡 | NUCLEO-G431RB + X-NUCLEO-IHM16M1 |
| 电机 | GBM2804H-100T，空载、可自由旋转 |
| 固件 | CM3 Diagnostic `0D62D11C...E1E66AF` |
| 供电 | 板端约 12.262～12.301 V；用户确认限流 2 A、可立即断电 |
| PWM / 控制 | 12 kHz / 12 kHz |
| 开环运行 | 582 rpm、800 mA、每次 5 s、trace 关闭 |
| 闭环请求 | 582 rpm、800 mA、最多 5 s、50 Hz trace |
| 固定项 | PI、SMO、PLL、Rev-Up、电机参数、保护阈值均未修改 |

所有运行都由脚本显式 `--allow-motor-run`，开始与异常/正常结束路径均调用
`foc_stop`。闭环脚本还会恢复 `closedloop=0`。

## 3. 开环重复性结果

测试顺序是 stage 0 三次、stage 2 三次、stage 4 三次、stage 0 括号组三次。

| Stage | 门 `总/观测/PWM` | 次数 | reliable | 可靠轮次速度均值 | WCET 范围 | 峰值电流范围 | error/miss/fault |
|---:|---|---:|---:|---|---|---|---|
| 0 | `0/0/0` | 6 | 5/6 | 579～589 rpm | 9,221～9,272 cycles | 约 896～936 mA | 全部 `0/0/0` |
| 2 | `1/1/0` | 3 | 3/3 | 581～588 rpm | 9,867～9,899 cycles | 约 904～912 mA | 全部 `0/0/0` |
| 4 | `1/1/1` | 3 | 3/3 | 575～584 rpm | 10,445～10,485 cycles | 约 911～924 mA | 全部 `0/0/0` |

stage 0 的不可靠轮次得到 `speed mean=-813 rpm`、gate `0x3b`；其余可靠轮次 gate
均为 `0x3f`。stage 0 末尾括号组三次全部可靠，说明初始温度、停机间隔、初始转子位置
或未观测的启动条件可能影响结果。当前不是随机交错试验，也没有温度/转子位置真值，
所以 5/6 与 3/3 不能直接换算成可靠性提升概率。

## 4. 闭环基线请求

只测试 stage 0：

| 项目 | 结果 |
|---|---|
| 请求 | `closedloop=1`，582 rpm，最长 5 s，50 Hz trace |
| 实际捕获 | 133 samples，约 2.640 s |
| 状态 | 经 alignment/open-loop/handoff-wait，但没有进入稳定 closed-loop |
| 观察器 | 0 reliable samples；最终 speed mean 约 -817 rpm，variance 约 1,127 rpm² |
| 可靠性缺口 | min-speed 25/25 个摘要样本不通过，variance 8/25 不通过 |
| 故障 | control status 4，`rust_fault=0x00000004`（observer startup timeout） |
| 实时性 | ISR max 12,184/12,500 cycles，0 deadline miss |
| 电流 | 板载估计峰值约 931 mA，未触发 1,150 mA 保护 |
| 结束 | 脚本先 `foc_stop`，恢复 `closedloop=0`；随后人工复位清除锁存故障 |

50 Hz trace 使 post 段峰值增加到 3,745 cycles，完整 ISR 只剩 316 cycles（2.53%）
软件截止余量。因此后续闭环诊断不能再向 ISR 增加重型 trace 字段；需要先离线利用本次
数据定位观察器反向估速和接管窗口问题。

## 6. 下一步门

下一步是 CM4.1 离线诊断，不再运行电机：

1. 对齐 forced angle、observer angle、BEMF、PLL phase error、speed mean/variance 与状态迁移；
2. 判断反向估速来自相序/角度符号、低速 BEMF 可观测性、SMO/PLL 收敛，还是接管时机；
3. 不通过放宽 min-speed/variance 门来掩盖问题；
4. 先在 PC/MATLAB/Host 回放本次失败 trace，再提出单变量候选；
5. 只有候选通过离线门和新的明确实机条件确认，才重新做 stage 0 闭环基线。
