# EXP-B3 S4.1：原始样本窗与实际施加电压重构

## 1. 结论

S4.1 的 Host 与目标静态门通过，但它仍不是功率注入许可：

- C 应用层新增 256×24 B 固定原始窗，满窗锁存且不覆盖旧证据；
- Rust 纯算法层复用同一逆变器损失模型重构实际平均 line-to-neutral 相电压；
- 没有增加 `foc_lsi_start`，没有 PWM/ADC 平台适配，没有修改当前 ADC ISR；
- 新 Identification 固件只在本地构建，未下载，板上继续运行上一版 S4 安全固件。

## 2. 数据契约

每拍原始记录为 24 B：`sequence/control_tick`、U/V 电流 ADC、同步 Vbus ADC、当拍实际
生效的 U/V/W CCR、PWM 周期和状态/故障标志。容量 256 拍，共 6 KiB；默认候选的
120 拍 bias + 48 拍双极性脉冲 + 至少 24 拍 cooldown 可完整保留。若电流迟迟不回零导致
第 257 拍仍需记录，`record_isr` 返回失败并锁存 `OVERFLOW`；未来平台必须同拍关断，不能
环形覆盖或继续实验。

Vbus 字段必须来自与 U/V 电流相同的 injected sequence。当前平台的
`g_foc_diagnostics.bus_voltage_raw` 是停机慢速监测值，不能用于本实验。CCR 必须在 ISR 写
下一拍命令前采集，保证“电流样本—实际施加 PWM”对齐。

Rust 公式先把 duty 转成三个桥臂电压，再扣除统一的死区/器件压降，最后去掉三相共模：

```text
leg_x     = duty_x * Vbus - loss_x(current_x, dead_time, device_drop)
common    = (leg_u + leg_v + leg_w) / 3
applied_x = leg_x - common
```

非法 duty、非正 Vbus、NaN/Inf 电流或非法损失参数直接返回 `None`，不做钳位。

- 本轮无串口、无下载、无上电、无 PWM、无电机运行；主电源保持关闭。
- 板上仍为 BIN `AED75B3A...875F7C3`；本轮 Identification HEX
  `EF74DD76...37309A` / BIN `BAA538DD...98D853` 未烧录。
- 下一步只实现平台适配器的无功率骨架和 Host fake：同步 Vbus、active CCR 快照、序号/
  overflow/量程错误同拍关断。仍不导出 start。
- 只有新增路径的 target size、ISR 机器码与板端无功率 WCET 重新通过，才可另行评审是否
  允许 0.2 A S5；S4.1 本身不提供许可。
