# EXP-B3 S4.8：bounded active session 静态与无功率门

## 1. 结论

S4.8 **PASS**。STM32G431 私有 preload sink 已从 validation-only one-shot 扩展为可表达
bounded active session 的逐拍许可层，并完成 Host、四档 S2 和目标板无主功率 S4：

- active session 必须使用独立 `LSIA` confirmation，且一次只能打开一个 generation；
- 每个 permit 绑定 generation、session mode、permit sequence、source/expected tick、
  CCR1/2/3 和 ARR，旧 permit、重放、篡改或跳拍都会拒绝；
- active 写入上限硬限制为 600 次，总拍数上限硬限制为 6000 拍；调用者还能选更小值；
- 第一笔 active preload 只允许 gate/MOE/CCER 全关，之后每笔只允许三者全部开启；
- 任一 sink 侧错误清三相 compare 并关闭 session；budget/sequence 在 issue 阶段返回错误，
  未来 ISR 调用者必须同拍执行平台快速关断；
- 目标启动期只验证 active session 的**第一笔 outputs-off 写入**，随后完成 executor ledger、
  abort 和 CCR 清零，并置位诊断 bit 24。

本阶段仍然没有 ADC ISR active caller、`foc_lsi_start`、gate-enable 操作或 power-arm token。
因此 S4.8 是“权限与预算契约可用”的证据，不是 powered session，也不批准 S5。

## 2. 私有契约

`foc_lsi_preload_session_t` 版本升为 2，私有状态增加：

```text
active_open
active_write_limit / active_write_count
active_total_tick_limit / active_start_control_tick
next_permit_sequence / last_consumed_sequence
last_source_control_tick / has_last_source_control_tick
```

permit 版本同样升为 2，新增 `session_mode` 与 `permit_sequence`。validation 和 active 使用
不同 confirmation、不同 mode 和同一 fail-closed tag 生成路径，不能把 validation permit
带入 active session。

活动硬件相位门：

| 阶段 | gate | MOE | CC1E/2E/3E | 允许结果 |
|---|---:|---:|---:|---|
| active 首笔 preload | 0 | 0 | 0 | 允许写入/读回；仍不产生功率输出 |
| active 后续 preload | 1 | 1 | 1 | 只有三者全开且无 fault/trip 才允许 |
| 任意混合或故障 | 任意 | 任意 | 任意 | 拒绝、清 CCR、关闭 session |

该表只冻结未来平台调用规则。S4.8 目标固件没有执行第二行。

Clippy、CPU/CORDIC target 和 C Host 14/14。`foc_lsi_private_preload_sink` 新增覆盖：

- active confirmation 与 600/6000 硬上限；
- 首笔 off、后续 on 的硬件事实门；
- permit sequence、generation、跳拍、重放与篡改；
- active write budget、total tick budget 和失败关闭；
- validation 原有 one-shot、ARR、寄存器 alias/readback 失败不退化。

## 5. 下一门

S4.9 才接入 session coordinator、ADC ISR 和一次性 `foc_lsi_start`。必须先解决：

1. OFFSET_CAL 与 active raw 窗的切换时刻；256 点缓冲只能记录 active/cooldown，不能从
   preflight 开始占满；
2. 首笔 preload 经 UEV 生效后再开 gate/MOE/CCER，下一拍 ledger 必须对上；
3. 每次 issue/apply 非 OK、capture COMPLETE/error、过流、Vbus、Break、driver fault、
   operator abort 和总超时都同拍快速关断；
4. 将整条 active ISR 纳入同拍 WCET，不能沿用本阶段 550 条静态 ISR 指令或无功率 monitor；
5. start 只接收冻结 confirmation，不接收 duty/电压/拍数参数，普通 `foc_start` 继续拒绝。

S4.9 的 Host/S2/无功率 S4 通过后，才允许再次讨论接主功率和 0.2 A S5。
