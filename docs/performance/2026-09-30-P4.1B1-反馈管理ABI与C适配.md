# P4.1B1 反馈管理 ABI 与 C 适配

## 范围

本轮把 P4.1A 的纯 Rust 反馈核心开放为独立管理 ABI，并增加不依赖 HAL/RT-Thread 的
Sensorless、ABZ 和 Hall C sample adapter。批准后的标定结果只进入既有配置事务的 pending
Axis/Calibration 组；没有自动 validate/apply/commit，没有写 Flash，也没有接入默认 ISR。

实现入口：

- `rust/crates/foc-rt-bridge/src/feedback_abi.rs`：V1 ABI、固定原位上下文、路由/标定入口；
- `foc/include/foc_feedback_bridge.h`：C 镜像布局和静态断言；
- `foc/include/foc_feedback_adapter.h`、`foc/runtime/foc_feedback_adapter.c`：目标中立规范化；
- `tests/host/test_foc_feedback_adapter.c`：严格警告 Host 正/负例。

## 安全边界

- 独立 ABI 不改变 V19/V20 每拍快环布局；
- 输出指针先校验，失败不会消费路由拍或批准状态；
- 不可用、NaN/Inf、坏方向和非规范输入 fail-closed；
- `stage_config_update()` 只改 pending，不直接改 active 或 Flash；
- 事务仍须由唯一 owner 完成 validate、apply、commit/readback；失败时可 rollback；
- 真实 GPIO/Timer/EXTI、RT-Thread 管理服务和电机参数均未改变。
