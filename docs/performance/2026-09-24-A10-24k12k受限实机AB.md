# A10｜24 kHz PWM + 12 kHz 控制受限实机 A/B

## 结论

本轮完成了低压、2 A 电源限流、空载自由旋转条件下的受限 S5 A/B，但**不批准**
24/12 kHz 候选成为默认配置：

1. A8/A9 使用的 `TIM1 Update TRGO -> ADC` 方案已被实机电流数据否决。它虽然能得到
   正确的 12 kHz 中断频率，却把三分流电流采样放到了无效开关窗口；电机转动并不代表
   电流反馈有效。
2. 候选已改为 `TIM1 OC4REF -> TIM2 ITR0 二分频 -> TIM2 Update TRGO -> ADC`。
   修正版保留 OC4 的有效三分流采样窗口，同时维持 24 kHz PWM、12 kHz ADC/控制。
3. 修正版开环电流、`Iq` 和 `Vq` 与默认 12/12 kHz 基线基本一致，没有 deadline miss，
   证明采样链和多速率执行已经工作。
4. 闭环短测默认 12/12 kHz 为 2/3 次完成 5 s，修正版 24/12 kHz 为 1/3 次完成 5 s；
   失败均为 `OBSERVER_LOST (0x8)`。样本数不足以作统计结论，但候选没有显示出可靠性收益。

因此板上和配置均已恢复为默认 12/12 kHz。下一步先在默认频率上解决 BEMF-SMO/PLL
观察器可靠性、相位延迟和电压模型问题，再决定是否继续载波提频。

## 1. 为什么原 Update 方案必须废弃

原方案把 TIM1 的 Update 事件直接作为 ADC 注入组触发源。无功率测试只能证明事件频率
和寄存器配置正确，不能证明采样瞬间落在三分流可观测窗口内。首次上电开环短测显示：

| 指标 | 默认 12/12 kHz | 原 24/12 Update 候选 |
|---|---:|---:|
| phase current RMS（典型） | 约 0.33～0.57 A | 约 0.003～0.008 A |
| `Iq`（典型） | 约 0.408 / 0.800 A | 约 0.002～0.005 A |
| `Vq` | 约 2.36～4.70 V | 约 6.3 V，接近饱和 |
| Diagnostic 峰值电流 | 约 0.927 A | 约 0.035 A |

这些数值与实际电机已经带载于逆变器、能够转动的现象不相容，说明 ADC 读到的不是有效
相电流。该方案随即停止，没有继续做闭环试验。

这里也修正了一条验证原则：**频率正确、寄存器正确、ISR 能运行，都不能替代电流采样
窗口正确性。** STM32G4 的定时器主从触发和 ADC 外部触发关系可参考
[STM32G4 RM0440](https://www.st.com/resource/en/reference_manual/dm00355726.pdf)，但具体功率板
的三分流窗口仍必须由拓扑、PWM 状态和实测共同确认。

## 2. 修正版硬件事件链

```text
TIM1 中心对齐 PWM，24 kHz，ARR=3541，RCR=3
  └─ CH4/CCR4=ARR-1 产生 OC4REF 有效采样事件
       └─ TIM1 TRGO=OC4REF
            └─ TIM2 ITR0，外部时钟模式 1，ARR=1
                 └─ 每两个 OC4REF 上升沿产生一次 TIM2 Update TRGO
                      └─ ADC1/ADC2 injected，同步 12 kHz
                           └─ ADC1 JEOS IRQ
                                └─ Rust 完整控制步，12 kHz
```

配置契约新增 `FOC_PWM_ADC_TRIGGER_DIVIDED_OC4REF=3`。旧的 Update 枚举仅保留为历史
兼容标识，并被时序计划校验明确拒绝。默认 12/12 kHz 仍直接使用 TIM1 OC4REF。

HotPlug 运行态读回的关键值：

| 外设 | 关键读回 |
|---|---|
| TIM1 | `CR1=0x121`，`CR2=0x70`（TRGO=OC4REF），`ARR=0xDD5`，`RCR=3`，`CCR4=0xDD4` |
| TIM1 输出 | `CCER=0x1000`，仅 CH4E；`BDTR=0x03302C00`，MOE=0（无功率门） |
| TIM2 | `CR1=1`，`CR2=0x20`，`SMCR=0x7`，`PSC=0`，`ARR=1`，`CNT=0` |
| ADC | ADC1 `JSQR=0x00000488`，ADC2 `JSQR=0x00001C88`，触发源为 TIM2 TRGO |

无功率运行超过 500,000 个样本，平均同步间隔约 14,163 cycles；固件自报
`pwm/control=24000/12000`、`ratio=2`、`delay=2`、`trigger=3`。

## 4. S5 数据

### 4.1 默认 12/12 kHz

- 开环 3 s：脚本与控制运行判据通过；trace 峰值约 0.851 A，Diagnostic 峰值约
  0.927 A，完整 ISR 最坏约 9,824 cycles，无 deadline miss、控制错误或硬件故障。
- 闭环三次：第 1 次约 2.34 s 后 `OBSERVER_LOST`；第 2、3 次完成 5 s。
- 三次闭环最坏 ISR 分别不超过约 10,076 / 10,044 / 10,034 cycles；峰值电流约
  0.903～0.908 A。

### 4.2 修正版 24/12 kHz

1.2 s 对齐短测已经能复现默认链路量级：状态 3 时相电流 RMS 约 0.331 A、
`Iq≈0.408 A`；状态 4 时相电流 RMS 约 0.566 A、`Iq≈0.800 A`。

3 s 开环对比：

| 状态 | 指标 | 默认 12/12 | 修正版 24/12 |
|---|---|---:|---:|
| 3 | phase current RMS | 0.3322 A | 0.3312 A |
| 3 | `Iq` | 0.4087 A | 0.4076 A |
| 3 | `Vq` | 2.3578 V | 2.4040 V |
| 4 | phase current RMS | 0.5602 A | 0.5629 A |
| 4 | `Iq` | 0.7918 A | 0.7958 A |
| 4 | `Vq` | 4.7023 V | 4.7566 V |

该开环运行最坏 ISR 约 10,022 cycles，Diagnostic 峰值电流约 0.892 A，无 deadline
miss、控制错误或硬件故障。

闭环三次结果：

| 次数 | 结果 | 可靠样本/闭环样本 | 最坏 ISR | 峰值电流 | 故障 |
|---|---|---:|---:|---:|---|
| 1 | 约 2.26 s 停止 | 7 / 9 | 10,602 cycles | 0.877 A | `0x8 OBSERVER_LOST` |
| 2 | 约 2.36 s 停止 | 11 / 13 | 10,260 cycles | 0.900 A | `0x8 OBSERVER_LOST` |

所有运行均低于 1.15 A 软件保护阈值，且未出现 deadline miss。这里的“峰值电流”来自
板上采样链，不是外部电流探头真值。

## 5. 捕获脚本判据修正

`simulation/capture_hardware_trace.py` 现在：

- 必须显式传入 `--allow-motor-run` 才会打开串口并运行电机；
- `--closed-loop` 只临时开启闭环，`finally` 中恢复为关闭；
- 不再把“串口和 CSV 捕获成功”误报为“电机控制运行成功”；
- 读取最终 `errors`、`FOC last status` 和 `rust_fault`，分别输出
  `FOC_HW_CAPTURE_PASS` 与 `FOC_HW_RUN_PASS/FAIL/UNVERIFIED`；
- 控制错误、状态 4 或 Rust fault 返回非零退出码，并始终执行 `foc_stop`。

旧失败日志回放能解析为 `(errors=1, status=4, fault=8)`，说明新的自动判据能够识别本轮
观察器失锁，而不是只看 CSV 是否生成。

## 6. 仿真与实机相关性边界

采样窗口修正后，两种频率的开环低频量（电流 RMS、`Iq`、`Vq`）能大体对齐，这支持
现有平均值模型用于控制状态、参数量纲和低频趋势回归。但仿真没有预报原 Update 方案的
“近零电流”问题，因为当前 plant 使用平均值逆变器，没有开关状态、三分流可观测区和
ADC aperture 模型；它也没有预测短测中随机出现的观察器失锁裕量。

因此本轮不能宣称“仿真与实机已经完全一致”。现阶段证据是：

- 可以对比：状态切换时刻、目标/反馈量级、低频电流和电压趋势；
- 暂不能对比：真实转速、转矩、相位误差、电流纹波、THD、声学噪声和效率；
- 必须补模：开关级 PWM、有效采样窗口、采样/计算/占空生效延迟以及观察器噪声；
- 必须补仪器：编码器或测速真值、电流探头/示波器、声学记录。
