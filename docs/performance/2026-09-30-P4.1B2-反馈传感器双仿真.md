# P4.1B2 反馈传感器双仿真

## 范围

本轮在不改变目标固件默认路径的前提下，为统一反馈核心增加 Rust PC 与 MATLAB 两套独立
传感器模型。两端读取同一个版本化场景，分别模拟 ABZ 编码器与 Hall 输入，再由严格比较器
执行 D0、D2、D3、D4 和 feature-off 门。

共同输入与入口：

- `simulation/scenarios/feedback_sensor_fault_matrix_v1.json`：5 个 case、16 个评估拍；
- `rust/crates/foc-sim/src/simulation_contract/feedback_sensor.rs`：Rust 独立样本模型，复用
  产品 `FeedbackRouter`；
- `simulink/run_feedback_sensor_contract.m`：MATLAB 独立样本和路由模型；
- `simulation/compare_feedback_sensor_results.py`：跨引擎严格比较；
- `simulation/run_feedback_sensor_gate.ps1`：Rust → MATLAB → Python 一键门。

## 场景结果

| Case | 关键结果 |
|---|---|
| feature_off | tick 0 保持 Sensorless，`valid=31`、`quality=4` |
| nominal | tick 2 获取主编码器 |
| encoder_drop_fallback | tick 2 获取主源、tick 7 回退 Hall、tick 12 恢复主源 |
| encoder_index_missing | tick 2 进入 Hall 回退 |
| hall_wrong_order_and_primary_drop | tick 7 两源不可用并 fail-closed，tick 12 重获主源 |

两端共输出 5 个 case、80 行，连续量与离散事件均通过共同门。这里的 Hall 错序是明确的
输入质量退化场景，不是对真实电气波形和 GPIO 边沿的建模。

## 边界与下一门

- 当前只完成反馈传感器子系统的 D2～D4；通用闭环连续波形仍须分阶段扩展；
- 未接入 RT-Thread 管理服务、默认 ISR、TIM/GPIO/EXTI 或真实 ABZ/Hall；
- 未烧录、未上电、未运行电机，最高证据为 S3；
- 下一步 P4.1C 实现默认关闭的管理服务，负责配置事务、标定请求和只读状态；
- P4.1D 才进入真实传感器接线及 S4～S6 安全验证。
