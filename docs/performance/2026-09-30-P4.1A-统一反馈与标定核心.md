# P4.1A 统一反馈与标定核心

## 范围

本轮只实现 `foc-control` 内的纯 Rust 软件核心，复用产品契约 V1 的 68 B
`ProductFeedbackSnapshot`。没有新增 C ABI、没有连接 RT-Thread/ISR、没有读取 ABZ/Hall
硬件、没有写配置或 Flash，也没有烧录和运行电机。

实现文件：

- `rust/crates/foc-control/src/feedback.rs`：归一输入、质量门、主备路由、标定生命周期；
- `rust/crates/foc-control/src/lib.rs`：注册并重导出模块；
- `rust/crates/foc-control/src/config.rs`：让同 crate 的标定核心复用唯一 Hall 序列校验器。

详细设计见[统一反馈源与标定核心 V1](../统一反馈源与标定核心V1.md)。

## 关键安全语义

- 只有互不重复的新样本增加获取/恢复 good 计数；
- 坏样本和超龄样本按评估拍增加 loss bad 计数；
- 失效宽限拍保留角色但立即清空有效量，并置 `DEGRADED/STALE`；
- 备用接管快照始终显式 `DEGRADED`；
- 不支持的 Absolute/Resolver/Fused、未知位、NaN/Inf、非规范零值和倒退序号 fail-closed；
- 标定只在 Disabled、输出关闭、无故障时运行；坏证据锁存 Failed；批准只生成配置更新。
