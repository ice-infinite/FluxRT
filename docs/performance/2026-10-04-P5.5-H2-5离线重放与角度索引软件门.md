# P5.5 H2-5 离线重放与角度索引软件门

## 1. 结论

H2-5 的首个纯软件前置门已经完成：同一份冻结的 G431 Ls(I) 转换后 trace 现在可以由
Rust 和 MATLAB 两个互不调用的实现独立重放，并生成逐候选电感的误差表；Python 比较器
负责逐字段核对。VS Code 也已有单独任务入口。

本轮只使用 2026-09-27 的历史 `6x6` trace 来验证管线。该历史记录没有同步 AS5600
角度，因此场景明确写为：

```text
angle_index_valid=0
angle_source=unavailable-historical
angle_evidence=BLOCKED_UNTIL_VALID_INDEX
```

所以本结果只达到离线结构和数值对拍 S1/S3，不关闭 H2-5，不批准参数，也不授权烧录、
PWM 或电压注入。

## 2. 数据流与职责

```text
G431 FLSI_RAW（未来实机）
  │ analyze_lsi_hardware_run.py：原始合同、SI换算、安全与单次拟合
  v
冻结的转换后 CSV + H2 replay 场景
  ├─ Rust foc-sim：候选L残差表
  └─ MATLAB：独立候选L残差表
             │
             v
Python comparer：身份、角度门、转换拍数、RMSE、最大残差逐字段对拍
```

- 板端仍只负责固定容量 ISR 原始采集，不在 ISR 内做文件、拟合或 MATLAB 工作；
- Rust 与 MATLAB 都只消费项目内相对路径，拒绝绝对路径和上级目录；
- 候选表当前固定比较 `1.0580/1.1133333/1.9500/2.1000 mH`，它们是模型比较点，
  不是批准参数；
- `angle_index_valid=1` 时合同要求来源为 `as5600-window`、至少 3 个样本且静态窗跨度
  不超过 2 count；历史 fixture 不满足这些条件，只能保持 0；
- 静态 H2 可以由 PC 时间窗关联 DengFOC AS5600 与 G431 注入。进入动态 H3 前仍必须使用
  硬件同步时间戳或让 G431 直接读取传感器，不能把两个串口到达时间当作动态真值。

## 3. 当前对拍结果

冻结 trace 提供 `71` 个相邻脉冲转换；Rust 与 MATLAB 的 4 行误差表在 `2e-9 A`
绝对容差内一致：

| 候选 L | RMSE | 最大绝对残差 | 解释 |
|---:|---:|---:|---|
| `1.0580 mH` | `0.013306821 A` | `0.032266012 A` | 历史候选比较点 |
| `1.1133333 mH` | `0.012300629 A` | `0.030353744 A` | 历史 LCR 相值比较点 |
| `1.9500 mH` | `0.006455851 A` | `0.013179509 A` | 本 trace 中残差较低，但不构成批准 |
| `2.1000 mH` | `0.006545939 A` | `0.013402700 A` | 用于确认误差曲线已越过局部最低区 |

这些结果复现了旧报告的趋势，只证明两个离线实现对同一数学口径一致。历史 trace 的电流、
母线、死区和 `Rs` 比例仍是名义/旧配置，且没有角度真值，因此不能推导当前 H2 首拍参数。

## 4. 执行入口

命令行：

```powershell
powershell -ExecutionPolicy Bypass -File .\simulation\run_lsi_h2_replay_gate.ps1
```

VS Code：运行任务 `FluxRT: H2 Ls(I) Rust-MATLAB离线重放`。

主要落点：

- `simulation/scenarios/lsi_h2_replay_v1.json`：冻结输入、候选值和角度证据字段；
- `rust/crates/foc-sim/src/lsi_h2_replay_contract.rs`：Rust 独立重放；
- `simulink/run_lsi_h2_replay_contract.m`：MATLAB 独立重放；
- `simulation/compare_lsi_h2_replay_results.py`：跨引擎误差表核对；
- `simulation/results/lsi-h2-replay/`：生成结果，已由 Git 忽略。

## 5. H2-5 尚缺的真实证据

1. H2-3c 快速关断门和 H2-4 首拍必须先完成；当前缺少 `5.0 V / 0.20 A` 可调限流电源；
2. 每次真实 run 必须冻结 `motor_id`、固件 SHA、原始日志/CSV SHA、G431 控制拍范围和
   AS5600 静态时间窗；
3. 至少覆盖多个分散机械角，每个角度独立授权一次，不自动重试；
4. 每窗要求 AS5600 有效、失败计数不增长、至少 3 点且跨度不超过 2 count；
5. 比较正/负脉冲响应、同角重复性、跨角响应、峰值电流与停止原因；
6. 只有完整矩阵通过，才进入 H2-6 参数/能力审批。一次历史或一次新 trace 都不能批准
   `Ld/Lq`、HFI 幅值或任何目标能力位。

多 run 身份、哈希、静态时间窗和重复性门已经在下一层离线聚合器中实现，见
[H2-5多run证据聚合软件门](2026-10-04-P5.5-H2-5多run证据聚合软件门.md)。该工具仍不
创建公共时钟采集；真正的双串口协调采集器继续列为未完成项。
