# P5.5-H3 G431 TIM4/DMA发送软件门

## 1. 结论

G431侧固定身份帧发送端已经完成S1/S2及双板无主电身份链S4：

- 公共`foc_time_sync_toggle_plan`把任意高/低symbol转换为TIM输出比较的绝对翻转时刻；
- STM32G431 Identification专用端使用`PB6/TIM4_CH1 + DMA1 Channel3`，不占用TIM1控制快环；
- 161个codec symbol后追加10 us保护高脉冲，共162个物理symbol、324次翻转；
- 首次compare直接写CCR1，DMA提供其余323次翻转和一个不执行的sentinel；DMA完成恰好发生在保护脉冲的最终下降沿；
- 只有Identification镜像暴露`foc_h3_sync_*`命令，启动时不会自动初始化或发送；Production镜像中只有芯片启动文件的弱默认IRQ，没有TX符号；
- 任何初始化、DMA或TIM错误都会停止TIM4/DMA、关闭通道并把PB6切回普通低电平；
- 实板根据DengFOC RMT反证修正了PB6 AF切换和完成接管顺序，避免旧SDA上拉制造伪SOF或截断guard-low。
- 首个compare现在同时锁存连续170 MHz DWT tick和12 kHz控制拍；ADC高优先级抢占时按同域cycle把边沿归属到最近的已完成控制拍；
- TX状态ABI v3还提供默认关闭的`PB7/TIM4_CH2`实际上升沿回采字段，未接跳线时不会置`LOOPBACK_VALID`。

当前已把PB6并接到PB7/CN7-21并完成本地物理回采。最终自动run3取得20/20配对锚点和
8,294条AS5600真值，PB7捕获tick全部为100，计划/回采绝对差最大0.712 us；PB7到DengFOC
1 MHz时基的拟合绝对漂移23.328 ppm、最大残差1.326 us、RMS 0.558 us。该证据仍是无主电
短窗同步链，不是带功率动态角度或HFI闭环证明。

## 2. 分层实现

| 层 | 路径 | 职责 |
|---|---|---|
| 公共规划 | `foc/include/foc_time_sync_toggle_plan.h`、`foc/runtime/foc_time_sync_toggle_plan.c` | 固定容量symbol→绝对compare tick；检查零宽、容量、单调性和16 bit越界 |
| 线协议 | `foc_time_sync_wire` | 生成20字节身份+CRC的161个codec symbol；不知道TIM/DMA |
| G431平台 | `foc/platform/stm32g431/foc_time_sync_stm32g431.*` | PB6 AF2、TIM4 1 MHz、DMA1 Channel3、IRQ、错误关停 |
| 操作入口 | `applications/foc_time_sync_shell.c` | Identification-only显式init/send/status/abort，不在startup自动运行 |
| Host测试 | `tests/host/test_foc_time_sync_toggle_plan.c` | 精确小向量、完整162-symbol帧、容量/零宽/16 bit越界fail-closed |

平台头没有进入公共ABI；RMT/Arduino也没有进入G431目录。以后换MCU时只需重写平台输出端，
codec和toggle规划器可以直接复用。

## 3. 时序与状态

- TIM4输入时钟170 MHz，预分频169，计数分辨率1 us，ARR固定65535；
- 首次翻转安排在计数100 us，给接收端预留arm时间；
- short/long/data-low/SOF为20/40/20/80/40 us，与DengFOC RMT目标一致；
- 保护高脉冲10 us，最后保持低电平；
- `foc_h3_sync_send`只在状态READY或COMPLETE接受下一帧；BUSY、未初始化和非法身份均拒绝；
- TIM4首次compare IRQ用`CNT=100 us`和ISR入口的DWT差反推compare发生时的连续DWT tick，并读取同域控制拍；该值可用于初始映射，但**不是独立物理边沿测量**；
- PB7/TIM4_CH2已配置为可选上升沿输入捕获。只有实际把PB6并接PB7且状态置位`LOOPBACK_VALID`，才能比较`loopback_delta_cycles`并关闭引脚边沿回采门。

Identification命令：

```text
foc_h3_sync_init
foc_h3_sync_send <session> <sequence> <tag>
foc_h3_sync_status
foc_h3_sync_abort
```

这些命令只操作PB6同步诊断线，不打开TIM1、Gate、MOE或电机功率级。

## 5. 下一门

G431到DengFOC的无主电身份链已完成，下一步建立动态时间映射：

1. 仍保持12.3 V主电断开；
2. 当前只保留PB6→IO23和公共GND，VCC/IO5/IO21继续悬空；
3. PB6→PB7实际边沿、`LOOPBACK_VALID`和`loopback_delta_cycles`已经通过；
4. 自动采集工具已把PB7/DengFOC锚点、真值、原始行和SHA-256写入正式证据目录；
5. 下一步必须先确认AS5600与G431待驱动电机属于同一转子，再在新的带功率授权下采动态query；
6. 完成前保持六项sensorless能力为0。

本报告不授权12.3 V、PWM功率输出、HFI注入或电机运行。
