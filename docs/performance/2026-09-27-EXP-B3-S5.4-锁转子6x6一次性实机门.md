# EXP-B3 S5.4：锁转子 6×6 一次性实机门

## 1. 结论

本次 **bounded hardware execution PASS，6×6 窗内重复性 PASS，参数更新 REJECT**。

用户确认转子已可靠固定、主电源已接通；本次沿用同一硬件会话此前确认的 12.3 V、2 A
限流和可立即断电条件。预检确认 `IDLE/OFF`、Vbus=12.275 V、配置
`12000/256/24/6/6/24` 后，只发送一次 `foc_lsi_start LSI1`，不自动重试。31.42 ms
bounded session 自动完成，随后立即及最终再次执行 `foc_stop`：

- final state=`COMPLETE(7)`，abort=0，drive=`OFF`，token=`1/1`；
- 120 点 sequence/tick 连续，24 bias + 36 positive + 36 negative + 24 cooldown；
- 0 overflow/contract/storage error，0 deadline miss，最终 duty=`0/0/0`；
- 名义换算最大三相绝对电流 0.2330 A，Vbus 12.223～12.378 V；
- active ISR WCET 11,053/12,750 cycles，占用 86.69%，余量 13.31%。

新序列把六组脉冲拟合的极差/均值从 S5.0 的 15.68% 降到 **6.73%**，达到 10% 窗内门；
但固定 `Rs=4.9667 Ω` 的 applied-voltage 拟合仍为 **1.950 mH**，比 LCR 相值
1.1133 mH 高 **75.15%**。因此它只证明新会话安全且更可重复，不能证明动态 L 正确。

| 项 | 实际值 |

最后一次读回只证明功率输出关闭，**不证明主电源物理断开**；本报告完成后仍应断开主电源。

### 4.2 已排查项

| 模型 | 结果 | 能否解释冲突 |
|---|---|---|
| ST 4096/current/Vbus 官方比例 | 1.950 mH；与本工程比例差约 0.0244% | 否 |
| 电压错拍 `-1/0/+1` | 1.810 / 1.950 / 2.986 mH；0 拍 RMSE 最低 | 否 |
| Rs/L 联合拟合 | 4.45 Ω / 1.842 mH | 否；Rs 也偏离 DC 实测 |
| 仿射 RL + 常量桥压降 | 3.881 Ω / 1.8395 mH / 0.1044 V | 否；L 仍明显偏高 |
| 理想中心对齐 PWM 子周期积分 | 2.024 mH；平均 command 模型为 2.026 mH | 否 |
| bias tail / cooldown 噪声 | U 相 1.221 / 0.608 count | 噪声下降，但不能消除系统偏差 |

“理想 PWM 子周期积分”只复现 TIM1 PWM1 的理想开关状态，不含器件非线性；结果与平均
command 电压几乎相同，说明不能把 75% 差异简单归因于中心对齐波形。常量压降模型也不能
独立代表真实桥损耗：STSPIN830 的 HS+LS `RDS(on)` 典型值为 1 Ω，压降随电流变化，而非
一个固定常数。ST 官方资料同时确认 IHM16M1 FOC 默认使用 330 mΩ 三分流与 1.53 增益；
这些名义值与工程一致，但仍不是逐板电流/电压动态标定。

   授权中改变机械角度；每个 powered session 都必须单独确认，不能连续自动运行。
