# P1.2 / P1.3 命令仲裁与双仿真共同契约验证报告

## 1. 范围与结论

本轮并行完成两个不改变板上默认行为的软件阶段：

- P1.2：固定容量命令仲裁、来源权限、sequence/timestamp/lease/timeout 和同拍安全优先级；
- P1.3：Rust PC 与 MATLAB/Simulink 共用的 scenario/profile/trace/comparison 契约及
  `legacy_speed_start` D0/D1 严格对拍。

同时修复 P1.1 校验缺口：`AxisRequest` 现在拒绝非规范 `feedback_mode`，Rust 与 FFI 负例
均覆盖。产品契约仍为 V1、bridge 仍为 V20，104 B `ProductCommand` 和 V19 快环输入未改变。

## 2. 关键实现

| 范围 | 结果 |
|---|---|
| P1.2 | `foc-control::command`，固定 `[SourceMailbox; N]`、无堆、无锁、`no_std` |
| 权限 | priority/lease/timeout/command permissions 全由受信策略提供 |
| 时序 | 32位半区间回绕；排他 validity/lease 截止；超时不自动复活旧来源 |
| 安全 | fault > EStop > timeout > ClearFault > normal；EStop 独立通道 |
| P1.3 | 一份 bundle/schema/profile/scenario/trace/comparison，文件哈希闭环 |
| D0 | 完整硬件/配置/契约/ABI/模型/Git workspace identity 精确一致 |
| D1 | 两个独立 lifecycle engine，七字段事件、零 tick 容差 |

完整语义见[命令仲裁与租约契约 V1](../命令仲裁与租约契约V1.md)和
[双仿真共同契约 V1](../双仿真共同契约V1.md)。

### 3.2 S2 四档目标构建

四档均执行 `build.ps1 -Regenerate -Profile <...> -RustOptLevel s`：

| Profile | ROM/BIN | RAM | BIN SHA-256 |
|---|---:|---:|---|
| Diagnostic | 110,572 B | 22,472 B | `95DA8A899D617F6712C19F035B9EC0169CA89BE7619CE5F613A73598E4F36B77` |
| Calibration | 102,932 B | 13,024 B | `C985A2843FE74E27DC9D922F6D28F6A806E1B4EF3F7D86084231ECBCB2F9B7F6` |
| Identification | 115,780 B | 15,496 B | `FDD620A90333EDAD42E347B2D7D48937808F4DC5218F5066B056EFF04DFAE680` |
| Production | 101,656 B | 8,904 B | `DB991EEF6CA506F266DA8106E5B69B93CA9E3816421A9369CEEC7F51054DABBD` |

BIN/HEX/ELF 的尺寸和 SHA-256 与 P1.1 完全相同。最终 ELF `nm -C` 四档均找不到
`CommandArbiter`、`simulation_contract` 或 `command_is_current` 可达符号，证明本轮仍是
Host-only/section-GC 的纯逻辑，不是目标端命令接入。map 中可看到静态库归档成员名称，不能
把归档索引误读为最终 ELF 可达代码。

唯一构建提示仍是 Arm GNU `crtn.o` 缺 `.note.GNU-stack` 的工具链 deprecated warning，
没有新增源码 warning。

## 4. 证据边界与下一步

- 达到 S1、S2 和共同契约的 S3 D0/D1；未执行串口、烧录、PWM、电机或 fault 实机注入；
- P1.2 没有实际 source policy、协议鉴权、管理线程或 Axis 状态机消费者；
- P1.3 没有完成连续波形 D2～D4，也没有证明仿真与实机相关性；
- reference profile 不是批准参数，A26 参数真值限制保持不变；
- 下一软件主线是 P3.1 可恢复配置核心，再串行进入 P3.2 设备端参数事务；硬件窗口仍可独立
  执行 P0.2/P0.3，但不能与软件 PASS 混写。
