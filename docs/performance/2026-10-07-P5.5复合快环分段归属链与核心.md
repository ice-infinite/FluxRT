# 2026-10-07 P5.5 复合快环分段归属：传感链约 7,080 cycles（43%），共享核心约 9,460（57%）

日期：2026-10-07
基线：`main@7dbac93` + 本提交（帧归属计时）
证据等级：S4（烧录 + 无主电板端运行）
板：NUCLEO-G431RB + X-NUCLEO-IHM16M1，ST-LINK `00400027544B500120343637`，COM6@115200
主电源：**12.3 V 物理断开**，全程仅 USB/ST-LINK；未使能 Gate/MOE/CCER；电机未动

---

## 1. 结论

**12,750-cycle 预算的超支在两个部分上都成立，且传感链占了 43%。**

单拍（12 kHz）成本归属，256 拍稳定值：

| 部分 | cycles | 占 control | 占 12,750 预算 |
|---|---:|---:|---:|
| **传感链**（`foc_rust_sensorless_step`：HFI、解调、PLL、融合） | **约 7,080** | 42.8% | **55.5%** |
| **共享核心**（Clarke 之后：观察器、启动链、Park/逆 Park、电流 PI、最终限幅、SVPWM） | **约 9,460** | 57.2% | **74.2%** |
| control 段合计 | 16,538 | 100% | 129.7% |
| 前后处理（total − control） | 约 505 | — | 4.0% |
| **整拍** | **17,043** | — | **133.7%** |

**两个部分各自单独就已超出预算**：链 7,080 需再削约 4,400，核心 9,460 需再削约 6,700，才能各自回到 12,750。

---

## 2. 这意味着裁剪必须双线进行，且链侧性价比更高

**传感链在占 43% 预算的情况下，并不产出电压输出**——它只产出角度、速度与可靠性判定。而核心是真正的电流环。

两种可行动方向：

1. **降低链的执行速率（抽取）**。链是估计器，不需要每拍 12 kHz。若降到 4 kHz（每 3 拍一次），链的摊销成本从 7,080 降到约 2,360，**仅此一项即可让整拍回到约 12,320，落在 12,750 之下**。这与既有记录 `LOG-20261003-007`（观察器 12→6 kHz、MTPV 24→8 步）验证过的路线一致。
2. **削减链内部计算**。7,080 cycles 对一个 HFI 链偏高，值得先看其内部分布（解调、PLL、融合、包络）后再决定。

**核心侧的 9,460 是真正的电流环，削减空间更小、风险更高**，应放在链侧之后。

**建议顺序：先抽取链，重测；再评估核心。**

## 3. 测量方法

### 归属方式

平台测量整拍与 control 段；Rust 侧测量链自身。因此：

```
core = control − chain
```

只需**一个新字段**（`chain_cycles`）即可完成归属，无需在 `step_core` 的每一级插桩——避免了穿透四层调用栈的高风险改动。

### 接口

| 对象 | 变更 |
|---|---|
| `FocSensorlessRealtimeOutput` | ABI V2→V3，追加 `chain_cycles`（84→88 B），追加在末尾故旧偏移不变 |
| 复合输入 `reserved` | 由"必须为 0"改为接受 `0`（不计时）或 `0x54494D45`（`"TIME"`，计时）。**未升输入版本**，已通过校验的 V1 调用方不受影响 |
| Rust `foc_platform_probe_cycles()` | 外部依赖，形状与既有 CORDIC 加速器一致：算法库不读外设寄存器，宿主构建不定义该符号 |

**生产帧零成本**：不请求计时时 Rust 不调用计数器，字段保持 0。

### 原始数据

## 4. 边界与不确定

- **单一镜像、单次运行、单板、空载、合成电流**（约 1.5 mA 未通电 ADC 读数）；
- `chain` 含两次计数器读取的外部调用开销（量级几十 cycles，**< 1%**），故 7,080 略高于链的净计算量；
- `core` 是**差值**，因此吸收了 Clarke、组合事务、限幅与两次计数器读取的开销；
- 256 拍 = 12 kHz 下 21 ms，不覆盖长测；**不带功率**；
- 「链降到 4 kHz 可回到预算内」是**基于本测量值的算术外推**，未实测，且抽取会改变链的动态特性（HFI 解调与 PLL 带宽需重新整定）。

**不得引用为**：带功率工况成本、其它 feature 组合成本、稳态以外的任何结论。
