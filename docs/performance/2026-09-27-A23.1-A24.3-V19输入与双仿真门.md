# A23.1～A24.3：V19 实时输入与双仿真门

## 1. 结论

本轮完成了三个不需要上电的工程门：

1. A23.1 将 C/Rust 快环 ABI 从 V18 提升到 V19，增加 88 B 完整实时输入快照；
2. A24.2 在 Rust PC 仿真侧增加相电压传感器非理想与故障注入模型；
3. A24.3 用独立 MATLAB 公式重建 13 个场景，并与 Python 基准逐项对拍为 13/13 一致。

本轮最高证据等级为 S3。没有连接串口、烧录、使能功率级或运行电机。Measured/Hybrid
仍没有进入目标快环，默认观察器电压源仍为 `CommandModel`。

## 2. A23.1：V19 完整实时输入快照

新增的 `foc_realtime_input_t` / `FocRealtimeInput` 固定为 88 B、4 B 对齐。C
`_Static_assert` 与 Rust `size_of/align_of/offset_of` 同时锁定全部字段偏移，配置结构版本继续保持
V11，避免把输入 ABI 迁移与控制参数迁移混在一起。

快照一次携带：

- 结构尺寸、ABI 版本、控制拍序号和相电压采样序号；
- 三相电流、母线电压、可选三相相电压、可选角度和温度；
- 有效位、硬件故障镜像、相电压来源/质量/原因、实际选择和回退事件；
- 样本年龄及调用方观测到的 `actual_dt_s`。

兼容入口仍接受旧 20 B `foc_feedback_t`，但会先构造 V19 `CommandModel` 快照：只标记
电流和母线电压有效，相电压状态为 `Unconfigured`，角度无效。目标 ISR 当前也只走这个兼容
包装，因此本轮没有偷偷开放 Measured/Hybrid。

失效安全规则已锁定：

- 错误尺寸、错误版本、未知枚举、非有限或非正 `actual_dt_s` 立即返回
  `InvalidArgument` 并清零输出；
- 已知的 7 个硬件故障位任意置位，均在进入算法前清零输出并进入
  `Fault/HardwareFault`；未知故障位拒绝；
- `Measured` 或 `Unavailable` 在当前未接入条件下返回 `NotConfigured`；Hybrid 回退必须由 C
  侧以实际 `CommandModel` 选择传入；
- 可选测量只有在已标定、有效位齐全、质量有效、reason 为零且序号/年龄关系一致时才具有
  measured eligibility；序号回绕已有测试。

`actual_dt_s` 本轮只完成运输和校验，控制器内部仍使用配置的 `1/pwm_frequency_hz`。128 拍
等价测试故意传入非名义 `dt`，确认兼容包装没有改变原控制数值；这不是可变步长控制已完成。

## 3. A24.2：Rust PC 相电压传感器模型

`foc-sim/src/phase_voltage_sensor.rs` 新增固定容量、逐拍确定性的传感器模型，覆盖：

- 全局和逐相偏置、增益误差；
- ADC 有效位量化；
- 0～8 拍延迟；
- 丢样、强制 stale 年龄；
- 低端/高端饱和；
- 开路/卡值故障；
- sequence、age、available、配置有效性、raw、物理电压和 rail mask 输出。

模型步进不分配堆内存，并有 6 个 Rust 定向测试。当前它仍是独立模型，尚未接入完整 PMSM
plant→质量门→V19→观察器链路，因此 A24 不能标成完成。

## 4. A24.3：MATLAB 独立公式对拍

`run_phase_voltage_fault_scenarios.m` 没有调用 Rust 或 Python 实现，而是独立重建状态优先级、
质量原因和 CommandModel/Measured/Hybrid 选择规则。它读取 Python 生成的 13 场景基准并输出
独立 JSON：

| 指标 | 结果 |
|---|---:|
| 场景数 | 13 |
| 不一致数 | 0 |
| 重复运行 SHA-256 | `1AB40B717531B1C2D10919611AD6073E7AD8EF0C07C5FA54875B0BC289ED351B` |

MATLAB 输出为 `MATLAB_PHASE_VOLTAGE_PASS scenarios=13 mismatches=0`。这证明两个公式实现对
当前场景矩阵的语义一致，不证明板级分压、噪声、采样时刻或真实故障阈值正确。

## 6. Diagnostic 容量门与构建策略

V19 包装使 Diagnostic + `s` 链接达到 131,416 B，超过 128 KiB Flash 344 B。该失败结果
保留为容量证据，不能写成“所有档位都以 `s` 通过”。改用 Diagnostic + `z` 后为
129,952 B，剩余 1,120 B；其余三档继续使用 `s`。

因此 `build.ps1` 和 `custom.cmake` 的省略参数策略调整为：

- Diagnostic 默认 `z`；
- Calibration、Identification、Production 默认 `s`；
- 显式 `-RustOptLevel` 仍覆盖默认值。

这只关闭 S2 容量门。旧 Diagnostic + `s` 的板端 WCET 不能移植到 V19 + `z`；下一次
powered Diagnostic 前必须在 A21 重新测量完整 ISR WCET。
