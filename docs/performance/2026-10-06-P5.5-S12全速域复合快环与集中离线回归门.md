# P5.5-S12 全速域复合快环与集中离线回归门

## 1. 本轮目标

在 12.3 V 主电源物理断开的条件下，一次性关闭后续实机前可以完成的软件工作：

- 把 HFI/极性辨识/HFI-BEMF 融合角真正接入基本 FOC 快环；
- 固定“同一 ADC 电流样本、同一融合角、一次最终电压限幅”的事务边界；
- 补齐正反向接管、单通道丢失、双通道丢失以及弱磁/MTPV 滞环仿真；
- 准备 H3 固定反向真值采集与正反向离线比较工具；
- 保持能力位为 0，禁止普通 arm，不访问串口、不烧录、不产生实机 PWM。

## 2. 复合快环结果

新增正式入口 `foc_rust_realtime_step_sensorless()`。G431 ISR 把同一拍 V19 三相电流
快照传入 Rust；电流只 Clarke 一次，同时供全速域角度链和基本电流环使用。融合可靠后，
同一拍融合角/融合速度成为 Park、逆 Park 和速度环反馈。

电压侧顺序固定为：

```text
第 N 拍实际施加注入与序列回报
  -> Sensorless 链核对 N 拍账本并生成 N+1 注入请求
  -> 基本 dq PI 产生基波 alpha/beta
  -> 基波 + HFI 注入合成
  -> 唯一一次最终电压圆限幅与 duty window
  -> 返回限幅后的实际注入，供 N+1 拍核对
```

任一 ABI、能力、序列、Sensorless 链或主控制失败均先清零输出，再进入现有快速故障
关断。Break、软件过流、deadline、fault epoch 和 CCR commit 门没有被绕过。

旧 `foc_rust_sensorless_compose_voltage()` 只保留给未武装 commissioning：其基波
alpha/beta 固定为 0，只写 inactive CCR preload。它与正式 armed composite 分支互斥，
不会在同一拍重复执行。

## 3. 安全边界

- `foc_sensorless_platform_capabilities()` 仍返回 `0U`；
- Sensorless candidate 仍定义 `FLUXRT_MOTOR_ARM_DISABLED_BUILD`；
- 普通启动入口先执行 emergency stop，再返回 `FOC_STATUS_DISABLED`；
- 当前候选不能打开 Gate、TIM1 MOE 或三相 CCER；
- 正式 composite 路径已通过目标编译，但在当前候选中仍不可达；
- 本轮没有串口、SWD、烧录、上电或电机动作。

因此，本轮关闭的是 S1/S2/S3 软件门，不是 HFI 或全速域实机批准。

## 4. 仿真与反向证据准备

全速域 Rust/MATLAB 合同由 6 个扩展为 9 个场景：

- 正反向 `HFI -> Blend -> BEMF`；
- 正反向 `BEMF -> Blend -> HFI`；
- 过渡区 BEMF 单通道失效；
- 过渡区 HFI 单通道失效；
- 双通道不可用后的有界 fallback。

新增 `transition_mask`，验证真实切换方向而不只是检查来源是否曾出现。修复了相差约
pi 的错误 BEMF 角可能翻转 HFI 极性分支的问题；极性辨识继续拥有分支选择权。

高级 FOC 合同由 9 个扩展为 15 个场景，补齐弱磁进入前/保持/退出以及反向 MTPV
进入/保持/退出。

H3 固定反向候选锁定为 `-582 rpm`、1,200 活动拍和唯一令牌 `P55-H3-REV`。Host
采集不自动重试，并新增哈希绑定的正反向比较 schema/工具；比较产物始终保持
`not-approved`，不会自动提升能力位。

## 6. 下一门

下一次集中实机阶段分两份互斥固件执行，不能合并到 128 KiB G431：

1. 固定反向H3镜像S4已经完成，继续保持主电断开；
2. 只申请一次 12.3 V/2 A、空载、可立即断电的反向动态采集；
3. 将正反向 raw、固件哈希和配置哈希送入离线比较器；
4. 反向真值门通过后，再烧录 arm-disabled Sensorless candidate，测正式 composite
   快环板端 WCET；
5. WCET、N+1 账本和 fail-close 板端证据通过后，才讨论单独的低幅 HFI 参数门；
6. 只有 H3/H4/H5/H6 逐级通过，才允许停机态 capability/config 事务提升能力。

禁止直接把 capability 改成非零，也禁止用本报告宣称已经完成全速域实机闭环。
