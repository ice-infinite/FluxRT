# CM4.3 多转速观察器获取、接管与 BEMF 重同步

## 1. 结论

CM4.3 已把正转无感闭环从单一 582 rpm 扩展到 582、700、800、1000 rpm，并解决了
800 rpm 附近偶发启动失败和 1000 rpm 接管后误失锁。最终候选在当前低压、限流、空载
条件下完成 15 次实机运行：短测 14 次全部通过，另有 700 rpm 连续 30 s 通过；累计
2,041,140 个控制拍，0 deadline miss、0 control error、0 fault。

这证明的是当前板卡、电机和工况下的**正转受限闭环重复性**，不是量产验收。实机速度仍
来自同一个 SMO/PLL，没有编码器或测速仪独立真值，不能据此宣称绝对转速精度、角度精度
或带载性能。

## 2. 暴露出的故障链

CM4.2 在 582 rpm 已可工作，但直接扩展速度时出现两类不同故障：

1. 捕获门逐拍使用原始相位误差，单个 SMO 尖峰会打断本应连续的可靠窗口；
2. 重试时周期性完整清空 SMO、BEMF 与 PLL。电机已建立可观测 BEMF 后仍从零重新学习，
   会反复落回同一个错误捕获盆，800 rpm 表现为偶发超时；
3. 运行保持门错误复用了捕获阶段的 64 ms 方差/相位历史，1000 rpm 已完成接管后仍可能
   被旧历史判为失锁。

因此故障不是简单“电流不够”或“PLL 增益太小”。0.6/0.7 A 启动电流消融失败，而恢复
官方 0.8 A 后只改善机械强拖；真正消除重复失败的是捕获门、运行门和重同步状态的分离。

## 3. 实现修正

### 3.1 获取门与运行门分离

- 获取阶段使用 64 ms 窗口的平均绝对原始相位误差，阈值 0.65 rad；
- 运行阶段只使用即时原始相位误差、有限性、最大转速、BEMF 和运行最低转速，阈值
  0.65 rad；不复用获取方差和历史；
- ABI 升为 V17、配置版本升为 V11，`FocRuntimeConfig` 为 296 B；C/Rust 布局、CRC 和
  Host tripwire 同步。

### 3.2 有 BEMF 时只重同步 PLL

`SmoPllEstimator::prepare_acquisition_at_speed()` 现在先检查已学习 BEMF 向量：

- BEMF 有效时保留 SMO 电流模型和 BEMF，按滤波器相位提前量对齐 PLL；
- PLL 角度对齐到 `theta_emf + phase_advance`，速度和积分器预装为已知强拖电角速度；
- 只清空可靠性统计窗口，不清空电机动态状态；
- BEMF 不可用时才走完整复位，并继续用同拍电流和强拖速度作初值。

新增单元测试 `smo_bemf_resynchronization_preserves_model_and_realigns_pll`，防止今后把
重试退化成完整清零。

### 3.3 最终候选参数

| 项目 | 值 |
|---|---:|
| alignment / ramp / transition | 1000 / 1800 / 50 ms |
| alignment / ramp-hold current | 0.8 / 0.8 A |
| SMO `k_slide` / boundary / alpha | 4.0 V / 0.24 A / 0.015 |
| PLL Kp / Ki / acquisition ratio | 40 / 1000 / 0.5 |
| acquisition / run phase gate | 0.65 / 0.65 rad |
| confirm / acquisition timeout / loss timeout | 20 / 5000 / 200 ms |
| handoff support / PI preload / Iq slew | 0.47 / 0.20 / 4 A/s |
| inverter model stage | 2（只修正观察器电压，不做 PWM 前馈） |
| 冷启动静置 | 8 s |

8 s 静置不是飞行启动实现。当前固件没有对旋转中转子做检测和接管，低摩擦电机在上一轮
停止后仍可能滑行；2 s 预等待会把机械残余转动混入“冷启动”结果，因此正式重复门统一
使用 8 s。

### 4.3 PC、MATLAB 与实机相关性

700 rpm、30 s 同参数对照：

- 仿真/实机进入 closed-loop：3.28 / 3.28 s；
- 相电流峰值：0.800 / 0.855 A；
- Iq 跟踪 RMSE：0.0078 / 0.0108 A；
- Id 跟踪 RMSE：0.0103 / 0.0098 A；
- MATLAB 对齐后的 Iq RMSE 0.0133 A。

状态时序和电流量级一致，足以说明当前仿真可用于接管逻辑和参数候选预筛。硬件没有独立
转速真值，所以 `observer_speed_rpm` 的一致只能证明软件轨迹相关，不能证明观察器真的测准。

## 5. 安全结束状态与后续门

最终烧录的是上述 Diagnostic HEX。实机测试后已执行 `foc_stop`，再通过 ST-LINK 硬件复位，
COM6 回读为 `uninitialized`、closed 0、step/error/miss 0、duty `0/0/0`、逆变器三门
`0/0/0`；Vbus 约 12.275 V。profile revision 5 的 approvals 仍为 0，不能升格为
Production 默认闭环。

CM4.3 正转速度范围门完成后，A27 下一项是反转符号契约和纯软件门，然后才允许低压短时
反转实机；其后依次做热启动/冷启动、飞行启动明确拒绝或实现、带载、独立真值和保护矩阵。
