# FOC 算法组合、应用场景与工程落地指南

本文回答的不是“算法库里有哪些算法”，而是下面四个工程问题：

1. 一套真正能运行的电机控制系统由哪些算法层组成；
2. 哪些算法可以串联，哪些只能二选一，哪些需要按速度区间切换；
3. 机器人关节、云台、无人机电调、风机水泵和研究型控制分别适合什么组合；
4. 在本工程中应把组合逻辑放在哪里，以及需要完成哪些实验才能证明组合可用。

算法的完整索引仍以
`rust/crates/foc-algorithm/算法库总览与对接指南.md` 为准。本文只讨论组合与系统集成。

> 重要边界：算法单元测试通过、PC 仿真通过或目标程序编译通过，都不能证明电机系统已经稳定。最终结论必须来自实际功率板、电机、负载、母线电压、PWM 频率和保护链下的测量。

## 1. 先把“算法组合”理解正确

FOC 不是把算法库中的模块越叠越多越好。一套控制系统通常从每个功能层选择一个主算法，再增加必要的辅助算法：

```text
命令与轨迹
  Ramp / 轨迹规划 / 限速限加速度
          ↓
外环控制
  位置 P/PD/PID/ADRC/SMC……（主算法通常只选一个）
          ↓ speed_ref
  速度 PI/ADRC/SMC……（主算法通常只选一个）
          ↓ torque 或 iq_ref
电流参考优化
  Id=0 / MTPA / 弱磁 / MTPV（按电机类型和工作区调度）
          ↓ id_ref, iq_ref
电流内环
  d/q PI，或经过专门验证的 MPC/其他控制器
          ↓ vd, vq
坐标反变换与调制
  inverse Park → SVPWM / DPWM / SinePWM（三选一）
          ↓ duty_a, duty_b, duty_c
功率级与电机

角度反馈是另一条并行链：

编码器/旋变，或开环启动 → SMO/BEMF/磁链/HF 观测器 → PLL/融合
          ↓ theta_e, omega_e, confidence
          └────────────────────────────→ Park、电流环和外环
```

因此，“组合”有三种不同含义：

| 组合类型 | 例子 | 规则 |
|---|---|---|
| 串联 | 位置环 → 速度环 → 电流环 → SVPWM | 每层输入输出单位和执行周期必须一致 |
| 并联辅助 | PI + 前馈；观测器 + PLL；控制器 + 限幅 | 辅助算法不能破坏主环的限幅和复位逻辑 |
| 分区切换 | 高频注入 ↔ BEMF；MTPA → 弱磁 → MTPV | 必须有滞环、驻留时间、平滑过渡和失败回退 |

以下做法通常是错误的：

- 同一个速度环中同时把 PI、ADRC、SMC 和 MPC 的输出直接相加；
- 同一 PWM 周期同时运行 SVPWM 与 DPWM，然后任意选择某一路占空比；
- 低速 BEMF 不可靠时仍强行把 BEMF 角度交给 Park；
- MTPA、弱磁和 MTPV 同时各自修改 `id_ref/iq_ref`，却没有工作区管理器；
- 在控制器饱和、模式切换或故障恢复时不重置/跟踪积分器状态；
- 仅凭“电机能转”判断组合正确。

## 2. 本工程中算法所处的层次

本工程不是让 C 直接调用 63 个零散函数，而是保持三层边界：

```text
C：RT-Thread、ADC/PWM/编码器、同步采样、故障关断、参数存储
                      ↓ 固定业务级 C ABI
Rust：模式/状态机、算法组合、工作区切换、参数快照
                      ↓
foc-algorithm：纯算法原语
```

主要源码位置：

| 功能 | 当前入口 |
|---|---|
| ST 参考速度环、电流环和电压圆限幅 | `rust/crates/foc-control/src/controller.rs` |
| 电机与控制参数 | `rust/crates/foc-control/src/params.rs` |
| 无感启动序列 | `rust/crates/foc-control/src/startup.rs` |
| BEMF + PLL 适配器 | `rust/crates/foc-control/src/observer.rs` |
| C ABI、状态机与快环入口 | `rust/crates/foc-rt-bridge/src/lib.rs` |
| P/PI/PID、级联、前馈 | `rust/crates/foc-algorithm/src/controller.rs` |
| Clarke/Park 与逆变换 | `rust/crates/foc-algorithm/src/transform.rs` |
| SVPWM、DPWM、SinePWM | `rust/crates/foc-algorithm/src/modulation.rs` |
| MTPA、弱磁、MTPV、V/f | `rust/crates/foc-algorithm/src/optimization.rs` |
| BEMF、磁链、SMO、高频注入、状态估计 | `rust/crates/foc-algorithm/src/observer/` |
| ADRC 和高级控制 | `rust/crates/foc-algorithm/src/adrc.rs`、`advanced_control.rs` |

当前 `foc-control::CurrentLoop` 已经包含：

```text
三相电流 → Clarke → Park → Id/Iq PI → 电压矢量圆限幅
        → inverse Park → SVPWM → 三相 duty
```

而纯算法库中的 `FocBasicState` 是更基础的组合。它包含双 PI 与 SVPWM，但没有 `foc-control::CurrentLoop` 中基于实测母线电压的矢量圆限幅。板级闭环优先扩展 `foc-control`，不要误把 `FocBasicState` 直接等同于完整产品控制器。

## 3. 每个功能层应怎样选择

### 3.1 命令整形与轨迹层

| 算法 | 适用情况 | 不解决什么 | 推荐组合 |
|---|---|---|---|
| `RampState` | 速度、电流、占空比给定需要限制上升/下降速率 | 不限制加加速度，不是完整轨迹规划器 | Ramp → 速度 PI 或电流给定 |
| 位置轨迹规划器 | 机器人关节、云台需要速度/加速度/jerk 限制 | 当前纯算法库没有完整 S 曲线模块 | 上层规划 → 位置环 → 速度环 |
| `AdrcFastTdState` | ADRC 参考平滑和参考导数生成 | 不是通用运动学规划器 | FastTD → ADRC |
| `limit/clamp` | 对任意给定建立硬边界 | 不能替代动态斜坡 | 所有外部命令入口 |

即便已经有闭环，外部目标也不应直接跳变到满电流、满速度或满位置。机器人关节尤其需要在上层限制速度、加速度和 jerk；无人机电调至少需要油门斜坡、启动电流斜坡与堵转超时。

### 3.2 位置环

| 主算法 | 优点 | 代价与风险 | 适合场景 |
|---|---|---|---|
| P | 简单、容易稳定，关节位置环常用 | 静态误差由内层积分和前馈共同处理 | 大多数机器人关节基线 |
| PD | 增加阻尼，抑制机械共振倾向 | 微分对编码器噪声敏感 | 云台、轻载关节、柔性机构 |
| PID | 可消除稳态位置误差 | 多重积分环容易 wind-up 和低频振荡 | 负载偏置明显且前馈不足的系统 |
| ADRC | 可估计总扰动并补偿 | 参数更多，必须验证 ESO 噪声和带宽 | 负载变化大、摩擦不确定的关节 |
| SMC | 鲁棒性强 | 抖振、噪声和执行器带宽要求高 | 研究、强扰动场景 |
| LQR | 可联合多个状态设计性能 | 需要可信模型和离线求解增益 | 状态可测的高性能伺服研究 |

位置环的输出一般是 `speed_ref`，而不是直接输出 PWM。只有在经过严格建模的力矩/阻抗控制中，位置误差才可能直接参与 `iq_ref`，且仍需要电流内环和限流。

### 3.3 速度环

| 主算法 | 默认建议 | 适用情况 |
|---|---|---|
| `SpeedLoopState`/PI | 首选基线 | 绝大多数电调、关节和风机 |
| ADRC | 在 PI 基线稳定后替换 | 负载扰动大且模型不确定 |
| SMC | 实验性替换 | 对鲁棒性要求高、能处理抖振 |
| MRAC/Adaptive | 慢速在线参数适应 | 惯量或增益变化范围大 |
| MPC | 模型和约束明确、WCET 可证明 | 研究型小模型控制 |

同一时刻只应有一个速度主控制器。需要比较算法时，应通过控制模式枚举选择 PI/ADRC/SMC，并在停机状态切换，同时对新控制器执行 `reset()` 和无扰初始化。

### 3.4 电流/转矩环

量产基线仍然是 d/q 双 PI：

```text
ia, ib, ic + theta_e
  → Clarke/Park
  → Id PI、Iq PI
  → 电压矢量限幅
  → inverse Park
  → 调制
```

它需要额外保证：

- 电流采样与 PWM 同步，三相值属于同一控制周期；
- 相序、电流符号和电角度方向一致；
- `ts` 等于真实快环周期；
- `vd/vq` 做联合矢量限幅，而不是只分别限制 d/q；
- 饱和后有 anti-windup；
- 采样窗口无效时不得继续沿用错误电流；
- `iq_ref` 最终受电机、电调、母线和热模型共同限幅。

MPC、H∞、SMC 等可以研究性地替换电流 PI，但不能只更换一个函数名。必须重新定义电机离散模型、输入约束、候选数量、采样延迟和最坏执行时间。当前 `MpcState` 是固定小模型的有限候选搜索，不是现成的通用 FCS-MPC 电机控制器。

### 3.5 电流参考优化层

| 工作区 | 建议算法 | 典型输出 | 前提 |
|---|---|---|---|
| SPM、基速以下 | `id_ref = 0` | `id=0`，`iq=转矩电流` | `Ld≈Lq` 时 MTPA 收益很小 |
| IPM、基速以下 | MTPA | 负 `id` + 对应 `iq` | `Ld/Lq/ψpm` 可信 |
| 接近电压上限 | 弱磁 | 逐渐增加负 `id` | 实时 `Vbus` 与电压矢量可信 |
| 极高速电压受限区 | MTPV | 在电流/电压约束内选择 d/q | IPM 参数可信，必须限制搜索 WCET |

正确调度通常是：

```text
转矩命令/电流幅值
      ↓
低速：Id=0 或 MTPA
      ↓ 当电压利用率超过进入阈值并持续一定时间
弱磁：在基础 Id 上叠加受限负 Id
      ↓ 当速度更高、弱磁已到边界并持续一定时间
MTPV：接管 d/q 分配
```

必须设置退出阈值低于进入阈值，形成滞环。若 MTPV 返回 `valid == 0`，应回退到受限弱磁或降转矩，而不是使用上一次结果。

### 3.6 调制层

| 调制 | 优点 | 缺点 | 推荐场景 |
|---|---|---|---|
| SVPWM | 母线利用率高、通用、资料多 | 开关损耗高于部分 DPWM 工况 | 默认 FOC 基线 |
| DPWM | 可减少部分桥臂切换和开关损耗 | 谐波、噪声、采样窗口与共模特性变化 | 高功率/高速且硬件已重新验证 |
| SinePWM | 最容易理解和检查 | 母线利用率低 | 教学、低性能开环验证 |
| 六步换相 | 算法与计算简单，高速容易实现 | 转矩脉动和噪声更高，不是正弦 FOC | BLDC 电调或极简高速方案 |

SVPWM、DPWM、SinePWM 是末级替代关系，不应在同一周期串联。当前 `FocBasicState` 内部固定调用 SVPWM；若需要 DPWM，应在组合控制器中复用其 `voltage_alpha_beta`，再明确选择 `dpwm_update()`，而不是先产生 SVPWM 占空比再“转换”为 DPWM。

### 3.7 角度与速度估计层

| 反馈/观测方式 | 零速 | 低速 | 中高速 | 主要用途 |
|---|---:|---:|---:|---|
| 编码器/磁编码器/旋变 | 好 | 好 | 好 | 机器人关节、云台、可靠伺服 |
| Hall | 可换相 | 分辨率有限 | 可用 | 成本敏感的有感电调 |
| BEMF/SMO + PLL | 差 | 较差 | 好 | 无人机、风机、中高速无感 |
| 高频注入 | 好，取决于凸极性 | 好 | 不宜长期高占比 | IPMSM 零低速无感 |
| 脉冲注入 | 初始位置辨识 | 非连续运行主观测器 | 不适合 | 启动前辨识转子极性/位置 |
| 磁链观测器 | 易受积分漂移影响 | 需融合/补偿 | 可用 | 研究或全速域融合 |
| EKF/UKF | 取决于可观测性 | 模型正确时可用 | 可用 | 模型驱动研究与多状态估计 |

滤波器或 Kalman 估计器是观测链的辅助，不是角度源本身。把噪声滤平不等于角度正确；控制状态机还需要 `confidence/valid`、角度误差、速度方向和锁定持续时间等可信度判据。

## 4. 典型算法组合方案

### 4.1 组合 A：有感电流/转矩控制基线

适合：首次闭环上板、力矩模式、机器人关节内环、后续所有高级组合的基准。

```text
Iq_ref + Id_ref(通常为 0)
  → Ramp/限流
  → Clarke/Park
  → Id/Iq PI
  → 电压矢量圆限幅
  → inverse Park
  → SVPWM

编码器机械角 × 极对数 + 电角度偏置 → theta_e
```

必需参数：极对数、电角度零偏、三相电流比例/偏置、相序、`Kp/Ki`、快环 `ts`、母线电压比例、最大相电流和最大电压利用率。

通过标准至少包括：

- 锁轴小电流下 `Id/Iq` 符号正确；
- `Iq_ref` 正负与期望转矩方向一致；
- 阶跃和正弦给定下电流带宽、超调和稳态误差达到项目指标；
- 电压饱和时积分器不继续发散，退出饱和后能恢复；
- Break/过流触发到栅极关闭的时间实测达标；
- 任何无效反馈、NaN、母线欠压或角度失效都输出安全关断，而不是沿用旧 duty。

### 4.2 组合 B：有感速度 FOC

适合：实验台、轮毂、风机、泵、带编码器电调。

```text
speed_target
  → Ramp
  → 速度 PI
  → iq_ref 限幅
  → 组合 A 电流环
```

调试顺序：先锁定速度环，只验证电流环；再把速度 PI 的积分关闭，从很小 `Kp` 开始；确认方向后逐步加 `Kp` 和 `Ki`。速度环输出限幅必须小于硬件允许峰值电流。

不要用速度 PI 掩盖错误的电流环。如果电流波形、电角度或相序不正确，速度环可能仍然让空载电机“勉强转起来”，但带载会失稳或过流。

### 4.3 组合 C：机器人关节位置/速度/电流三环

适合：机器人旋转关节、执行器、减速器伺服。

推荐基线：

```text
位置轨迹（位置/速度/加速度）
  → 位置 P 或 PD
  → speed_ref
  → 速度 PI
  → iq_feedback
  + 速度/加速度/重力/摩擦前馈
  → iq_ref 限幅
  → 有感 d/q 电流 PI
  → SVPWM

绝对编码器/双编码器 → 位置、速度、电角度
```

适合叠加的辅助算法：

- `FeedForwardState`：根据目标速度、加速度和已辨识偏置给出前馈；
- 低通/微分滤波：处理编码器速度，但要计算相位延迟；
- ADRC：可先替换速度环，再考虑位置环；
- MTPA：仅 IPMSM 且参数可信时用于提高电流利用率；
- 扰动观测与摩擦补偿：作为受限前馈，不能绕开电流保护。

不推荐：无编码器 BEMF 作为零速关节的主要角度源；在位置、速度、电流三层都放强积分；在线学习算法直接输出未限幅 `iq_ref`。

机器人关节除电机闭环外还必须验证：减速器回差、弹性、碰撞、外力、抱闸、编码器断线、零位校准、机械限位、热降额和通信失联。电机 FOC 通过不等于关节成品通过。

### 4.4 组合 D：云台/低速平滑伺服

适合：相机云台、低速直驱、低噪声平台。

```text
平滑角度轨迹
  → 位置 PD/PID（微分必须滤波）
  → 速度 PI
  → 电流 PI
  → SVPWM
  ← 高分辨率编码器
```

重点不是最大转速，而是低速齿槽、速度纹波、电流噪声、声噪和静止抖动。优先使用编码器和 SVPWM。DPWM、六步换相和长期高频注入可能增加声噪或转矩纹波，除非实测证明满足要求。

### 4.5 组合 E：无人机 PMSM/BLDC FOC 电调

适合：螺旋桨高速电机、需要效率与平顺性的无人机电调。

推荐无感主链：

```text
油门/转速/转矩命令
  → 输入合法性 + Ramp + 电流限制
  → 启动：转子对齐或初始位置检测
  → 开环角度/电流爬升 RevUp
  → SMO+PLL 或 BEMF+PLL
  → 角度误差平滑融合
  → Id/Iq PI
  → SVPWM
  → 高负载条件下可评估 DPWM
```

高速扩展：

```text
SPM：Id=0 → 弱磁（若允许）
IPM：MTPA → 弱磁 → MTPV
```

无人机的关键不是“最高空载转速”，而是：带桨启动成功率、快速油门变化、失步检测、堵转关断、母线再生过压、MOSFET 温升、电机温升、EMI、同步整流和故障后不二次误启动。

建议先无桨、低压、限流完成全部方向和保护验证，再使用测功机/安全笼带载。装桨测试必须建立独立的人身安全流程。

### 4.6 组合 F：风机/水泵/压缩机无感 FOC

适合：单向启动、负载规律、成本敏感系统。

```text
频率/速度命令
  → V/f 或强拖开环启动
  → BEMF/SMO 可信度建立
  → 角度融合切换
  → 速度 PI
  → 电流 PI
  → SVPWM
```

如果动态和低速效率要求不高，可使用 `VfState → SinePWM/SVPWM` 作为简化方案；它不是严格的闭环 FOC。若要求抗负载变化、低速转矩或高效率，应切入观测器闭环。

必须处理反转/顺风启动、液泵带压启动、启动超时、堵转、干转、过温和掉电再启。BEMF 观测器只在信号幅值足够后接管。

### 4.7 组合 G：IPMSM 零低速到高速的全速域无感

适合：具有明显凸极性的 IPMSM，且不希望使用位置传感器。

```text
静止：PulseInjection 初始位置/极性判断
  → 低速：RotatingHF/HFInjection
  → 过渡区：HfBemfState 按角度差和速度融合
  → 中高速：SMO+PLL 或 BEMF+PLL
  → 高速：MTPA → 弱磁 → MTPV
  → 电流 PI → SVPWM/验证后的 DPWM
```

这是一套复杂系统，不是调用 `HfBemfState::update()` 就自动完成。项目还要实现：注入电压叠加、注入电流解调、基波/载波分离、凸极性判定、角度 `π` 模糊消除、切换滞环、可信度和失败回退。SPM 若凸极性不足，高频注入可能无法给出可靠角度。

### 4.8 组合 H：BLDC 六步无感

适合：成本优先、转矩纹波和噪声可接受的高速风机/电调。

```text
开环六步启动
  → 浮空相 BEMF
  → BemfZeroCrossState
  → 换相提前角/延迟补偿
  → six_step_from_sector
```

它和正弦 FOC 是两套不同主链。六步模式下不要同时调用 Park、d/q PI 和 SVPWM。可以在产品中同时支持“六步模式”和“FOC 模式”，但必须停机切换并分别验证采样、换相和保护时序。

### 4.9 组合 I：高级控制算法试验平台

适合：算法研究、论文复现、已具有稳定 PI 基线的系统。

推荐替换顺序：

1. 保留成熟电流 PI，仅替换最外层位置或速度控制器；
2. 使用同一工况、同一限幅和同一日志对比 PI 与候选算法；
3. 证明稳定性、参数敏感度、故障恢复和 WCET 后，再考虑更内层替换；
4. 任意学习算法都只在安全包络内提供补偿量或候选参数。

可行组合例子：

| 组合 | 合理用途 | 主要风险 |
|---|---|---|
| FastTD → ADRC → 电流 PI | 速度/位置外环抗扰 | ESO 噪声、带宽耦合 |
| LQR → 电流 PI | 多状态伺服外环 | 模型误差、状态可测性 |
| MRAC/Adaptive → 电流 PI | 慢变化负载/惯量 | 参数漂移、激励不足 |
| Fuzzy 调整 PI 参数 | 低频增益调度 | 规则边界不连续 |
| NN 前馈 + PI | 补偿可重复非线性 | 训练域外行为 |
| GA 离线搜索参数 → 固化参数 | 仿真/台架整定 | 不能放入快环在线随机搜索 |
| RL 高层动作选择 → 安全限幅 → PI | 低频策略研究 | 探索行为不可直接上真实功率级 |

## 5. 组合选择矩阵

| 场景 | 角度源 | 外环 | 电流参考 | 电流环 | 调制 | 首选程度 |
|---|---|---|---|---|---|---|
| 首次上板 | 编码器/已知强制角 | 无 | `Id=0`、小 `Iq` | PI | SVPWM | 必做基线 |
| 机器人关节 | 绝对编码器/旋变 | 位置 P/PD + 速度 PI | `Id=0` 或 IPM MTPA | PI | SVPWM | 首选 |
| 云台 | 高分辨率编码器 | 位置 PD/PID + 速度 PI | `Id=0` | PI | SVPWM | 首选 |
| 无人机 FOC ESC | RevUp → SMO/BEMF+PLL | 油门/速度 PI | SPM `Id=0`；IPM MTPA/FW | PI | SVPWM，DPWM 待验证 | 首选无感链 |
| 风机水泵 | V/f/RevUp → BEMF/SMO | 速度 PI | `Id=0` | PI | SVPWM | 首选 |
| 极简 BLDC | 过零检测 | 油门/速度调节 | 不使用 d/q | 六步电流/占空控制 | SixStep | 成本优先 |
| 全速域无感 IPM | Pulse/HF → BEMF/SMO | 速度 PI | MTPA → FW → MTPV | PI | SVPWM/DPWM | 高复杂度 |
| 高级控制研究 | 优先编码器 | ADRC/LQR/SMC/MPC 等 | 仍受安全调度 | 先保留 PI | SVPWM | 基线后进行 |

## 6. 工作区和观测器切换状态机

建议把复杂组合实现为明确状态机，而不是在快环中散落大量 `if`：

```text
DISABLED
  → SELF_TEST       ADC 偏置、母线、驱动器、传感器自检
  → ALIGN/INITIAL   编码器零位或注入辨识/转子对齐
  → OPEN_LOOP       限流 RevUp
  → OBSERVER_BLEND  强制角与观测角平滑融合
  → CLOSED_LOOP     正常 Id/Iq 闭环
      ├→ FIELD_WEAKENING
      └→ MTPV
  → STOPPING

任一状态 ──硬件/软件故障──→ FAULT_LATCHED → 人工或受控清故障
```

每个切换条件至少包含：

| 条件 | 说明 |
|---|---|
| 进入阈值 | 如观测器最小可靠速度、电压利用率、角度误差 |
| 退出阈值 | 与进入阈值分开，形成滞环 |
| 驻留时间 | 条件必须连续满足若干周期，防止来回抖动 |
| 可信度 | 信号幅值、残差、PLL 锁定和方向一致性 |
| 最大过渡斜率 | 角度、速度、`id/iq` 和电压不能跳变 |
| 超时 | 未按时建立观测器或启动失败时关断 |
| 回退 | 观测器失锁后是降转矩、回开环还是直接停机 |
| 复位项 | PI 积分器、PLL、滤波器和旧 duty 如何清零 |

角度融合不能直接线性相加两个 `0..2π` 数值，必须先计算 `[-π, π]` 的最短角差，再逐步融合。本库 `HfBemfState` 已按最短角差融合，但项目仍需提供可信度、滞环、驻留时间和回退状态机。

## 7. 多速率调度

不同控制层不应盲目全部采用同一频率。当前 G431 实机配置为 12 kHz；保留确定性分频接口供后续更高 PWM 频率或更慢 MCU 使用：

| 层 | 示例频率 | 说明 |
|---|---:|---|
| ADC 同步采样、电流环、调制 | 12 kHz | 每个 PWM 周期一次；最高优先级 |
| 观测器 | 12 kHz 或其确定性分频 | 当前 SMO 为 12 kHz；与电压/电流快照严格对齐 |
| 速度环 | 1 kHz | 当前 ST 参考参数采用 1 kHz |
| 位置环 | 0.5～1 kHz | 由机械带宽、编码器与通信决定 |
| 温度、功率、降额 | 10～100 Hz | 慢保护；硬件过流不能依赖它 |
| 参数保存、日志、通信 | 低优先级线程 | 不得阻塞快环 |

所有 `Param.ts` 必须与实际调用周期一致。当前电流 PI 的 `ts=1/12000 s`，观测器分频时则使用 `divider/12000 s`；偶尔丢周期但仍使用固定 `ts` 会改变闭环增益。

快环的时间预算应写成：

```text
T_ISR总 = ADC读取 + 单位换算 + 保护检查 + 观测器 + 控制器 + 调制 + CCR写入
T_ISR总最坏值 + 中断抖动 < 可用PWM计算窗口
```

平均执行时间不等于 WCET。需要用 DWT 周期计数器在不同扇区、饱和、模式切换和最坏候选数下测量最大值。

## 8. 参数依赖：换电机时哪些组合会失效

| 参数 | 影响模块 | 错误后表现 |
|---|---|---|
| 极对数 | 电角度、转速换算、RevUp | 角度频率错误、失步 |
| `Rs` | BEMF/SMO/磁链、PI 整定 | 低速观测误差、发热时漂移 |
| `Ld/Lq` | 电流 PI、MTPA、MTPV、HF 凸极性 | 转矩分配错误、观测失败 |
| 永磁磁链 `ψpm/Ke` | BEMF、转矩估算、MTPA/MTPV | 速度/转矩估计错误 |
| 电流比例与偏置 | 所有电流闭环与保护 | 转矩纹波、过流或误保护 |
| 母线电压比例 | SVPWM、限幅、BEMF、弱磁 | 占空比和观测器模型错误 |
| 转动惯量/摩擦 | 速度/位置外环、仿真 | 外环超调或响应慢 |
| 编码器零偏与方向 | 有感 FOC | 电流增大但不出转矩，甚至反向 |
| PWM/控制频率 | 所有含 `ts` 的状态算法 | 闭环极点和滤波截止频率改变 |

所以换电机后不能只修改极对数。至少重新确认电流采样、相序、电角度偏置、电机参数、所有 `ts`、电流环 PI、速度环 PI、启动序列、观测器、弱磁边界、最大电流/速度和热保护。

## 9. 每套组合的验证方法

### 9.1 先验证公共底座

1. 栅极默认关闭，复位、断言和 panic 都能关断；
2. PWM 频率、中心对齐、互补输出、死区和极性实测正确；
3. ADC 采样点位于有效窗口，偏置、增益、三相重构和母线换算正确；
4. Break/COMP/驱动器故障是硬件优先关断，软件仅负责锁存与报告；
5. 编码器角度、机械方向、电角度、相序和电流符号一致；
6. 固定小电压矢量和小电流闭环均不会产生异常发热或过流。

### 9.2 再按层逐步闭环

| 阶段 | 只启用 | 测量 |
|---|---|---|
| 1 | 开环小电压/小电流 | PWM、相序、转向、采样同步 |
| 2 | 有感电流环 | d/q 阶跃、带宽、超调、稳态误差、饱和恢复 |
| 3 | 速度环 | 加减速、加载/卸载、堵转、反转、速度纹波 |
| 4 | 位置环 | 跟踪、超调、稳态误差、回差、柔性振动、碰撞 |
| 5 | 观测器并行运行但不接管 | 观测角与编码器真值的误差分布 |
| 6 | 观测器受控切换 | 启动成功率、切换冲击、失锁回退 |
| 7 | MTPA/FW/MTPV/DPWM | 效率、电流、温升、电压裕量、声噪和 WCET |

### 9.3 对比高级算法必须保持公平

比较 PI、ADRC、SMC 或 MPC 时，应保持：

- 同一电机、负载、母线、温度范围和采样频率；
- 同一电流/电压/速度/位置限幅；
- 同一轨迹和扰动工况；
- 同一故障与复位条件；
- 同一评价指标：上升时间、超调、稳态误差、RMS 电流、效率、温升、噪声、WCET 和失稳次数。

若高级算法只在没有限幅或没有噪声的仿真中更好，不能据此替换实机基线。

## 10. 在当前工程中的推荐实施顺序

结合本工程现状，推荐按以下顺序增加组合，而不是一次性启用全部算法：

1. 完成编码器或可信强制角下的 `CurrentLoop → SVPWM`，验证相序、电流方向和所有保护；
2. 完成 `Ramp → SpeedLoop → CurrentLoop` 有感基线；
3. 若目标是机器人关节，再增加轨迹层、位置 P/PD、前馈和关节级安全；
4. 若目标是无人机/风机，再让 BEMF/SMO 与编码器或外部真值并行比对；
5. 实现 `RevUpSequencer → observer blend → closed-loop` 的明确状态机；
6. 在基线稳定后，按电机类型增加 MTPA、弱磁和 MTPV 工作区管理器；
7. 最后评估 DPWM、ADRC、SMC、MPC、NN/RL 等高级模块。

当前 `RevUpSequencer` 中的 1 s 对齐、1.164 s 爬升、582 rpm、0.8 A 和 25 ms 过渡来自当前 ST 参考项目，只能作为 `GBM2804H-100T` 的起始参考。换电机或换负载后必须重新验证，不能作为通用常量。

## 11. 推荐的 Rust 组合接口形态

不建议给每个算法增加一个 C ABI。更稳定的方式是在 Rust 中组成业务控制器，只向 C 暴露少量模式和快环入口：

```rust
enum ControlMode {
    Disabled,
    SensoredCurrent,
    SensoredSpeed,
    SensoredPosition,
    SensorlessSpeed,
}

enum AngleSource {
    Forced,
    Encoder,
    HfInjection,
    BemfPll,
    Blended,
}

enum OperatingRegion {
    BaseSpeed,
    FieldWeakening,
    Mtpv,
}
```

一个周期的内部顺序建议固定为：

```text
读取同周期反馈快照
  → 硬件/软件保护检查
  → 更新角度源与可信度
  → 按分频更新位置/速度外环
  → 生成并限幅 id/iq 基础命令
  → 工作区管理器执行 MTPA/FW/MTPV
  → 电流环和电压圆限幅
  → 选择一种调制
  → 检查 duty 有限且在安全范围
  → 返回 C，由 C 最终写寄存器
```

参数应分为三类，并只在 `Disabled` 状态原子应用：

- 板级标定：ADC 比例/偏置、母线比例、PWM、死区、保护极性；
- 电机参数：极对数、`Rs/Ld/Lq/ψpm`、额定/峰值电流、速度和温度；
- 控制参数：各环增益、频率、斜坡、观测器阈值、切换滞环和超时。

## 13. 最终选型建议

若没有特殊理由，优先采用以下三条基线：

- 通用有感：`Ramp → PI 外环 → d/q PI → 电压圆限幅 → SVPWM → 编码器`；
- 机器人关节：`轨迹规划 → 位置 P/PD + 前馈 → 速度 PI → d/q PI → SVPWM → 绝对编码器`；
- 无人机/风机无感：`限流 RevUp → SMO/BEMF+PLL 平滑接管 → 速度/转矩命令 → d/q PI → SVPWM`。

MTPA、弱磁、MTPV、DPWM 和高级控制器都应建立在上述基线已经稳定、可测、可回退的前提上。算法库提供的是构件；状态机、同步采样、参数可信度、保护、切换和实机验证共同决定它能否成为完整产品。
